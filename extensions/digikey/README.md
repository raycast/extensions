# DigiKey

This is a simple extension for [DigiKey](https://www.digikey.com/) - _a globally authorized distributor of electronic components and automation products_.

This extension allows you to search a product and get its details.

## 🚀 Getting Started

1. **Install extension**: Click the `Install Extension` button in the top right of [this page](https://www.raycast.com/xmok/digikey) OR `install` via Raycast Store

2. **Get required credentials**: `Sign up`, `apply` for API access then plug in the following:

    a. Client ID
    
    b. Client Secret
    
    c. Account ID

    d. (If using Sandbox) Is Sandbox
