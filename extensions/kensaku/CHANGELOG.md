# Kensaku Changelog

## [Initial Version] - 2026-11-25

- Added **Search Files** command with live query-language filtering, document/code/OCR filters, cursor pagination, and a toggleable `read_snippet` + metadata preview pane.
- Added **Search Code Symbols** command powered by Kensaku tree-sitter symbol definitions (`find_symbol`) across Rust, TypeScript, JavaScript, and Python files.
- Added **Index Status** command to inspect index health, watched folders, embedding model details, and manage the local `kensaku-cli serve` background server.
