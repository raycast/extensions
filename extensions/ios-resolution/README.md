# iOS Resolution

Display properties of every iPhone, MacBook, iPad, iPod touch and Apple Watch Apple ever made

Some announced devices have published physical resolutions but no verified logical resolution or scale factor yet. These fields show **Not yet verified** and are `null` in copied JSON. Copy actions are available only for verified values.

MacBook logical resolutions depend on the selected macOS display mode. Physical resolution is the panel's native pixel count; dividing it by the Retina scale factor does not necessarily give the default desktop size.

See [data sources and verification notes](DATA_SOURCES.md) for the 2025–2026 update.
