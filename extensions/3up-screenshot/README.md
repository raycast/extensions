# 3up-screenshot

Capture a screen area and instantly extract text using macOS Vision OCR. The recognized text is automatically copied to your clipboard.

## Features
- **Fast and Accurate**: Powered by the native macOS Vision Framework.
- **Interactive**: Select precisely the area you want to capture.
- **Privacy Focused**: No data leaves your machine; everything is processed locally.

## Getting Started
1. Run the **3up-screenshot** command.
2. Select a portion of the screen containing text.
3. The text will be copied to your clipboard.

## Note on Permissions
This extension requires **Screen Recording** permission to capture screenshots for OCR. If the command fails, please ensure Raycast is allowed to record the screen in **System Settings > Privacy & Security > Screen Recording**.
