# Kavel AI Image Generator

Generate AI images from a prompt without leaving Raycast. Type a prompt, pick an aspect ratio, and
get an image you can copy or open.

Works with **no API key**: it uses the free tier of [Kavel](https://www.kavel.ai/?utm_source=raycast&utm_medium=extension)
(1K images with a watermark, small daily allowance). Add an API key from
[kavel.ai/settings/apikeys](https://www.kavel.ai/settings/apikeys?utm_source=raycast&utm_medium=extension)
in the extension preferences to run on your account.
