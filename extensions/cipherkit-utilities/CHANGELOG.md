# CipherKit Utilities Changelog

## [Initial Version] - 2026-06-15

### Added

- JWT Decoder command to decode and inspect JSON Web Tokens locally
- Expiration status indicator (🟢 Valid / 🔴 Expired / ⚪ No Expiry)
- Human-readable timestamp conversion for `exp`, `iat`, and `nbf` claims
- Keyboard shortcuts for quick actions (⌘⇧P copy payload, ⌘⇧H copy header, ⌘N new token)
- 100% local processing - your data never leaves your device
