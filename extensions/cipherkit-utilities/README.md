# CipherKit Utilities

Developer tools that run 100% locally in your Raycast. Your sensitive data never leaves your device.

## Features

### 🔐 Decode JWT

Decode and inspect JSON Web Tokens with:

- **Header & Payload Parsing** — Instantly view the decoded JSON structure
- **Expiration Tracking** — See if your token is 🟢 Valid or 🔴 Expired
- **Timestamp Conversion** — `exp`, `iat`, `nbf` claims shown as human-readable dates
- **Quick Copy** — Keyboard shortcuts for instant clipboard access

## Privacy First

All processing happens locally in memory. No network requests. No telemetry. No data storage.

This extension is part of [CipherKit](https://cipherkit.app) — 85+ free developer tools that run entirely client-side.

## Keyboard Shortcuts

| Action | Shortcut |
|--------|----------|
| Copy Payload | `⌘⇧P` |
| Copy Header | `⌘⇧H` |
| Decode Another | `⌘N` |

## Installation

Install from the [Raycast Store](https://raycast.com/karthickajan/cipherkit-utilities) or clone and build locally.
