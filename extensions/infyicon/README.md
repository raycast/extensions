# Infyicon Free Icons

Search **161,000+ free hand-drawn vector icons** from [infyicon.com](https://infyicon.com) without leaving Raycast, then copy, paste or download them in one keystroke. Every icon comes in four matching styles — outline, fill, color-outline and color-fill — so a whole project can share one consistent look.

No account and no API key: the extension talks to the public Infyicon search and image endpoints.

## Command

**Search Icons** — a grid of results with a style dropdown and endless scrolling.

| Action | Shortcut |
| --- | --- |
| Copy SVG (default primary action) | `⌘ C` / `Ctrl C` |
| Paste SVG into the frontmost app | `⌘ ⇧ V` |
| Copy JSX (React-ready attributes) | `⌘ ⇧ J` |
| Copy PNG URL (64–512 px, see preferences) | `⌘ ⇧ P` |
| Download SVG / PNG to `~/Downloads` | `⌘ ⇧ D` |
| Open icon page | `⌘ O` |
| Copy icon id · Find related icons | `⌘ ⇧ I` · `⌘ R` |

Preferences let you pick the primary action, the default style filter and the PNG size.

## AI Extension

Mention `@infyicon` in Raycast AI to search icons conversationally:

- "@infyicon find a shopping cart icon"
- "@infyicon give me the SVG for a rocket icon in fill style"

Tools: `search-icons` (keyword search with style filter) and `get-icon-svg` (ready-to-embed markup for up to 20 icon ids).
