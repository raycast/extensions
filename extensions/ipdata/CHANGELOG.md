# ipdata IP Lookup Changelog

## [Initial Version] - 2026-11-13

- **Look Up IP**: look up an IPv4 or IPv6 address or a hostname, with the place, a street map and the location details, plus tabs for Raw JSON, Analysis, Scores, Flags, Blocklists, Connection, Operator and Owner.
- **Look Up Selected IP** and **Look Up Clipboard IP**: city, country and operator in a HUD for the IP address in the selection or the clipboard.
- **My IP**: this Mac's public IPv4 and IPv6 addresses with their details.
- **IP Menu Bar**: country flag and public IP address in the menu bar, refreshed every 10 minutes. The last part of the address is hidden by default; the label can also show the full address, "My IP" or nothing.
- Works on ipdata's free tier without a key; an optional API key, on the global or EU endpoint, adds company, carrier and threat data.
