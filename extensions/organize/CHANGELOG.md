# Organize Changelog

## [Initial Release] - {PR_MERGE_DATE}

Initial release of the Organize extension for Raycast.

### Features

- **Three organization commands** for Downloads, Desktop, and Temp folders
- **Smart duplicate detection** using MD5 hashing with space savings reporting
- **Large file management** for files over 1GB
- **Intelligent file categorization** into 20+ categories
- **Date-based organization** for Temp folder (creates folders like "11-5th November 2025")
- **Archive old files** (60 days for Downloads, 30 days for Desktop)
- **Folder consolidation** to keep directories tidy
- **Full undo support** for all file operations
- **Detailed result summaries** with operation statistics
- **Safe deletion** using macOS Trash instead of permanent deletion
- **Automatic conflict resolution** for duplicate filenames
