# Easy Open Changelog

## [Initial Version] - 2026-05-04

- Added graphical management for multiple root folders.
- Added support for multiple application openers with manual ordering.
- Added support for command-based openers with Terminal, iTerm, and Ghostty.
- Added optional one-shot command execution with terminal auto-close behavior.
- Added recent-directory prioritization in the search results.
- Added command opener editing and clearer root folder status feedback.
