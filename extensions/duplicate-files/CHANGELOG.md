# Duplicate Files Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Added **Quick Duplicate**, a no-view command that copies the Finder selection straight away, with an optional argument for the number of copies
- Added **Duplicate with Custom Names**, a form that names copies from a template with a live preview
- Naming schemes for Quick Duplicate: Finder style, space, parentheses, dash, and underscore
- Template variables for names, extensions, counters, dates, times, random strings, and UUIDs, with case modifiers and custom date formats
- Options for the starting counter value, zero padding, destination folder, and what to do when a name already exists
- Folders are duplicated recursively
