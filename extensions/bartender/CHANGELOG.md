# Bartender Changelog

## [Bartender 7 support] - 2026-10-06

- Added support for Bartender 7, including its new menu bar item IDs and click commands.
- Fixed "Open Search Overlay" and "Search Menu Bar Apps" failing when "Bartender 5" isn't installed.
- Show a clear error when Bartender isn't installed.
- Menu bar item names no longer include ".app" when Finder shows all filename extensions.
- Note: menu bar item IDs changed in Bartender 7, so pinned items, saved shortcuts and Quick Links created with older versions need to be recreated.

## [Bug fix] - 2025-03-27

- Added support for Setapp and standalone versions of Bartender.

## [Initial Version] - 2025-03-25
