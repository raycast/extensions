# Changelog

## [List, send, and AI tools] - 2026-08-27

- Rank teammates in List Bots by how often you ask them, without mixing Bots, Groups, and Hidden
- Copy a bot ID with ⌘⇧C, refresh with ⌘R, and show a HUD after a send
- Unique name or title fragments resolve to one bot. Ambiguous names stay unsent
- Raycast AI can list teammates, then send a task once the name is unique

## [Initial Version] - 2026-08-27

- List Grok Bot teammates and send them a task
- Ask a named bot, including from selected text
- Open the Grok Bot desktop app
- Raycast AI tool to send a task to a named bot
