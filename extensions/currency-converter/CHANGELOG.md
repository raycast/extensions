# Currency Converter Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Live currency conversion across 44+ currencies via freecurrencyapi.com
- **Convert Currency** command with reactive search-bar amount input and favorites
- **Quick Convert** command with arguments for one-shot conversions
- **Latest Rates** command to browse exchange rates by base currency
- Local rate cache (configurable, default 30 min) to minimize API calls
- Friendly onboarding when no API key is configured
