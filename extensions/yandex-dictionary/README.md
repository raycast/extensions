# Yandex Dictionary for Raycast

Translate words quickly between multiple languages using the **Yandex.Dictionary API**.
This Raycast extension allows you to:

- Translate words from one language to another.
- View detailed translations with parts of speech, synonyms, and meanings.
- Keep a history of your translations and reuse past queries instantly.

## Features

- The service supports a total of 17 language pairs.
- Shows detailed translation results with phonetics, synonyms, and meanings.
- Translation history with one-click search of previous queries.

## Requirements

- A **Yandex.Dictionary API key**. You can get it here: [Get API Key](https://yandex.com/dev/dictionary/keys/get/?service=dict).
