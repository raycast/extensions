# Contact Caller Changelog

## [1.0.0] - Initial Release

### Features
- Search macOS contacts by name or phone number
- Multiple communication actions:
  - Phone Call
  - FaceTime Video
  - FaceTime Audio
  - Send Message (iMessage/SMS)
  - Copy Number
- Configurable default action
- Action mode: direct execution or choose from menu
- Phone type labels with color coding (Mobile, Home, Work)
- Frecency-based sorting (frequently used contacts appear first)
