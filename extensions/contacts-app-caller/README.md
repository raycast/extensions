# Contact Caller

Quickly search your macOS contacts and call, message, FaceTime, or copy their phone numbers by pressing `Enter`.

## Features

- **Fast Contact Search** - Search contacts by name or phone number
- **Multiple Actions** - Call, Message, FaceTime Video, FaceTime Audio, or Copy number
- **Frecency Sorting** - Frequently used contacts appear at the top

## Setup

### Required Permissions

This extension requires access to your Contacts. When you first run the extension, macOS will prompt you to grant
Raycast access to Contacts.

If the prompt doesn't appear or you denied access:

1. Open **System Settings** > **Privacy & Security** > **Contacts**
2. Enable the toggle for **Raycast**

## Preferences

| Preference              | Description                                                                   |
|-------------------------|-------------------------------------------------------------------------------|
| **Default Action**      | Choose the primary action when pressing Enter (Call, Message, FaceTime, etc.) |
| **Action Mode**         | Execute default action directly or show a menu to choose                      |
| **Show Phone Labels**   | Display phone type tags (Mobile, Home, Work)                                  |

## Keyboard Shortcuts

| Shortcut  | Action                 |
|-----------|------------------------|
| `Enter`   | Execute default action |
| `Cmd + C` | Copy Number            |
