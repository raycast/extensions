## Setting Up Your Vault Path

Zhigeng Capture needs to know where your Obsidian vault lives. Enter the **absolute path** to your vault's root directory.

**Examples:**
- `/Users/yourname/Documents/MyNotes`
- `~/Obsidian/Personal`

The path must point to an existing Obsidian vault directory. The extension will create a `_raw/` folder inside it where all captures are saved.

### Finding Your Vault Path

1. Open Obsidian.
2. Click the vault switcher (bottom-left) and select **Manage Vaults**.
3. The path is shown next to each vault name.
