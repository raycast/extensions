# AudioCast Control Changelog

## [Initial Version] - 2026-07-17

- Device discovery via mDNS with HTTPS mTLS authentication
- Overview screen with playback state, track info, cover art, and Wi‑Fi status
- Playback controls: play/pause, stop, volume, mute, reboot
- Radio station manager with ICY metadata and iTunes cover art
- Spotify track info via UPnP
