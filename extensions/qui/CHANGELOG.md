# Qui Changelog

## [Initial Version] - {PR_MERGE_DATE}

- List every listening TCP port with its process, project, git branch, uptime and memory
- Detect the runtime and framework behind each server (Node.js, Bun, Python, Next.js, Astro, Vite, Express and more)
- Show the chain of processes that started each server
- Terminate (`⌃X`) or force kill (`⌃⇧X`) a process
- Refresh automatically every few seconds while open
- Works on macOS and Windows
