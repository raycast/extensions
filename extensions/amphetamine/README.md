# Amphetamine

Keep your Mac awake from the keyboard with [Amphetamine](https://apps.apple.com/app/amphetamine/id937984704). Start a session for an hour, until a set time or indefinitely, without opening the menu bar.

## Commands

- **Start New Session**: Starts a session with your default settings.
- **Quick Start Session**: Type a duration inline. Leave every field empty for a session with no time limit.
- **Configure New Session**: Start a session for a duration or until a specific time.
- **Get Remaining Time**: Shows how long the current session has left.
- **End Current Session**: Ends the current session.

## Setup

Install Amphetamine from the Mac App Store first. This extension controls it.

## Tips

- Give **Quick Start Session** an alias like `awake`, then type `awake 2h` before a long download or presentation.
