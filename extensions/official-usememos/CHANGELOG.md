# Memos Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Add **Setup Memos** command with a native checklist that verifies the instance URL and access token (defaults to https://demo.usememos.com)
- Add **Search Memos** with Markdown preview, a My Memos / All Visible Memos scope toggle, and ⌘E to edit your own memos with the same editor and ⌘P preview as Create Memo
- Add **Create Memo** with Markdown editing, ⌘P preview, and a Default Visibility preference
- Add **Capture Memo** to type a memo in Root Search and save it immediately
- Add **Save Clipboard as Memo** to capture clipboard text as a new memo
- Add **Open Memos** to open the configured instance in the browser
