# Slowed + Reverb Changelog

## [Windows, Batch Audio, and Raycast AI] - 2026-11-06

- Added Windows support with a file picker for all four Generate commands.
- Added batch processing with adjustable speed and reverb, pitch-preserving tempo changes, and conversion to MP3, WAV, or FLAC.
- Choose where to save results, open or reveal completed files, and see which files failed. Existing files are kept when output names collide.
- Inspect audio metadata or render audio files through Raycast AI.

- Initial version of the extension
- Adding settings for sox path, slowed speed, and nightcore speed
