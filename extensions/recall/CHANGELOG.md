# Recall Changelog

## [2.0.0] - 2026-11-02

- Bookmark-style two-column view: card list with thumbnails, and a detail pane with page preview, source URL and domain, description, date, and tags
- Search bookmarks by title, with date range filters
- Description is fetched on card selection for a quick preview
- Ask This Card unchanged: read full card content and ask questions about any card
- Removed unused agent/skill workflow files

## [Initial Version] - {PR_MERGE_DATE}

- Browse Recall: list cards with thumbnails, date range filters, and source URL filtering
- Read card content in Markdown with source and timestamp annotations
- Ask a card a question to focus on the most relevant content chunks
- Actions to open or copy source URLs and copy card content
