# Recall for Raycast

Browse and read the cards saved in your [Recall](https://www.recall.it) knowledge base directly from Raycast.

- List all your saved cards with thumbnails and dates
- Filter by date range or by source URL
- Read full card content in Markdown
- Ask a card a question to see only the chunks that answer it
- Open or copy the original source URL

## Setup

1. Log in to the [Recall web app](https://app.getrecall.ai).
2. Go to **Settings → API & MCP → API Keys** and click **Create key**.
3. Copy the generated key (it starts with `sk_` and is shown only once).
4. Open the **Browse Recall** command in Raycast — you'll be prompted to paste the key.

The key is stored locally by Raycast and is never sent anywhere except the Recall API.
