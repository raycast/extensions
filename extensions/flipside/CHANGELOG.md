# Flipside Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Scan Two-Sided: two ADF passes with hands-free flip detection, collated into an ordered PDF.
- Scan One-Sided: a single ADF pass into a PDF.
- Reorder Scanned PDF: fix an already-concatenated front/back PDF without rescanning.
- Bonjour auto-discovery of eSCL scanners, with a manual host preference.
- Resolution, color mode, default save folder, and open-after-save preferences.
