## [首次发布] - 2026-11-04

- 按标题、项目或会话 ID 查找 Claude Code 和 Codex 会话，包括历史对话。
- 从 Raycast 搜索或全局快捷键订阅当前对话，也可在 All Sessions 中选择会话订阅。
- 在支持搜索的订阅列表和菜单栏中跟踪会话，在问题、授权及其他待处理请求出现时接收通知。
- 按回车跳回桌面对话、终端标签页或 tmux 窗格，按 Command-Return 切换订阅，按 Command-D 标记已处理。
- 用云朵图标标识 Claude 云端对话并支持跳转，不将其显示为已接入本地状态监测。
- 可选开启本地全文索引，搜索用户与智能体消息；默认关闭。
- 通过 Raycast 原生偏好设置配置终端、通知和搜索，图标适配浅色与深色主题，提供英文与简体中文文档。
