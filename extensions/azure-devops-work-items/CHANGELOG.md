# Azure DevOps Work Items Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Browse work items assigned to you across all Azure DevOps projects
- Group, filter, and search by state, type, or project
- Configurable state ordering and per-state visibility
- Change state on a single item or multiple items at once
- View descriptions, acceptance criteria, repro steps, and comments inline
- Inline image rendering with attachment listing and Preview integration
- Create new work items with title, description, assignee, parent link, and attachment
- Create branches linked to work items from any chosen base branch and repository
- Quick copy actions for IDs, titles, URLs, branch names, and markdown links
