# cmarks for Raycast

Commands for [cmarks](https://github.com/yuchanghyun/cmarks), the read-only Markdown reader for macOS.

- **Search Markdown Files** — lists every Markdown file in the folders you have open as cmarks workspaces (it reads cmarks' saved session) and opens the one you pick in cmarks. Respects the Markdown extensions and ignored folders from cmarks' settings.
- **Open Recent File** — the files you read recently in cmarks.
- **Open Finder Selection in cmarks** — opens the Finder selection with cmarks; folders become workspaces.

Requires cmarks 1.3 or later, from the [Mac App Store](https://apps.apple.com/app/cmarks/id6813011637), Homebrew (`brew install --cask cmarks` after tapping `yuchanghyun/cmarks`) or the GitHub release.
