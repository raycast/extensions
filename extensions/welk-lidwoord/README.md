# Welk Lidwoord

Quickly find the correct Dutch article (de/het) for a noun, right from Raycast.

## Commands

- **Lidwoord** — search for the correct article for a word.
- **Geschiedenis** — view your previously searched words.

## Preferences

| Preference | Description                          | Default                 |
| ---------- | ------------------------------------- | ------------------------ |
| API URL    | Base URL of the Welk Lidwoord API.    | `http://localhost:8806` |

By default the extension talks to a locally running instance of the API. If you're not running the API on your own machine, open **Raycast Preferences → Extensions → Welk Lidwoord** and set the **API URL** to the address where the API is hosted.
