# Luckynote Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Capture notes directly to Inbox with Quick Save Note.
- Save messages with an optional body and searchable folder selection.
- Create tasks with a leading `-` or the Save as Task action.
- Connect through the Luckynote website and return automatically after sign-in.
- Preserve newer edits made while a note is being saved.
- Show Quick Save errors when the Server URL preference is invalid.
- Keep connections in Raycast’s token storage and use its built-in logout.
