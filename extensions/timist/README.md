# Timist for Raycast

Track your time with [Timist](https://timist.app) without leaving Raycast: start and stop timers and contexts, review today's blocks, and keep an eye on what's running from the menu bar.

The extension is a pure client of the Timist public API v1 — you need an API key (`timist_sk_…`) from a Timist Plus account with API access.

## Commands

- **Show Status** — what's running, with start/stop/delete actions and today's stats.
- **Start Timer** — create and start a timer with title, project, tags, and notes. New project and tag names are created on the fly.
- **Stop Timer** — stop the running timer from anywhere.
- **Start Context** — restart a recent context, search past ones, or create a new project/tag combination.
- **Stop Context** — stop the running context from anywhere.
- **Timist Menu Bar Status** — menu bar item showing the running timer or context, refreshed every minute.

## Setup

1. Create an API key in Timist.
2. Open any Timist command in Raycast and paste the key into the **API Key** preference.
