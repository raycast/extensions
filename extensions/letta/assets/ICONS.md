# Extension Icons

This folder should contain the following icons for the Raycast extension:

## Required
- `icon.png` - Main extension icon (512x512 recommended, PNG format)

## Recommended
You can use a single icon for the extension or create specific icons for each command:
- Use the Letta brand colors and logo
- Icons should be clear at small sizes (16x16 minimum)
- PNG format with transparency

## Getting Letta Icons
1. Download from Letta's brand assets
2. Or create a simple icon using the Letta "L" letterform
3. Ensure proper licensing for any brand assets

## Raycast Icon Guidelines
- Square format (1:1 aspect ratio)
- Minimum 512x512 pixels
- PNG format
- Transparent background recommended
- Simple, recognizable design
