# Simple Draw Changelog

## [Box, Oval, and Arrow Tools] - 2026-10-08

- Add Box and Oval tools with solid, dashed, and dotted line styles
- Add an Arrow tool
- New tools use the existing line width options
- Add **B**, **O**, and **A** keyboard shortcuts for the new tools
- Hold **Shift** to draw square boxes and perfect circles, and to snap arrows to 45° angles

## [Initial Version] - 2026-06-11

- Annotate clipboard images with draw and text tools
- Use Raycast's Swift bridge for macOS pasteboard and viewer integration
- Store session HTML under `environment.supportPath`
