# File Content Search

Grep-based file search for Raycast with regex support.

## Features

- Real-time search (min 3 chars)
- File preview with context lines
- Results grouped by file
- Regex mode toggle
- Advanced search with validation
- Search history
- Replace in file
- Open in VS Code / Xcode

## Shortcuts

| Action | Key |
|--------|-----|
| Toggle regex | ⌘R |
| Change directory | ⌘L |
| Reset to home | ⇧⌘H |
| Open in VS Code | ⇧⌘O |
| Open in Xcode | ⇧⌘X |
| Replace in file | ⇧⌘R |
| Copy line content | ⌘. |
| Copy with context | ⇧⌘. |
| Copy path | ⇧⌘C |
| Change timeout | ⇧⌘T |
| Change max results | ⇧⌘M |

## Excluded
