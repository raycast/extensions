# F1 Dashboard

A comprehensive Formula 1 companion for Raycast. Stay up to date with the latest from the paddock, directly from your raycast command bar.

## Features
- **Race Schedule:** View upcoming sessions with automatic local timezone conversion.
- **Standings:** Track the Driver and Constructor Championship battles.
- **Race Results:** View full grid classifications, including historical data back to 1950.
- **AI News Summary:** Get the latest headlines summarized by AI for a quick paddock briefing.

## Data Source
This extension uses the [Jolpi API](https://api.jolpi.ca/ergast/) (a community-maintained replacement for the Ergast API).
