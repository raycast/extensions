# JibberJabber

A quick scratchpad right inside Raycast. Open it, type whatever's on your mind, and copy it to your clipboard — no apps, no windows, no friction.

## Features

- Instant scratchpad — no file to open, no app to switch to
- **⌘ + Return** to copy everything to the clipboard and close
- **⌘ + Shift + Backspace** to clear the scratchpad

## Usage

1. Open Raycast and search for **Jot Now**
2. Start typing your note, idea, command, or snippet
3. Press **⌘ + Return** to copy it to your clipboard

## Commands

| Command  | Description                              |
| -------- | ---------------------------------------- |
| Jot Now  | Open a blank scratchpad and start typing |
