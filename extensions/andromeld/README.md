# AndroMeld for Raycast

Search the apps on your connected Android device and open them on the Mac.

Requires [AndroMeld for Mac](https://andromeld.catchingnow.com) with a connected device. AndroMeld
publishes the app list — name, device, icon and launch link — to its App Group container; this
extension reads that file and hands the launch link back to AndroMeld.

## Development

```sh
npm install
npm run dev
```
