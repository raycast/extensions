# Sleep Control Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Added a menu bar sleep toggle with moon and sun status icons and an optional text label.
- Added native sleep controls and a direct toggle command for hotkeys.
- Added macOS administrator approval and optional, revocable quick switching for the two exact sleep commands.
- Added status refresh and verification of the macOS setting after changes.

Physical closed-lid behavior has not yet been tested for this release.
