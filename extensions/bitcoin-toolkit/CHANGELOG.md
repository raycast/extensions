# Bitcoin Toolkit Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Add `Look up Block` command to fetch a block's hash, mined time, and age from a mainnet block height, with estimates for future blocks
- Add `Look up Transaction` command to show confirmation status, fee, size, and value details for a TXID
- Add `Bitcoin Price Dashboard` command to view the current Bitcoin price in USD, EUR, GBP, CAD, CHF, AUD, and JPY
- Add `Convert Sats ↔ USD` command to convert between satoshis (or BTC) and USD at the live Bitcoin price
