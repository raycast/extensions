# Go Package Explorer for Raycast

A Raycast extension for browsing and searching Go packages from pkg.go.dev.

## Features

- 🔍 Search for any Go package from pkg.go.dev
- 📚 Browse Go standard library packages
- 🎯 Filter packages by name, description, and popularity
- 📖 View package documentation and examples
- ⚡ Quick access to package details and source code

## Usage

1. Open Raycast
2. Type "Search Go Packages" to search for any Go package
3. Type "Browse Standard Library" to explore the Go standard library
4. Use the search bar to filter packages
5. Press Enter to view package details and examples

## Development

```bash
# Install dependencies
npm install

# Run in development mode
npm run dev

# Build the extension
npm run build
```

## New to Golang?

This extension is perfect for beginners! It provides:
- Easy filtering and searching of packages
- Quick access to examples
- Direct links to documentation
- Standard library browser for learning core packages
