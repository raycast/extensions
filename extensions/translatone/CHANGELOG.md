# TranslaTone Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Translate text with Default, LinkedIn, Email and Chat tones, with streaming results
- Translate automatically between a main and second language, or choose a fixed target
- Paste translations into the active app or copy them to the clipboard
- Translate Selection replaces selected text directly; Translate keeps clipboard previews local until submitted
- Add, edit, test, enable, disable and remove connections in Manage Providers
- Support Groq, Gemini, Ollama, OpenAI, Anthropic, OpenRouter and OpenAI-compatible endpoints
- Choose a primary provider and explicitly opt into automatic fallback
- Store managed credentials in encrypted local storage; empty required keys disable the provider
- Browse provider models with Choose Model and restore the configured model at any time
- Track local provider usage and show actionable errors with redacted debug reports
