# VNC Connect

Quickly connect to VNC servers using macOS Screen Sharing. Manage your VNC connections directly from Raycast.

## Features

- **List saved connections** from macOS Screen Sharing app
- **Add custom connections** with host, port, username, and password
- **Edit and delete** your custom connections
- **Auto-fill credentials** - passwords are passed via VNC URL for seamless connections
- **Search** through all your connections

## Usage

1. Open Raycast and search for "Connect to VNC"
2. Select a connection and press Enter to connect
3. Press `Cmd+N` to add a new connection
4. Press `Cmd+E` to edit a custom connection
5. Press `Cmd+Backspace` to delete a custom connection

## Connection Types

- **Custom** (blue) - Connections you've added manually, fully editable
- **System** (gray) - Connections imported from macOS Screen Sharing app (read-only)

## Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Enter` | Connect to selected server |
| `Cmd+N` | Add new connection |
| `Cmd+E` | Edit selected connection |
| `Cmd+C` | Copy host address |
| `Cmd+Backspace` | Delete connection |
