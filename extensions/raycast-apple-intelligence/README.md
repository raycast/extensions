# Apple Intelligence

Use Apple Intelligence Writing Tools on selected text from Raycast, with a hotkey for each one.

## Commands

**Writing Tools on selected text**

- **Rewrite**, **Proofread**, **Summarize** and **Create Key Points**.
- **Make Concise**, **Make Friendly** and **Make Professional**.
- **Make List** and **Make Table**.

**More**

- **Compose**: Write with ChatGPT through Apple Intelligence.
- **Create Image**: Opens Image Playground.
- **Show Writing Tools**: Opens the Writing Tools menu.
- **List Writing Tools**: All Writing Tools in one list.

## Setup

Apple Intelligence needs to be turned on in System Settings, on a Mac that supports it.

## Tips

- Give **Proofread** a hotkey to fix the text you've just written in any app.
