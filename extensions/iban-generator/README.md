# IBAN Generator

Generate test IBANs, BICs, and bank details for development. Every value is synthetic and is not linked to a real bank account.

## Commands

- **Generate IBAN** — pick a country, bank, format, and whether the result should be valid or intentionally invalid. Pass a country argument such as `DE` or `Germany` to generate immediately.
- **IBAN** — paste the last generated IBAN.
- **Paste BIC** — paste the BIC for the saved IBAN, when one is known.
- **Search Test IBANs** — search published payment-provider test IBANs, then paste, copy, or save one as the current IBAN.
