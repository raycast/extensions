For the user: today "Pin as Quicklink" turns a choice into a root-search command, and Quick Capture is a separate command that takes text inline for one fixed capture choice. Generalize: any choice can be pinned so that Raycast asks for a text argument inline in root search and the run starts with that text pre-seeded as the choice's `value`. A capture pinned this way behaves like Quick Capture without a window; a template pinned this way gets its title from the argument and still prompts for anything else.

How: Raycast Quicklinks support an `{argument}` placeholder in the link (read the Raycast docs: https://manual.raycast.com/quicklinks and the `Action.CreateQuicklink` API; check how the argument is encoded when substituted, including the `raw` variant, and verify live). Keep "Copy Deeplink" as is.
