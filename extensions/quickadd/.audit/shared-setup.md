# Shared setup for raycast-quickadd threads (read first)

Repo: `chhoumann/raycast-quickadd`, Raycast extension (TypeScript/React) that drives the QuickAdd Obsidian plugin through the Obsidian CLI. Read `ARCHITECTURE.md` and `README.md` in your worktree, then the files your brief names. Main is at 6cc7c9f or later.

- **pnpm**: the vite-plus shim is blocked on this machine; use `~/.vite-plus/package_manager/pnpm/10.32.1/pnpm/bin/pnpm`. Run `pnpm install --frozen-lockfile` in your worktree first.
- **Gates**: `pnpm lint`, `pnpm test`, `npx tsc --noEmit`, `pnpm build` (writes to `dist/`, safe), and `pnpm e2e:protocol` (drives every e2e choice through the real plugin; needs the e2e vault open).
- **Obsidian CLI**: `/opt/homebrew/bin/obsidian`. QuickAdd 2.31.0 is released and installed in the e2e vault.
- **The e2e vault** is registered in Obsidian as `e2e-vault` at `/Users/christian/Developer/raycast-quickadd/e2e-vault` (the MAIN checkout, not your worktree). Your worktree has its own copy of `e2e-vault/`; commit fixture changes there, and copy them into the registered vault too when a live check needs them (then `obsidian vault=e2e-vault plugin:reload id=quickadd` if `data.json` changed). Never register a second vault named `e2e-vault` (same-name vaults break CLI routing). You have full authority over anything named `e2e-vault`. The user's own vaults (`notes`, `worknotes`, `dev`) are OFF LIMITS: never run a choice in them, never write to them, never close them.
- **Raycast deeplinks**: `raycast://extensions/christian_bager_bach_houmann/quickadd/<command>?context=<urlencoded JSON>`; `context.vaultPath` selects the vault (use the e2e vault path above). Choice ids there: e2e-text, e2e-select, e2e-multi, e2e-custom, e2e-number, e2e-date, e2e-picker, e2e-runtime, e2e-template, e2e-macro, e2e-slow, e2e-meeting.
- **Raycast's installed dev build is a single shared resource.** Other threads run in parallel. Before `ray develop`: `pgrep -fl "ray develop"` must be empty; if not, wait and retry (poll every 30 s, up to 10 min), do not kill it. Run yours in the background, wait for "built extension successfully", do your live checks in one short window, then stop it and run `npx ray develop` from `/Users/christian/Developer/raycast-quickadd` (main) until it prints "built extension successfully", stop it, and state that you restored main's build. Keep the whole window as short as you can: a Raycast window that opens steals the user's keystrokes.
- **Keystroke guard, non-negotiable.** Raycast keeps a hidden window, so counting Raycast windows through System Events is NOT a guard (two agents typed into the user's other apps that way). Before EVERY keystroke run `/tmp/raycast-guard.sh`; it must print `ok` (CGWindowList, on-screen only, a window owned by Raycast at least 600pt wide). Anything else: do not send, wait, re-check; if the panel stays absent, report that step as not verified. Send keystrokes only as `tell application "System Events" to tell process "Raycast" to keystroke ...` (or `key code`), re-running the guard immediately before each one. Never script any other app with AppleScript. Report the time window in which you sent keystrokes.
- Screenshots: `screencapture -x /tmp/<thread>/<slug>.png`, inspect each with the Read tool, describe what it shows. Field contents can be read through the accessibility tree if a dialog covers pixels. Anything not seen is reported as not verified, never as passed.
- **Rules from the user**: never use the em dash character, use "-". Keep changes small; delete before adding. No helper text under labels unless it prevents an error. Code comments only for a non-obvious why. Tests must fail on a real defect (no tautologies; mutation-check if cheap).
- **Finish**: Conventional Commit titles. Push your branch and open a PR against `main` with `gh pr create` (not draft), body sections: Why, What changed, Scope, Verification; short sentences; no em dashes. Confirm the CI run is green (`gh pr checks`). Do not merge. Report: PR URL, commits, gate output tails, every screenshot path with what it shows, the keystroke window, and anything you could not verify.
