# QuickAdd for Obsidian Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Run any QuickAdd choice from Raycast and answer its prompts in native Raycast forms and lists.
- Quick Capture sends text to a capture choice of your choosing.
- Capture Selection sends the text selected in the frontmost app to a capture choice.
- Capture Clipboard sends the clipboard text to a capture choice.
- Typing `[[` in a text field completes notes and aliases, and `#` completes tags.
- Pin any choice as a Quicklink to run it from root search or a hotkey.
- Finds the vault that has QuickAdd, and opens it in Obsidian when it is closed.
- Run in Obsidian runs a choice with QuickAdd's own modals.
