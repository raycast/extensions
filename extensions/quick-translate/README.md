# Quick Translate

Translate selected text instantly using DeepL API. Simply select text in any application and run the command - the translation appears immediately.

## Features

- **Instant translation** - Select text anywhere and translate with a hotkey
- **Auto-detect source language** - DeepL automatically detects the source language
- **13 target languages** - Spanish, English (US/UK), German, French, Italian, Portuguese, Dutch, Polish, Russian, Japanese, Chinese
- **Auto-copy** - Translation is automatically copied to clipboard
- **Change language on the fly** - Switch target language without leaving the panel

## Setup

1. Get a free DeepL API key at [deepl.com/pro-api](https://www.deepl.com/pro-api) (500,000 characters/month free)
2. Open Raycast Settings → Extensions → Quick Translate
3. Enter your API key
4. Set your default target language

## Usage

1. Select text in any application
2. Open Raycast and run "Translate Selection" (or use a hotkey)
3. View the translation
4. Press `⌘ + Return` to paste or `⌘ + C` to copy

## Keyboard Shortcuts

| Action | Shortcut |
|--------|----------|
| Paste translation | `⌘ + Return` |
| Copy translation | `⌘ + C` |
