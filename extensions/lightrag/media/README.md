# Store media

## Screenshots (before publishing)

Raycast recommends at least **three** screenshots (max. six), **2000×1250** PNG, no sensitive data ([Prepare for Store](https://developers.raycast.com/basics/prepare-an-extension-for-store)).

1. Enable **Window Capture** in Raycast Advanced Preferences (e.g. `⌘⇧⌥M`).
2. Run the extension in **development** mode, open a command, then capture with **Save to Metadata** checked.
3. Save PNGs here and reference them when publishing (or follow the publish CLI prompts).

Use a neutral wallpaper; do not show real server URLs, passwords, or private document titles.
