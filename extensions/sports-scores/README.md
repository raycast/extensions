# Sports Scores

Check live sports scores and schedules directly from Raycast.

## Features

- **Multi-Sport Support**: Browse scores for NFL, NBA, MLB, NHL, NCAA Football (CFB), NCAA Basketball (CBB), and Soccer (EPL)
- **Live Updates**: View real-time scores with period/quarter information
- **Game Details**: Access comprehensive game information including team stats, box scores, and broadcast details
- **Smart Navigation**: Navigate between dates to see upcoming games, past results, and current scores
- **Quick Search**: Find teams across all leagues instantly
- **League Filtering**: Filter by specific sport or view all leagues together
- **ESPN Integration**: Direct links to detailed game information on ESPN

## Usage

Simply open Raycast and type "Check Scores" to get started. No configuration or API keys required!

## Supported Leagues

- 🏈 NFL (National Football League)
- 🏀 NBA (National Basketball Association)
- ⚾ MLB (Major League Baseball)
- 🏒 NHL (National Hockey League)
- 🏈 NCAA Football (College Football)
- 🏀 NCAA Basketball (Men's College Basketball)
- ⚽ Soccer (English Premier League)

## Data Source

All game data is provided by ESPN's public API.
