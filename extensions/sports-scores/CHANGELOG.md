# Changelog

## [Initial Release] - {PR_MERGE_DATE}

### Features

- **Multi-Sport Support**: Browse live scores and schedules for NFL, NBA, MLB, NHL, NCAA Football (CFB), NCAA Basketball (CBB), and Soccer (EPL)
- **Dynamic Game Details**: View comprehensive game information with sport-specific layouts
  - Pre-game: Team records, broadcast information, and game time
  - Live: Real-time scores with period/quarter information
  - Post-game: Final scores with detailed box scores and team statistics
- **Date Navigation**: Navigate between dates to view upcoming games, past results, and current scores
- **Smart Search**: Quickly find teams across all supported leagues
- **League Filtering**: Filter view by specific sport or view all leagues together
- **ESPN Integration**: Direct links to game details and box scores on ESPN
- **Optimized Performance**: Smart caching and memory-efficient league loading
- **Cross-Platform Shortcuts**: Platform-aware keyboard shortcuts for seamless navigation
