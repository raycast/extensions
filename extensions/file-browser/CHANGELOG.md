# File Browser Changelog

## [Added File Search and Tag Browsing] - {PR_MERGE_DATE}

- Add Find Files, a natural-language Spotlight search command with reusable recent searches.
- Add Browse Tags for exploring Finder tags and opening tagged files or folders from Raycast.
- Improve file management with metadata editing, Finder tag updates, folder creation, copy, move, and Trash actions.
- Improve documentation for current commands, preferences, and the bundled Spotlight helper.
