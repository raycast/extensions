# Date Format

Raycast 확장으로 날짜를 다양한 로컬 및 국제 형식으로 변환합니다.

## 기능

특정 날짜를 입력하거나 현재 시간을 기준으로 다양한 형식의 날짜를 확인할 수 있습니다:

- **ISO 8601**: 국제 표준 날짜 형식
- **Unix Timestamp**: 초 및 밀리초 단위
- **RFC 2822**: 이메일 표준 날짜 형식
- **UTC**: 협정 세계시
- **한국 형식**: 긴 형식 및 짧은 형식 (YYYY-MM-DD)
- **미국 형식**: MM/DD/YYYY
- **유럽 형식**: DD/MM/YYYY
- **시간**: 24시간 및 12시간 형식
- **상대 시간**: "3시간 전" 또는 "2일 후" 등
- **SQL DateTime**: SQL 데이터베이스용 형식
- **JSON**: JSON 직렬화 형식

## 사용 방법

1. Raycast를 열고 `Date Format` 커맨드를 실행합니다
2. 날짜를 입력합니다 (예: `2024-01-15`, `Jan 15 2024`, `2024/01/15`)
   - 입력하지 않으면 현재 시간이 사용됩니다
3. 원하는 형식을 선택하고:
   - `Cmd + C`: 클립보드에 복사
   - `Cmd + V`: 바로 붙여넣기

## 예시

### 입력
- `2024-01-15`
- `January 15, 2024`
- `2024/01/15 14:30:00`
- 빈 값 (현재 시간 사용)

### 출력
다양한 형식으로 변환된 날짜 목록이 표시됩니다.
