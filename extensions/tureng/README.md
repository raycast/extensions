# Tureng
This extension allows you to search for phrases in English Turkish dictionary of Tureng.

This extension has been published with the explicit permission of the Tureng team. Assets has been provided by the Tureng team.

## Commands
### Translate
Allows you to search for a word / phrase in English Turkish dictionary of Tureng.

### Translate Selected Text
Allows you to search for the selected text in your screen in English Turkish dictionary of Tureng.
