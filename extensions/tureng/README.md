# Tureng for Raycast

Search the [Tureng](https://tureng.com) English-Turkish dictionary directly from Raycast.

## Commands

| Command | Description |
|---------|-------------|
| **Tureng Search** | Type to search with live autocomplete suggestions |
| **Tureng Translate** | Enter a word directly for instant translations |
| **Tureng Selected Text Lookup** | Look up selected text from any app — assign a hotkey for one-keystroke translations |
| **Tureng Favorites** | Browse and manage your saved words |

## Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Enter` | Look up selected term |
| `Cmd+Shift+C` | Copy term |
| `Shift+Enter` | Paste translation into frontmost app |
| `Opt+Enter` | Open Tureng page in browser |
| `Cmd+Shift+Alt+C` | Copy all translations |
| `Cmd+Shift+P` | Open pronunciation |
| `Cmd+S` | Add word to favorites |

## Features

- **English-Turkish & Turkish-English** — results are grouped by translation direction
- **Autocomplete** — suggestions appear as you type in Tureng Search
- **Drill-down** — select any translation to look it up further
- **Paste translation** — paste a translation directly into whatever app you're working in
- **Suggestions** — if a word isn't found, similar terms are shown to choose from
- **Favorites** — save words for vocabulary building, browse them anytime

## Deeplinks

Trigger a lookup from scripts, Shortcuts, or any app that can open URLs:

```
raycast://extensions/gokce/tureng/search-tureng?arguments=%7B%22query%22%3A%22hello%22%7D
```
