# Profile Porter

Open links and sites in the right browser profile from Raycast, with [Profile Porter](https://profileporter.com).

Profile Porter is a Mac app that remembers which browser profile you use each site in (Chrome, Edge, Brave, Arc, Firefox, Safari and more) and opens links there. This extension hands links and searches to it.

## Setup

Install [Profile Porter](https://profileporter.com) and open it once, so it can find your browsers and profiles. The extension finds the app wherever it's installed; there is nothing to configure.

## Commands

- **Open in Profile**: lists your browser profiles. ↩ opens the link you typed, or the link on your clipboard, in that profile; with no link it opens a window of the profile. ⇧↩ opens it in a private window.
- **Open Link in the Right Profile**: hands a link to Profile Porter, which opens it in the profile you use that site in (or asks, the first time).
- **Search Sites and Pages**: shows Profile Porter's panel with what you typed: the profile each site is used in, and the pages you visited.
