# Random Value Generator

A Raycast extension for generating and copying common random values.

## Supported values

- Date
- UUID v4
- Complex password
- Integer and decimal number
- Alphanumeric string
- Email address
- URL
- Boolean
- Hex color
- ISO and Unix timestamps
- Base64
- API token
- IPv4 address

Select a value and press `Enter` to copy it. Use `Command + R` to regenerate all values.

## Local development

Run `npm run dev` to load the extension in Raycast.
