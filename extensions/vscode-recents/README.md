# VS Code Recents

A Raycast extension to quickly search, list, and open your recent VS Code projects, workspaces, remote containers, and files directly from Raycast.

## Features

- 🔍 **Search Recent Projects**: Instantly search through your recently opened folders, `.code-workspace` workspaces, remote SSH/Container sessions, and files.
- ⚡ **Quick Open**: Launch projects with VS Code CLI (`code` / `code-next`) or macOS application directly.
- 📋 **Copy Actions**: Easily copy file paths or CLI commands (`code "<path>"`) to your clipboard.
- 🎨 **Rich Badges & Icons**: Visual tags and icons distinguishing folders, workspaces, remote containers, and file types.

## Prerequisites

- Visual Studio Code installed on macOS.
- (Recommended) `code` command installed in your `PATH` (in VS Code: `Cmd+Shift+P` -> `Shell Command: Install 'code' command in PATH`).

## Commands

- **Search VS Code Recent Projects**: Search and open recent VS Code projects and workspaces.
