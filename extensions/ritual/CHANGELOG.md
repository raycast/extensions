# Ritual Changelog

## [Initial release] - {PR_MERGE_DATE}

- Add Task takes the title as an argument, so capture never draws a form — type, Enter, done
- Today and Upcoming, with a scope switcher (Today, Upcoming, Inbox, All) without leaving the list
- Upcoming is grouped by day, week and month exactly as Ritual groups it
- Search across every task, with the full action panel
- Complete (with Undo), reschedule, set a deadline, move to a project and delete from every task list
- Edit a task's title, notes, when, deadline, project and tags
- Habits, with check-ins per slot
- The Ritual command-line tool is found automatically
