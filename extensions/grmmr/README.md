# Grmmr

Fix grammar and spelling in selected text using AI.

## Features

- Select any text and instantly fix grammar and spelling errors
- Supports multiple AI providers:
  - OpenAI (GPT-4, GPT-3.5, etc.)
  - Anthropic (Claude models)
  - Google Gemini
- Automatically replaces selected text with corrected version

## Setup

1. Choose your preferred AI provider from the extension preferences
2. Select the model you want to use (or use the default)
3. Enter your API key for the selected provider

### Getting API Keys

- **OpenAI**: Get your API key from [platform.openai.com](https://platform.openai.com/api-keys)
- **Anthropic**: Get your API key from [console.anthropic.com](https://console.anthropic.com/)
- **Google Gemini**: Get your API key from [ai.google.dev](https://ai.google.dev/)

## Usage

1. Select any text in any application
2. Trigger the "Fix Grammar" command from Raycast
3. The corrected text will automatically replace your selection
