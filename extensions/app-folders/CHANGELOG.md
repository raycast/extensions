# App Folders Changelog

## [Initial Version] - 2026-11-10

- Initial release of App Folders extension for Raycast
- Smartphone-style app grouping in a unified 6-column grid view
- Dynamic iOS/Launchpad-style 2×2 frosted glass squircle container previews
- Dedicated shortcut slots (Slots 1–5) and quick hotkey launching (`⌘1`–`⌘9`)
- Batch launch all applications in a folder simultaneously with `⇧⌘↵`
- Inter-folder application moving with `⇧⌘M`
- Toggleable `⌘1`–`⌘9` shortcut badges beneath items (`⇧⌘H`)
- Full configuration backup and restore via JSON
- Custom folder icon support: custom emojis, local image files (`.png`, `.icns`, `.ico`), and preset graphics
- Automatic background caching and high-resolution icon extraction from native macOS `.app` bundles
