# Tallies

A Raycast extension for tracking attendance. With Tallies you can:

- create reusable **Templates** with headings, notes, and default times
- manage a separate **Check In** roster for each template
- copy attendance tables to Excel or another spreadsheet
- export and import JSON backups

## Getting started

1. Run `npm install`, then `npm run dev` from this project directory to load Tallies locally in Raycast.
2. Open **Template** to create a roster template, then use **Check In** to add attendance entries.

## Upgrading from the previous name

Export a backup from your existing attendance extension before loading Tallies, then import it into Tallies. Older attendance backups are supported. Raycast stores the renamed extension's data separately.

See [PUBLISHING.md](PUBLISHING.md) for validation and publishing instructions.
