# SMRY

[SMRY](https://smry.ai) is an AI-powered article reader and summarizer — read any article in a clean, distraction-free format directly from Raycast.

## Commands

### Read Article

Enter any URL to extract and read the article in clean reader mode with proper formatting, metadata sidebar (source, author), and quick actions.

### Summarize Article

Enter any URL to get an AI-generated bullet-point summary of the article. Requires Raycast Pro (uses Raycast AI).

### Read Clipboard URL

Instantly reads whatever URL is on your clipboard — no need to type or paste.

### Open in SMRY

Opens any URL in smry.ai in your browser for the full reading experience with highlights, text-to-speech, and chat.

## Features

- Clean reader mode with markdown formatting
- AI-powered article summarization via Raycast AI
- Article metadata (source, author, published date)
- Auto-prepends `https://` when protocol is omitted
- Copy article text or URL with keyboard shortcuts
- Open original article or read in smry.ai
