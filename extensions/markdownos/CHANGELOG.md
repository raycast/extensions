# MarkdownOS Changelog

## [Menu Bar] - 2026-09-29

- Add the MarkdownOS Menu Bar command: create a note, search notes or bookmarks, open the app, open
  Bookmarks, or open Settings, from a menu bar icon.

## [Notes] - 2026-09-29

- Add the Search Notes command: search by title and body, preview a note with matches highlighted,
  open it in the app (a new window or the main one), copy its markdown or a link to it, or move it
  to Trash.
- Add the Create Note command.

## [Initial Version] - 2026-09-29

- Add Search Bookmarks, Save Bookmark, and Save Current Tab commands.
