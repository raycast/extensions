# MarkdownOS

Quick actions for MarkdownOS — search and create notes, and manage bookmarks — without leaving
Raycast.

## Requirements

- MarkdownOS installed and pointed at a vault folder.
- On first run, point this extension at that same vault folder (Raycast will prompt for it).

## Commands

- **Search Notes** — search your notes by title and body, preview one, open it in the app (in a
  new window or the main one), copy its markdown or a link to it, or move it to Trash.
- **Create Note** — create an empty note and open it in a new MarkdownOS window.
- **Search Bookmarks** — search, edit, tag, archive, or delete your bookmarks.
- **Save Bookmark** — save a URL as a bookmark, with an optional title.
- **Save Current Tab** — save your active browser tab as a bookmark.
- **Open Bookmarks** — jump straight to the Bookmarks section in the app.
- **MarkdownOS Menu Bar** — the above, from a menu bar icon.

## Development

```sh
npm install
npm run dev
```
