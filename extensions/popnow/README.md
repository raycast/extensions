# PopNow

Generate AI images and videos from Raycast with [PopNow](https://popnow.ai): Nano Banana, GPT Image, Seedream, FLUX, Kling, Seedance, MiniMax H3, Veo and more through one API key.

Requires a PopNow account and paid API credits.

## Setup

1. Create an API key at [popnow.ai/api/console/keys](https://popnow.ai/api/console/keys) and add funds to your API balance.
2. Open any PopNow command and paste the key when Raycast asks for it.

## Commands

- **Generate Image**: write a prompt, pick a model and aspect ratio, and get the image in Raycast. Save it to Downloads or copy the link.
- **Generate Video**: the same for short videos. Rendering usually takes one to three minutes; the view updates by itself.
- **Browse Models**: search every image, video and audio model with its USD price.

## Pricing

Every generation is priced before it starts: you see the maximum charge and confirm it first. If the price changes between the quote and the start, nothing is charged. Failed jobs are refunded automatically.

Model prices are listed in **Browse Models** and on [popnow.ai/api](https://popnow.ai/api).
