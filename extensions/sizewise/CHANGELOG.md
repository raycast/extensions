## [Initial version] - {PR_MERGE_DATE}

- Add **Scan Folder**, which scans a disk, a common folder, or a folder by its path in Sizewise, or
  lists its largest files.
- Add **Scan Finder Selection**, which scans the folder selected in Finder.
- Add **Get Folder Size**, which shows how much space the folder selected in Finder takes up.
- Add **Largest Files**, which lists the largest files in your home folder or a folder you choose.
- Add **Disk Space**, which shows your startup disk's available space in the menu bar.
- Add AI tools, so you can ask `@sizewise` how much space your disks have available, how big a
  folder is, and which files are largest, or have it open a folder in Sizewise.
- Let `@sizewise` answer from the scans you save in Sizewise: what's in a folder, its largest
  files, the space each kind of file takes up, and what changed between two scans.
