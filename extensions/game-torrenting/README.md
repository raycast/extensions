# Game Torrents

Search and download game torrents from CloudTorrents directly from Raycast.

## Features

- Search for games on CloudTorrents
- View details like seeds, leeches, size, and upload date
- Copy magnet links to clipboard or open them directly

## Usage

1. Run the "Search Game Torrents" command.
2. Type your query.
3. Press Enter on a result to view actions (Open Magnet, Copy Magnet, etc.).
