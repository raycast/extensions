# Hookpost

Draft social media posts and check what's scheduled in [Hookpost](https://hookpost.hookstep.in) without leaving Raycast.

## Setup

1. Sign in to [Hookpost](https://hookpost.hookstep.in) and open **Settings → Developers**.
2. Copy your API key.
3. Run any Hookpost command in Raycast and paste the key when asked.

The key gives full access to your workspace's channels and posts, so keep it private. You can change it later in the extension preferences.

## Commands

- **Draft Post**: pick one or more connected channels, write the post, and save it as a draft. Nothing is published until you schedule it in Hookpost.
- **Scheduled Posts**: posts scheduled for the next 30 days, grouped by day. Filter by channel, copy a post's text, open the Hookpost calendar, or delete a post.

Channels are connected in the Hookpost app; the extension uses the ones you already have.
