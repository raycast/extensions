## [Initial Version] - 2026-02-22

- Cross-post from Bluesky to one or more Mastodon accounts
- Compose Post command with 300-grapheme limit, link cards, and image attachments
- Browse Posts command to repost existing Bluesky posts to Mastodon
- Manage Mastodon Accounts command for multi-account support
- Draft auto-save for Compose Post
- Automated post detection via configurable URL prefix
