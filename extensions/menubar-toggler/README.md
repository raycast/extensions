# Menu Bar Toggler

A Raycast extension for quickly toggling macOS menu bar auto-hide settings.

## Features

- **Toggle Menu Bar**: Switch between automatically hiding and showing the menu bar
- **Fast Execution**: Runs in no-view mode for instant response
- **Simple Interface**: Just one command to control your menu bar visibility

## Usage

1. Open Raycast (default: `Cmd + Space`)
2. Type `Toggle Menu Bar`
3. Press Enter to toggle the menu bar auto-hide setting

The extension uses AppleScript to communicate with System Events and change your menu bar preferences.
