# Dolibarr Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Search across companies and contacts from a local index, with fuzzy matching that ignores case
  and diacritics
- Company view with contacts, proposals, orders and invoices, plus a detail pane (`⌘I`) showing
  master data and both public and private notes
- Derived document states that Dolibarr's status code does not expose on its own: overdue invoices,
  expired proposals, and delivered orders that have not been invoiced yet
- Contact view with direct dialling — `↵` calls the first available number
- Line items and PDF preview for every document kind
- Connection check that tells an unreachable address, a wrong URL and a rejected API key apart
- Four AI tools: search, company overview, recent documents and open items
- Number and date formatting selectable independently of the interface language
