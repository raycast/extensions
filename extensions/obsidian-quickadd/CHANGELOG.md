# Obsidian QuickAdd Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Run any QuickAdd choice from Raycast and answer its prompts in Raycast: text, one-page forms, dropdowns, file and tag pickers, multi-selects, checkboxes, dates and times, confirmations
- `[[` links and `#` tags in text fields, from Obsidian's own index
- Quicklinks for single choices, so each can have its own alias or hotkey
- Opens the vault or starts Obsidian when needed
- Basic mode when Obsidian's command-line interface is off
