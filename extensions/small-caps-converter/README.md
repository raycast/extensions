# Small Caps Converter

This Raycast extension converts text into small caps Unicode text.

## Usage

1. Open the command `Convert to Small Caps`.
2. Type your text into the input box.
3. Press `Cmd + Enter` to copy the converted output.

Example:

- Input: `example text`
- Output: `ᴇxᴀᴍᴘʟᴇ ᴛᴇxᴛ`

## Development

```bash
npm install
npm run dev
```
