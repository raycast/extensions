# Security Policy

## Supported Versions

Security fixes are applied to the latest version.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it to us by emailing [security@spoo.me](mailto:security@spoo.me). We will respond as quickly as possible to address the issue.

Please include the following details in your report:
- A description of the vulnerability and its impact.
- Steps to reproduce the vulnerability.
- Any potential fixes or mitigations you have identified.

## Security Updates

We will notify users about security updates through our [GitHub repository](https://github.com/spoo-me/spoo-raycast) and our [Discord server](https://spoo.me/discord).

## Security Best Practices

- Keep the extension up to date through the Raycast Store.
- Review scopes granted during the spoo.me consent flow before approving.
- Revoke tokens from your spoo.me dashboard if you suspect your device is compromised.

## Contact

For any security concerns, please contact us at [security@spoo.me](mailto:security@spoo.me).
