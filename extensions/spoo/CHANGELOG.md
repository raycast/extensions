# Changelog

## [Initial Release] - {PR_MERGE_DATE}

### Added

- Quick Shorten command - one keystroke shortens active tab or clipboard URL
- Shorten Link command - custom alias, password, max clicks, expiry, bot blocking, private stats
- My Links command - search, browse, edit, sort, toggle, and delete links with live analytics sidebar
- Dashboard command - aggregate analytics with SVG charts, weekly trends, top performing links
- Link Analytics - per-link breakdowns (country, browser, OS, referrer) with SVG bar and line charts
- QR code generation - preview, save to Downloads, copy to clipboard
- Edit Link - update destination, alias, password, click limits, expiry, flags
- Linked App authentication - OAuth-style device flow, no API keys needed
- Status filter and sort options in My Links
- Favicon display for destination sites
- Theme-aware QR codes (dark/light mode)
