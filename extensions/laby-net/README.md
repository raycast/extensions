# Laby.net

Search Minecraft player profiles by username and browse Minecraft skins and capes with data from laby.net.

## Commands

### Search Profiles

Search for a Minecraft username and open the matching profile. With an empty search field, the command lists your recent profile searches.

Profile details include:

- Current username and name history
- Skins, capes, and cloaks
- Profile view count and badges
- Linked social accounts

From the results list, you can copy a UUID or remove a profile from recent searches. From a profile, you can open its Laby.net page, copy its UUID, or open its Mojang profile data.

### Search Skins

Browse popular skins or search by a name or tag. Results include the number of users for each skin; open a result to view it on Laby.net.

### Search Capes

Browse popular capes or search by name. Each result includes its user count and links to its Laby.net page.
