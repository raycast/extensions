# Everhour Teamlead Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Added "Team Overview" command showing tracked time for all team members by week
- Week navigation with Cmd+Left/Right and Cmd+T for current week
- Visual colored day pills showing time distribution across the week
- Drill-down into team members with three view modes: All Days, By Project, and individual days
- Task budget indicators with warning (80%) and exceeded (100%) icons
- Project name resolution from IDs
- Detail view with full metadata, comments, and budget info
