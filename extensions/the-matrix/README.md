# The Matrix

Summon a click-through Matrix rain overlay from Raycast, complete with procedural audio, quotes, density controls, and a graceful red pill exit.

## Commands

- **Take a Blue Pill** starts the Matrix overlay.
- **Take a Red Pill** fades out and stops the Matrix overlay.

## Preferences

- **Audio enabled** controls enter, ambient, and exit sounds.
- **Matrix density** controls how sparse or packed the rain appears.
