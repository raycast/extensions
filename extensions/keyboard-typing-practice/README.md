# Keyboard Typing Practice

Practice your typing in Raycast. Run quick sessions, track WPM and accuracy, and watch your progress over time.

If you find this useful, you can support it here:

[![Buy me a coffee](https://img.shields.io/badge/Buy%20me%20a%20coffee-FFDD00?logo=buy-me-a-coffee&logoColor=000000)](https://buymeacoffee.com/idea404)

## Commands

- Start Practice: begin a typing session with a fresh prompt
- Show Stats: view aggregated stats and recent trends

## Features

- Prompts curated from a local quote list (offline)
- Session auto-saves on completion
- WPM and accuracy tracking with recent charts
- Stats stored locally in Raycast

## Development

```bash
npm install
npm run dev
```

## Notes

- Quotes live in `src/quotes.json`.
- Stats are stored in Raycast LocalStorage on your machine.
