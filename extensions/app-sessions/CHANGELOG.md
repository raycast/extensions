# App Sessions Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Create named app sessions with custom icons
- Start all apps in a session with a single command
- End a session by gracefully quitting its apps
- Apple Shortcuts integration with installed Shortcut selection
- Run ordered Raycast commands after starting or ending a session
- Configurable start delay between apps
- Searchable app picker from all installed macOS apps
