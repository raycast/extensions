# Prompt Enhancer

Enhance and refine your AI prompts with a single command. Supports multiple LLM providers and enhancement styles.

## Features

### 🚀 Commands
- **Enhance Prompt** - Form view with comparison before copying
- **Quick Enhance Selected** - Instant enhancement via hotkey
- **View History** - Browse and reuse past enhancements
- **Use Template** - Apply pre-defined templates for common tasks

### 🔌 Multi-Provider Support
- OpenRouter
- Google Gemini
- OpenAI
- Anthropic Claude
- Ollama (local)
- Groq

### ✨ Enhancement Styles
- **Balanced** - Default well-rounded enhancement
- **Concise** - Short and focused
- **Detailed** - Comprehensive and thorough
- **Creative** - Imaginative and artistic
- **Technical** - Code and developer focused

### 📋 Templates
Pre-built templates for common tasks:
- Code Review, Explain Code, Refactor, Write Tests
- Debug Help, Summarize
- Plus create your own custom templates!

### ⚡ Other Features
- Compare view showing original vs enhanced
- Paste directly to active app (⇧⌘+Return)
- Model quick-switch in action menu
- Custom system prompt support
- Auto-fill from clipboard

## Configuration

1. Open Raycast Settings → Extensions → Prompt Enhancer
2. Select your preferred **LLM Provider**
3. Add the corresponding **API key**
4. Optionally adjust enhancement style and custom instructions

## Usage

### Enhance Prompt
1. Open Raycast → "Enhance Prompt"
2. Type or paste your prompt
3. Press `⌘+Return` to enhance
4. Compare view shows both versions
5. Copy or paste the enhanced prompt

### Quick Enhance
1. Select text in any app
2. Trigger "Quick Enhance Selected"
3. Enhanced prompt copied to clipboard

### Use Template
1. Open "Use Template"
2. Select a template (e.g., Code Review)
3. Paste your content
4. Prompt is instantly formatted and copied
