# Prompt Enhancer

A Raycast extension that enhances and refines prompts using LLMs via OpenRouter.

## Features

- **Enhance Prompt**: Form view to type/paste prompts and enhance them
- **Quick Enhance Selected**: Instantly enhance selected text with a hotkey
- Automatic clipboard integration
- Configurable LLM model

## Installation

1. Clone this repository
2. Run `npm install`
3. Run `npm run dev` to start development mode
4. Open Raycast and search for "Enhance Prompt"

## Configuration

Set your OpenRouter API key in the extension preferences:
- Open Raycast Settings → Extensions → Prompt Enhancer
- Enter your API key from [openrouter.ai](https://openrouter.ai)

## Usage

### Enhance Prompt (Form View)
1. Open Raycast → search "Enhance Prompt"
2. Type or paste your prompt
3. Press `⌘+Return` to enhance
4. Enhanced prompt is copied to clipboard

### Quick Enhance Selected
1. Select any text in any app
2. Press your assigned hotkey
3. Enhanced prompt is instantly copied to clipboard
