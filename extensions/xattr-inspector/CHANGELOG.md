# File Attributes Inspector Changelog

## [Initial Version] - 2026-02-22

- View extended attributes of selected Finder files
- Rich formatting for dates, URLs, tags, quarantine data, and plists
- Edit text, XML plist, binary plist, and date attributes
- Add new attributes from common presets or custom keys
- Manage flag suffixes on attribute names
- Remove attributes
- Knowledge base with descriptions for 40+ known macOS attributes
