# File Attributes Inspector

View and edit macOS extended attributes (xattrs) of files directly from Finder using Raycast.

## Features

- **Inspect attributes** — Select one or more files in Finder and view all their extended attributes at a glance.
- **Rich formatting** — Dates, URLs, Finder tags, quarantine info, and binary plists are automatically decoded and displayed in a human-readable format.
- **Knowledge base** — Each known attribute includes a description explaining its purpose.
- **Edit values** — Modify text, XML plist, binary plist, and date-type attributes in place.
- **Add new attributes** — Pick from a list of common macOS attributes or enter a custom key.
- **Manage flags** — Append or strip flag suffixes (e.g., `#PS`) on attribute names.
- **Remove attributes** — Delete any extended attribute from a file.
- **Multi-file support** — Inspect attributes across multiple selected files in a single view.

## Usage

1. Select one or more files in Finder.
2. Open Raycast and run **Inspect File Attributes**.
3. Browse attributes in the list — the detail panel shows the formatted value and description.
4. Use the action menu to copy, edit, add, or remove attributes.
