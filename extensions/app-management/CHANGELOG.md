# Window Switcher & Badges Changelog

## [Initial Version] - {PR_MERGE_DATE}

- One list of running apps and their windows, including hidden, minimized, full-screen, and other-Desktop windows; Return focuses the exact window.
- Dock badges for the apps you track, on the same rows, with Pinned + Badged and Badged Only filters.
- Pinned apps stay listed with no window, so the list also works as a launcher.
- Quit Selected App and Quit Other Apps, as row actions and as hotkey commands.
- Trash row with Empty Trash through Raycast's own System Actions.
- Manage Pinned Apps for pins, badge tracking order, and the Trash pin.
