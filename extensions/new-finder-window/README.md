# New Finder Window

Open a new Finder window on the current macOS Space directly from Raycast. The extension creates a new window instead of reusing an existing Finder window on another Space.

## Usage

1. Open Raycast.
2. Search for "Open New Finder Window".
3. Press Enter.

## Preferences

Choose the directory that each new Finder window opens. The default directory is `~/Downloads`.

## Permissions

On first use, macOS may ask for permission to let Raycast control Finder. Allow access in **System Settings > Privacy & Security > Automation**.
