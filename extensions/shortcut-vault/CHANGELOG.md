# Changelog

## [Initial Release] - {PR_MERGE_DATE}

- Initial release of Shortcut Vault, a local-first keyboard shortcuts manager for macOS.
- Unified search across 530+ bundled shortcuts for 18 popular macOS apps and developer tools.
- Personal custom shortcut vault with creation, editing, duplication, and deletion.
- Fast shortcut search by command name, key symbols (`→`, `←`, `↑`, `↓`), and aliases (`cmd`, `esc`, `return`).
- Interactive dropdown filtering by source (Default/Custom), scope (Global/App/Webapp), and app owner.
- Versioned JSON import and export for local backups and easy transfers between Macs.
