# Copy Page as Markdown Changelog

## [Initial Version] - {PR_MERGE_DATE}

Convert any webpage to clean Markdown with one command using the Raycast Browser Extension.

### Features

- High-quality HTML to Markdown conversion using Turndown
- GitHub Flavored Markdown support (tables, strikethrough, etc.)
- Automatic removal of page structure elements (headers, footers, navigation)
- Preserves all content while removing UI chrome (scripts, styles, buttons)
- Handles multi-line links properly
- Works across all major websites
