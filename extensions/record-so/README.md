# Record for Raycast

Start screen recordings and take screenshots with [Record](https://record.so) — the
dead-simple screen recorder. No signup, no watermark, unlimited length.

## Commands

- **Record Screen** — start recording your entire screen (after the in-app countdown)
- **Record Window** — pick a window and record it
- **Record Area** — drag out a custom area and record it
- **Stop Recording** — stop and get the share link in your browser
- **Screenshot Area / Screen / Window** — instant screenshot share links
- **Open Record** — surface the Record panel

## Requirements

The [Record desktop app](https://record.so) must be installed. The commands drive it
through its `recordso://` deep links; if it isn't installed, the website opens instead.
