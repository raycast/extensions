# Lucide Extended

Search [Lucide Extended](https://lucideextended.applifted.work/)'s filled and duotone icons from Raycast, and copy them without leaving what you're doing.

Not affiliated with or endorsed by Lucide.

## Usage

Run **Search Icons** and type a name, tag or use case. `heart filled` narrows the search to one style, and Lucide's old names work too, so `circle-alert` finds `circle-exclamation-point`.

- **Style:** the dropdown in the search bar switches between all styles, filled and duotone.
- **Color:** **Change Color…** in the actions panel (`⌘K`) changes the preview color. Copied SVGs always use `currentColor`.
- **Primary action:** choose what Enter does in the command's preferences.

## Network

Icons load from [jsDelivr](https://www.jsdelivr.com/package/npm/lucide-extended-static), which serves the [`lucide-extended-static`](https://www.npmjs.com/package/lucide-extended-static) npm package, so new icons appear without an extension update. The extension collects no data.
