# IconsRoom — 276,000+ Icons

Search the whole open source icon universe from your keyboard — 276,000+ icons across 220 packs (Heroicons, Tabler, Lucide, Phosphor, Google Material, Font Awesome, Bootstrap and many more), rendered in a fast Raycast grid.

> 🔑 **Requires an IconsRoom lifetime license** — a single one-time purchase at [iconsroom.com/pricing](https://iconsroom.com/pricing), no subscription. The same key unlocks the Figma plugin, the VS Code and Chrome extensions, and the MCP server for AI agents. Raycast asks for the key on first run; full setup guide at [iconsroom.com/setup](https://iconsroom.com/setup).

## Actions

| Action               | Shortcut |
| -------------------- | -------- |
| Copy SVG             | ⏎        |
| Copy React component | ⌘J       |
| Copy CDN URL         | ⌘U       |
| Open on IconsRoom    | ⌘O       |

## Why it's fast

- Type a keyword → results appear as you type, across every pack at once
- Icons render as true SVGs straight from the IconsRoom CDN
- Copy lands on your clipboard ready to paste into code, Figma, or a design file

## Privacy

Your search keyword goes to IconsRoom's public search index and your license key is verified against iconsroom.com — nothing else ever leaves your Mac. No telemetry.
