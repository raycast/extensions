# Pomme Versions

Current macOS, iOS, iPadOS, watchOS, tvOS, and visionOS versions, with release dates, build numbers, and patched CVEs for recent releases, powered by [SOFA](https://sofa.macadmins.io/).

You can also download a version's firmware (`.ipsw`, from [ipsw.me](https://ipsw.me)) or, for macOS, its full installer package (`.pkg`), similar to [Mist](https://github.com/ninxsoft/Mist). Downloads are saved to the folder set in **Download Location** in the extension's settings.
