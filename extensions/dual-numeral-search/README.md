# Dual Numeral Search

Search Spotlight with both Eastern and Western Arabic numerals interchangeably.

## Features

- Automatically searches for both Eastern Arabic numerals (٠١٢٣٤٥٦٧٨٩) and Western numerals (0123456789)
- Real-time search results as you type
- Open files directly from search results
- Show files in Finder
- Copy file paths to clipboard

## How to Use

1. Open Raycast
2. Type "Search with Both Numerals"
3. Enter your search query with either numeral format
4. Navigate results and press Enter to open files
