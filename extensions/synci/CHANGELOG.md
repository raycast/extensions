# Synci Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Support macOS and Windows with native platform shortcuts.
- Search transactions with account, booking-date, and status filters.
- Check balances and currency totals, inspect sync dates, and create account Quicklinks.
- View brokerage and crypto holdings with account filters, position details, and currency totals.
- Explore recent booked outflows by merchant and currency, with enriched merchant logos when available.
- Monitor financial connection health and consent expiry.
- Sign in using Synci OAuth with PKCE and automatic token refresh.
- Reconnect Synci from the launcher to update account access and permissions with a clear return to the launcher on completion; cancellation preserves the saved session.
- Ask Synci in Raycast AI using five read-only tools backed by the existing Synci MCP server and shared OAuth session.
