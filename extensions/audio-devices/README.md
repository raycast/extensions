# Audio Devices

Switch the Windows device that plays sound, and the one that records it, from Raycast.

## Commands

**Set Output Device** and **Set Input Device** list what's plugged in. Press Enter to switch. Volume and mute are in the action panel.

**Cycle Output Device** and **Cycle Input Device** move to the next device and close. Bind those to a hotkey if you swap headsets a lot.

Enter changes normal playback or recording. Calls stay put. `Ctrl+Shift+Enter` moves calls as well. `Ctrl+Shift+K` only changes the calls device.

No extra install. It uses the audio devices Windows already exposes.
