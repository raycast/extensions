# Speak out Changelog

## v1.0.0 - 2025-12-18

- Add word pronunciation lookup using Free Dictionary API
- Display IPA (International Phonetic Alphabet) transcriptions
- Play pronunciation audio with `afplay` (macOS)
- Support multiple accents: US, UK, Australian
- Add Text-to-Speech fallback for words not in dictionary
- Support TTS voices: US (Samantha), UK (Daniel), AU (Karen), Indian (Veena)
- Add search history with LocalStorage persistence
- Copy IPA, word, or definition to clipboard
- Show part of speech and definitions
