# Rerout Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Create Short Link: optional custom domain and path; copies the short URL on success.
- My Links: loads every link page by page as you scroll; search matches short URL, code, destination and tags across all links; copy the short URL, open the destination or QR code, delete.
- Manage Tags: list tags with link counts; create and delete tags.
- Sandbox API keys (`rrk_test_…`) are detected and routed to the sandbox automatically.
