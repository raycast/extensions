# Spacetime Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Track time spent in each macOS Space from the menu bar
- Start, stop, and browse tracking sessions with a per-space breakdown and percentages
- Name your spaces and use those names everywhere time is shown
- Switch spaces from the menu bar, the Spaces command, or Ctrl + number shortcuts
- One-click Setup that configures the switching shortcuts and checks Accessibility
- Export a session to CSV, or save sessions automatically when they stop
- Optional year/month subfolders for saved CSV files
- Automatic daily session that starts a fresh session once a day
- Automatic pause when you're away from the keyboard, with a configurable idle threshold
- Track only the main display
