# Arabic Helpers

Arabic Helpers brings two small Arabic text utilities to Raycast.

Commands show two editable text areas and update the opposite representation immediately. Commands start empty by default. Enable **Preload Selected Text or Clipboard** to load selected text automatically and fall back to the clipboard, or load clipboard text explicitly from the Action Panel.


## Features

| Feature | Brief Info | Example |
| --- | --- | --- |
| **Convert Arabic Numerals** | Converts live between Western (`0–9`) and Arabic-Indic (`٠–٩`) digits while preserving the surrounding text and formatting. | `لدي 3 كتب` → `لدي ٣ كتب` |
| **Arabic Harakat** | Removes Arabic marks live while preserving the marked source. Optional Raycast AI can add harakat without changing the underlying text. | `بِسْمِ ٱللَّهِ` → `بسم الله` |

Press `⌘ ↵` in either command for the shared **Show Recent Clipboard** action, which lists Raycast's six most recent text entries.


## Development

This project uses npm to match the Raycast Store build environment:

```sh
npm install
npm run dev
```

Quality checks:

```sh
npm test
npm run lint
npm run build
```

The original shell utilities live in this [online](https://github.com/goodm4ven/CLI_MACOS_dot-zsh) repo.
