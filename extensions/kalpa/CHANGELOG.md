## [Initial Kalpa Raycast extension] - {PR_MERGE_DATE}

- Added Kalpa extension for Raycast with the following commands:
  - **Login to Kalpa** – connect your Kalpa account via short‑lived API token
  - **Search Links** – search across all saved links, videos, and CodePens
  - **Browse Universes** – browse links organized by universe (collections)
  - **Quick Save** – save the current browser tab or clipboard URL to Kalpa
  - **Recent Links** – view recently saved links grouped by time period
- Implemented Convex-backed Kalpa client with retry, timeout, and auth handling
- Added Raycast preferences for Kalpa API token configuration
- Included README with setup instructions, commands overview, and troubleshooting
