# Central Icon System Changelog

## [Initial Version] - 2026-07-27

- Search 2,078 Central Icon System icons by name, alias, and category
- Line and Solid variants side by side, or filtered to one
- Copy or paste SVG, name, JSX, or a style-aware import statement
- Export PNG at 16–512px — copy, paste, or save to Downloads
- Quick Look previews and preview backdrops (none, white, black, 50% gray)
- Pins and recently used, kept as separate lists
- Style controls matching centralicons.com: five corner options, three stroke weights
- **Update Icon Data** command to check for and install the latest upstream release
- Styles install from within the extension — no clone or build step required
