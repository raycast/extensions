# Magic 8-Ball 🔮

Get mystical answers to your burning questions with the classic Magic 8-Ball experience, right in Raycast!

## Features

- 🎱 **20 Classic Responses**: All the authentic Magic 8-Ball answers you know and love
- ⚡ **Lightning Fast**: Get instant answers to your yes/no questions
- 🎨 **Beautiful UI**: Clean HUD display with emoji indicators
- ❓ **Optional Question Input**: Ask a question or just shake the ball for a random answer
- 🌈 **Response Types**: Positive, neutral, and negative responses categorized appropriately

## How to Use

1. Open Raycast (⌘ + Space)
2. Type "Ask 8 Ball" or just "8 ball"
3. (Optional) Type your yes/no question
4. Press Enter and receive your mystical answer!

## Examples

- "Should I learn a new programming language?"
- "Will my code work this time?"
- "Is it time for a coffee break?"
- "Should I refactor this code?"

## Classic Responses

### Positive (10)
- It is certain
- It is decidedly so
- Without a doubt
- Yes definitely
- You may rely on it
- As I see it, yes
- Most likely
- Outlook good
- Yes
- Signs point to yes

### Non-committal (5)
- Reply hazy, try again
- Ask again later
- Better not tell you now
- Cannot predict now
- Concentrate and ask again

### Negative (5)
- Don't count on it
- My reply is no
- My sources say no
- Outlook not so good
- Very doubtful

## Development

```bash
# Install dependencies
npm install

# Development mode
npm run dev

# Build the extension
npm run build

# Lint and fix
npm run fix-lint
```

## Publishing to Raycast Store

To publish this extension to the Raycast Store:

```bash
npm run publish
```

Make sure you have:
1. A Raycast account
2. Followed the [Raycast Store Guidelines](https://developers.raycast.com/basics/prepare-an-extension-for-store)
3. All assets properly configured
