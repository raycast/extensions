# Assets

This directory contains the assets for the Magic 8-Ball extension.

## Files

### extension-icon.png
- The main icon for the Magic 8-Ball extension
- Should be a square image (512x512px recommended)
- Represents the extension in Raycast and the Store

## Design Guidelines

For Raycast Store submission, ensure:
- Icons are clear and recognizable
- Use simple, clean designs
- Follow Raycast's design guidelines
- PNG format with transparency if needed

## Creating Your Own Icon

If you want to customize the icon:
1. Create a 512x512px image
2. Use the 🎱 or 🔮 theme
3. Keep it simple and recognizable at small sizes
4. Export as PNG
5. Name it `extension-icon.png`
