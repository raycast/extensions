# Capso for Raycast

Trigger [Capso](https://github.com/lzhgus/Capso) screenshots, OCR, video recordings, and history directly from Raycast.

## Features

- 📸 **Area & Window Capture:** Quickly select and snap any screen region or active window.
- 🔤 **Instant OCR (Text Extraction):** Extract text directly from screen elements to your clipboard.
- 🎥 **Screen Recording:** Start and stop video recordings seamlessly.
- 📜 **Scrolling Capture:** Capture full-length scrollable webpages and documents.
- 🕒 **Screenshot History:** Open Capso's capture gallery to browse, copy, or manage past recordings and screenshots.
- 🌐 **Translate:** Capture text and translate instantly.
- ⚡️ **Zero-Config Sync:** Automatically reads and syncs with your custom keyboard shortcuts configured in Capso Preferences.

## Prerequisites

- [Capso](https://github.com/lzhgus/Capso) must be installed and running on macOS.
  ```bash
  brew tap lzhgus/tap
  brew install --cask capso
  ```

## Permissions

Raycast requires **Accessibility** permissions (`System Settings -> Privacy & Security -> Accessibility`) to send keystroke events to Capso.
