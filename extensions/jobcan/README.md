# Jobcan

Manage your Jobcan time tracking via Raycast.

Jobcan gets the job done, but the attendance workflow can be painful: too many clicks, form fields that are easy to miss, and repetitive end-of-month fixes that should not require babysitting a web UI. This extension exists to make the common attendance tasks faster from Raycast, especially checking the month and submitting missing clock-in / clock-out requests.

This project is inspired by [calendar2jobcan](https://github.com/m13/calendar2jobcan), which showed that Jobcan attendance work can be automated instead of handled manually every time.

ℹ️ This extension is built around the Jobcan attendance product used in Japan. I am not sure how Jobcan is used or localized in other countries.

## Features

- View attendance of current month
- View attendance of previous months (capped at three)
- Submit attendance for an "Absent" day
- Submit attendance for all "Absent" days of the month
