# API Manager Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Add, edit, and delete API keys with name and key as required fields
- Optional fields: provider, URL, expiry, and tags
- Expiry supports entering days (e.g. `90`) or an exact date (`YYYY-MM-DD`)
- Visual expiry status: active, expiring soon (≤7 days), and expired
- Filter keys by expiry status from the search bar dropdown
- Keys grouped by provider in the list view
- Detail panel showing key info and metadata
- Copy API key to clipboard with one shortcut (⌘C)
- Open provider URL directly from the action panel
