# Ask Dust.tt

Query the [dust.tt](https://dust.tt/) service extention for [Raycast](https://www.raycast.com/)

## Setup

You need a dust.tt account to use this extension.

## Connection

### Using your Dust account

Raycast will automatically show a popup to sign in with Dust.

## Commands

### Ask Dust

Directly ask something to the Dust assistant.

If you ask a question with the parameter, you will get a form to add one, auto-filled with the currently selected text.

### Ask ...

Select a specific dust assistant to query

### Replace Selection with Agent

Silently sends the currently selected text (in any app) to a specific
custom agent and replaces the selection with the answer — no window, just
background notifications. Great for grammar fixes, translations, or
rewrites. Configure it via "Set up Replace Selection" below (you can't
launch it directly — it needs a Quicklink to know which assistant to use).

### Set up Replace Selection

Pick any Dust assistant, then "Create Quicklink…" to save a dedicated,
freely-renamable shortcut that silently replaces your selected text with
that assistant's answer. Create as many as you want, one per assistant,
and assign each its own hotkey from Raycast Preferences → Quicklinks.
