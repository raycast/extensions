# Linear Project Hub

Search your Linear projects and open a focused project briefing hub, right from Raycast.

Unlike a generic project list, this surfaces everything you need to get context on a project in one place:

- **Summary** — the project's Linear description and content
- **Latest pulse updates** — recent project updates with health status, plus a dedicated, navigable pulse reader (`⌘⇧U`)
- **Resources** — external links and documents attached to the project
- **Slack** — one-click into the connected Slack channel
- **Open pull requests** — GitHub PRs connected to the project's open issues, aggregated automatically
- **Issues** — browse the project's issues (`⌘⇧I`), grouped by open/closed

You can open any project in the browser or directly in the Linear desktop app (`⌘L`).

## Authentication

The extension uses Linear OAuth. On first run you'll be asked to sign in to your Linear workspace. It requests read-only access and stores no data of its own — every user only sees data from their own authenticated Linear account.

## Commands

- **Search Projects** — search projects by name and open the briefing hub.
