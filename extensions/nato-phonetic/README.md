# NATO Phonetic

Convert text to the NATO phonetic alphabet instantly in Raycast.

## Features

- **Real-time conversion** - Type text and see the NATO phonetic spelling immediately
- **Pronunciation guide** - See how to pronounce each letter (e.g., AL-FAH, BRAH-VOH)
- **Text-to-speech** - Press ⌘S to hear the phonetic spelling spoken aloud
- **Quick copy** - Copy phonetic text, pronunciation, or both to clipboard

## Usage

1. Open Raycast and search for "NATO Phonetic"
2. Type or paste text to convert
3. Press Enter to copy, or ⌘S to speak

## Examples

| Input | Output |
|-------|--------|
| hello | Hotel Echo Lima Lima Oscar |
| SOS | Sierra Oscar Sierra |
| 123 | One Two Three |

## Actions

| Action | Shortcut |
|--------|----------|
