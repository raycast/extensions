# Changelog

## [1.0.0] - {PR_MERGE_DATE}

### Added
- Initial release of Playtime extension
- Automatic Steam installation detection (macOS & Windows)
- Local file reading for zero-setup experience
- Steam API fallback support for public and private profiles
- Game library search and filtering
- Multiple sort options (Total Hours Played, Name, File Size, Installed)
- Launch and uninstall game actions (for installed games)
- Copy playtime to clipboard action
- Time display format preferences (hours/days)
- Game box art display from Steam CDN
- File size calculation for installed games
- Recent playtime display (last 2 weeks) when available
- Total library playtime display
- Contextual filter options (File Size and Installed only show when games are installed)
- Cross-platform support (macOS and Windows)
- View game on Steam store action
- Refresh library action
- Open preferences action
