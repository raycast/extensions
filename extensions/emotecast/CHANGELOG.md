# Emotecast Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Search 7TV, BetterTTV and FrankerFaceZ emotes from a single grid
- Paste as a file at emoji size (`⏎`) or sticker size (`⇧⏎`), animation preserved
- Variants are picked by measured pixel height, so the output is exact even when
  a provider reports the wrong dimensions
- Toggle animated-only results, hide NSFW emotes behind a placeholder
- Prepared files are cached, so repeat pastes are instant
