# trip1 Hotel Search

Search hotels on [trip1](https://trip1.com) straight from Raycast: about 3 million properties in 200+ countries.

Enter a destination and dates, browse the available hotels with their total stay price, and open one on trip1 to book it. trip1 takes payment in crypto: USDC, BTC, ETH and 120+ other currencies.

No account or API key is needed. Prices are for 2 adults in one room.

The extension uses trip1's public [MCP server](https://trip1.com/agents).
