# RedReplier for Raycast

Go through the conversations RedReplier found for your product without leaving Raycast, using your [RedReplier](https://redreplier.com) account.

## Setup

1. Open [API Tokens](https://redreplier.com/api-tokens) in RedReplier and create a key.
2. Run any RedReplier command in Raycast and paste the key when asked.

Approving mentions and changing keywords needs a role that can edit RedReplier data.

## Commands

| Command | What it does |
| --- | --- |
| Search Mentions | Read scored mentions with the reason for each score. Copy the suggested reply and open the conversation in one step, then approve or reject the mention. |
| Search Websites | See your monitored websites and turn their keywords on or off. |
| Add Keywords | Add keywords to a website, one per line or separated by commas. Keywords over your plan's allowance wait as pending until you activate them in RedReplier. |

RedReplier never posts for you. You read the draft, change it and post it yourself.
