# Text Utils Changelog

## [1.0.0] - {PR_MERGE_DATE}

### Added

- **Text Utils** — unified list view showing all transformations at once with a live before/after preview panel and inline result subtitles
- **AI transforms** (Raycast Pro) — Fix Grammar, Make Concise, Make Formal, Make Casual, Summarize, Bullet Points, Translate to French/Spanish
- **Bracket swaps** — convert between `{}`, `[]`, and `()` in all 6 combinations
- **Accent tools** — remove diacritics, encode accented characters to HTML entities (é → &eacute;) and decode back
- **HTML tools** — encode/decode special characters (& < > " '), URL encode/decode
- 30 individual no-view commands: replace quotes, count words/letters/vowels/consonants/spaces/lines, extract emails/IPs/IDs/URLs, sort/reverse/deduplicate/number lines, trim whitespace, remove empty lines, unwrap lines, markdown to plain text, reverse text, and more
