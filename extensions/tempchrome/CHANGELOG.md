# TempChrome Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Quick Launch command that creates a temp profile and opens Chromium with no user interface
- Root list with Launch Now, Launch with Options…, Recent Launches…, Manage Temp Profiles…, and Install or Update Chromium…
- Auto-cleanup that deletes the profile after the Chromium window closes
- 17 launch options, including start URL, browsing mode, app mode, window geometry, proxy, and custom flags
- Profile manager that shows the size of each profile and can relaunch or delete it
- Live log viewer that tails `chrome_debug.log` for any profile
- Built-in Chromium installer with resumable downloads and cancel support
