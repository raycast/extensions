# Account Manager

Manage multiple accounts across different projects and environments directly from Raycast. Perfect for developers who need to switch between Dev, Staging, and Production accounts frequently.

## Features

- **Project & Environment Grouping**: Organize your accounts by project and environment tags.
- **Auto-fill**: Automatically fill username and password into login forms using AppleScript (macOS).
- **Password Generator**: Generate strong, secure passwords with a single shortcut (`Cmd + G`).
- **Data Portability**: Export and import your account data as JSON for backup or migration.
- **Quick Actions**: Copy/Paste usernames and passwords, or open login URLs with customizable shortcuts.
- **Privacy First**: All data is stored locally on your machine.

## How to Use

1. **Add Account**: Press `Cmd + N` or use the "Add New Account" item.
2. **Setup Automation**: Fill in the "Login URL" to fetch the site's favicon automatically.
3. **Login**: Select an account and press `Enter` to auto-fill (requires Accessibility permissions for Raycast).
4. **Manage**: Use `Cmd + E` to edit or `Ctrl + X` to delete accounts.
5. **Pinning**: Use `Cmd + Shift + P` to keep your most-used accounts at the top.

## Privacy

Account Manager stores all data locally in Raycast's internal storage. No data is ever sent to external servers.
