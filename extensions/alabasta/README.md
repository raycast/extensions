# Alabasta for Raycast

Create, find, and update Alabasta tasks, projects, and documents without leaving Raycast.

## Setup

1. Install **Alabasta** from the Raycast Store.
2. Run any command and select **Connect Alabasta**.
3. Sign in at Alabasta, choose one of your workspaces, and approve access.

The extension requests read and write access only to the workspace you select during authorization. You can remove the connection from Raycast preferences.
