# Ask Anybody

A Raycast extension to quickly open a new chat in your favorite AI assistant with a query.

## Supported Services

| Command | Service | Opens in |
|---------|---------|----------|
| Ask ChatGPT | ChatGPT | Browser |
| Ask Claude | Claude | Browser |
| Ask Claude (Desktop) | Claude | Desktop app |
| Ask Gemini | Gemini | Browser |
| Ask Grok | Grok | Browser |
| Ask Mistral | Mistral | Browser |

## Usage

1. Open Raycast
2. Type a command name (e.g. "Ask Claude")
3. Enter your query
4. A new chat opens with your query pre-filled

## Development

```bash
npm install
npm run dev
```
