# KeyProbe Changelog

## [Initial Release] - {PR_MERGE_DATE}

- Native translucent panel that highlights keys as they're pressed and marks them tested once released.
- Built-in ANSI, JIS, and ISO layouts with automatic hardware-based detection.
- Searchable **Select Keyboard Layout** command covering 50+ bundled custom keyboard layouts, switchable live while the panel is open.
- Non-testable state for keys with no fixed OS keycode (layer keys, media keys) so they don't read as dead keys.
- Reset button to clear all tested state without closing the panel.
