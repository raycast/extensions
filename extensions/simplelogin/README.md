# SimpleLogin

Manage your SimpleLogin Account: view, create and manage aliases.

## Features
- **Alias Management**: Easily view, create and manage email aliases to protect your privacy.
- **Browser Integration (macOS only)**: Automatically fetch the active browser tab's URL for quick alias creation using AppleScript.

## Usage
- Open the Raycast extension and navigate to the SimpleLogin commands.
- Use the commands to create or manage your aliases effortlessly.

## Compatibility
- **macOS**: Full support including browser integration via AppleScript for automatic URL detection and alias prefix/note pre-filling.
- **Windows**: Core functionality supported. Browser URL pre-filling is disabled due to reliability issues with cross-browser URL extraction on Windows.
