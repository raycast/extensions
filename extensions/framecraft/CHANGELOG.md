# FrameCraft Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Capture the paused frame from Jellyfin, Emby (experimental), IINA or QuickTime at full resolution and bit depth, including HDR
- Read only the needed window of large remote MKV/WebM and MPEG-TS/M2TS files over parallel HTTP Range requests
- Experimental Blu-ray ISO / BDMV support through libbluray
- Subtitle Layer Studio: switch and stack subtitle tracks, adjust position, OCR image subtitles; saves automatically
- Export A/B clips without re-encoding
- Background task queue with gallery, retry and cancel
