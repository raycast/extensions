# Quick Math Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Initial release of Quick Math (forked and enhanced from Quick LaTeX)
- Support local LaTeX rendering using `latex` and `dvipng` (no external API calls)
- Add Typst rendering support via `typst` CLI
- Real-time adaptive dark/light preview
- One-click copy of tightly-cropped, 512 DPI transparent PNGs to clipboard
- Support custom LaTeX preambles for additional packages and macros
