# The Default Browser

A [Raycast](https://raycast.com) extension that provides commands and utilities that automatically adapt to your default browser — so you never have to reconfigure when you switch.

## Features

- **Open My Browser** — Focus or launch your default browser instantly, without hardcoding a specific app.
- **Set My Browser** — Browse all browsers registered on your Mac and set any of them as your system's default. Your current default is highlighted with a checkmark.

## Usage

1. Install the extension in Raycast.
2. Run **Open My Browser** to focus or launch your default browser.
3. Run **Set My Browser** to pick any installed browser and make it your system's default. Confirm the system dialog if one appears.
4. To bind a hotkey: open Raycast Preferences → Extensions → My Browser, then assign a keyboard shortcut to any command.

Switching your default browser? Everything keeps working — no hotkey changes needed.
