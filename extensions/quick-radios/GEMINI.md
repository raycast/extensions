# Project Guidelines & Preferences

## Version Control (Git) Discipline
- **Initialize Git Repositories**: When starting out on any software project or codebase that does not already have version control, initialize a Git repository (git init) with a proper .gitignore.
- **Commit After Major Changes & Fixes**: At the end of every major change, feature addition, optimization, or bug fix, stage the changed files and commit them.
- **Descriptive Commit Messages**: Write clear, professional commit messages following conventional commit formatting (e.g., `feat:`, `fix:`, `perf:`, `refactor:`) with bullet points summarizing the key modifications.
