# ScreenOCR for Windows Changelog

## [Initial Release] - {PR_MERGE_DATE}

- Recognize Text: drag-select area capture with frozen-screen overlay, local OCR via Windows.Media.Ocr
- Recognize Text on Entire Screen: full virtual-screen (all monitors) OCR
- Recognize Text in Clipboard Image: OCR images or copied image files from the clipboard
- Auto or pinned recognition language, driven by installed Windows language packs
- Copy / paste / both result actions, ignore-line-breaks option, confirmation HUD
- CJK spacing cleanup, automatic up/downscaling for accuracy and engine limits
- Per-monitor-v2 DPI awareness, multi-monitor support, Esc/right-click cancel
