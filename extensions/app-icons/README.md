# App Icons Finder

Search the App Store and download official icons as PNG. English only.

Queries and the selected region go to Apple. Uwarp does not receive them.

## Develop

```bash
cd raycast-plugins/app-icons
npm install
npm run icons
npm run dev
```

Open Raycast and run **Search App Icons**.

## Actions

- **Download PNG** — saves to `~/Downloads` via `sips`
- **Copy Image** — copies the PNG file
- Region switch lives in the search bar accessory

Change the default region in Raycast Preferences → Extensions → App Icons Finder.
