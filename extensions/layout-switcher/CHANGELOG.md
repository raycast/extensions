# Layout Switcher Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Convert text between a macOS Cyrillic layout (Russian, Ukrainian or Belarusian) and English (QWERTY)
- Automatic direction detection from the content
- Works on the current selection, or the whole field via Cmd+A
- Selectable Cyrillic layout in the command preferences
- Key maps dumped from the macOS system layouts, so they match Apple's layouts (not Windows ЙЦУКЕН)
