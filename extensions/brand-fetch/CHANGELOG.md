# Brandfetch Changelog

## [Windows support] - 2026-10-31

- Add support for Windows platform
- Add a configurable download path and a Finder/File Explorer action after downloads
- Replace Axios with the built-in `fetch` API
- Add copyable error details for search, brand loading, and downloads using `raycast-kit`
- Bump all dependencies to the latest

## [Bug Fixes] - 2025-05-21

- Add support for url queries with `scheme`

## [New Features] - 2024-07-25

- Support free search API
- Support input as both query or url
- Add multi stage preview for logos
