# Antinote Changelog

## [Fix crash when the database is missing] - 2026-10-12
- Search Notes and Search Slotted Notes no longer crash when Antinote's database file does not exist; they show a message instead: [#30498](https://github.com/raycast/extensions/issues/30498)

## [v2.0.0] - 2026-08-10
- Added support for Antinote v2.* (Beta)
- Added "Search Slotted Notes" command for Antinote v2.* (Beta)
- Added "Execute Timer Command" command for Anitnote v2.* (Beta) 
- Added "Create New Note from Selection" command for both Antinote v1.* and v2.* (Beta)

## [v1.0.2] - 2025-05-22
- Support for Setapp version of Antinote

## [v1.0.1] - 2025-03-27
- Fixed a problem in code resulting in search functionality not working
