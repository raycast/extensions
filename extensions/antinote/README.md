# Antinote

Extension to control Antinote app with Raycast.
This extension supports both version 1.* and 2.* (beta), including some of the
features being only available in the beta version. Interested in beta? [Join our
Discord](https://discord.gg/qDvCVnhqd)!

## Features

### Compatible with both v1 and v2 (beta)
- Create new note (optionally with content) 
- Create new note with selection
- Search notes
- Pin Antinote to top

### Only available in v2 (beta)
- Execute timer command
- Search slotted notes
