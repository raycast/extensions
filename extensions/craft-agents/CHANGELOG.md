# Craft Agents Changelog

## [Initial Release] - {PR_MERGE_DATE}

- Open a new Craft Agents session (`New Session`, `New Session (Quick)`).
- Start a session and auto-send a message (`Quick Ask`).
- Browse and resume recent sessions (`Resume Session`), with flag / copy actions.
- Browse flagged sessions with inline unflag / delete actions (`Flagged Sessions`).
- Jump to any built-in view — sessions, sources, skills, settings (`Open View`).
- Browse configured sources and trigger OAuth inline (`Open Source`).
- Merge and browse global + workspace skills (`Open Skill`).
- All commands powered by the `craftagents://` deeplink protocol — no IPC, no network.
