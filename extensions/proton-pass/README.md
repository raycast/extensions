# Proton Pass

Interact with Proton Pass in Raycast

> [!NOTE]
> This extension is still in development. If you want to use this extension to access your Proton Pass credentials in Raycast, you must
create a `.pgp` proton backup file (at the moment this extension only supports that file format) and import it.

> [!Warning]
> Proton Pass, at the moment, does not provide any way to synchronize your vaults into this extension.
> Therefore, whenever you added your credentials (such as passwords, notes, etc) are not automatically updated unless you
> manually re-export your proton pass backup into a `.pgp` and re-import it into this extension.
