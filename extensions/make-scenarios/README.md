# Search Make Scenarios

Search, browse, and open [Make.com](https://www.make.com) scenarios across all your organizations, teams, and zones.

## Features

- Search scenarios across all organizations and teams in one place
- Search and jump into an organization's scenarios page
- Unified search across scenarios and organizations
- Supports multiple Make.com zones (EU1, EU2, US1, US2, Celonis)

## Setup

1. Get your API token from your [Make.com profile settings](https://www.make.com/en/api/documentation)
2. Open the extension preferences and paste the token value (without the `Token ` prefix)
3. Select your Make.com zone

## Commands

- **Search Make** — Unified search across both scenarios and organizations
- **Search Make Scenarios** — Search and browse scenarios across all organizations
- **Search Make Organizations** — Search and jump into an organization's scenarios page
