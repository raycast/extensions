# Flickr Uploader Changelog

## [Initial Version] - 2026-05-08

Initial release of Flickr Uploader extension.

### Features

- Upload photos to Flickr with title, description, and tags
- Add photos to existing albums or create new albums
- Post photos to multiple Flickr groups
- Privacy controls (private, public, friends, family, friends & family)
- OAuth 1.0a authentication
- Form drafts support to prevent data loss
