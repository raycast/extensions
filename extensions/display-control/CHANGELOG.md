# Display Control Changelog

## [Initial Version] - 2026-11-24

- You can select a display and adjust its speaker volume, brightness, and contrast with keyboard shortcuts.
- The detail pane shows control levels as compact bars with percentages and configurable reset defaults.
- Rapid key repeats accelerate adjustments, and pausing restores the base step.
- The setup screen opens Raycast’s Brew extension to install m1ddc for external displays on Apple Silicon.
- The bundled native helper controls built-in display brightness and Mac speaker volume without a separate app.
- The list retains known levels during temporary refresh failures and supports switching displays during resets.
