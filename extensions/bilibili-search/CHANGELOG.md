# Bilibili Search Changelog

## [Initial Version] - 2026-05-15

- Add Bilibili search for videos, anime, movies/TV, live rooms, articles, and users.
- Add QR-code login with Bilibili account cookie storage in Raycast local cache.
- Add watch history command with pagination and rich video details.
- Add favorites command with folder selection and cross-folder search.
- Add popular video browsing when the search query is empty.
- Add detail views with covers, metadata, statistics, tags, scores, cast, and staff.
- Add actions to open Bilibili links in the browser and copy result URLs.
