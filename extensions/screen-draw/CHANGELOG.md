# Screen Draw Changelog

## [Fix Install on Current Raycast] - 2026-10-23

- Target Raycast API 1.x so the extension installs on the current Raycast release (it required v2.8.2, which is not out yet)

## [Initial Version] - 2026-10-22

- Draw on Screen command that toggles a transparent drawing overlay on every display
- Pen, highlighter, arrow, rectangle and ellipse tools
- Six colors, adjustable stroke width, undo and clear
