# Get Api Key
HockeyStack extension for Raycast to get the HockeyStack customer's API keys easily.

## Install dependencies
```shell
$ npm install
```

## Start the project
```shell
$ npm run dev
```

## Usage
In Raycast, start typing `apikey`. The placeholder for the customer to look for will appear.
Press `TAB` and enter the customer you are looking for.
If it is a valid customer, the API key and domain will appear in Raycast.
Just press `enter`, and the API key will be copied to the clipboard.

## Notes
After starting the project and running it on Raycast, the extension will be already installed.
There is no need to keep the project running.
