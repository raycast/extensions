# Uttero for Raycast

Control [Uttero](https://danielgamrot.cz/nastroje/uttero) voice dictation directly from Raycast — start dictating, switch styles, browse history, and more. All commands work silently in the background without activating or flashing the Uttero window.

## Commands

| Command | Description |
|---|---|
| **Start Dictation** | Start voice dictation with the currently active style |
| **Dictate with Mode** | Pick any of your Uttero styles and start dictating immediately |
| **Transcript History** | Browse and copy the last 20 dictation transcripts |
| **Copy Last Transcript** | Copy the most recent transcript to the clipboard |
| **Insert Last Transcript** | Insert the most recent transcript at the cursor position |
| **Search Styles** | Browse and switch between your Uttero styles |
| **Toggle Offline Mode** | Switch between cloud and on-device (WhisperKit) transcription |
| **Uttero Status** | Menu bar item showing today's word count and dictation stats |
| **Open Uttero Settings** | Open the Uttero settings window |

## Requirements

- macOS 14+
- [Uttero](https://danielgamrot.cz/nastroje/uttero) v1.4.9+ running in the background

## Tips

- Assign a keyboard shortcut to **Dictate with Mode**: open the command, hover over a style, press `⌘K` → Assign Shortcut. This gives you one-key access to any specific style.
- All styles you create in Uttero appear automatically in **Dictate with Mode** — no extension update needed.
