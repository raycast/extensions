# Changelog

## [Unreleased]

### Added
- Start Dictation command — triggers Uttero dictation via `uttero://dictate`
- Dictate with Mode command — pick a style from a list and start dictating immediately
- Transcript History command — browse and copy the last 20 Uttero transcripts (reads `history-snapshot.json`)
- Copy Last Transcript command — copies most recent transcript to clipboard (no insert)
- Insert Last Transcript command — inserts most recent dictation at cursor
- Search Styles command — browse and switch Uttero styles (renamed from Select Style)
- Toggle Offline Mode command — switches Uttero between cloud and on-device transcription
- Uttero Status menu bar item — shows today's word count and dictation stats in the macOS menu bar
- Open Uttero Settings command — opens Uttero settings window
