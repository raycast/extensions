# Clawdbot for Raycast

Chat with your [Clawdbot](https://clawd.bot) AI agent directly from Raycast.

## Features

- **Quick Chat** — Send a message with inline input, get a persistent response view
- **Chat** — Full conversation interface with history
- **Gateway Status** — Monitor your Clawdbot gateway, channels, and sessions
- **Open Webchat** — Jump to the browser-based chat interface

## Requirements

- [Clawdbot](https://clawd.bot) installed and running locally
- Gateway must be accessible at `http://127.0.0.1:18789` (default)

## Commands

| Command | Description |
|---------|-------------|
| Quick Chat | Fast inline message → response view |
| Chat with Clawdbot | Conversational chat with history |
| Gateway Status | See gateway, channels, sessions status |
| Open Webchat | Open browser webchat |

## Configuration

- **Webchat URL** — Override the default gateway URL
- **Agent ID** — Target a specific agent (leave blank for default)

## Installation

1. Install Clawdbot: `npm install -g clawdbot`
2. Start the gateway: `clawdbot gateway start`
3. Install this extension from the Raycast Store
