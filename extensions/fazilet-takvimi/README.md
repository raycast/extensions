# Fazilet Takvimi - Raycast Extension

A Raycast extension for displaying Islamic prayer times using Fazilet Takvimi data.

## Features

- Display daily prayer times
- Real-time countdown to the next prayer
- Support for all cities and districts in Turkey
- Automatic data caching
- Save and remember your location preferences

## Data Source

This extension fetches prayer times from the official [Fazilet Takvimi](https://fazilettakvimi.com/) API.

## Usage

1. Open the extension from Raycast
2. By default, Istanbul prayer times are displayed on first use
3. To change city, use the `Change City` menu and select your desired city
4. To select district, use the `Select District` menu and choose your district
5. Your preferences are automatically saved and used on next launch

## Features Detail

- **Automatic Updates**: Prayer times are automatically updated daily
- **Live Countdown**: Real-time countdown to the next prayer time
- **Fast Access**: Data is cached for quick loading
- **Location Selection**: Support for all 81 provinces and their districts

## Technical Details

- Built with React and TypeScript
- Developed using Raycast API
- Data caching with LocalStorage
- Fazilet Takvimi API integration
