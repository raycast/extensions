# WeInc

Build websites with [WeInc](https://we.inc) AI and browse your WeInc projects, right from Raycast.

## Commands

- **Build Website** — describe the site you want, and WeInc opens in your browser and starts building it. No account setup needed to start.
- **List Projects** — browse your WeInc projects and open a live preview of any of them.

## Setup

The **List Projects** command requires a WeInc API key:

1. Sign in at [my.we.inc](https://my.we.inc)
2. Generate an API key (starts with `wk_`) from your agency dashboard
3. Paste it into the command's preferences in Raycast
