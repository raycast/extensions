# No as a Service

Get a creative, random reason to say "no" to any request.
Inspired by the No-as-a-Service API. [https://github.com/hotheadhacker/no-as-a-service]

## Features
- 🎲 Generate random, humorous, or professional rejection reasons.
- 📋 Copy reasons directly to your clipboard with a single keystroke.
- 🔄 Refresh instantly to find the perfect excuse.

## How to use
1. Open Raycast and type "Random No".
2. View the generated reason.
3. Press `Enter` to copy to clipboard or `Cmd + R` to get a new reason.
