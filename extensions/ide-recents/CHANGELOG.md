# IDE Recents Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Search and open recent projects from VS Code, Trae, and Antigravity IDE in a single list.
- Filter recents by IDE, and switch between all, active, and missing projects.
- Open a project with any supported IDE straight from the action panel.
- Copy a project path, or a terminal command that opens the project in its IDE.
- Hide stale entries from the list, or delete them from the IDE databases (a `.bak` backup is kept next to each database).
