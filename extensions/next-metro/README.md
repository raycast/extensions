# Next Metro

Real-time Paris metro departures in Raycast.

## Setup

1. Get an API key from [prim.iledefrance-mobilites.fr](https://prim.iledefrance-mobilites.fr) (subscribe to "Next Departures" API)
2. Run **Configure Stop** command to select your line and station
3. Use **Check Next Metro** to view departures
4. Use **Next Metro Menu Bar** to show next metro departure in the menu bar

## Commands

- **Check Next Metro** — View upcoming departures at your configured stop
- **Configure Stop** — Select your metro line and station
- **Next Metro Menu Bar** — Show next metro departure in the menu bar
