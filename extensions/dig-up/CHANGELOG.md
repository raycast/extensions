# Dig Up Changelog

## [Initial Version] - {PR_MERGE_DATE}

- **Dig Up**: search screenshots, photos, PDFs, documents, recordings, videos and code by meaning and by words.
  Keyword results show at once and results by meaning replace them after a short pause; results are grouped by kind,
  with the weaker ones folded away. A detail pane shows the page, frame, passage or lines of code that matched.
- **Dig Up Pictures**: the same search as a picture grid, with a kind filter that counts each kind's results.
- **Dig Up Folders**: choose the folders and code folders to search, skip folders and file types, see how long the
  first pass takes, and check that macOS lets Raycast read them.
- **Dig Up Status**: indexing progress in the menu bar, with Pause / Resume, Index Now and Rebuild Index.
- **Index Now**, **Pause or Resume Indexing** and **Rebuild Index** commands.
- Results open where they matched: a PDF page with its words in the PDF app's search, a recording at its moment in
  QuickTime Player or IINA, code at the line in your editor.
- A one-time setup downloads EmbeddingGemma 2 (865 MB) and llama.cpp, or reuses DigUp's copy of the model.
