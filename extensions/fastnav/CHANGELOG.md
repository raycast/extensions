# FastNav Changelog

## [Initial Release] - {PR_MERGE_DATE}

- Optionally search and run menu commands across all running macOS applications, with results from the previously focused application ranked higher.
- Collapse duplicate Apple-menu and Services results when searching all applications.
- Search visible buttons, links, tabs, rows, and controls by default.
- Match displayed keyboard shortcuts and learn from recently used actions.
- Filter the search to one application from FastNav's Raycast command.
