# GitHub Repository Browser

Browse and search repositories across your personal GitHub account and organizations. Switch between them, see open issue and pull-request counts at a glance, and open a repository, its issues, or its pull requests without leaving Raycast.

## Setup

1. Generate a [GitHub personal access token](https://github.com/settings/tokens) with at least the **repo** and **read:org** scopes.
2. Open Raycast → **Browse GitHub Repositories** → set the token in the extension preferences.
3. Use `⌘` `P` to switch between your personal repos and your organizations.
