# Changelog

## [1.0.0] - 2024-02-02

### Added

- Initial release
- Chat command with real-time streaming responses
- Status command showing gateway health and channel connections
- Skills command to browse and manage installed skills
- Cron Jobs command to view and trigger scheduled tasks
- Device identity management with Ed25519 keypairs
- Support for local and remote (Tailscale) connections
- Password authentication for Funnel mode
