## Suggested Store Copy

### Manifest Description

`Native Raycast console for Tryambakam Noesis: run Selemene readings, workflows, Daily Witness, and pulse insights with local history.`

### Longer Listing Description

Tryambakam Noesis brings Selemene-powered readings into a compact Raycast surface. Run single engines, multi-engine workflows, and Daily Witness reflections, keep the current pulse in the menu bar, and review a readable local history backed by SQLite instead of a browser dashboard.

### Positioning Notes

- Lead with `Tryambakam Noesis`, not `Selemene Engine`.
- Treat `Selemene` as the powered-by backend layer.
- Emphasize native Raycast flow, readable results, explicit routing, and local continuity.
- Avoid promising transformation outcomes. Keep the copy practical and operator-focused.
