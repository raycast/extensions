# Fontshare

Search, preview, download and install the free fonts of [Fontshare](https://www.fontshare.com) from Raycast.

No account or API key is required. Data comes from the API that powers fontshare.com.

## Search Fonts

- Browse the catalogue as a grid of "Aa" previews drawn in each font, or as a list (⌘⇧L to switch)
- Search by font name, designer, publisher, category or tag, and filter by category, use, variable fonts or license
- Open a font to read its story, styles, variable axes, license, tags, OpenType features and pairings
- Download the font family to your Downloads folder (⌘S)
- Install the font family on your Mac (⌘⇧I)
- Copy the CSS `@import`, the HTML `<link>` or the `font-family` declaration for the web

## Search Font Pairings

- Browse the pairings curated by Fontshare, previewed with their headline and body text
- Download or install both styles of a pairing as one kit, or copy the CSS that loads them

## Preview Text

- Type a word or a sentence and see it set in every Fontshare font
- Change the text without leaving the command (⌘E), and filter fonts by name, designer, category or tag

## Installing Fonts

Install Family and Install Pairing are available on macOS. They copy the desktop fonts (OTF when available, otherwise TTF) from the Fontshare download to `~/Library/Fonts`, replacing files with the same name. Remove them from Font Book if you no longer need them.

Previews are rendered locally from the Fontshare font files and cached in the extension's support folder.
