# Done Bear

[Done Bear](https://donebear.com) is a local-first GTD task manager. This extension lets you capture, search, and complete tasks, browse Today, Inbox, Anytime, Upcoming, and Someday, manage projects, and keep Today in the menu bar. Everything stays in sync with Done Bear on web, desktop, iOS, Chrome, and the CLI.

## Sign in

The extension uses OAuth. The first time you run a command, Raycast prompts you to connect your Done Bear account. If your session expires or you sign in again, the extension uses your new token automatically.
