# Changelog

## [Initial Version] - 2026-08-12

- Parse decimal, hexadecimal, and binary values with 8, 16, 32, or 64-bit widths.
- Show all bits set to `1` before the complete bit list.
- Switch between high-bit-first and low-bit-first display order.
- Add optional labels for fault and status bits.
- Copy or paste individual bit values and complete reports.
- Reject values that exceed the selected bit width instead of truncating them.
- Treat unprefixed values as decimal in Auto Detect mode.
- Reject empty values and digits that do not match the selected number base.
- Accept an optional value argument from selected text or the command search bar.
- Return to the input form from results while preserving entered values and options.
