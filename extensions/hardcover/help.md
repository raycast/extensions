### Set Up Your API Key

1. You can generate an API key from hardcover by clicking this [link](https://hardcover.app/account/api/keys/new?scope=read%3Acatalog+read%3Alists+write%3Alists+read%3Alibrary+read%3Ame+write%3Alibrary). It will automatically prefill the **New API key** form with the required scopes.
2. Alternatively, generate it manually by logging onto [hardcover](https://hardcover.app/) then navigate to **Settings → Hardcover API** and create a key with the following scopes:
   - `read:catalog`
   - `read:library` 
   - `read:lists` 
   - `read:me` 
   - `write:library` 
   - `write:lists`
3. Copy the generated key into the **API Key** preference, then continue.
