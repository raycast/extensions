# Open Symbols Search Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Search ~29,900 Open Symbols across ten libraries by name or tag
- Export as PNG, SVG, PDF or custom SF Symbol template (for Xcode), with size, weight, color, frame and format settings
- Copy Image (PNG) and Copy SVG Code for design tools and web work
- Copy or paste Xcode names, and SwiftUI, UIKit and AppKit snippets
- Weight picker (Ultralight to Black), grid sizes, pins and recents
- Check for Symbol Updates: updates the symbol list only when a new Open Symbols release changes symbols
- License attribution embedded in exports, and a Copy Attribution action
