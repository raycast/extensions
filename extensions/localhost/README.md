# Localhost

A simple, fast, and responsive Raycast extension to view and manage your locally running servers.

## Features

- ⚡ **Fast & Responsive**: Instantly scans your local network ports.
- 🎨 **Favicons**: Automatically fetches and displays the favicon for each running server.
- 📝 **Page Titles**: Grabs the page title so you know exactly what each server is running.
- 🔍 **Smart Detection**: Identifies common processes and ports automatically.

## Note from the Author

This is a very basic extension I built primarily for my own personal needs to quickly jump between local projects. I decided to share it in case others find it useful too! It's designed to be lightweight and do just one thing well.

## Requirements

- **Windows**: This extension currently uses PowerShell commands to detect running processes and ports.
