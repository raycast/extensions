# XDR Boost Changelog

## [Toggle Shows the Current State] - 2026-11-19

- Toggle XDR Boost shows the current state in root search, such as "Off", "On · High" or "On · High · Screen Locked", and updates it after every change
- The README says that other external HDR monitors with EDR headroom are boosted too, with the same conservative limit as a Pro Display XDR, and that we haven't tested any of these monitors
