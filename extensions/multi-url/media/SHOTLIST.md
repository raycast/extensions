# Multi-URL Screenshot Shotlist

Use this file as the capture plan for Raycast Store screenshots.

## Store Requirements

- Format: PNG
- Size: 2000 x 1250 px
- Show clean, realistic sample data
- Keep language and labels in English

## Suggested Sequence (3-6 screenshots)

1. Main overview
- Command: `Multi-URL`
- Show pinned and saved sets, plus tag filter.
- Caption idea: `Save and launch URL sets from one place.`

2. Create new set
- Open the `Create New Set` flow.
- Show URLs input and browser selection (`System Default`).
- Caption idea: `Create a reusable URL set in seconds.`

3. Browser per set
- Open `Change Browser` for one set.
- Show choice between default and a specific browser.
- Caption idea: `Use default browser globally or choose per set.`

4. QuickURL management
- Open a saved set action menu and show the `QUICKURL` section with slot mapping actions.
- Caption idea: `Map your most-used sets to instant hotkeys.`

5. Set actions
- Open action panel for one set (pin, duplicate, merge, edit).
- Caption idea: `Manage sets with power actions and stats.`

6. Trash and restore
- Show deleted set in Trash with restore/permanent delete options.
- Caption idea: `Recover sets safely with built-in trash.`

## Capture Checklist

- Hide sensitive or personal URLs.
- Keep set names short and legible.
- Use consistent visual style across all screenshots.
- Capture in the same Raycast theme for all images.
- Verify each image exports at exactly `2000 x 1250`.
