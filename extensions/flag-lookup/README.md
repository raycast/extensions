# Flag Lookup Raycast extension

Search country flags and view key facts like capital, population, languages, currencies, borders, and more.

Data sources:

- Country data from [REST Countries](https://restcountries.com/)
- Flags are from [Flagpedia.net](https://flagpedia.net/)
- Coats of arms are from [MainFacts.com](https://mainfacts.com/)

This extension currently focuses on countries. Lower-level administrative flags may come later.

Please do not use this extension to cheat at GeoGuessr.
