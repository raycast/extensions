# Miti Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Initial release of Miti: a Bikram Sambat (Nepali) calendar, date converter, and reminder tool for macOS.
- Dashboard with today's BS date in both English and Devanagari, weekday, and an interactive month grid.
- Tithi (lunar day) computed astronomically for any date, evaluated at Kathmandu sunrise, with Ekadashi, Purnima, Aunsi, Ashtami, and Chaturdashi highlighted.
- Month navigation and jump-to-day search within the calendar grid.
- Public holidays marked on the calendar grid.
- AD to BS and BS to AD date conversion.
- Create dated reminders in the macOS Reminders app.
