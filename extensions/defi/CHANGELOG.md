# Defi Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Search Windows: focus any managed window, bring it to the current workspace, move it, float it, or copy its title or ID.
- Search Workspaces: jump to a workspace on any display, or move the focused window or column there.
- Search Commands: run any Defi command; the search text sets widths and heights and targets workspaces.
