# USB Devices Changelog

## [Initial Version] - 2026-11-25

- Browse connected USB devices by type, by hub or port, or by hubs and their controller chips
- Detail pane with link speed, USB version, power, interfaces, drivers, volumes, serial ports and network interfaces
- Combines the USB 2 and USB 3 halves of hubs into one entry
- Click a pill to copy its value; pills in Path and On This Hub jump to that device
- Show the selected device in System Information, eject drives, copy IDs, summary or JSON
- Live updates with "New" tags and a "Just Disconnected" section
