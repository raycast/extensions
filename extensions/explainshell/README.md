# Shell Command Explainer

Explain a shell command argument by argument, using [explainshell.com](https://explainshell.com).

Type a command in the search bar. Each piece of it is listed with the man page text that covers it,
and the detail pane shows where the piece sits in the command.

## Built on the Original Project

This extension is an unofficial client for the open source
[explainshell](https://github.com/idank/explainshell) project by Idan Kamara. It does not run the
command: it opens the page explainshell.com produces for it and reads the result. Every explanation
and all man page text come from that project, not from this extension.

It is not affiliated with or endorsed by the explainshell project.

## Privacy

The command you type is sent to explainshell.com as part of the page URL, so that site logs it. Do
not type passwords, tokens, or anything else you would not put in a URL.

## Requirements

Nothing to set up. The extension works once installed and needs a connection to explainshell.com.
