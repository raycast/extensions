# Mac Browse

Search [Mac Browse](https://macbrowse.com), a hand-picked directory of Mac apps, without leaving Raycast.

## Commands

- **Search Mac Apps**: type to search by name, tagline, description or tag. With nothing typed, it shows featured and newly added apps.
- **Browse by Category**: pick a category, such as Productivity or Developer Tools, and see its apps from A to Z.

Each app shows its icon, tagline, category and price type (Free, Freemium, Paid or Subscription).

## Actions

- **Open on Mac Browse** (↵): the app's page, with screenshots, reviews and details.
- **Open Website** (⌘↵): the maker's own site.
- **Copy Mac Browse Link** (⌘⇧C) and **Copy Website Link** (⌘⇧.).

No account or API key is needed. The extension only reads Mac Browse's public search.
