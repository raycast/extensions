# Changelog

## [Initial Release] - {PR_MERGE_DATE}

- Switched the extension from a Bring Your Own Key setup to a proxy-backed architecture using a Cloudflare Worker.
- Removed Apple Developer credential fields from the Raycast preferences UI.
- Added Windows-focused local development sync for Raycast X.
- Added inline default-location setup with support for city names or coordinates.
- Added local weather response caching keyed by resolved location and `expireTime`.
- Added support links for Buy Me a Coffee and GitHub Sponsors in the command UI.
- Updated documentation for the proxy-based setup and deployment flow.
