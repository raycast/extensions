# Kloak Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Initial release of Kloak Password Manager extension for Raycast
- Instant search and filtering across vault credentials (Logins, Secure Notes, Payment Cards, Identities, Email Aliases, Authenticators)
- One-click credential copy with automatic memory-wiping clipboard protection
- High-entropy password and EFF wordlist passphrase generator
- Real-time 2FA code generator (TOTP & HOTP) with visual countdown timers
- Fast entry creation with the Add Entry command
- Instant Lock Vault command to wipe memory and secure credentials
- Import credentials from 1Password, Bitwarden, LastPass, Apple, and Chrome; export to Bitwarden JSON and encrypted Kloak backups
