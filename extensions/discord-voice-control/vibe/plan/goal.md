# Raycast Discord extension

There is an existing extension for Discord on Raycast, but it provides very limited operations that can be done.

https://www.raycast.com/Aayush9029/discord

The above is the link to the extension.

## Operations planned

For now, I plan to develop features like toggle mute, toggle deafen, as I feel like these features are often very in need of special hotkeys that work even though they are not the current focused window.

There are already hotkeys in place in Discord that allows toggle mute and toggle deafen, but they only work if I am actively on the Discord application. I cannot toggle mute or deafen using hotkeys while, let's say I am working in Visual Studio Code.
