# Taskit

Create tasks and work Today, Inbox, Upcoming, Overdue, and Backlog from Raycast.

## Sign in

Open **My Tasks** (or any other Taskit command) and choose **Sign in to Taskit**. A browser window opens the Taskit login page. Sign in with the Taskit account you already have, using Google or email. When the browser says you are connected, return to Raycast.

No API key is required. The extension uses the hosted Taskit API.

## Commands

- **Create Task** — add a task from a sentence. Dates, tags, and priority are parsed for you. Example: `Buy milk tomorrow #errands !!`
- **My Tasks** — browse Today, Inbox, Upcoming, Overdue, and Backlog. Complete, reopen, schedule, set priority, or move a task.
- **Search Tasks** — find a task by words in its title.
- **Today in Menu Bar** — show how many tasks are still open today. Refreshes every 10 minutes.

Raycast AI can also create, search, list, complete, and update tasks once you are signed in.

## Preferences

**API URL** is optional. Leave it at the default to use the hosted Taskit service. Change it only if you run your own Taskit API.
