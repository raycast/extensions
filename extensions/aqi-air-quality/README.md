# AQI Air quality

An air quality information extension that allows you to see air quality in your status bar

## Data Sources & Attribution

- Air quality data from [Open-Meteo](https://open-meteo.com/).
- Air quality data from [IQAir](https://www.iqair.com/) when an API key is provided.
- Europe-only modelled AQI data from [EEA Discomap](https://discomap.eea.europa.eu/) when available.
- Manual location search uses [Open-Meteo Geocoding](https://open-meteo.com/en/docs/geocoding-api).
- IP geolocation by [IP Location Finder by KeyCDN](https://tools.keycdn.com/geo).
- Public IP lookup via [ipify](https://www.ipify.org/).
