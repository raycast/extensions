# XKeen Manager Changelog

## [Initial Version] - 2026-08-06

- Status, start/stop/restart with health checks and a crash alert
- Server profiles: create, switch, rename, delete — with automatic backup and rollback on failed switches
- Quick Add: domains, keywords, geosite/geoip entries into the routing config with comment preservation and duplicate detection
- JSON editors for outbounds and routing with validation and safe apply
- Backups with one-click rollback and automatic pruning
- IP check (direct vs exit), log viewer, SSH setup wizard
- Menu bar status command with background refresh
- AI tools: get-status, list-profiles, switch-profile, add-domains
