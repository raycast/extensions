# XKeen Manager Changelog

## [2.0.0] - 2026-03-21

### Рефакторинг
- Переписано из монолита (2060 строк) в модульную архитектуру с 16 независимыми модулями
- Главный компонент сокращён с 2060 до ~220 строк
- Интерфейс оптимизирован: 8 пунктов → 6 с 3 секциями (Xkeen, Routing, Manage)

### Оптимизация производительности
- Объединены 3 последовательных SSH-вызова в 1 комбинированный (`loadStartupData`)
- Время запуска: 3-6 сек → 1-2 сек
- Добавлена маркерный протокол для надёжного чтения файлов

### Критические исправления
- **Баг в health-check**: OPT-монтирование проверяется через наличие `/opt/bin` вместо парсинга `mount`
- **Баг в routing-preview**: Env-переменные из Keenetic shell отсекаются маркерным протоколом
- **Восстановление комментариев**: Routing больше не теряет комментарии при записи

### Новые возможности
- **Entry Type selector** в Quick Add: dropdown для выбора типа записи (domain/keyword/geosite/geoip)
- **Crash alert**: Toast-уведомление при запуске, если xkeen не запущен
- Компактные однострочные комментарии в routing (вместо 3-строчных блоков)

## [1.0.0] - 2026-01-18

### Основная функциональность
- Полный контроль над Xray: Status, Start, Stop, Restart с индикацией режима работы
- Менеджер профилей серверов: создание, сохранение, быстрое переключение между профилями
- Smart IP Check: проверка реального IP (с роутера) и VPN-IP (с Mac)
- JSON-редакторы для Routing и Outbounds конфигов с валидацией синтаксиса
- Просмотр логов Xray (последние события, новые строки сверху)
- Управление бэкапами конфигов с rollback функцией
- Health-check: проверка доступности /opt, свободного места, статуса xkeen
- SSH Setup Wizard: автоматическая генерация ключей, их загрузка на роутер и настройка соединения
- Quick Add: быстрое добавление записей в маршрутизацию (без редактора)
