# XKeen Manager for Raycast

**XKeen Manager** — это ультимативный пульт управления для Xray (пакет `xkeen`) на роутерах Keenetic.
Позволяет мониторить статус, менять серверы и править маршрутизацию, не касаясь терминала.

## ✨ Возможности

*   🚀 **Полный контроль:** Start, Stop, Restart с индикацией статуса (Зеленый/Красный) и режима работы.
*   🌍 **Smart IP Check:** Гибридная проверка. Показывает реальный IP провайдера (запрос с роутера) и IP VPN (запрос с Mac), чтобы вы точно знали, работает ли обход блокировок.
*   🔄 **Менеджер профилей:**
    *   Создавайте разные профили под разные страны/серверы.
    *   Переключайтесь на лету. Скрипт безопасно подменяет конфиг сервера (`04_outbounds.json`).
    *   *Auto-Sync:* Если вы отредактируете конфиг активного профиля, изменения сохранятся и в работу, и в бэкап профиля.
*   📝 **JSON Редактор:** Встроенный редактор для `Routing` и `Outbounds` с валидацией синтаксиса.
*   📜 **Логи:** Просмотр последних событий Xray (новые строки сверху).

### Новые возможности

*   **Menu Bar:** Команда "XKeen Menu Bar" показывает цветной индикатор статуса (зелёный — работает, красный — остановлен, оранжевый — ошибка подключения). Переключение профилей и рестарт прямо из меню, фоновое обновление каждые 10 минут.
*   **AI Tools:** Управление через Raycast AI — команды `get-status`, `list-profiles`, `switch-profile`, `add-domains` с подтверждениями для изменяющих действий.
*   **Preferences:** Настройка "Proxy Outbound Tag" — для указания тега исходящего узла; пусто = автоопределение из `04_outbounds.json`.

## 🛠 Требования

1.  **macOS** (Raycast работает только на Mac).
2.  **Keenetic** с установленным [Entware](https://github.com/Entware/Entware).
3.  Установленный пакет **xkeen** (оригинал или форки, например jameszeroX).

## ⚙️ Установка и Настройка

### Шаг 1. Установка расширения
1.  Склонируйте репозиторий и установите зависимости:
    ```bash
    npm install
    ```
2.  Добавьте в Raycast:
    ```bash
    npm run dev
    ```

### Шаг 2. Настройка подключения (Магия!)
Чтобы расширение работало мгновенно и не запрашивало пароль каждые 5 секунд:

1.  Найдите в Raycast команду **Setup SSH Connection** (она идет в комплекте).
2.  Нажмите Enter. Откроется терминал.
3.  Введите IP роутера (обычно `192.168.1.1`) и пароль администратора.
4.  Мастер сам:
    *   Сгенерирует SSH-ключи.
    *   Загрузит их на роутер.
    *   Настроит `~/.ssh/config` с оптимизацией `ControlMaster` (ускорение в 10 раз + защита от банов).

**Что делает мастер на локальной машине:** если файл `~/.ssh/id_ed25519` не существует, он создаст новый Ed25519 ключ **без парольной фразы** (чтобы Raycast мог подключаться без запроса пароля), скопирует публичный ключ на роутер через `ssh-copy-id` и добавит блок `Host` в `~/.ssh/config` с настройками `ControlMaster`. Больше на вашем Mac ничего не изменяется.

### Шаг 3. Финал
1.  Запустите **XKeen Manager**.
2.  При первом запуске укажите настройки (если меняли их в мастере):
    *   **SSH Connection:** `xkeen` (или ваш алиас).
    *   **Paths:** Оставьте по умолчанию, если у вас стандартный Entware (`/opt/etc/xray...`).

## 📖 Как работать с профилями

1.  Зайдите в раздел **Switch profiles**.
2.  Нажмите **Create** -> введите имя (например `germany`).
    *   Расширение создаст копию текущего сервера, сохранит её в профиль `germany` и сразу переключится на него.
3.  Теперь идите в главное меню -> **Outbounds**.
4.  Вставьте туда VLESS-конфиг вашего немецкого сервера и нажмите **Save**.
5.  Готово! Теперь этот конфиг привязан к профилю `germany`.

Чтобы вернуться на старый сервер, просто выберите его в списке профилей и нажмите Enter.

## 🤝 Troubleshooting

*   **Status: Command failed / Connection reset:**
    Роутер временно заблокировал вас за частые запросы.
    1. Перезагрузите роутер.
    2. Обязательно выполните **Шаг 2 (Setup SSH Connection)**, чтобы включить оптимизацию соединений.
*   **IP Error:**
    Убедитесь, что сайт `2ip.io` добавлен в маршрутизацию Xkeen как проксируемый.
