# Folder Search for Windows Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Search folders by name across your user folder, external drives, Google Drive and network drives
- Built-in folder index with background refresh and a Rebuild Folder Index command
- Optional Everything (es.exe) integration for instant results on NTFS drives
- Pinned and recent folders, browse subfolders and go to the enclosing folder
- Open in File Explorer, Terminal or Editor; copy or paste the path
