# Contrast Picker Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Pick & Check Contrast: pick text and background colors with the native macOS eyedropper, then see the result
- Check Contrast: type, paste or prefill colors from the last two clipboard entries
- WCAG 2.2 AA / AAA (normal and large text) and APCA Lc with minimum font size
- Suggested fixes that keep hue (OKLCH lightness), for text, background or both, for AA, AAA and APCA
- Copy fixes as HEX, OKLCH, RGB or nearest Tailwind color (⌘1–⌘4)
- Accepts HEX, rgb(), hsl(), oklch(), CSS names and Tailwind classes, with transparency
