# Snag Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Search 7TV emotes from Raycast and paste one into the frontmost app
- Animated emotes paste as GIF and static ones as PNG, resolved against the
  files the 7TV API actually lists rather than a guessed URL
- Size selector from 1x to 4x, defaulting to 2x, remembered between launches
- Results load 60 at a time and page in as you scroll
- Copy Emote as a secondary action when you want the clipboard without pasting
