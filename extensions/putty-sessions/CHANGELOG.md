# PuTTY Sessions Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Search your saved PuTTY sessions and launch any of them directly
- Connect to any typed host over SSH without saving a session first
- Optional entry to open PuTTY without a session, and an option to start sessions maximized
- Port of the [Flow Launcher PuTTY plugin](https://github.com/jjw24/Flow.Launcher.Plugin.Putty) by [@jjw24](https://github.com/jjw24), based on the original Wox plugin by [@kosz78](https://github.com/kosz78)
