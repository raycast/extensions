# Study notes from a video or an article

1. Call The Downloader's `read-link` tool with the URL.
2. Build the notes in the source's order:
   - `## <Section title>` for each chapter, heading or topic shift. For a video, add a linked timestamp for where it starts, e.g. `[12:30](https://www.youtube.com/watch?v=ID&t=750s)`.
   - Under each section: the main ideas as short bullets, **bold** for key terms.
   - A **Definitions** list for terms the source explains.
   - Numbered **Steps** for any procedure, command or recipe, with exact values (commands, settings, quantities) as given.
3. End with **Review questions**: 5 questions that test the main ideas, then the answers (with their timestamps, for a video).
4. Only use what the source says. Mark anything you add from general knowledge as _(not from the source)_.
5. If the transcript or text isn't available, say so and offer notes from the description and chapters only.

Reply in the language the person wrote in.
