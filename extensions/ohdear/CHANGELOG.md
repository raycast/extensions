# Oh Dear Changelog

## [Windows Support and Reliability] - 2026-10-19

- Added Windows support with keyboard shortcuts for site actions and reports.
- Fixed the initial group filter to show all sites by default.
- Show errors when adding or removing sites fails and restore sites after rejected deletions.
- Prevent duplicate site submissions while a request is pending.
- Show pass/fail results for certificate checks.
- Changed the Performance shortcut to Cmd+P on macOS and Ctrl+P on Windows to avoid conflicting with Open in Oh Dear.
