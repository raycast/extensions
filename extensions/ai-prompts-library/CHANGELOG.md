# Changelog

## [1.0.0] - Initial Release

### Added
- Search through 14,000+ AI prompts from curated library
- Auto-categorization into 7 categories: Development, Marketing, Writing, Research, Design, Business, and General
- Real-time search by prompt name or content
- Category dropdown filter in search bar
- Copy to Clipboard action for all prompts
- Paste to Active App action with automatic fallback to clipboard
- View Full Prompt detail view
- Color-coded category badges and icons
- Empty state and loading state handling
- Toast notifications for user feedback
- Grouped display by category with prompt counts

### Features
- Fast CSV parsing for large prompt library
- Keyword-based smart categorization
- Responsive search with instant filtering
- Accessible keyboard shortcuts
- Professional UI with consistent styling
