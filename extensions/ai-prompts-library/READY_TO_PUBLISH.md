## 🎯 Publishing Steps

### 1. Run the Publish Command

In your terminal (from the extension directory):

```bash
npm run publish
```

### 2. What Will Happen

1. **GitHub Authentication**: You'll be prompted to authenticate with GitHub
2. **Create PR**: A pull request will be created automatically to the Raycast extensions repository
3. **Upload Screenshots**: You'll be prompted to upload your 3 screenshots:
   - `/Users/tpanos/Desktop/Builds/raycast-extension/assets/store-screenshot-1.png`
   - `/Users/tpanos/Desktop/Builds/raycast-extension/assets/store-screenshot-2.png`
   - `/Users/tpanos/Desktop/Builds/raycast-extension/assets/store-screenshot-3.png`

### 3. Review Process

- **Raycast Team Review**: Typically 24-48 hours
- **Possible Feedback**: They may request changes via PR comments
- **Updates**: If needed, run `npm run publish` again to push updates to the same PR
- **Approval**: Once approved, automatically published to Raycast Store!

### 4. After Publishing

Your extension will be available at:
- **Store URL**: `https://raycast.com/TomsTools/ai-prompts-library`
- **Search**: Users can find it by searching "AI Prompts Library" in Raycast
