# VPS Upload Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Upload the Finder selection to a remote host over SSH with a single command (hotkey-friendly, no window)
- Manual file picker command with drag-and-drop / browse and a live progress bar
- Remote path is copied to the clipboard the moment the upload starts
- First-run onboarding and a Test Connection action
- Streaming upload over `ssh cat` with accurate byte-based progress (no scp tty requirement)
