# Tweak Changelog

## 1.0.0 — Initial Release

- **Enhance Prompt**: Turn rough ideas into high-quality AI prompts.
- **Fix Grammar**: Correct spelling and grammar while preserving 100% of meaning.
- **Custom Actions (1-5)**: 5 slots to build your own AI tools in preferences.
- **Multi-provider support**: Groq (free), OpenAI, and Anthropic.
- **Automated Workflow**: Copy text → Hotkey → Polished text auto-pastes back.
