# Changelog

## [1.0.0] - 2024-09-23

### Added
- Initial release of Copy Browser URL extension
- Support for getting current browser tab URL from major browsers (Chrome, Safari, Firefox, Arc, Brave, Vivaldi, Orion)
- Automatic removal of common tracking parameters (UTM, Facebook, Google Analytics, etc.)
- Copy cleaned URL to clipboard functionality
- Toast notifications for operation status (loading, success, error)
- Support for both Browser Extension API and AppleScript fallbacks
