# U2L Link Shortener

Shorten links with [U2L AI](https://u2l.ai) without leaving Raycast.

## Setup

1. Create a free account at [u2l.ai](https://u2l.ai) (every plan includes API access).
2. In the dashboard, go to **Settings → API** and create an API key.
3. Paste the key into the extension's API Key preference on first run.

## Commands

- **Shorten Link** — shortens the URL you type as an argument, or falls back to your selected text, then your clipboard. The short link is copied to your clipboard automatically.
- **Search Links** — search all your short links; copy or open them, view details (clicks, tags, type), or delete a link.
