## Get a Brix API key

1. In the Brix console, go to **Settings › AI, API & MCP › API keys**.
2. Select **New key**. Give the key a name, for example "Raycast", and a role. Then select **Create key**.
3. Copy the key and paste the key in **API Key**. The key starts with `ak_`.

The extension can do only what the key's role lets it do. A view-only role can search, but cannot change content or send commands.
