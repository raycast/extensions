# Wallpaper Engine Changelog

## [Initial Version] - 2026-08-03

- Add commands to pause, play, stop, mute, and unmute wallpapers
- Add commands to hide and show desktop icons
- Add command to skip to next wallpaper on a monitor
- Add command to close wallpaper on a monitor
- Add command to view current wallpaper for each monitor
- Add command to open a specific wallpaper on a monitor
- Add command to open a saved playlist on a monitor
- Add command to apply a saved display profile
- Add command to apply wallpaper properties dynamically via JSON
- Auto-detect Wallpaper Engine installation from Steam libraries
- Support manual Wallpaper Engine path configuration via preferences
