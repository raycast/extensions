# File Manager

Browse your files and folders without leaving Raycast. Move through folders, open files and create new ones from the keyboard.

## Commands

- **Manage Files**: Starts in your chosen folder. Browse, open, create and delete files.

## Setup

In the preferences you can set:

- **Start Directory**: Where browsing starts. `~` is your home folder.
- Sorting: folders first, and uppercase names before lowercase.
- Show dotfiles, file permissions and file sizes.
- Show iCloud Drive at the top of the start folder.
- Hide files listed in `.gitignore` or `.rayignore`.
- Turn delete actions on or off, and use `⌃X` for Move to Trash and `⌃⇧X` for Delete.
