# ZenNotes Changelog

## [Initial Version] - 2026-04-30

- Search ZenNotes notes from Raycast using the local `zen` CLI.
- Open notes in the ZenNotes desktop app or directly in a floating window.
- Filter notes by folder and tag from the search dropdown.
- Archive, unarchive, move to Trash, reveal in Finder, copy note paths, and copy wikilinks from Raycast actions.
