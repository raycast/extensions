# Apple Devices Battery Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Added battery status view for Mac and all connected Bluetooth devices
- Detailed Mac battery info with health, cycle count, temperature, voltage, and power usage
- AirPods displayed as separate rows for earbuds and case
- Auto-refresh every 1 second
- 25 custom Apple device icons with user-assignable icon per device
- Status indicated by icon color: green for connected, blue for charging, gray for cached
