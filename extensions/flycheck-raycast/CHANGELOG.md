# FlyCheck Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Fetch raw METAR weather data by ICAO code from CheckWX API
- Display decoded weather breakdown with flight category, wind, visibility, temperature, and pressure
- Color-coded flight categories (VFR, MVFR, IFR, LIFR) for quick visual reference
- Copy raw METAR or decoded JSON to clipboard
- Search history with quick access to recent airports
- Toggle temperature units between Celsius and Fahrenheit in preferences
- Download FlyCheck macOS app from within extension
