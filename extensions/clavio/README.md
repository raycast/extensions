# Clavio

Companion extension for [Clavio](https://clavioapp.com) — AI hands-free dictation that adapts to every app (macOS 14+, Apple Silicon).

## Commands

- **Open Clavio** — launch or focus the Clavio app. If Clavio isn't installed, opens the download page (free tier: 3,000 words/month, no card).
- **Search Clavio Guides** — browse Clavio's guides on Mac dictation, voice typing, punctuation commands, per-app workflows, and troubleshooting.
- **Download Clavio** — open the download page.
- **Clavio Changelog** — see what's new.

## About Clavio

Hold a key or say "Hey Clavio," talk in any app, and finished text — cleaned up, punctuated, in the right tone — types itself where your cursor is. Per-app styles, optional auto-send, 28 dictation languages, on-device voiceprint.
