# AWS Console Launcher

Quickly search and open AWS service consoles from Raycast.

## Features

- Search 73+ AWS services by name, alias, or keyword
- Recently used services are shown at the top
- Console URLs are generated based on your configured region
- Copy console URLs to clipboard

## Search Examples

| Input | Match |
|-------|-------|
| `ec2` | Amazon EC2 |
| `cw` | Amazon CloudWatch |
| `logs` | CloudWatch Logs |
| `fn` | AWS Lambda |
| `queue` | Amazon SQS |

## Configuration

Set your **Default Region** from the extension preferences (default: `ap-northeast-1`).
