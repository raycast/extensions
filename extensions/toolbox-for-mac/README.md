# Toolbox for Mac

Run [Toolbox](https://mactoolbox.app) tools from Raycast: compress videos, remove backgrounds, merge and compress PDFs, extract text, transcribe, download videos and more. Everything runs on your Mac. Files are never uploaded.

## Requirements

- [Toolbox for Mac](https://mactoolbox.app) 2.0 or later. It's a **paid app** (one-time purchase). If it isn't in /Applications, pick it in the extension's preferences.
- Video and audio tools need FFmpeg, and Download Video needs yt-dlp. Toolbox can install both.

## Commands

- **Search Toolbox Tools**: find any tool, choose files (the Finder selection is filled in) and options, then run it.
- **Quick commands** that use the files selected in Finder, so they're nice to give a hotkey: Compress Video, Compress Images, Remove Background, Compress PDF, Merge PDFs, Extract Text (copies the text), Transcribe (copies the text), Video to GIF.
- **Download Video**: paste a link (it's filled in from the clipboard) and pick a quality or audio only.

Results go to Toolbox's results folder (Downloads by default), in a new dated folder. Your originals are never changed.
