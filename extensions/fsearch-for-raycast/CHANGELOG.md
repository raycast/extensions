# FSearch Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Fuzzy, whole-disk file search and indexed content search through a local fsearch daemon, over its Unix socket.
- Home screen with saved searches, quick searches, and places; file-type menu, folder scoping, sorting, and more results as you scroll, up to 500. Saved searches as Quicklinks, and a Search Files tool for Raycast AI.
- Preview pane for images, text and code, Word, RTF, and OpenDocument text, archives, property lists, and Quick Look thumbnails, with Spotlight metadata.
- One-command install from the home screen; the executable is found in the usual install locations.
- Full Disk Access detection, index rebuild, and automatic retries while the daemon starts or indexes.
