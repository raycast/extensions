# Changelog

## [Initial Release] - 2026-02-16

- Add local-only pet snippet search command.
- Support fuzzy search and `tag:<name>` filtering.
- Support Copy/Paste actions with configurable default action order.
- Persist local recency ranking with `last_used_at`.
- Auto-refresh when snippet file changes and provide manual reload action.
- Add custom extension icon and icon generation script.
