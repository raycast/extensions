# Media Assets

This folder contains screenshots and media for the extension README.

## Screenshots Needed

For the Raycast Store submission, consider adding:

1. **send-request.png** - Screenshot of the Send Request form
2. **response-view.png** - Screenshot of a successful response
3. **collections.png** - Screenshot of the collections management
4. **environments.png** - Screenshot of environment variables
5. **history.png** - Screenshot of request history

## How to Take Screenshots

1. Run `npm run dev` to load the extension
2. Open each command in Raycast
3. Take screenshots (Cmd+Shift+4 on macOS)
4. Save them in this folder
5. Reference them in README.md like: `![Screenshot](media/send-request.png)`

## Image Guidelines

- Use PNG format
- Show the extension in action
- Include both light and dark theme examples if possible
- Keep file sizes reasonable (< 1MB each)
