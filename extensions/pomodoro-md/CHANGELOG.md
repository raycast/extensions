# Pomodoro.md Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Start, stop, and switch pomodoro timers from Raycast with a menu bar countdown
- Manual mode: manage tasks directly in Raycast (no external files needed)
- Daily Note mode: load tasks from a markdown timetable and append pomodoro logs to the same note, leaving everything else in it untouched
- Break timer that offers to resume the task you were on when it ends
- Quick Start command for a configurable default task
- Configurable pomodoro/break durations, daily note filename pattern, section headers, break keywords, and optional logging
