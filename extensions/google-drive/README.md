# Google Drive

Find any file in your Google Drive folder on your Mac with fuzzy search, without opening Finder or a browser.

## Commands

- **File Search**: Fuzzy search the files in your local Google Drive folder and open them.

## Setup

- **Google Drive root path** (required): The full path to your Google Drive folder, usually under `~/Library/CloudStorage/`.
- Optional settings: show hidden files and folders in results, exclude paths, and how often the file index refreshes.

This extension searches the Google Drive folder synced to your Mac. To search Drive online, use [Google Workspace](https://www.raycast.com/thomaslombart/google-workspace).
