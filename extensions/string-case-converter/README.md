# String Manipulation

This Raycast extension is a fast and lightweight string transformation tool for developers. It allows you to:

- Convert to camelCase
- Convert to PascalCase
- Convert to kebab-case
- Convert to snake_case
- Convert to dot.case
- Convert to CONSTANT_CASE
- Convert text to UPPERCASE
- Convert text to lowercase
- Preview all transformations in real time as you type
- Copy results instantly with a single press of Enter

---

## How It Works

Simply open the command and start typing in the search bar.
All supported case formats are generated automatically and displayed in the list.

Select a format and press Enter to copy the result to your clipboard.

No extra steps. No additional screens. Just fast conversion.
