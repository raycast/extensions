# Delink

一个 [Raycast](https://raycast.com) 插件，可以即时解析剪贴板中 URL 的查询参数。

## 功能特性

- 📋 **自动读取剪贴板** — 打开即自动解析剪贴板中的 URL
- 🔍 **参数列表视图** — 以清晰的左右分栏布局展示所有查询参数及详情面板
- 🔓 **自动 URL 解码** — 自动解码百分号编码的参数值
- 📦 **JSON 格式化** — 自动美化 JSON 格式的参数值，方便阅读
- 🏷️ **参数类型标注** — 自动识别并标注参数类型：`JSON`、`Base64`、`Timestamp`、`Encoded`
- 🔐 **Base64 自动解码** — 自动解码 Base64 值，并在详情面板中展示解码结果
- ⏱️ **时间戳识别** — 自动将 10 位（秒级）和 13 位（毫秒级）Unix 时间戳转换为可读格式
- 📏 **URL 统计** — 显示参数数量和 URL 长度，超过 2048 字符时显示警告
- 🕘 **URL 历史记录** — 记录最近 20 条解析过的 URL，按 `⌘H` 可浏览并重新解析历史记录
- 📌 **多种复制方式** — 一键复制解码值、原始值、`key=value` 格式或全部参数
- 🔄 **随时重新解析** — 按 `⌘V` 可随时重新读取剪贴板中的 URL

## 使用方法

1. 复制任意 URL 到剪贴板
2. 打开 Raycast，搜索 **URL Parse**
3. 浏览解析出的查询参数列表
4. 选中某个参数，在右侧面板查看完整解码值、类型信息等详情
5. 通过操作面板以你需要的格式复制参数值

## 操作说明

| 操作                 | 快捷键 | 说明                                   |
| -------------------- | ------ | -------------------------------------- |
| 复制解码值           | `↵`    | 复制 URL 解码后的参数值                |
| 复制原始值           | `⌘⇧C`  | 复制原始编码的参数值                   |
| 复制 key=value       | `⌘⌥C`  | 复制完整的 `key=value` 键值对          |
| 复制全部参数（解码） | `⌘⇧A`  | 复制所有参数解码值，每行一个 key=value |
| 复制全部参数（原始） | `⌘⇧R`  | 复制所有参数原始编码值                 |
| 复制完整 URL         | `⌘⇧U`  | 复制完整的 URL                         |
| 从剪贴板粘贴         | `⌘V`   | 重新读取剪贴板中的 URL                 |
| 查看历史记录         | `⌘H`   | 浏览之前解析过的 URL                   |
| 清空历史记录         | `⌘⇧⌫`  | 删除所有历史记录                       |
