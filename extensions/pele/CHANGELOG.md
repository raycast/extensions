# Changelog

## Initial Version - 2026-10-18

- Render Mermaid diagrams locally with Pele from selected text, the clipboard, or the built-in editor.
- Preview diagrams with light, dark, and Flexoki themes and optional transparent backgrounds.
- Use Inter and IBM Plex Mono typography inspired by Pele's examples, with font-aware label sizing and monochrome emoji support.
- Copy images and source code, save PNG and SVG files, and open diagrams at full size.
- Start from examples for common diagram types.
- Use Mermaid frontmatter config, with a Sankey example for hiding values and adjusting node width and spacing.
- Generate and save diagrams from descriptions with Raycast AI, with links to the rendered PNG or SVG files.
