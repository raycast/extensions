# Healing Icons for Raycast

Search 3,500+ icons in 4 styles from Raycast, then copy or paste them.

- Search by name or tag; switch the style (outline, outline-duo, fill, glyph-duo) in the dropdown.
- **Enter**: copy the SVG (change it in the extension preferences: paste SVG, copy React JSX or copy the name).
- More actions: copy the import for React, Vue or Svelte, copy a `<healing-icon>` tag, open the icon on the website.

Icon data comes from [healing-icons.vercel.app](https://healing-icons.vercel.app). MIT.

## Develop

```bash
npm install
npm run dev     # opens the extension in Raycast
npm run build   # type-check and build
```

Publishing goes through a pull request to [raycast/extensions](https://github.com/raycast/extensions): `npm run publish`.
