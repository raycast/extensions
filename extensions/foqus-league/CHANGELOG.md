# Foqus League Changelog

## [Menu Bar Stats Setup and Duration Field] - 2026-10-10

- New icon
- Show League and Show Recap offer to turn on Menu Bar Stats when it isn't running
- Starting or finishing a Focus session no longer asks you to run Menu Bar Stats
- Notes such as "No sessions yet" now sit above the board and the recap
- Add Session and Edit Session take a duration like "45 min", "1:30" or "2 hours"
- Escape in Browse Sessions goes back to Show League when you opened it from there

## [Initial Version] - 2026-10-09

- Show League, Show Recap, Browse Sessions and Menu Bar Stats commands
- Export and import your sessions as one JSON file
- Weekly leagues, streaks with shields, quests and a 26-week calendar
- Shareable recap for any period, as an image
- One-click starts for recent goals, with each goal's own blocks
- A notification and a short chime when you hit your daily goal, reach a new league or a perfect week, beat last week, or hit a streak milestone
- An evening reminder when one session would extend your streak
- Records finished sessions automatically. Everything stays on your Mac
