# Agent Sessions Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Full-text search over every session from ten coding agents — Claude Code, Codex, Cursor, Gemini CLI, Qwen Code, GitHub Copilot CLI, opencode, Crush, Goose and Droid — with PR-aware ranking.
- Resume a session in one keystroke: its own CLI in your terminal (Terminal, iTerm2, Ghostty, Warp), or Claude Desktop and the Codex app for sessions created there.
- Agents are detected automatically in their standard locations; the agent filter only lists agents you have sessions from.
- Background incremental indexing every 30 minutes, plus manual refresh and rebuild commands.
