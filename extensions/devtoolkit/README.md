# Dev Toolkit

Dev Toolkit is a Raycast extension with everyday utilities for local developer workflows.

## Utilities

- Base64 encode and decode UTF-8 text.
- Format records by splitting, trimming, quoting, deduplicating, and joining values.
- Generate MD5, SHA-1, SHA-256, SHA-384, and SHA-512 hashes.
- Generate UUIDv7 values.
- Parse cron expressions and view field breakdowns.
- Validate and format JSON.

No API keys, accounts, or external setup are required.
