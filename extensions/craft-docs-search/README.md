# Craft Docs Search

Search Craft docs from Raycast by title or tag.

## Setup

1. Open Craft.
2. In the sidebar, open the Imagine view.
3. Create an API connection.
4. Choose what docs Raycast will be able to search:
   - Select `Connect All Documents` for the usual setup.
   - Select `Connect Selected Documents` only if you want Raycast limited to certain docs.
5. Edit the API connection to review its settings and retrieve the API URL.
6. Set the permission level to `Read & Write` or `Read Only`. `Write-Only` will not work for this extension.
7. Optional but recommended: Change the access mode to `API Key`, then generate an API key for Raycast. Copy this key; you will need it for the `Craft API Token` field.
8. Copy the connection URL.
9. Open this extension's Raycast preferences.
10. Paste the URL into `Craft API URL`.
11. If you generated an API key, paste it into `Craft API Token`.

## Usage

Use `Search Docs` to search for docs in your Craft repository by name. Search for docs by tag by starting your query with `#`.
