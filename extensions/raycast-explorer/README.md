# Raycast Explorer

Find snippets, AI prompts, AI Presets, Quicklinks and themes that other people made, and add them to Raycast in one step.

## Commands

- **Explore Snippets**: Ready-made snippets to add.
- **Explore Prompts**: AI prompts for writing, coding and more.
- **Explore Presets**: AI Presets to try.
- **Explore Quicklinks**: Useful Quicklinks to add.
- **Explore Themes**: Custom themes for Raycast.

## Use it with Raycast AI

Mention `@raycast-explorer` in Raycast AI to find something specific. For example, "find a prompt for writing commit messages".
