# Assets

Place your extension icons and images here.

## Required Icons

- `icon.png` - Main extension icon (512x512px recommended)
- `search-icon.png` - Search command icon
- `portfolio-icon.png` - Portfolio command icon

## Icon Guidelines

- Use PNG format
- Recommended size: 512x512px for main icon, 64x64px for command icons
- Use transparent background
- Keep icons simple and recognizable
