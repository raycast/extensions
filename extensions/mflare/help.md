# Connect to MFlare

This extension needs the [MFlare](https://mflare.yuy1n.io) app running on this Mac, with **MFlare Pro**, a separate one-time purchase.

1. In MFlare, open **Settings › Integrations** and turn on **Raycast**.
2. Click **Copy Connection**.
3. Run any MFlare command and press ↵ to paste it. To use another connection later, choose **Change Connection…** or **Clear Connection** from a command's actions (⌘ K).
