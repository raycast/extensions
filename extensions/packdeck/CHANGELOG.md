# Packdeck - npm Package Manager Changelog

## [Initial Version] - {PR_MERGE_DATE}

- **Search npm Packages**: Instant npm registry search with weekly download counts, popularity/quality/maintenance scores, README and version history viewer, and quick install.
- **Manage Projects**: Automatic discovery of local `package.json` projects, active and pinned project switching, lockfile-based package manager detection (npm, pnpm, Yarn, Bun), and full Project Hub.
- **Check Outdated Packages**: Outdated dependency detection with Major, Minor, and Patch semver badges and individual or bulk updates.
- **Run Security Audit**: Vulnerability scanning via native CLI audits and npm bulk advisories fallback with severity filters, advisory links, and `audit fix` remediation.
- **Run Project Scripts**: Discover and execute `package.json` scripts inline with ANSI-clean output, with extra arguments, or in Terminal, iTerm, Warp, Ghostty, Alacritty, or Kitty.
- **Manage Global Packages**: View, update, reinstall, install, and uninstall globally installed packages across npm, pnpm, Yarn, and Bun.
- **Favorites & History**: Bookmark frequently used packages and replay previous installation and script commands.
- **Package Status Menu Bar**: Background health monitoring for watched projects with menu bar badges and smart notifications.
