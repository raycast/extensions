# Changelog

## [Initial Release] - {PR_MERGE_DATE}

Initial release of Color Filters extension for Raycast.

### Features

- Toggle Color Filters on/off
- Switch between 5 filter types: Grayscale, Protanopia, Deuteranopia, Tritanopia, Color Tint
- Visual filter selector with descriptions and active filter indicator
- Fast performance by keeping System Settings in background
- Clean UX with automatic window hiding after actions

### Commands

- Toggle Color Filters
- Select Color Filter (interactive list)
- Set Grayscale Filter
- Set Protanopia Filter
- Set Deuteranopia Filter
- Set Tritanopia Filter
- Set Color Tint Filter
- Disable Color Filters
