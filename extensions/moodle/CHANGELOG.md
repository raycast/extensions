# Moodle Changelog

## [Initial Release] - {PR_MERGE_DATE}

- Browse all enrolled Moodle courses and download slides, PDFs, and lecture notes directly from Raycast
- View upcoming assignment deadlines with live countdowns across all courses
- Add assignment deadlines to macOS Calendar with one click, including a 24-hour reminder alarm
- Read Moodle notifications and course announcements with formatted markdown preview
- Mark notifications as read directly from Raycast
- Quick-launch shortcuts to Moodle Dashboard, My Courses, Calendar, and Grades
- Supports both Web Service API token and browser MoodleSession cookie authentication for SSO logins
