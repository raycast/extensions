# Defined.fi

Search tokens by name, symbol, or contract address and open them on [Defined.fi](https://www.defined.fi).

## Setup

The extension needs a Codex.io API key. Codex.io provides Defined.fi's data.

1. Create an account at [dashboard.codex.io](https://dashboard.codex.io/signup). Activation costs $1 once (card or 1 USDC). The plan then includes 10,000 free requests a month.
2. Copy your key from the [API Keys page](https://dashboard.codex.io/dashboard/api-keys).
3. Run **Search Defined.fi** and paste the key. The extension checks the key before it saves it.

To change the key later, set **Codex.io API Key** in the extension preferences.

## Usage

- Type a token name, symbol, or contract address. Type `$HYPE` to match the symbol exactly.
- Results are sorted by 24h volume. Use the dropdown to search one network.
- When the search is empty, the list shows tokens you opened recently.

| Shortcut | Action |
| --- | --- |
| `↵` | Open on Defined.fi |
| `⌘⇧C` | Copy contract address |
| `⌘⇧E` | Open on block explorer |
| `⌘D` | Show or hide details |

This extension is not affiliated with Defined.fi or Codex.io.
