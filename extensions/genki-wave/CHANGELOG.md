# Genki Wave Changelog

## [Faster connection, sturdier dictation] - 2026-10-26

- Dictating into an app that isn't open now opens it and types into it,
  instead of failing.
- Dictate & Send presses Return in web-based apps such as Claude too.
- Your ring reconnects as soon as it's turned on, and Configure Wave shows it
  within a second.
- The app picker opens instantly after the first time.
- Dictation into a terminal always runs the line: quotes are typed as
  typographic ones, which a shell doesn't wait on.
- No double text when Raycast Dictation's output is set to paste.
- Uninstalling the extension also stops its background helper.

## [Initial Version] - 2026-10-23

- Map each Wave button and swipe to dictation, slides, media, hold-and-turn
  volume, a key, or any Raycast command or URL.
- Dictation typed into the app chosen for each button, sent or as a draft.
- Ring status with battery, and a fix for anything that needs attention.
