# Rubiks Cube Timer Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Random scrambles for 3×3 and 2×2 cubes with a start/stop timer
- Timer precision options (seconds, half, tenths, hundredths) and an optional hidden timer
- Optional WCA inspection with configurable time, +2 / DNF penalties, and an optional hidden countdown
- Session stats (best, ao5, ao12), scoped per cube
- csTimer import/export, with options to replace history or drop very fast solves
- Built-in cube notation guide
