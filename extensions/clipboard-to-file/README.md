# Clipboard to File

Save clipboard text or a copied file to a configurable folder without leaving Raycast.

## Setup

Open the extension's preferences and choose an existing destination folder. The destination defaults to `/Users/Shared` so files can be accessed by every user account on the Mac.

The selected folder must be writable.

## Usage

1. Copy text or a file.
2. Run **Write Clipboard to File**.
3. Enter the destination filename, including an extension when needed.

Text is saved as UTF-8. A copied file is copied with its original contents. If the destination filename already exists, it is replaced.
