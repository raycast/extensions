# Heed Changelog

## [Initial Version] - 2026-09-27

- Step through visible windows with Focus Next and Focus Previous Window
- Move to the nearest window left, right, above, or below
- Focus Window lists every visible window by name and focuses the one you pick
- Enable, disable, or toggle Heed's focus follows mouse
- Release every shortcut Heed holds so Raycast can have the combinations, and restore them
- Enable or disable mouse follows focus, the pointer following a command into the window it focused
