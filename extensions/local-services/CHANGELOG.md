# Changelog

## [1.0.0] - 2026-04-15

### Added
- Initial release of Local Services extension
- Discover and manage localhost services: lsof, Docker containers, /etc/hosts entries, Docker Compose services
- View all listening ports with process information and icons
- Stop/kill running processes and Docker containers
- Start stopped Docker Compose services
- Filter services by name, port, type, or source
- Copy URLs and ports to clipboard
- Open services in browser
- Customizable ignored ports via preferences
