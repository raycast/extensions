# Memry

Save links to [Memry](https://savememry.com) directly from Raycast. Memry is an AI-powered link manager that remembers why your links matter.

## Features

- **One-step saving** — Open Raycast, type your command, paste a URL, and hit Enter
- **Auto-clipboard** — If you have a URL copied, it's pre-filled automatically
- **AI-powered** — Every saved link is analyzed by AI to extract key takeaways, topics, and a summary
- **Never forget** — Memry resurfaces important links so you never lose track of what you saved

## Setup

1. Sign up or log in at [savememry.com](https://savememry.com)
2. Go to **API Keys** (from the user menu)
3. Create a new API key and copy it
4. Open this extension's preferences in Raycast and paste your key

## Usage

1. Open Raycast
2. Search for **"Save Link to Memry"**
3. If you have a URL copied, it will be pre-filled — otherwise paste or type one
4. Press **Enter** to save

Your link appears in Memry instantly and AI analyzes it in the background.

## Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Enter` | Save link |
| `⌘V` | Paste from clipboard |
| `⌘,` | Open extension preferences |
