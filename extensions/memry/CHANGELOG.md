# Memry Changelog

## [Initial Version] - {PR_MERGE_DATE}

### Added

- Save Link to Memry command — paste any URL and save it to your Memry account
- Automatic clipboard detection — if a valid URL is on your clipboard, it auto-fills the URL field
- API key setup flow with validation against the Memry API
- Support for both preference-based and in-app API key storage
- Paste from Clipboard action (Cmd+V)
- Disconnect Account action (Cmd+Shift+D)
- Open savememry.com to generate API key (Cmd+O)
- Success/error toast notifications for all actions
- Automatic AI analysis triggered on save — Memry extracts takeaways, topics, and summaries
