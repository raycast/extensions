# ArgoCD Changelog

## [Initial Release] - {PR_MERGE_DATE}

- Search Applications: search by name, view sync/health status, browse resources, view manifests, tail pod logs, view rollout history, favorite apps
- Search Projects: search by name, view details, drill into a project's applications, favorite projects
- Login: authenticate the `argocd` CLI via SSO
- Favorited applications/projects are pinned to the top of their list
- Search Applications supports an optional `appName` argument for deep-linking straight to an application's Details screen
- Copy Deeplink action on application rows and the Details screen
