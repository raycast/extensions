# TrellisWM

Control [TrellisWM](https://trelliswm.app), the fractal window manager for Mac, from Raycast.

## Requirements

- TrellisWM installed (Apple silicon, macOS 14 or later).
- **TrellisWM Pro.** The extension uses TrellisWM's `trelliswm://` URL commands, which are a Pro feature. On Free, TrellisWM shows its upgrade prompt instead. Open Settings works on both.

## Saved view names

TrellisWM does not report its saved views to other apps. The names you give views in **Saved Views** are stored in Raycast only.
