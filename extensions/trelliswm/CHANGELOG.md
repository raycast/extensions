# TrellisWM Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Commands for every TrellisWM URL action: zoom, back and forward, neighbouring spaces, framing, arranging and settings.
- Saved Views: name your nine views in Raycast, then open or save them from one list.
- Save View and Go to View: choose a view by name. Save View asks before it replaces one.
