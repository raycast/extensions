## 2. Implement Daytona Execution Service Call [done]
### Dependencies: 6.1
### Description: Wire the AI tool to the Daytona execution engine. When the tool is invoked, it should pass the AI-generated Python code to the imported Daytona service.
### Details:
Inside the tool's execution block, call the `executePythonCode` function, passing the code string provided by the AI. Use `await` to handle the asynchronous nature of the call and store the returned `CodeExecutionResponse` object in a variable.

## 3. Format Successful Execution Output for the AI [done]
### Dependencies: 6.2
### Description: Process the response from the Daytona service for successful executions. Format the `stdout` into a clear, structured string that the AI can easily parse and use in its final response.
### Details:
Check the `CodeExecutionResponse` for an exit code of 0 and empty `stderr`. If the execution was successful, format the result into a string, for example: `Execution successful. Output: [stdout content]`. This string will be the return value of the tool.

## 4. Format Execution Errors and Failures for the AI [done]
### Dependencies: 6.2
### Description: Handle failed executions by processing the `stderr` and non-zero exit code from the Daytona service. Format this information into a descriptive error message for the AI.
### Details:
If the `CodeExecutionResponse` contains a non-zero exit code or content in `stderr`, format the output to clearly indicate failure. For example: `Execution failed. Error: [stderr content]. Exit Code: [exit code]`. This allows the AI to understand the error and inform the user.
