# AGENTS.md

## Scope

This folder contains project documentation.

## Guidance

Keep docs practical and command-oriented. When updating workflow docs, include both WSL and Windows commands when the behavior differs by operating system.

When source behavior changes, keep documentation aligned with the current command UX, cache schema, and parser/URL-normalization responsibilities. `docs/maintenance.md` should describe operational checks and data-shape changes; `docs/windows-development-workflow.md` should stay focused on the Windows/WSL development loop.
