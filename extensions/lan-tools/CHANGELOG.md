# LAN Tools Changelog

## [V1.0.0] - {PR_MERGE_DATE}

- **My LAN** command: ARP-based device inventory with mDNS name enrichment,
  vendor lookup, status (online/idle/offline), and per-device actions
  (Ping / Traceroute / DNS Lookup / Copy / Open Web Panel).
- **This Mac** command: network identity, Wi-Fi RF state, public IP, DNS, and
  neighbor channel summary.
- **Speed Test** command: internet download, upload, and latency via pure-HTTP
  providers (Yandex default, Cloudflare).
- **Ping / Traceroute / DNS Lookup** network tools, available from My LAN
  device rows.
