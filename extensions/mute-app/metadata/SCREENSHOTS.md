# Screenshot Requirements

Before publishing to the Raycast Store, you need to add 3-6 screenshots of the extension.

## Specifications

- **Resolution**: 2000 x 1250 pixels (16:10 aspect ratio)
- **Format**: PNG
- **Quantity**: 3-6 screenshots (3 minimum recommended)
- **Background**: Use a high-contrast, consistent background across all screenshots
- **Focus**: Show only your extension within Raycast (no other apps)

## Suggested Screenshots

### 1. Main List View (REQUIRED)
- Show the list of applications with audio
- Include active/inactive tags
- Show muted indicators
- Demonstrate file icons for apps
- Filename: `mute-app-01-main-list.png`

### 2. Toggle Action Panel (REQUIRED)
- Show the action panel with "Toggle Mute" options
- Display the keyboard shortcuts
- Show the icon differences between muted/unmuted
- Filename: `mute-app-02-action-panel.png`

### 3. Mute Status Change (REQUIRED)
- Show before and after of muting an application
- Display the success toast notification
- Highlight the muted indicator
- Filename: `mute-app-03-mute-toggle.png`

### 4. Preferences Screen (OPTIONAL)
- Show the refresh interval preference dropdown
- Display all available options
- Filename: `mute-app-04-preferences.png`

### 5. Active Application View (OPTIONAL)
- Focus on active applications with green tags
- Show real-world apps (Chrome, Spotify, etc.)
- Filename: `mute-app-05-active-apps.png`

### 6. Empty State or Loading (OPTIONAL)
- Show what users see when no apps have audio
- Or show the loading state
- Filename: `mute-app-06-empty-state.png`

## How to Capture Screenshots

1. Open Raycast and launch the Mute App command
2. Use a screenshot tool that captures at exact dimensions:
   - Windows Snipping Tool (crop to 2000x1250)
   - ShareX (with custom region)
   - Greenshot
3. Use a high-contrast background (dark mode recommended)
4. Ensure no sensitive information is visible
5. Save as PNG with descriptive filenames

## Naming Convention

Place all screenshots in this `metadata/` folder with names:
- `mute-app-01-main-list.png`
- `mute-app-02-action-panel.png`
- `mute-app-03-mute-toggle.png`
- etc.

## Before Publishing

- [ ] Created at least 3 screenshots at 2000 x 1250 pixels
- [ ] All screenshots use consistent background
- [ ] No sensitive data visible in screenshots
- [ ] Screenshots show the extension's key features
- [ ] Files saved as PNG in this metadata folder
- [ ] Verified screenshots look good in Raycast Store preview
