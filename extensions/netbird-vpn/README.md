# NetBird VPN

Check status and connect or disconnect NetBird VPN from Raycast.

## Requirements

- NetBird app or CLI installed.
- NetBird daemon running (the extension calls `netbird status`, `netbird up`, and `netbird down`).

## Usage

- Open the `NetBird VPN` command to view status.
- Press Enter to toggle connect/disconnect.
- Use the action panel for explicit Connect/Disconnect and Refresh.

## Store Screenshots (Metadata)

- Save screenshots to `metadata/` at the repo root.
- Use a consistent naming pattern, e.g. `metadata/netbird-01.png`, `metadata/netbird-02.png`, `metadata/netbird-03.png`.
- Raycast Window Capture can auto-save to `metadata/` when you tick “Save to Metadata”.
