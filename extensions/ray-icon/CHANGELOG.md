# Ray Icon Changelog

## [Initial Version] - 2026-10-29

- Create and export icons from the Raycast icon set or a custom SVG.
- Edit icons with a live preview, including preset, appearance, glare, noise, size, and corner radius.
- Keep the preview clear with optional metadata, and edit fill, colors, and file name directly from the settings list.
- Generate light, dark, or matching light and dark icons through AI, with preview Markdown and links to each PNG and SVG.
- Reopen the latest 100 icon designs from History, including exports, clipboard copies, and AI generations.
- Keep exact designs in Favorites and reuse built-in or named style templates with any icon.
- Switch collections from the icon browser or open History, Favorites, and Templates directly from Raycast.
- Ask AI to reuse saved designs, favorite icons, and save named templates without regenerating them.
