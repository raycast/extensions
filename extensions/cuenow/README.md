# CueNow

[CueNow](https://github.com/sworup-kumar/cuenow-releases) is a free and lightweight sticky note app for your Mac. Now you can search and create new sticky notes within Raycast without leaving your current active task.

---

## Search notes

You can now search for your notes quickly by their title or by their text inside them and open the note. 

For each note, you will also have multiple actions with their own shortcuts:

- `Open Note` - Opens the note and places it in front
- `Copy Content` - Copies the note content body without opening the note
- `Hide Note` - Hide the selected active note
- `Delete Note` - Delete the note after a confirmation and puts it into CueNow's trash

## Create notes

Rather than manually reaching out to the menu bar item to create a new note, you can now do the same by selecting the `Create Note` command. 

You can also add a hotkey to make this process faster.

## Troubleshooting

- CueNow **1.5.1 or later** must be installed. You can download the latest version of the application [here](https://github.com/sworup-kumar/cuenow-releases/releases)
- CueNow does not need to be running. Any of the commands will run CueNow if it is closed
- If you face any issue with the application, you can create a [new issue](https://github.com/sworup-kumar/cuenow-releases/issues) or reach out to me directly via [Instagram](https://www.instagram.com/sworup_ku/) or [email](mailto:hello@sworupkumar.com)
