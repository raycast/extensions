# Substack

Search for Profiles and Posts on [Substack](https://substack.com/)

Create and edit unpublished drafts, manage multiple accounts, and use draft tools through Ask Substack.

## Account setup

Open **Manage Accounts** and add your publication using its `yourname.substack.com` address, even if it uses a custom domain.
The optional account label defaults to the publication name.

Sign in to Substack in your browser. In developer tools, find Cookies under Application or Storage.
Copy the `substack.sid` value into **Substack Session Cookie**. **Connect Session Cookie** (`connect.sid`) is optional.
Paste cookie values only. Raycast stores credentials in encrypted local storage.

## Drafts

Use **Create Draft** with a title and Markdown text or file.
Use **List My Drafts** to browse drafts, edit them in Raycast, or open the full Substack editor.
Publish, schedule, and send emails on Substack.

Draft forms support basic Markdown and public HTTPS images. Code blocks, tables, HTML, and local image uploads are unsupported.
For rich content that the native editor cannot preserve as Markdown, edit the body on Substack.
