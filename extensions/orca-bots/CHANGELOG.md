# Orca Bots Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Add **Ask a Bot** command to pick an Orca bot, send a prompt, and read its reply in Raycast.
- Add **Ask Default Bot** command to query your configured default bot directly from the Raycast bar.
- Add **Open Agents** command to monitor Orca agents grouped by state, inspect conversations, copy session IDs, and jump to terminals.
- Add preferences for a custom Orca CLI path and a default bot folder.
