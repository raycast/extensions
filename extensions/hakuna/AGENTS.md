This is a raycast extension for Hakuna.

# Hakuna

Is a time tracking application.
API docs: https://app.hakuna.ch/api_docs

Not all tenants have projects enabled – always account for this.
Not all tenants use groups – always account for this.
Not all tenants use teams – always account for this.
