# Live Tennis Changelog

## [Initial Version] - {PR_MERGE_DATE}

- **Live Matches** command: in-play matches for ATP, WTA, Challenger, ITF and Juniors with current score, serving player and a break-point indicator. Optional auto-refresh (default every 60 seconds, configurable or off) with a detail pane per match.
- **Upcoming Matches** command: scheduled fixtures, earliest first, filterable by tour.
- **Search Players** command: player lookup with current ranking, ranking movement, points, country and age.
- Free-tier friendly: tour filtering of live matches happens client-side, and every error state (invalid key, rate limit) is explained in place.
