# Color Contrast Checker Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Live WCAG contrast ratio between a foreground and background color
- AA and AAA pass/fail for normal text, large text, and UI components
- Suggest the nearest passing foreground color for AA or AAA
- Accepts HEX, RGB, HSL, and CSS named colors, including alpha
- Swap colors and copy the report or hex values
