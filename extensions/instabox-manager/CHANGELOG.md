# InstaBox Manager Changelog

## [Initial Version] - 2026-10-22

- Manage Machines: list machines grouped by state, view details, start, stop, pause, resume and delete them, with operation progress
- Connect over SSH in Terminal or iTerm with a short-lived SSH token, or copy the SSH, Mosh or CLI command
- Open a machine's desktop, take a screenshot, and copy view-only or interactive desktop links
- Set the idle pause and labels, publish public ports, and save snapshots
- Create Machine from a template or one of your snapshots, optionally stopping it after a set time
- Run Command on a machine and see its output and exit code
- Manage Snapshots: list, delete and create machines from them
