# Ghostty Launcher Changelog

## [Initial Version] - 2025-01-21

- Add Recent Projects command to browse and open recent projects in Ghostty
- Add Workspaces command to save and open multiple projects as tabs
- Add Create Workspace command to group projects together
- Add New Window command to open Ghostty in any directory
- Add Open Config command to edit Ghostty configuration
- Add project directory scanning with configurable depth
- Add support for detecting Git, Node, Rust, Python, and Go projects
- Add shell history parsing for additional project discovery
