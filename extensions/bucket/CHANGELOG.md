# Bucket Bookmarks Changelog

## [Bucket Bookmarks] - {PR_MERGE_DATE}

### Added

- Added the Search Bookmarks command with matching across titles, URLs, descriptions, and tags.
- Added the Save Bookmark command with automatic URL detection from the clipboard.
- Added the menu bar command for quick access to recent and featured bookmarks.
- Added device connection authentication with secure pairing codes.
- Added API token authentication for advanced users.
- Added the Manage Authentication command to review connection status and methods.
- Added folder support when saving bookmarks.
- Added tag support for categorization.
- Added featured bookmarks with a star indicator.
- Added a server-side AI organization trigger for bookmarks.
- Added edit and delete bookmark flows with confirmation on delete.
- Added copy URL and copy title actions from the search list.
- Added empty states and clearer error feedback when loading or commands fail.
