# Bucket Bookmarks Changelog

## [Initial Release] - {PR_MERGE_DATE}

### Added

- Search Bookmarks command with fuzzy matching across titles, URLs, descriptions, and tags
- Save Bookmark command with automatic URL detection from clipboard
- Menu Bar command for quick access to recent and featured bookmarks
- Device Connection authentication with secure 6-character pairing codes
- API Token authentication support for advanced users
- Manage Authentication command to view and switch between auth methods
- Folder support for organizing bookmarks
- Tag support for better categorization
- Featured bookmarks with star indicator
- AI organization trigger to auto-organize bookmarks
- Edit bookmark functionality with full metadata support
- Delete bookmark with confirmation dialog
- Copy URL and title actions
- Auto-refresh on bookmark changes
- Empty state views with helpful messages
- Comprehensive error handling and user feedback
