# Xcode Manager Changelog

## [Initial Release] - {PR_MERGE_DATE}

### Added

- ✨ Select and switch between installed Xcode versions
- 📋 List all installed Xcode versions
- 🌐 Browse all available Xcode versions for download
- ⬇️ Download specific Xcode versions
- 🚀 Install Xcode versions directly from Raycast
- 🗑️ Uninstall Xcode versions
- 📱 Manage iOS/watchOS/tvOS simulator runtimes
- 🔄 Update available Xcode versions list
- 🔐 Secure password storage for sudo authentication
- 🌍 Multi-language support (English and Portuguese)
- ⚙️ Configurable language preference (auto-detect or manual selection)
- 📝 Detailed logging for troubleshooting

### Features

- **Smart Authentication**: Automatically handles sudo password requirements
- **Password Management**: Securely store and reuse your macOS password
- **Language Detection**: Auto-detects system language or use manual preference
- **Comprehensive Logging**: Debug-friendly logs with clear prefixes
- **Clean UI**: Modern Raycast interface with icons and shortcuts

### Requirements

- macOS
- [xcodes](https://github.com/XcodesOrg/xcodes) CLI installed
- Apple Developer account (for downloading Xcode versions)
