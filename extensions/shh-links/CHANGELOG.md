# Shh Links Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Add the Paste Link Without Embed command: a form whose text and URL come from the Discord selection and the clipboard.
- Add the Paste Clipboard Without Embed command: pastes the clipboard links with no form.
- Name links after their site, and number site names that repeat in a list.
- Remove tracking parameters from links, with a preference to turn it off.
- Support Discord, Discord PTB and Discord Canary.
