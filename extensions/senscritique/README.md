# SensCritique

Search movies, TV shows, books, and videogames on SensCritique and quickly view community ratings.

## Features

- Fast autocomplete followed by full result enrichment
- Community rating and rating count in results
- Filter by media type (movie, TV show, book, game)
- Open result pages directly in browser

## Notes

This extension queries SensCritique's GraphQL endpoint at https://apollo.senscritique.com/graphql.
Ensure this usage is compliant with SensCritique's Terms of Service before publication.
