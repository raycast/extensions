# Pretty Link

Quickly copy formatted links from GitHub Pull Requests and Plain threads to share with your team.

## Supported Platforms

- **GitHub**: Pull Requests and Issues
- **Plain**: Customer support threads

## Features

- Auto-detects the active tab type (GitHub or Plain)
- Customizable prefixes for urgent and non-urgent links
- Separate prefix settings for GitHub and Plain

> [!NOTE]
> This extension requires the [Raycast Browser Extension](https://www.raycast.com/browser-extension) to be installed.
