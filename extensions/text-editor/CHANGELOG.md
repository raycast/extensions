# Changelog

All notable changes to the **Text Editor** extension will be documented here.

## [1.0.0] - {PR_MERGE_DATE}
### Added
- Initial release of **Text Editor** (formerly QuickDraft).
- Core editor form with **Title** and **Contents** fields.
- **Save** action (Ctrl ⏎) with persistence via LocalStorage.
- **Save As…** action (Ctrl ⇧ ⏎) with secondary form for file name, type, and location.
- Built‑in icons: `SaveDocument` for Save, `Folder` for Save As.
- Toast notifications for save and export actions.

### Changed
- Renamed extension from **QuickDraft** to **Text Editor** to comply with Title Case publishing rules.

### Fixed
- Linting issues (Title Case action titles, proper ellipsis character).
- Prettier formatting applied across codebase.
