# Memory Machine Changelog

## [Initial Version] - {PR_MERGE_DATE}

- **Open Search** opens Memory Machine Search with an optional query, including support for app filters.
- **Open History** opens your screen history and can jump to a date or time entered in plain language.
- **Open Settings** opens the Memory Machine app settings.
- Mention `@memory-machine` in Raycast AI to open search, history, or settings.
- If the Mac app is missing, commands offer to open the download page and retry.
