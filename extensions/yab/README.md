# Yab

[Yab](https://yetanotherbrowser.com) from Raycast: its tabs, spaces, history, bookmarks, downloads and mail, its windows, and its agent.

## Commands

- **Search Yab**: open tabs, history, bookmarks, search suggestions and the agent in one field. ↵ opens, ⌘↵ opens in the Small Window.
- **Search Tabs** and **Search Space Tabs**: every space's tabs, pins first. Switch, close, reload, copy, close duplicates.
- **Search Spaces**: go to a space, or open a tab or window in it.
- **Search History**: pages you visited, found by title, address or the words inside them, with the passage that matched.
- **Search Bookmarks** and **Search Downloads**.
- **New Tab**, **New Window**, **New Private Window**, **Open in Small Window**, **Move Page to Yab** (the front tab of Safari, Chrome, Arc, Dia, Brave or Edge).
- **Copy Current Tab URL**, **Copy Current Tab as Markdown Link**, **Close Duplicate Tabs**.
- **Ask Yab**: hand a task to Yab's agent and read the answer in Raycast. **Ask in Yab** opens ⌘J with your words. **Agent Sessions** lists what the agent is doing and what waits for you.
- **Search Mail**, **Search Files**, **Search Memory**, **Search Snippets**, **Purchases**: what Yab keeps on this Mac.
- **Yab in the Menu Bar**: spaces, pins, and agents at work.
- `@yab` in Raycast AI: tabs, spaces, history, bookmarks, downloads, mail and memory, and tasks for Yab's agent.

## Setup

Install Yab from [yetanotherbrowser.com](https://yetanotherbrowser.com). The first command that works with tabs asks macOS to let Raycast control Yab (System Settings › Privacy & Security › Automation).

Everything is read from Yab on this Mac. Nothing goes to a server, except search suggestions from Google or DuckDuckGo, which you can turn off in the extension's preferences.

Yab 0.39.1 or newer opens private windows, tabs in a given space, the Small Window and ⌘J directly. Older versions work too, through keyboard shortcuts.
