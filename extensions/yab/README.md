# Yab

Control the Yab browser from Raycast.

- **Search Yab** searches open tabs and history together. Type an address to open it, or any other text to search the web.
- **Search Tabs** lists tabs by space, marked Pinned, Kept or Today. Switch to a tab, close it or copy its URL.
- **Search Spaces** switches to another space.
- **Search History** searches pages you visited.
- **New Tab**, **New Window**, **New Incognito Window** and **New Small Window** open them in Yab.
- **Open URL in Yab** opens an address in a new tab. With no input it uses a URL on the clipboard.

The search engine for non-URL text can be set in the extension preferences.

The first time a command talks to Yab, macOS asks whether Raycast may control Yab. Allow it.
