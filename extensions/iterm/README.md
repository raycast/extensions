# iTerm

Control [iTerm2](https://iterm2.com) from anywhere. Open windows, tabs and splits, switch sessions and open folders, all from the keyboard.

## Commands

- **New iTerm Window** and **New iTerm Tab**.
- **Split iTerm Horizontally** and **Split iTerm Vertically**: Split the current pane using your current profile.
- **Open iTerm Here**: Opens iTerm in the folder selected in Finder.
- **Edit in iTerm**: Opens the selected files in iTerm with your `$EDITOR`.
- **Open iTerm Profile**: Opens a profile in a new window or tab.
- **Switch iTerm Session**: Lists every open session, grouped by window and tab, and switches to it.
- **Move iTerm Session**: Moves the current pane to a new or existing window.
- **Switch iTerm Color Preset**: Applies a color preset to the current profile.
- **Search Projects in iTerm**: Find a project folder and open it in iTerm.

## Use it with Raycast AI

Mention `@iterm` in Raycast AI to read what's in your terminal, or to type into it. For example, "what does this error in iTerm mean?"
