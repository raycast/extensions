# forkz for Raycast

Raycast commands for [forkz](https://github.com/houseofmackee/forkz), the
free and open source dual-pane file manager for macOS. The commands open
`forkz://` links, so forkz must be installed. Install it with
[Homebrew](https://brew.sh):

```sh
brew install --cask houseofmackee/tap/forkz
```

or download it from the
[releases](https://github.com/houseofmackee/forkz/releases).

| Command | What it does |
| --- | --- |
| Connect to Site | Pick a saved site (SFTP, FTP, WebDAV, S3, Azure, Box, Dropbox, Google Drive, OneDrive, and more) and connect to it |
| Recent Folders | Open a folder forkz showed lately, on the Mac or on a server |
| Favorites | Open a folder from forkz's sidebar |
| Run Synclet | Run a saved sync |
| Open Smart Folder | Run a saved search |
| Open Workspace | Open a saved set of tabs |
| Open Finder Folder | Show the item selected in Finder (the first, if several are), or the front Finder window's folder, in forkz |
| Search Files | Search a folder by name or contents, kind, size, and date |

The lists come from forkz's settings on your Mac: names, folders, and
server addresses only. Passwords stay in your Keychain and are never read.
