# TickTick Quick Add Changelog

## [Initial Release] - 2026-06-03

- Add task to TickTick inbox using natural language syntax
- Support priorities: `high`, `medium`, `low`, `!1`, `!2`, `!3`
- Support tags via `#tag` syntax
- Support list routing via `@list` syntax
- Support date formats: `today`, `tmr`, `monday`, `June 5`, `1.12.`, `12/1`
- Support time formats: `5pm`, `17:00`, `9:30am`
