# Caps n Case

Quickly convert text case to uppercase, lowercase, sentence case, and title case directly from Raycast.

## Features

Transform text instantly with four powerful conversion commands:

- **UPPERCASE** - Convert text to ALL CAPS
- **lowercase** - Convert text to all lowercase letters
- **Sentence case** - Capitalize the first letter, lowercase the rest
- **Title Case** - Capitalize major words following English grammar rules

## How to Use

1. Select text in any application, or copy text to your clipboard
2. Open Raycast and search for one of the conversion commands
3. The converted text will automatically replace your selection or be pasted from clipboard

### Commands

#### Uppercase Text
Converts selected or clipboard text to UPPERCASE format.

**Example:**
- Input: `hello world`
- Output: `HELLO WORLD`

#### Lowercase Text
Converts selected or clipboard text to lowercase format.

**Example:**
- Input: `HELLO WORLD`
- Output: `hello world`

#### Sentence Case Text
Capitalizes the first letter of the sentence while keeping the rest lowercase.

**Example:**
- Input: `HELLO WORLD`
- Output: `Hello world`

#### Title Case Text
Capitalizes major words for titles and headings, following English grammar rules. Articles, conjunctions, and short prepositions remain lowercase (except at the beginning or end).

**Example:**
- Input: `the quick brown fox jumps over the lazy dog`
- Output: `The Quick Brown Fox Jumps Over the Lazy Dog`

## Installation

Install this extension from the [Raycast Store](https://www.raycast.com/store) or via Raycast's extension manager.

## Keyboard Shortcuts

You can assign custom keyboard shortcuts to any command:

1. Open Raycast Settings
2. Navigate to Extensions → Caps n Case
3. Click on a command and set your preferred hotkey

**Suggested shortcuts:**
- `⌘ ⇧ U` - Uppercase Text
- `⌘ ⇧ L` - Lowercase Text
- `⌘ ⇧ S` - Sentence Case Text
- `⌘ ⇧ T` - Title Case Text
