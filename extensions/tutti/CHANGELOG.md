# Tutti Changelog

## [Display Brightness and Microphone Mute] - 2026-11-25

These commands require Tutti 2.1.0 or later.

- Set Brightness — set the brightness control group to a percentage (0–100).
- Increase Brightness / Decrease Brightness — adjust the group's brightness by 5 percentage points.
- Toggle Microphone Mute — mute or unmute the default microphone.

## [Initial Version] - 2026-07-30

- Apply Preset — pick a saved preset and switch to it.
- Toggle Mute — mute or unmute the whole output.
- Set Volume — set the output volume to a percentage (0–100).
- Increase Volume / Decrease Volume — nudge every speaker together in fixed steps.
