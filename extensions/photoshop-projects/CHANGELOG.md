# Photoshop Projects Changelog

## [Initial Version] - 2026-10-03

- Browse and open recently edited Photoshop documents (`.psd`, `.psb`, `.psdt`, `.pdd`) in visual Grid or dense List view.
- Fast fuzzy Spotlight search across file titles, directory paths, and indexed Photoshop layer names.
- Native macOS Quick Look previews with full resolution inspection and zoom support.
- File actions: Reveal in Finder, Open in New Finder Window, Open in New Finder Tab, Copy File, Copy File Path, and Move to Trash.
- Safe document renaming with extension protection and collision prevention.
- Backdate or frontdate file modification and creation timestamps with quick presets.
- Clear Photoshop memory, clipboard, and scratch disk caches with user confirmation.
- Customizable default view mode, grid column density, and search scope preferences.
