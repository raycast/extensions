# Bose Noise Cancelling

Switch the noise cancelling level on Bose QuietComfort 35 II headphones straight from Raycast.

## Commands

- **Toggle Noise Cancelling** - switches between high and off
- **Set Noise Cancelling to High**
- **Set Noise Cancelling to Low**
- **Turn off Noise Cancelling**

Assign a hotkey to any of them in Raycast's settings.

## Setup

1. Pair and connect the headphones to your Mac.
2. The first time you run a command, macOS asks whether Raycast may use Bluetooth. Allow it.

## Supported headphones

Tested on Bose QuietComfort 35 II. The original QuietComfort 35 uses the same protocol and should work too. The extension talks to the headphones over their Bluetooth control channel, the same one the Bose app uses. Other Bose models (QuietComfort Earbuds, QuietComfort Ultra, 700) use a different protocol and are not supported.
