# Call Contact

The fastest way to call, message, or FaceTime your contacts directly from Raycast.

## ✨ Features

- **⚡️ Instant Search**: Zero latency. Your contacts load instantly.
- **⭐️ Smart Favorites**: Favorites stay at the top, sorted by who you called last.
- **🚨 Priority Call**: One command to **text AND call** simultaneously (perfect for emergencies).
- **� Multi-Channel**: WhatsApp, FaceTime, iMessage, and Phone all in one place.

## 🚀 Getting Started

1. **Install**: Install the extension from the Raycast Store.
2. **Authorize**: On first launch, click **"OK"** when asked for access to **Contacts**.
   - *If you accidentally denied it, you can fix it in System Settings -> Privacy & Security -> Contacts.*
3.  **First Run**: The very first search might take 1-2 seconds to build the cache. Subsequent runs are **instant**.

## 📚 Usage Guide

### 📞 Making a Call
Simply search for a name, number, or initials and press `Enter`.
- **Default Action**: Starts a standard phone call.

### 🚨 Priority Call (`Cmd + Shift + P`)
In a rush? Use the Priority Call action.
1. It opens an **iMessage Draft** with a pre-set urgent message (e.g., "Urgent: Please pick up!").
2. It **immediately starts calling** the person.
*Customize your urgent message in Extension Preferences (`Cmd + ,`).*

### ⭐️ Favorites (`Cmd + Shift + F`)
Toggle a contact as a Favorite.
- Favorites always appear at the top of an empty search.
- They are sorted by **Recency** (who you spoke to last).

### 💬 Other Actions (`Cmd + K`)
Access the Action Panel to connect via other apps:
- **WhatsApp Message**: Opens a chat directly.
- **FaceTime**: Audio or Video calls.
- **iMessage**: Send a standard text.

## ⚙️ Configuration

Press `Cmd + ,` to customize settings:
- **Priority Message**: Set the default text sent during a Priority Call (default: "Urgent: Please pick up! 🚨").

*Note: Requires the native macOS Contacts app to be populated.*
