# Store screenshots

Raycast's Store listing expects up to 6 screenshots in this folder, named:

- `mac-updater-1.png`
- `mac-updater-2.png`
- `mac-updater-3.png`
- … etc.

Required dimensions: **2000×1250** (light mode) — recommended one matching `2000×1250` for dark mode if you want to provide both. PNG only.

## Recommended sequence

1. **`mac-updater-1.png`** — Main Updates view with a few pending apps. Captures the core value in one shot.
2. **`mac-updater-2.png`** — Detail pane open on one app, showing the app icon, version diff, source tag, and release notes.
3. **`mac-updater-3.png`** — Adopt view in the middle of running, with apps in various states (running, adopted, failed).
4. **`mac-updater-4.png`** — Update Everything queue running, showing per-app progress.
5. **`mac-updater-5.png`** — Sources dropdown open, showing the sidebar-style hierarchy with counts.
6. **`mac-updater-6.png`** — Menu bar dropdown showing pending updates passively.

## How to capture

In Raycast: Settings → Advanced → enable "Show Window Screenshots". Then `⌘⇧P` while in the extension lets you save a clean screenshot at the right resolution.
