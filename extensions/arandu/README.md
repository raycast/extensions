# Arandu

Manage your day in [Arandu](https://arandu.lvdev.com.br) straight from Raycast — today's plan, agenda, habits, tasks, reminders, and your assistant.

## Setup

1. Sign in to Arandu at [arandu.lvdev.com.br](https://arandu.lvdev.com.br).
2. Go to **Connections** (Conexões) and create a new API key in the **API Keys** section.
3. Copy the token (it is shown only once) and paste it into the extension's **API Token** preference.

The token grants full access to your account — treat it like a password. You can revoke it anytime from the same screen.

## Commands

- **View Today** — today's events, scheduled tasks, reminders, and habits; complete items inline.
- **View Agenda** — upcoming calendar events grouped by day.
- **Track Habits** — check off today's habits (with per-slot tracking).
- **Create Task** — add a task with priority and due date.
- **Create Reminder** — add a one-off reminder.
- **Ask Arandu** — send a message to your Arandu assistant and read the reply. Assistant turns can take up to a minute.
