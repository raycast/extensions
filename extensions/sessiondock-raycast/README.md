# SessionDock Raycast Extension

Control **SessionDock** directly from Raycast.

This extension lets you search and open your music production sessions without leaving your keyboard. It connects to the **SessionDock Local API** running on your machine and provides fast commands for navigating your creative work.

If you already use Raycast for launching apps and workflows, this extension makes SessionDock feel like a natural part of your system.

---

## Why This Is Useful

When you're producing music, the hardest part is often rediscovering old ideas.

SessionDock already organizes your sessions, previews, and notes. This Raycast extension makes that archive instantly accessible from anywhere on your system.

Instead of:

1. Opening SessionDock
2. Searching through projects
3. Clicking into sessions

You can simply:

```
⌘ Space → search your session → press Enter
```

Your project opens immediately.

---

## What You Can Do

**Search Sessions Instantly**  
Find any project in your SessionDock library using Raycast’s fuzzy search.

**Open Sessions Quickly**  
Launch a session directly in SessionDock without navigating the full app UI.

**Trigger Imports**  
Start session imports or refresh your library directly from Raycast.

**Stay in Your Flow**  
Access your entire session catalog using only your keyboard.

---

## Requirements

Before using the extension, make sure you have:

- **SessionDock (macOS)** installed
- **Local API enabled** inside SessionDock
- **Raycast** installed
- Your **SessionDock Local API token**

---

## Setup

### 1. Enable the Local API

Open:

**SessionDock → Settings → Local API**

Enable the Local API.

SessionDock will provide:

- A **Local API URL** (example: `http://127.0.0.1:18421`)
- A **secure API token**

### 2. Configure the Raycast Extension

Open Raycast settings for the extension and enter:

**Base URL**

```
http://127.0.0.1:18421
```

**API Token**

Paste the token generated by SessionDock.

---

## Example Commands

### Search Sessions

Quickly search your entire SessionDock library and open sessions instantly.

### Create Session

Create a new session with a title, kind, status, tags, and a preview audio file.

### Open Latest Session

Instantly open the most recently accessed session without any searching.
