# Copy Tab Link Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Copy the current tab as a rich text link, ready to paste into Teams, Outlook or Word
- Rich text is offered as RTF, HTML and plain text at the same time, so every app picks the flavour
  it understands; switchable to RTF only or HTML only
- Eighteen formats in total, including Markdown, HTML, Slack, Jira, Confluence, MediaWiki, AsciiDoc,
  reStructuredText, Org Mode, BBCode, Textile, LaTeX and a custom template
- "Copy Tab As…" with a live preview of every format
- "Copy All Tabs" for every tab of the frontmost window, as a bullet, numbered or plain list
- Removes tracking parameters and optionally the URL fragment
- Title cleanup: trailing site names, emoji, a length limit and your own regular expressions
- Works with Arc, Dia, Chrome, Brave, Edge, Vivaldi, Opera, Safari, Orion and more through AppleScript,
  and with Firefox and Zen through the Raycast browser extension
