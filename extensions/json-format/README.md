# Format JSON

Pretty-print JSON from your clipboard or your editor without pasting it into a website.

Format JSON indents JSON with the indentation you choose. It also handles JSON that has been stringified (escaped inside a string) and plain JavaScript objects, and it can turn an array into JSON Lines.

## Commands

- **Format Clipboard JSON**: Formats the JSON in your clipboard, then copies or pastes the result.
- **Format Selected JSON**: Formats the JSON selected in your editor and replaces it.
- **Format Selected JSON and Show**: Formats the selected JSON and shows it in a viewer.
- **Format JSON**: Paste JSON in and get it formatted.
- **Format Array of JSON to JSONLines**: Turns an array of objects into JSON Lines, one object per line.
- **Format Text into Valid JSON Value**: Wraps text in double quotes and escapes it, so it's a valid JSON string.
