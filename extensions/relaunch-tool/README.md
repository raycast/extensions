# Relaunch Tool

Relaunch Tool is a Raycast extension that force-quits and relaunches a target application.

## What It Does

- Select a running app from a dropdown.
- Force quit the target app and wait until it fully stops.
- Relaunch the app after it has stopped.
- Works on both macOS and Windows.
- Saves the last app name for faster repeated use.

## Command

- `Force Quit and Relaunch`: Force quit the selected app, wait until stopped, and reopen it.
