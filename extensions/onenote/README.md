# OneNote

This extension allows you to:

- search Microsoft OneNote notebook and section titles, plus note titles and content
- get a basic preview of notes
- open a note in Microsoft OneNote
- create a new note if research gets no results.

## Credits

- [Kevin Funderburg's Alfred workflow](https://github.com/kevin-funderburg/alfred-microsoft-onenote-navigator) for how to handle data from Microsoft OneNote databases.

## Local search index

Open OneNote, sign in, and sync your notebooks before searching. This extension searches the local macOS OneNote index, so results depend on what OneNote has indexed on this Mac.
