## Getting an AudD API token

This extension identifies songs through [AudD](https://audd.io), which needs your own API token:

1. Create an account at [dashboard.audd.io](https://dashboard.audd.io/).
2. Copy the `api_token` shown on the dashboard.
3. Paste it into the **AudD API Token** field.

AudD offers a limited free trial for new accounts. Once it ends, their API requires a paid plan, so check their current pricing before relying on it. The token stays on your machine, and every request is billed to your own AudD account.
