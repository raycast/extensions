# Multica Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Search Issues: browse open issues by status, search all issues, and change status, priority, or assignee, or comment
- Create Issue: create issues and assign them to teammates or agents
- Delegate Task: hand a prompt to an agent, which files the issue (Agent mode), plus a Delegate Sub-Issue action on issues
- My Inbox: notifications plus the open issues assigned to you
- Inbox Menu Bar: unread count in the menu bar, broken down by workspace
- Inbox Counts: per-workspace unread counts live in the root-search subtitle
- Agents & Runtimes: agent status, recent runs, and runtime availability
