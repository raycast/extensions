# Apple Translate Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Translate selected, pasted, or typed text locally using Apple's Translation framework.
- Automatically switch between Russian and English, or choose another supported target language.
- Read continuous side-by-side columns with shared scrolling.
- Preserve paragraph breaks, indentation, list markers, and available rich-text attributes.
- Copy or paste complete translations and optionally open a larger native window.
- Support Apple Silicon Macs running macOS 26.4 or later.
