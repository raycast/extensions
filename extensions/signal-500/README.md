# Signal 500

Search the [Signal 500](https://feeds.bar/signal-500/) from Raycast — 500 hand-scored news
and expert sources, ranked on editorial quality, ad restraint, signal-to-noise and
independence, with the [methodology published](https://feeds.bar/signal-500/method/).

- Fuzzy-search all 500 sources, filter by pillar
- Open a source's Signal 500 page or its own website
- Copy its feed URL straight into any RSS reader

Data comes from the same public API the feeds.bar site is built from, cached locally.
Maintained by [FeedsBar](https://feeds.bar), the Mac news ticker the catalogue was built for.
