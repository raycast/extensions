# World Clock Changelog

## [1.0.0] - 2025-10-27
It's time to finally release World Clock to the public! This version includes:
- An interface for selecting and changing timezones.
- Clock emoji as icon reflecting the current hour.
- Updated dependencies to the latest versions.

## [Initial Version - 0.0.1] - 2023-06-27
Just a very quick proof of concept to display the time in Pune, India in the menubar.
