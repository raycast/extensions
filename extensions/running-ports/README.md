# Running Ports

Quickly see which applications are using your local ports. This Raycast extension helps you easily view and manage the active ports on your machine, allowing you to instantly identify which processes are running on them.

## ✨ Features

- **Port Listings**: View all active ports currently being used on your system.
- **Quick Actions**: Right-click (or use `⌘K`) to access context menu actions for each port.
- **Application Visibility**: Instantly identify which application is associated with each port.

## 🚀 Usage

1. Open the **Running Ports** extension.
2. Browse the list of active ports and their associated applications.
3. Use the context menu to perform actions on specific ports.
