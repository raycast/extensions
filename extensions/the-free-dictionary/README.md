# The Free Dictionary (TFD) by Farlex
Extension to easily look up words in a dictionary.

## More than a dictionary
From the search, thanks to TFD, you can jump to :
- Thesaurus
- Medical Dictionary
- Legal Dictionary
- Financial Dictionary
- Acronyms
- Idioms
- Encyclopedia
- Wikipedia Encyclopedia
