# Hopper Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Back, Forward, Toggle, and History to move through your recently used apps, switching like Cmd+Tab so each app returns to the window you left.
- Search and Search Current App for tabs, windows, sessions, bookmarks, and recently closed items across apps: Chromium browsers, Safari, cmux, Ghostty, iTerm, Terminal, herdr, Claude, Muse, Notion, Obsidian, Apple Notes, Slack, and any app's windows. Incognito and private windows are left out.
- Agents and Next Agent to see AI agents (Claude Code, Codex, Cursor, herdr, agent CLIs) by status and jump to where they run.
