# Time Keeper

Simple Raycast extension that can display the current time, and create discord timestamps from natural language!

# Current Commnds

**Command:** `Current Time`  
Shows your current local time and timezone in a popup.

**Command:** `Create Discord Timestamp`

Convert a natural language date/time (e.g., “tomorrow 2pm”) to Discord timestamp format, copy the one you want, and send!
