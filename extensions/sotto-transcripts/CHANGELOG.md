# Sotto Transcripts Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Browse Sotto's recording history with fuzzy search across transcripts, source, model, and status
- Copy transcripts back to the clipboard or paste them into the active app
- Detail pane with relative timestamps, duration, word count, transcription cost, model, and status
- Full-screen transcript view (⌘↵)
- Toggle the detail pane with ⌘⇧D
- Open the original `.wav` in Finder or play it inline
- Friendly error states for missing history, permission errors, and corrupted JSON
- Configurable path for non-default Sotto installations
