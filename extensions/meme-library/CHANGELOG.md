# Meme Library Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Save Meme: save the copied image, GIF, image URL, or selected Finder images to your library.
- Meme Library: browse saved memes in a grid and paste one with Enter. The selected GIF plays in the grid.
- Add Text (⌘T): add captions in English or Chinese, drag them into place, change the font and colors, then press ⌘↩ to copy the meme. GIFs stay animated, and the original meme does not change.
