    <h3>Museum</h3>
    <p>Find public domain artworks by color</p>
    <br/>
    <br/>
</div>

Museum is a Raycast extension that finds public domain artworks by color, using [Museum](https://trymuseum.com)'s catalog, so you can browse palettes, copy or download images, and open the source collection page.
