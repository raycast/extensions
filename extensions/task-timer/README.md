# Task Timer

Set a time limit for a task and keep its countdown in the menu bar. Requires macOS 14 or newer.

## Usage

- Run **Start Task**, enter a task name and duration, then press **Start Task**.
- Use the menu-bar timer to pause, resume, extend, or end the active task.
- When time runs out, Task Timer shows a completion notification and saves the session automatically.
- Run **Task History** to browse finished sessions and see working time with pauses excluded.

Task data and history are stored locally on your Mac.
