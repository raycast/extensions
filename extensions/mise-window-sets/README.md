# Mise Window Sets

Apply saved [Mise](https://usemise.dev) window Sets from Raycast.

## Requirements

- macOS
- Mise from https://usemise.dev
- Apply Set uses layouts://apply which requires Mise Pro
- Reload Sets works on Free

## Commands

- Apply Set: search and apply a Set
- Reload Sets: reload config from disk

## Development

npm install && npm run dev
