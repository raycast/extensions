# Stock Charts

Track stocks, view live prices, and see price evolution charts — right inside Raycast.

## Features

- **Search any stock** by symbol or company name via Yahoo Finance
- **Favorites and Popular** sections so you always have something to look at
- **Beautiful charts with volume bars** across 7 intervals (1D · 1W · 1M · 3M · 6M · 1Y · 5Y)
- **Interval-aware change badges** — see how each stock moved over the selected period, not just today
- **Earnings calendar integration** — one keystroke to add the next earnings date to macOS Calendar
- **Latest news headlines** linked directly in the detail view
- **Pre / post-market awareness** with sunrise / moon indicators
- **Multi-currency support** — proper symbols and ISO codes (no confusion between USD and CAD)
- **Company logos** fetched automatically

## Setup

No setup required. The extension uses Yahoo Finance's public endpoints — no API key, no sign-in.

## Tips

- Press `⌘D` to add or remove a stock from your favorites
- Press `⌘⇧E` on a stock with an upcoming earnings date to add it to your Calendar
- Use the interval dropdown (top right) to switch the chart and the change badges across timeframes
- Press `⌘⌥↑` / `⌘⌥↓` to reorder your favorites

## Data Source

All financial data comes from [Yahoo Finance](https://finance.yahoo.com/). Charts are rendered as static images via [QuickChart.io](https://quickchart.io/).
