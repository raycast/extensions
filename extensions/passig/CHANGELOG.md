# Passig Changelog

## [Initial Release] - 2026-11-01

- Search your vault and copy or paste usernames, passwords and TOTP codes
- Save new logins with the built-in password generator
- Import passwords from Bitwarden, 1Password, LastPass, Chrome, Firefox, Safari, KeePass, Dashlane, Keeper, NordPass, Proton Pass, Enpass, RoboForm or a CSV file
- Generate strong passwords without unlocking the vault
- Auto-lock, manual lock and automatic clipboard clearing after 30 seconds
