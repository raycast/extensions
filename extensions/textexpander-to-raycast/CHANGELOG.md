# Changelog

## [Improve Migration Review] - 2026-11-03

- Combine multiple sources, search snippet content, and select or exclude matching snippets by group or warning type.
- Edit snippets, restore source content, rename groups, and resolve keyword conflicts against a supplied Raycast export.
- Optionally convert supported clipboard, cursor, and date macros with original and converted previews.
- Export separate group files and detailed migration reports, and save local progress to resume later.

## [Initial Version] - 2026-11-02

- Convert TextExpander settings, group exports, and CSV files into Raycast snippet JSON.
- Preview and select snippets, filter by group, and review conversion warnings.
- Exclude Suggested Snippets, empty content, and exact duplicates.
- Preserve snippet whitespace and flag macros, scripts, rich text, and unsupported keywords for review.
- Save private JSON files without overwriting existing exports.
