# Time Transfer

一个 Raycast 扩展，用于将时间戳转换为中文日期格式。

## 功能特性

- 🕐 支持毫秒级和秒级时间戳自动识别
- 📋 自动读取剪切板内容，支持多行和多时间戳解析
- ⌨️ 支持手动输入时间戳
- 📊 转换结果自动复制到剪切板
- 🎯 智能识别和提取剪切板中的时间戳

## 使用方法

1. 在 Raycast 中输入 `time` 打开命令
2. 界面会自动显示剪切板中的内容
3. 你可以：
   - 在搜索框输入时间戳，然后按回车转换
   - 选择剪切板中的时间戳项进行转换
4. 转换结果会显示在顶部，并自动复制到剪切板

## 示例

输入时间戳：`1769875200000`

转换结果：`2026-02-01 00:00:00`

## 支持的时间戳格式

- 毫秒级时间戳（13位数字）：`1769875200000`
- 秒级时间戳（10位数字）：`1769875200`

## 开发

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 构建
npm run build

# 发布到 Raycast Store
npm run publish
```
