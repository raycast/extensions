# Ninety

Work with [Ninety.io](https://www.ninety.io) — the EOS® platform — without leaving Raycast.

## Commands

- **My To-Dos** — your open To-Dos grouped by due date, or any Team's To-Dos. Complete, edit, reschedule, comment and delete.
- **Issues** — a Team's Short-Term and Long-Term Issues by priority. Solve, move, prioritize, comment and create linked To-Dos.
- **Rocks** — your Rocks or a Team's Rocks for the current quarter. Set status, manage Milestones, and create linked To-Dos and Issues.
- **Headlines** — a Team's Headlines and Cascading Messages.
- **Scorecard** — a Team's weekly, monthly, quarterly or annual Measurables with recent scores and goals. Enter scores.
- **Next Meeting** — each Team's next Meeting with its agenda, presenter, scribe and attendees.
- **Create To-Do / Issue / Headline / Rock** — quick-capture forms.

You can also ask Raycast AI things like `@ninety what are my open To-Dos?` or `@ninety add an Issue to Leadership about the Q1 hiring plan`. Anything that changes data asks for confirmation first.

## Setup

1. In Ninety, open your name at the bottom of the left navigation and choose **User Settings → Developer Settings**.
2. Select **Generate New Token**, pick an expiration and copy the token (it is only shown once).
3. Paste it into the extension's **Personal Access Token** preference.

API access requires a Ninety **Thrive** or **Legacy** plan. Observers can't create tokens. The extension can only do what your Ninety role allows, and items you create are owned by you.

If the extension can't identify your user from the token, add your Ninety email in the **Your Ninety Email** preference.
