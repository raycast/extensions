# Affipill

Play your affirmation tracks from Raycast.

## Usage

- **Affipill** — browse tracks, import several files at once, add new ones, edit covers, and play audio in the background.
- **Add New Tracks Via AI** — import audio and covers, then let Raycast AI clean titles and match artwork.
- **Stop Affipill Playback** — stop whatever is currently playing.
- **Now Playing** — menu bar item while a track is playing, with a quick stop action.

Enable **Now Playing** once from Raycast search (use **Activate Background Refresh**), then it will appear automatically whenever audio is playing.

## Managing tracks

Use the **Add New Tracks Via AI** command from Raycast to select audio files and cover images and let Raycast AI clean up titles and match artwork. From Affipill, **Import Tracks** still matches by filename, and you can turn on AI there or run **Improve with AI** while reviewing. You can still edit titles or assign a cover yourself before importing.

AI import uses the built-in Raycast AI API and needs Raycast Pro. If AI is unavailable, Affipill keeps the filename matches.

Use **Add Track** to pick an audio file and optional cover image one at a time. Tracks are saved locally by the extension, so you do not need to copy files into the project.

Each track can be edited later to change the title, replace the audio, or update the cover image.
