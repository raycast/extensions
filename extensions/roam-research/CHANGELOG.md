# Roam Research Changelog

## [TODO Capture Feature] - 2024-12-18

- Add new "TODO Capture" command for quick TODO creation with {{[[TODO]]}} prefix
- Include optional date picker for due dates with proper Roam formatting (e.g., "December 19th, 2025")
- Add flexible {due_date} template variable that users can place anywhere in their template
- Add dedicated TODO capture template preference (independent from Quick Capture)
- Support any template structure - users can customize exactly how due dates appear
- Maintain full feature parity with Quick Capture (page selection, tagging, etc.)

## [Major update] - 2023-08-09

- Renamed command "Append to Daily Note" to "Quick Capture" since you can use it to append to other pages in the graph too
- Supports searching across all graphs at once
- Adds a new command "Create Graph Quicklink" which can be used to create quick ways to open graphs or specific pages in a graph
- Optimizations and fixes
