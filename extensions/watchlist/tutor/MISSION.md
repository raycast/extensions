# Mission: Raycast Extension Development (Watchlist)

## Why
You vibe-coded a working Raycast extension that tracks movies and series in an Obsidian vault. An AI generated the code — now you want to actually *own* it: understand every design decision so you can extend it, debug it, and change it confidently without having to ask an AI every time.

## Success looks like
- Read and explain any file in this extension from first principles
- Add a new command or feature without breaking the Markdown data store
- Know which Raycast API component to reach for in a given UI situation

## Constraints
- One lesson only (user's explicit preference)
- Prefer depth over breadth in that single lesson

## Out of scope
- Publishing to the Raycast Store
- Testing infrastructure
- Other Raycast extensions beyond this one
