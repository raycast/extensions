# Set Up Easydict

- Set **First Language** to the language you usually want to translate into.
- Choose a different **Second Language**. Easydict translates into it when the input is already in your first language.
- **Youdao Dictionary** covers Simplified Chinese paired with English, French, Japanese, or Korean.
- **Linguee Dictionary** provides bilingual entries and examples for supported pairs such as English <-> German.
- **Wiktionary Dictionary** adds English definitions and available translations for English words. It fills gaps such as English <-> Danish and needs no API key.

Choose the dictionaries you want to use, then select **Continue**. You can change your choices later in the Raycast extension settings. Use **Search Word** to look up a word or translate text.
