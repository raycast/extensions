# Rotara

Control [Rotara](https://getrotara.app) workspaces from Raycast.

Rotara is a Mac app that gives every project its own workspace with its own windows. Switching hides everything from the last project and brings back exactly the windows of the next one.

## Requirements

This extension needs the Rotara app, macOS 13 or later. [Download it from getrotara.app](https://getrotara.app); it's free for 14 days.

## Commands

- **Switch Workspace**: pick a workspace and go there. From its actions you can also move the window you were last using into it, and follow it there or leave it.
- **Move Window to Workspace**: send the window you were last using to another workspace.
- **New Workspace**: type a name to create a workspace and switch to it (or switch to it if it exists already).

The ⌃1–9 shown beside each workspace are Rotara's default keys for jumping straight to it.
