# League Stats Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Search a player by Riot ID. The region is detected automatically.
- Player page: ranked Solo/Duo and Flex, win rate over the loaded games, and recent games with result, champion, KDA, queue, length, and date.
- Game page: every player with KDA, damage, items and CS, plus team kills, gold, damage and objectives. Open any player's page from it.
- Stats page for one player in a game: KDA, kill participation, damage, gold, vision, items with costs, and summoner spells.
- Game Type setting to list Solo/Duo, Flex, all ranked, ARAM, or everything else.
- Games to Load setting (default 20) and a Show More Games row, up to 100 games.
- Favorites, found by name without the tag, and Create Quicklink to reach a player from Raycast's main search bar.
- Champion, item, spell, profile and rank images from Riot's Data Dragon and CommunityDragon.
