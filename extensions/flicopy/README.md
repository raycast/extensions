# Flicopy

Start [Flicopy](https://flicopy.com/) captures from Raycast: screenshots, scrolling screenshots, element and subject captures, text recognition, screen recordings, the color picker and the Quick Panel.

Flicopy is a working memory for the Mac. It keeps what you copy and capture, so you can paste it again or hand it to an AI as context.

## Setup

1. Install [Flicopy](https://flicopy.com/download) (macOS 14 or later).
2. Keep **URL Scheme integration** turned on in Flicopy → Settings → Advanced. It is on by default.

Each command opens a `flicopy://` URL, so it does exactly what the matching Flicopy shortcut does, and the capture lands in Flicopy as usual. The full list of URLs is in the [Flicopy URL scheme reference](https://flicopy.com/help/url-scheme/).

## Combine Selected Images

Select two or more images in Finder and run **Combine Selected Images** to open them together in Flicopy's combine view.
