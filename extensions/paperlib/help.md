# Paperlib API Host

This extension talks to Paperlib through the official **API Host** plugin.

1. Install [Paperlib](https://paperlib.app) and open your library.
2. In Paperlib, open **Preferences → Extensions**.
3. Search for `@future-scholars/paperlib-apihost-extension` and install it.
4. Leave Paperlib running. The plugin listens on `http://127.0.0.1:21227`.

If Paperlib is closed, set **Library JSON or CSV** to an export, or leave **Use demo library** enabled for a built-in sample set.
