# Store screenshots

Place here the screenshots shown on the extension page in the Raycast Store.

- **Files:** `worktree-manager-1.png`, `worktree-manager-2.png`, … up to `worktree-manager-6.png`
- **Spec:** 2000 × 1250 px, aspect ratio 16:10, PNG
- **Recommendation:** At least 3 screenshots (e.g. Search Worktrees list, Create Worktree form)

You can use Raycast’s built-in capture (Raycast 1.37+): set a hotkey in Advanced Preferences for “Window Capture” and enable “Save to Metadata” when taking the screenshot.
