# DeserveOS for Raycast

Talk to your DeserveOS CRM, get today's deal briefing, and stay on top of follow-ups and reminders — without leaving Raycast.

## Commands

| Command | What it does |
| --- | --- |
| **Ask Your CRM** | Ask the DeserveOS sales copilot anything about your pipeline. It answers from your live CRM (deals, people, companies) using the same sales-copilot persona as the web app. Supports follow-up questions in the same conversation. |
| **Today's Briefing** | Your morning deal briefing — at-risk deals, silent threads, and what needs a reply today. |
| **Reminders & Tasks** | Open tasks and auto-generated follow-up reminders, grouped by Overdue / Today / Upcoming. |
| **Search CRM** | Search people, companies, and deals in your workspace and jump straight to the record. |
| **Log In to DeserveOS** | Sign in via the browser — Google or email, just like the web app. |

## Setup

1. Set your **Workspace URL** in the extension preferences (⌘,), e.g. `https://acme.app.deserveos.com`. Use the full subdomain of your workspace.
2. Run **Log In to DeserveOS** → it opens your browser. Sign in with **Google or email** (whatever you normally use), then approve access.
3. Use any command. Your session is refreshed automatically; DeserveOS never shares your password with Raycast.

## How it works

- **Auth**: browser-based OAuth2 + PKCE using DeserveOS's native-app flow. The extension dynamically registers a public OAuth client (`POST /oauth/register`), opens the `/authorize` page on your workspace (where you log in with Google/email and approve), exchanges the returned code at `/oauth/token`, and stores the access/refresh tokens in Raycast's secure storage (the system keychain). Tokens refresh automatically.
- **Endpoints**: AI chat and the deal briefing use the `/metadata` GraphQL schema; record queries (people, companies, deals, tasks) use the `/graphql` schema. The API host (default `https://app.deserveos.com`) is configurable for self-hosting.
- **AI chat**: a thread is created, the message is sent, and the assistant reply is polled from `chatMessages` (the answer is generated by a background worker, so no streaming subscription is needed).

## Notes

- "Deals" is the DeserveOS label for the internal `opportunity` object; the `CUSTOMER` stage is shown as **Client**.
