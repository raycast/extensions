# Apple Container Changelog

## [Initial Version] - 2026-07-27

- Manage Containers: list, start, stop, restart, kill, delete, view logs, open a shell in Terminal, and inspect.
- Manage Images: list, pull, run a container, tag, inspect, delete, and prune.
- Manage Volumes: list, create, inspect, and delete.
- Container System: view daemon status and disk usage, and start/stop/restart the service.
- Running Containers menu bar command with a live count and quick stop actions.
- Graceful recovery UI when the container system service is not running.
