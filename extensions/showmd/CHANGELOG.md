# ShowMD Changelog

## [Initial Release] - {PR_MERGE_DATE}

- Open files and folders with a native picker, or return to recent documents.
  Open a recent document's containing folder, reveal it in Finder, copy its
  path, or remove it from the list.
- Add new targets as Spaces in a running ShowMD when possible, or start a new
  ShowMD window.
- Manage ShowMD: see every running window and its Spaces, open, restart, or
  stop individual windows, stop them all, or start ShowMD.
- Edit Settings: change ShowMD's color mode, open mode, font, browser, port,
  and update checks.
- Browse Agent Skills: open ShowMD's Skills page.
- Open Selected: open the file or folder selected in Finder or Explorer.
- Menu Bar: see running ShowMD windows and Spaces, open recents, and start or
  stop ShowMD on macOS.
- AI Extension tools: open a document, list recents, and check ShowMD's status.
- Find ShowMD on `PATH` or at a configured path, with an `npx` fallback when
  it is not installed.
