# Google Search Results

Read Google results in Raycast and open only the links you need.

## Search Google

Enter a query in **Search Google**. To search by country and language, set **Country** and **Language** (for example, `us` and `en`). Select a result to read its snippet and see its URL and rank, when available.

- Open a source, copy its URL, or copy a single snippet.
- Choose **Copy Results as Markdown** to paste the whole list into your notes, or **Copy Results as JSON** for the raw response.
- Filter the list as you type. Choose **Edit Search** to change the query or fetch another page.

## Set up

Add your own [FlashData](https://flashdata.dev/signup?utm_source=raycast&utm_medium=integration&utm_campaign=intent_gtm_2026q4&utm_content=google_search-task) API key with **Google Search** access in extension preferences. Each submitted search or page uses FlashData Credits. Typing and filtering are free. Raycast Pro is not required.

The extension sends your key and search only to FlashData and does not store search history. If a search times out, check your FlashData query history before submitting it again.
