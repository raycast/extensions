# Connect FlashData

Create an account at [FlashData](https://flashdata.dev/signup?utm_source=raycast&utm_medium=integration&utm_campaign=intent_gtm_2026q4&utm_content=google_search-task) and create your own API key with **Google Search** access. Paste it in **FlashData API Key**.

Searches consume your own FlashData Credits. No key or free calls are included. The normal command does not require Raycast Pro.

See the [Google Search API reference](https://flashdata.dev/docs/sources/google_search?utm_source=raycast&utm_medium=integration&utm_campaign=intent_gtm_2026q4&utm_content=google_search-task) for setup and usage details.
