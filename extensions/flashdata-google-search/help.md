# Connect FlashData

Create an account at [FlashData](https://flashdata.dev/signup?utm_source=raycast&utm_medium=integration&utm_campaign=intent_gtm_2026q4&utm_content=google_search-task) and create a key with access to the Google and YouTube sources you intend to use. Paste it in **FlashData API Key**. Cloud delivery also requires a private destination configuration file.

Searches consume your own FlashData Credits. No key or free calls are included. The normal command does not require Raycast Pro.

See the [Google Search API reference](https://flashdata.dev/docs/sources/google_search?utm_source=raycast&utm_medium=integration&utm_campaign=intent_gtm_2026q4&utm_content=google_search-task) for setup and usage details.
