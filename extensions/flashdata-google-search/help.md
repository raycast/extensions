# Connect FlashData

Sign in to [FlashData](https://flashdata.dev/) and create your own API key with **Google Search** access. Paste it in **FlashData API Key**.

Searches consume your own FlashData Credits. No key or free calls are included. The normal command does not require Raycast Pro.

See the [Google Search API reference](https://flashdata.dev/docs/sources/google_search) for setup and usage details.
