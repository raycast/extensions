# CSL locales

The locale files in this directory are provided by the [Citation Style Language project](https://citationstyles.org/).

Source: [citation-style-language/locales, commit 8bef426f89f38c0789223c50e53ec2197bc50bb3](https://github.com/citation-style-language/locales/tree/8bef426f89f38c0789223c50e53ec2197bc50bb3). Files are included without modifications; translator credits and license metadata are retained.

License: [Creative Commons Attribution-ShareAlike 3.0 Unported](https://creativecommons.org/licenses/by-sa/3.0/).

These files supply Simplified Chinese (zh-CN) and Japanese (ja-JP) locales for custom CSL styles. The installed-style path retains its existing language behavior.
