菜单栏下拉布局：三个候选，本轮只供选，不改实现

只画下拉里的排布，内容与数值沿用当前实现。三个候选都只用 MenuBarExtra.Section / Item / Submenu，因为是系统原生菜单：没有列、没有自定义绘制，只有「标签 + 右侧副标题 + 图标 + 子菜单」这几种原语。

原生菜单原语能不能用候选里怎么用
节标题（灰色小字）可以分组：CPU / 核心 / 进程
行 + 右侧数值副标题可以用户 5%、App 内存 18.3 GB
行图标（8px 色点 / 16px SVG 环）可以压力环、内存分段环、色点
子菜单（多一次点击）可以收纳分解项；进程行的 结束 / 强制结束
两列排版 / 表格式对齐不行—
自定义图表区（大直方、GPU 环墙）不行—（CPU 面板入口本轮已删）
A · 全展开分节（现状基线）CPU 11 行 / 内存 18 行

按当前实现原样：每个指标一行，进程区的每个进程是一个子菜单。信息一眼看全，代价是菜单最长、要滚动。
