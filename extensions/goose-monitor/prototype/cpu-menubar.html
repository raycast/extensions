这个问题：状态栏两颗竖图标（CPU / 内存压力），点开 CPU 怎么展示「用户 + 系统」两列？

先核过本机可采数据，再画三版。三版状态栏相同：两颗竖胶囊，各管一项。点开后的面板才分叉。频率和温度没有免权限接口，三版都不画。

能力本机核验Raycast 里
状态栏两颗竖胶囊能画 SVG两个 menu-bar 命令，各一张生成图标
用户 / 系统 两列直方os.cpus() 的 user / sys tick 差胶囊内堆叠蓝+粉柱
能效 / 性能核心M4 Pro：性能 10 + 能效 4；每核 tick 可分汇总百分比；环图做成一张 SVG
进程列表 + 结束已有菜单项 / 子菜单
下拉里的大图（直方、核心环）SVG只能当菜单项图标，会被缩到约 16–32px
真正的两列自定义窗口—MenuBarExtra 做不到；可「打开面板」进 List + Detail
3.56 GHz / 58°无免权限接口（要 sudo powermetrics / SMC）不做
1 秒刷新—后台最快 10 秒
A · 原生菜单点开就是系统菜单。用户/系统两行数字。最稳，和现在内存下拉同一套。
B · 图卡菜单菜单里塞缩小的直方和核心环图。看起来像 iStat，但图会偏小。
C · 两列面板状态栏仍是菜单；点「打开面板」进左右两栏：左进程、右图。这是唯一真两列。

下面桌面可点两颗胶囊。左右方向键或底栏切换 A/B/C。点 CPU 看当前变体；点内存看压力下拉（三版共用）。
