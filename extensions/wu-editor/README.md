# Wu

Open your recent [Wu](https://github.com/farshed/wu) projects, files, and settings from Raycast.

## Commands

- **Open Recent Project**: lists the folders you opened in Wu, newest first. Press `Enter` to open one, or `⌘ Enter` to open it in a new window.
- **Open New Window**: opens an empty Wu window.
- **Open with Wu**: opens the files or folders selected in Finder. With nothing selected, opens the front Finder window's folder.
- **Open Settings** and **Open Keymap**: open Wu's `settings.json` or `keymap.json`.
- **Show Installed Extensions**: lists the extensions installed in Wu with their version, and links to their repositories.

## Setup

Nothing to configure. The extension reads Wu's own list of recent workspaces and installed extensions.

Opening uses the `wu` command line tool if it is installed, otherwise the copy bundled inside Wu.app. Wu must be installed in a location Spotlight can see, such as /Applications.

If you moved Wu's data or config directory, adjust the paths in the extension preferences.
