# Connect OwnDrop

You need an [OwnDrop server](https://github.com/iml885203/owndrop#-quick-start-pick-one) before using this extension.

1. Open your OwnDrop web app, choose **Devices**, and add this computer.
2. Click **Copy Connection Details**.
3. Paste the copied value into **Connection Details or Device API Token** and save.

Leave **Server URL (Manual Setup)** empty when using connection details.

If you have a device token instead, enter the token and your server's HTTPS URL separately.

Keep your connection details private. Use a separate device token for each computer.
