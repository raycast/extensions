# mite Time Tracking

Track your time with mite directly from Raycast. Create, start, and stop time entries quickly and efficiently.

## Setup

1. Get your mite API key from your mite account settings
2. Configure the extension preferences:
   - **mite URL**: Your mite account URL (e.g., `yourcompany.mite.yo.lk`)
     - **Important**: Use the `.yo.lk` domain, not `.de`
   - **API Key**: Your personal mite API key

## Features

### Commands

- **Start Timer**: Create and start a new time entry with live tracking
- **Create Entry**: Create a completed time entry with a specific duration and date
- **Stop Timer**: Quickly stop the currently running timer
- **View Summary**: See today's entries and weekly summary

### Highlights

- **Favorite Projects**: Mark frequently used projects as favorites for quick access
- **Smart Service Memory**: Your last selected service is automatically remembered
- **Real-time Tracking**: See elapsed time for active timers
- **Week Overview**: View all entries from the current week with date information
- **Issue Detection**: Automatically highlights entries with missing notes or non-billable status
- **Organized Selection**: Projects grouped by customer for better navigation

## Requirements

- Active mite subscription and account with enabled API access
