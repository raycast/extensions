# Changelog

## [Initial Release] - {PR_MERGE_DATE}

Initial release of the Mite extension for Raycast.

### Features

- **Start Timer**: Create and start time entries with live tracking
- **Create Entry**: Create completed time entries with specific duration and date
- **Stop Timer**: Quickly stop the currently running timer
- **View Summary**: View today's and this week's time entries
- **Favorite Projects**: Mark and quickly access frequently used projects via Cmd+Shift+F
- **Smart Service Memory**: Last selected service is automatically remembered
- **Real-time Tracking**: Display elapsed time for active timers (updates every 30 seconds)
- **Week Overview**: View all entries from current week with date information
- **Issue Detection**: Highlight entries with missing notes or non-billable status
- **Organized Selection**: Projects grouped by customer for better navigation
- **Quick Actions**: Restart entries, edit in browser, and manage favorites
- **Search Enhancement**: Search entries by customer, project, and service names
