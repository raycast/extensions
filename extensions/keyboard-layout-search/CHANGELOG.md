# Changelog

## [Initial Release] - 2026-09-11

- Convert queries typed with Russian, Ukrainian, French, German, or Greek keyboard layouts to US English.
- Automatically detect the most likely source layout using input characters and installed-application matches.
- Allow choosing a fixed source layout in Raycast Settings.
- Find and open installed applications from corrected queries.
- Search the web, copy, or paste corrected text.
