# CoworkingView

Search coworking spaces, private offices, fixed and flex desks, day passes and meeting rooms in 70+ cities, with the prices operators publish, without leaving Raycast. Data from [CoworkingView](https://coworkingview.com).

## Commands

- **Search Coworking Spaces**: pick a city, filter by workspace type (⌘T), and see each space's district, operator, capacity and entry price, colored by how it compares with the local median. Open a space for its full price list, address and amenities.
- **Coworking Market Rates**: what a private office, fixed desk or flex desk costs per month in a city (median and middle half), plus day pass and meeting room medians, from the [Coworking Price Index](https://coworkingview.com/en/tools/price-index).

## Setup

None. The extension uses the public CoworkingView API, which needs no API key.

## Cities

Berlin, Munich, Hamburg, Frankfurt, Madrid, Barcelona, Málaga, Valencia, London, Manchester, Amsterdam, Dubai and more. Browse them on [coworkingview.com](https://coworkingview.com/en/coworking/berlin).
