# Pomodoro for Windows Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Customizable focus presets (Classic, Deep Work, Quick Sprint, or your own), each with its own task name
- Stop and keep time, or discard a session so it doesn't count
- Type a task and press Enter to start it; stats pinned at the top of the timer
- Raycast HUD on every change and when intervals end, alongside Windows notifications
- Quick Toggle command for a single hotkey
- Native Windows toast notifications and alarm sounds at the exact end of each interval
- Background status command that shows the live timer in root search
- Auto-start breaks and focus intervals
- Task labels, daily goal, streaks and session history
