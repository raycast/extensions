# Changelog

## [1.0.0] - 2024-12-15

### Added

- Initial release
- Clean curly quotes (single and double) to straight quotes
- Convert em-dashes and en-dashes to hyphens
- Convert ellipsis character to three periods
- Clean tab-indented numbered lists to markdown format
- Clean tab-indented bullet lists to markdown format
- Remove hidden Unicode characters (zero-width spaces, BOM, etc.)
- Remove non-breaking spaces
- Remove markdown heading markers
- Remove trailing whitespace
- Output as rich text (RTF) for proper list formatting in Slack, Notion, etc.
