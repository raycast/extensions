# App Switcher Changelog

## [Initial Release - 0.1.0] - {PR_MERGE_DATE}

### Added

- Initial release of App Switcher Raycast Extension

### Features

- List and switch to running apps on Windows
- Search by app name or window title
- Close apps gracefully
- Refresh app list
- Desktop-level filtering (PowerShell mode only)
- App enumeration via PowerShell and Raycast Window Management API
- Basic toast notifications for actions
