# Changelog

All notable changes to the DNS Quick Change extension will be documented in this file.

## [1.0.0] - 2026-05-29

### Added
- Initial release of DNS Quick Change extension
- Quick DNS preset switching
- Create, edit, and delete DNS presets
- Preset descriptions for organization
- View comprehensive network interface details
- Reset to DHCP functionality
- Built-in presets: Cloudflare, Quad9, OpenDNS
- Keyboard shortcuts for all major actions
- Network status display showing current DNS source
- Real-time active DNS server detection
