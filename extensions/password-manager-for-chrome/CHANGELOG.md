# Password Manager for Chrome Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Open Google Chrome built-in password manager from Raycast
- Optional search query via command argument (`?q=` URL parameter)
- Reuse an existing password manager tab on macOS (focus only, or update search when a query is provided)
- macOS support via AppleScript
- Windows support via launching `chrome.exe`
