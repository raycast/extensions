# Buffer Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Browse **scheduled posts**, **drafts** and **sent posts** with inline previews (text + media thumbnail)
- **Post detail** view with full text, media and per-post metrics
- **Open in Buffer** deep-links straight to the post; **Edit in Buffer** opens the full editor; **Quick Edit** changes text and schedule inline without leaving Raycast
- **Open on Network** jumps to the published post on LinkedIn, X and other networks
- **Analytics** grid with KPI tiles and change-versus-previous-period per channel (7 / 14 / 28 days)
- **Add Idea** to quickly capture a content idea
- **AI tools** (`@buffer`): summarize channel performance, list posts, and create ideas from natural language
