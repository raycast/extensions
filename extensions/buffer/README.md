# Buffer for Raycast

Browse, edit and analyze your [Buffer](https://buffer.com) posts without leaving Raycast.

## Features

- **Scheduled Posts** – see your queue with text and media previews, sorted by publish time
- **Drafts** – review and edit your drafts
- **Sent Posts** – revisit published posts with their metrics, and open them on the network
- **Analytics** – a grid of KPI tiles per channel with change versus the previous period (7 / 14 / 28 days)
- **Add Idea** – quickly capture a content idea
- **AI tools** – ask `@buffer` to summarize your performance, list posts, or turn a thought into an idea

## Actions on a post

- **Open in Buffer** – deep-links to the exact post
- **Edit in Buffer** – opens the full Buffer editor (drafts & scheduled)
- **Quick Edit** – change text and schedule inline, without opening the browser
- **Open on Network** – jumps to the published post on LinkedIn, X, etc.

## Setup

1. Create a Buffer API token at [publish.buffer.com](https://publish.buffer.com) → Settings → API. Grant all scopes so metrics and analytics work.
2. Paste the token into the extension preferences on first run.
3. The Organization ID is optional – leave it empty to use your first organization.

## Notes

- Analytics and post metrics require a Buffer plan with Insights. On the free plan, Insights history is limited to the last 31 days.
- The AI tools require Raycast Pro. All other commands work without it.
