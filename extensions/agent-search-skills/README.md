# Agent Search Skills

Raycast extension that indexes every agent skill installed on this machine and makes it searchable. Copy-only by design: it puts the slash command on your clipboard and stays out of the way.

## Sources scanned

- `~/.claude/skills/` — personal skills, gstack, and symlinked packs (symlinks resolved, duplicates removed)
- `~/.agents/skills/` — universal skills.sh installs not already linked above
- `~/.claude/plugins/installed_plugins.json` — every installed plugin's skills, including custom skill directories declared in `plugin.json` and single root-`SKILL.md` plugins
- Extra directories (extension preference) — point it at a project's `.claude/skills` folder

## Usage

Open Raycast, run **Search Skills**. Search matches names, descriptions, trigger words (`oklch` finds better-colors), and category names. Filter by category or source with the dropdown. `Enter` copies the slash command, `cmd+c` copies the bare name, `cmd+d` toggles the detail pane, `cmd+o` opens the SKILL.md, `cmd+shift+f` reveals it in Finder.

Model-only skills (`user-invocable: false`) are labeled and copy the bare name instead of a slash command.

## Categories

Every skill carries 1-3 categories from a fixed taxonomy (Design, Animation & Motion, Engineering, iOS & macOS, Marketing & SEO, Copywriting, QA & Review, Deploy & Infra, Workflow & Process, AI & Memory). The mapping lives in `assets/categories.json`, generated by classifying each skill's description. Skills installed after the last generation get a keyword-based best guess. To reclassify everything:

```
scripts/regenerate-categories.sh [extra-dirs]
```

Pass the same comma-separated extra directories as the extension preference so project skills are included. Rebuild afterward.
