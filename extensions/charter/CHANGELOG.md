# Charter Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Browse Charts: a catalog of chart and diagram types grouped by family, as a grid of thumbnails or a list with a detail panel
- A lens in the search bar: All, Mermaid, shadcn or ECharts, driving the picture, example, docs link and copy actions for every type
- Mermaid types carry the release that added them; shadcn types list every block in their family with source and install commands; ECharts types carry a complete option, including the map types with a bundled world map
- Favorites pinned to the top and a Recent section for the last five types used
- Copy the docs link, the example in a fence or raw, a prompt snippet or a shadcn install command from any type
- Render Chart: draw a Mermaid diagram or an ECharts option from the selection, the clipboard or a pasted source, then copy, save or open the picture
- Render Template draws any type's Mermaid or ECharts example; Open Preview shows the shadcn block
