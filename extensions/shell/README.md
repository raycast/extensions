# Shell

Run a shell command from anywhere and see its output, without opening a terminal. Works on macOS and Windows.

## Commands

- **Execute Shell Command**: Type a command, run it and see the output in Raycast.

## Run it in your terminal

Turn on **Use External Terminal** in the preferences to send commands to a real terminal. On macOS that's iTerm, kitty, Warp or Ghostty. On Windows it's PowerShell, PowerShell 7 or Command Prompt.

## Use it with Raycast AI

Mention `@shell` in Raycast AI and describe what you want, for example "how much space is left on my disk?" It writes and runs the command for you.
