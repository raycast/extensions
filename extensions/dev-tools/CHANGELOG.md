# Dev Tools Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Add **Text Encoder/Decoder**: a live two-way form that encodes/decodes text between Base 64, Base 64 (URL-safe), Base 32, Hex, URL (percent), and Binary, with a selectable text encoding (UTF-8 / UTF-16 LE / Latin-1). Editing Text encodes; editing Encoded decodes. Decoders are lenient (ignore whitespace, accept either Base 64 alphabet, accept hex with spaces/colons/`0x`).
- Add clipboard encode/decode shortcuts (no-view): **Base64 Encode**, **Base64 Decode**, **URL Encode**, and **URL Decode** — transform the clipboard in place and report via HUD.
- Add clipboard case shortcuts (no-view): **Lowercase** and **Uppercase** — convert the clipboard text's case in place (preserving whitespace) and report via HUD.
- Add **AES En-/Decryptor**: encrypt/decrypt text and files with a selectable cipher mode (CTR for legacy compatibility, GCM for authenticated encryption), configurable encoding (Base 64 / Hex), key length (128 / 192 / 256), and password-derivation algorithm (SHA-256 / SHA-512 / SHA-1 / MD5). The password and derived key stay in memory only and are never written to disk.
- Add **Number Base Converter**: a view that converts a number (with `0x`/`0b`/`0o` auto-detection or a forced source base) between binary, octal, decimal, and hexadecimal live, with a Unicode code-point preview; prefills from the clipboard.
- Add clipboard conversion shortcuts (no-view): **Decimal to Hexadecimal**, **Hexadecimal to Decimal**, **Decimal to Binary**, and **Binary to Decimal** — convert the clipboard in place and report via HUD.
- Add **Color Converter**: enter a color as hex, `rgb()`, `hsl()`, `hsv()`, `hwb()`, `oklch()`, or a CSS name (`teal`, `rebeccapurple`, `transparent`). The Overview shows every format (plus the CSS name when one matches), a shades/tints ramp, and harmonies — all copyable. Switch the view dropdown (or press ⌘E) to edit in gradient channel sliders for any model (OKLCH / HWB / HSL / HSV / RGB) with ⌘←/→ (⌘⇧←/→ for ×5). Prefills from the clipboard.
- Add **Text Analyzer**: analyze clipboard or typed multiline text — counts (characters, words, lines, sentences, paragraphs), UTF-8 byte size and encoding details (code points, UTF-16 units, grapheme clusters, non-ASCII), readability and timing (reading/speaking time, unique words, averages, longest word/line), character-class breakdown, and a sortable character-distribution view; every metric copyable, plus Copy Report / Copy as JSON.
- Add **Cron Expression**: type a cron expression into the search bar to get a plain-English description, a per-field breakdown, and a live preview of the next run times. Supports standard 5-field cron and 6-field cron with a leading seconds field, the `@yearly`/`@monthly`/`@weekly`/`@daily`/`@hourly` (and friends) macros, month/weekday names, and the `*`, `,`, `-`, `/`, `?` operators. Each result is copyable (description, field, formatted time, ISO 8601, or all upcoming runs).
- Add **JWT Inspector**: a read-only debugger for JSON Web Tokens. Import a token (from the clipboard or by pasting), then browse its header and payload as a list of claims with the full header/payload shown as syntax-highlighted JSON. Registered claims are labelled (Subject, Issuer, Expiration, …). Any value that looks like a Unix timestamp is shown as a human-readable date — the registered time claims (`exp`/`nbf`/`iat`) as a relative time with an expired/valid/future indicator, and any other timestamp-looking field as an absolute UTC time — with the exact epoch number revealed on hover. Copy any individual claim's value, copy a claim by name (with `⌘⇧` shortcuts for the common ones — Subject, Issuer, Audience, Expiration), or copy the whole header, payload, encoded token, or signature. On request (`⌘⇧Y`) it verifies the signature, automatically resolving the public key from the token's own `jwk`/`x5c`/`jku`/`x5u` header or — failing those — its issuer's OIDC discovery document; or you can supply an HMAC secret / PEM key yourself (`⌘⇧K`). Decoding is fully local; verification is the only thing that ever makes a network request, and only when you ask for it.
- Add **Unix Timestamp**: type a Unix timestamp into the search bar to convert it to a human-readable date, or type a date to convert it back. The unit (seconds, milliseconds, microseconds, or nanoseconds) is auto-detected from the number's magnitude or can be forced via the search-bar dropdown. Shows Local, UTC, ISO 8601, RFC 2822, and relative time, plus the timestamp in every unit — all copyable. With the field empty it shows the live current epoch; prefills from the clipboard.
- Add **JSON Converter**: a view that converts structured data between JSON, JSON5, YAML, TOML, JS/TS objects, XML, CSV/TSV, `.env`, and URL query strings. The source format auto-detects (with a manual override), and JS input is **evaluated** in a sandbox so a pasted snippet — including `export default …`, `module.exports = …`, expressions, and comments — turns into data. JS/TS output is configurable: quote style, quoted vs. bare keys, declaration wrapper (`const`/`export default`/`module.exports`), semicolons, trailing commas, and `as const`. Indentation (2 / 4 / Tab / Minified) and alphabetical key sorting apply across formats.
- Add clipboard shortcuts (no-view): **Format JSON**, **Minify JSON**, **JSON to YAML**, **YAML to JSON**, and **JSON to JS Object** — transform the clipboard in place and report via HUD.
- Add **Unicode Browser**: a grid of Unicode characters that you can browse by block (grouped by plane via the dropdown) or search by name, code point (`U+1F600`, `0x41`, `2603`), or the literal character — matching blocks surface alongside characters. Open any character for a detail view with a large glyph, its name, block, plane, general category, UTF-8/UTF-16 bytes, and the Unicode version it was added in. Copy as character, code point, name, HTML entity, or JS `\u` escape. Built from the Unicode Character Database (v16.0.0); CJK/Hangul names are generated on the fly.
- Add **Code Formatters** (10 commands): **Format JavaScript**, **TypeScript**, **CSS**, **SCSS**, **Less**, **HTML**, **XML**, **SQL**, **Markdown**, and **YAML** — a live form that prefills from the clipboard and pretty-prints as you type. Settings live in the panel (indent style/size, print width, quotes, semicolons, trailing commas, prose wrap; SQL dialect and keyword case) and are remembered per command. Powered by Prettier (plus `@prettier/plugin-xml`) and `sql-formatter`.
- Add **Code Minifiers** (6 commands): **Minify JavaScript**, **TypeScript**, **CSS**, **HTML**, **XML**, and **SQL** — live minification with per-command settings. JavaScript/TypeScript use terser (identifier mangling, compression, drop `console`/`debugger`, comment removal; TypeScript is type-stripped first), CSS uses clean-css (level 1/2), HTML uses html-minifier-terser (collapse whitespace, drop comments, minify inline JS/CSS), and XML/SQL collapse whitespace and strip comments while preserving literals and CDATA.
