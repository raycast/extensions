# ASCII Art Search

Search and copy ASCII art and kaomoji directly from Raycast.

## Features

- **Search ASCII Art**: Browse and search through a collection of ASCII art and kaomoji
- **Generate ASCII Art**: Create ASCII art from text using various figlet fonts

## Usage

1. Open Raycast
2. Search for "ASCII Art" or "Kaomoji"
3. Browse or search for the art you want
4. Press Enter to copy to clipboard

## Preferences

| Preference | Description | Default |
|------------|-------------|---------|
| Grid Columns | Number of columns in the grid view (3-8) | 5 |

## Contributing

The ASCII art collection is maintained manually in [SphereStacking/MojiArt](https://github.com/SphereStacking/MojiArt) without external libraries. If you have art to share or requests, feel free to open an issue!

Use the **Submit Art** action in the extension to quickly open a GitHub issue.
