# Atomberg Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Control Fans command: list every fan with its state, clickable speed tags, a speed dropdown
  and keyboard shortcuts for power, speed, sleep mode, light and timer.
- Fan Menu Bar command: a menu bar item with a section per fan and a speed submenu.
- Token and device-list caching with optimistic updates, to stay inside the developer API's
  daily call budget.
