# Google Workspace

Search, open, download and create Google Drive files from anywhere.

## Commands

- **Search Google Drive**: Search your files, or paste a link to find the file it points to.
- **Download Google Drive File**: Download a file or folder. Docs, Sheets and Slides are exported to Markdown or Office formats.
- **Starred Google Drive Files**: Your starred files in the menu bar.
- **Create Google Document**, **Create Google Spreadsheet**, **Create Google Presentation** and **Create Google Form**: Create a new file in one step.
- **Open Google Drive Home**: Opens Drive in your browser.

## Use it with Raycast AI

Mention `@google-workspace` in Raycast AI to find files, create documents or download files in plain language. For example, "find the Q3 budget spreadsheet".

## Setup

The first time you run a command, sign in with your Google account.
