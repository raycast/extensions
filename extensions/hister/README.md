# Hister Raycast Extension

Fast history and indexed URL search for Raycast powered by [Hister](https://github.com).

## Features

- **Instant Results**: Opens with your most recently indexed pages; updates as you type.
- **Rich Metadata**: Displays domain, relative visit time, and relevance score.
- **Fast Actions**: Press **Enter** to open in browser, **Cmd+C** to copy URL, **Cmd+Shift+C** to copy title.
- **Hister Syntax**: Supports Bleve search expressions like `domain:github.com` or boolean queries.
- **Automatic Favicons**: Uses website favicons with a fallback globe icon.

## Development

```bash
npm install
npm run dev
```

Running `npm run dev` automatically links this extension into your local Raycast app.
