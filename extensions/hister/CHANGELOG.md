# Hister Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Search History command for full-text search of a Hister index, with paginated results and highlighted snippets in a detail pane
- Opened Before section for results previously opened for the same query, pinned results first
- Opening a result records it in Hister's query history, as the web interface does
- Pin, unpin and remove results for a query
- Optional Similar Pages section for semantic matches
- Search the web or open the query in the Hister web interface from any result
- Works as a Raycast fallback command
