# Quick SSH Tunnel CLI ⚡

Interactive terminal UI (TUI) for creating and managing SSH tunnels with zero installation dependencies. Automatically syncs state with the Raycast Quick SSH Tunnel extension.

## Usage

Run directly using `npx`:

```bash
npx quick-ssh-tunnel
```

Or install globally:

```bash
npm install -g quick-ssh-tunnel
quick-ssh-tunnel
```

## Features

- **Zero-dependency bundle**: Lightning fast download and execution (~65 KB single file).
- **Interactive Autocomplete**: Real-time fuzzy filter for targets, ports, and remote hosts.
- **Full Tunnel Management**: Connect, Disconnect, Edit, Clone, Copy SSH command, and Delete.
- **Shared State**: Shares history & active process state (`~/.config/quick-ssh-tunnel/`) with the Raycast Quick SSH Tunnel extension.
