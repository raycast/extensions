# Bambu Live View Changelog

## [Initial Version] - {PR_MERGE_DATE}

- **Printer Setup** command: guided checklist for enabling LAN Only Liveview, installing mpv, saving the printer's IP address and access code, and testing the connection.
- **Toggle Live View** command: opens or closes a borderless, always-on-top mpv window with the printer's RTSPS camera stream.
- Preferences for window size, screen corner and window title.
