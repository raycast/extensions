# Screenshots Instructions

Please add 3-6 screenshots of the extension to this folder.

## Recommended Screenshots:

1. **Set Chrome Profile Slot** command showing the list of slots with different states (assigned, empty, occupied)
2. **Profile selection** view showing available Chrome profiles
3. **Slot assignment** action in progress
4. (Optional) **Raycast Settings** showing the hotkey configuration
5. (Optional) **Chrome window switching** in action

## Specifications:

- Format: PNG
- Naming: `toggle-chrome-profiles-1.png`, `toggle-chrome-profiles-2.png`, etc.
- Size: Recommended 1600x1000 or similar aspect ratio
- Show the extension in action with real data (not placeholders)

## Tips:

- Use `Cmd + Shift + 4` to take screenshots on macOS
- Capture the Raycast window with the extension open
- Make sure screenshots are clear and demonstrate the key features
- Avoid showing sensitive information (profile names can be generic like "Work", "Personal", etc.)
