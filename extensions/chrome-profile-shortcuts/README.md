# Toggle Chrome Profiles

Quickly switch between Chrome profiles using keyboard shortcuts. Assign up to 9 Chrome profiles to slots and toggle between them instantly.

## Features

- **9 Profile Slots**: Assign your most-used Chrome profiles to slots 1-9
- **Smart Profile Switching**: Focuses existing windows instead of opening duplicates
- **Fuzzy Name Matching**: Handles profile name variations (e.g., "Work" vs "Harshit (Work)")
- **Easy Re-assignment**: Quickly swap profiles between slots
- **Visual Indicators**: Color-coded icons show slot status at a glance

## How to Use

### 1. Assign Profiles to Slots

Run the **Set Chrome Profile Slot** command in Raycast:

1. Select the Chrome profile you want to assign
2. Choose a slot (1-9)
3. Press Enter to assign

**Slot Icons:**
- 🟡 Yellow Star in Circle = Assigned to current profile
- ⚪ Gray Circle = Empty slot
- ⚫ Gray Star in Circle = Assigned to another profile

### 2. Set Keyboard Shortcuts

1. Open Raycast Settings (`Cmd + ,`)
2. Go to **Extensions** → **Toggle Chrome Profiles**
3. Assign hotkeys to **Open Slot 1**, **Open Slot 2**, etc.
   - Example: `Cmd + Shift + 1`, `Cmd + Shift + 2`, etc.

### 3. Use Your Shortcuts

Press your assigned hotkey to instantly switch to that profile's Chrome window. If the profile isn't open, it will launch automatically.
