# Text Case Transformer - Raycast Extension

Una extensión de Raycast para transformar texto seleccionado a diferentes formatos de case como lowercase, UPPERCASE, camelCase, PascalCase, snake_case, kebab-case, y más.

## Características

- **Múltiples formatos de case**: Soporte para todos los formatos de case más comunes
- **Texto seleccionado**: Funciona con cualquier texto seleccionado en cualquier aplicación
- **Interfaz visual**: Lista interactiva con preview de las transformaciones
- **Comandos rápidos**: Comandos individuales para transformaciones específicas
- **Sin dependencias externas**: Implementaciones nativas para mejor rendimiento

## Formatos soportados

- **lowercase** - convierte todo a minúsculas
- **UPPERCASE** - CONVIERTE TODO A MAYÚSCULAS
- **camelCase** - convierteTodoACamelCase
- **PascalCase** - ConvierteTodoAPascalCase
- **snake_case** - convierte_todo_a_snake_case
- **kebab-case** - convierte-todo-a-kebab-case
- **CONSTANT_CASE** - CONVIERTE_TODO_A_CONSTANTE_CASE
- **Title Case** - Convierte Todo A Title Case
- **Sentence case** - Convierte todo a sentence case
- **dot.case** - convierte.todo.a.dot.case

## Uso

### Comando principal: "Transform Text Case"
1. Selecciona texto en cualquier aplicación
2. Abre Raycast y busca "Transform Text Case"
3. Elige el formato deseado de la lista
4. Presiona Enter para pegar o Cmd+C para copiar

### Comandos individuales
También puedes usar comandos específicos como:
- "To Lowercase"
- "To Uppercase"
- "To camelCase"
- "To PascalCase"
- "To snake_case"
- "To kebab-case"

## Instalación

1. Clona este repositorio
2. Ejecuta `npm install`
3. Ejecuta `npm run dev`
4. La extensión aparecerá en Raycast
