# Simple Setup Guide for Raycast Extension

## Quick Start (5 minutes)

### Step 1: Install the Extension

```bash
cd raycast-extension
npm install
npm run dev
```

### Step 2: Create Email/Password Account

Since your iOS app uses Sign in with Apple, you need a separate email/password account for Raycast.

**Option A: Using Firebase Console (Easiest)**

1. Go to [Firebase Console](https://console.firebase.google.com/)
2. Select your project
3. Go to **Authentication** → **Users** tab
4. Click **"Add User"**
5. Enter an email and password (e.g., `you@example.com` / `YourPassword123`)
6. Click **"Add User"**

**Important**: This creates a **new user** in Firebase. To share tasks with your iOS app:
- You'll need to migrate your tasks, OR
- Use the same user ID (advanced - see below)

**Option B: Link to Existing User (Advanced)**

If you want to use the same user as your iOS app:

1. Find your user ID from the iOS app (check console logs or auth file)
2. In Firebase Console → Authentication
3. Click on your Apple Sign In user
4. Click "Add Sign-In Method" 
5. Choose "Email/Password"
6. Set an email and password

This way, both sign-in methods access the same user data!

### Step 3: Configure Raycast

1. Open Raycast
2. Find "Add Task" command
3. Go to preferences (Cmd+K → "Configure Extension")
4. Enter:
   - **Authentication Method**: Email & Password (default)
   - **User Email**: The email you created
   - **User Password**: The password you created

**Firebase config is automatic** - it reads from the iOS app!

### Step 4: Test It!

Open Raycast → Type "Add Task" → Try:
```
Buy milk #groceries @high /tomorrow
```

That's it! 🎉

## Troubleshooting

### "Firebase configuration not found"
**Solution**: Make sure the iOS/macOS app is installed and has been run at least once. It writes the config to:
```
~/Library/Application Support/to-do/firebase-config.json
```

### "Authentication failed"
**Solution**: 
- Double-check your email and password
- Make sure you created the user in Firebase Console
- Try signing in to the iOS app to verify Firebase is working

### "User not found" or permission errors
**Solution**: Your Firestore security rules might be preventing access. Check:
```javascript
// Make sure your rules allow authenticated users
match /todos/{todoId} {
  allow read, write: if request.auth != null;
}
```

### I want to use the same account as iOS app
**Solution**: See "Option B" above to link email/password to your existing Apple Sign In user.

## Why Not Automatic?

You might wonder why we don't automatically share the login from the iOS app. Here's why:

1. **ID tokens can't be used as custom tokens** - Firebase requires special "custom tokens" generated by Firebase Admin SDK
2. **Service account keys are sensitive** - Can't be embedded in apps
3. **Email/password is simpler** - No complex token generation needed

For personal use, having separate credentials is fine. For enterprise, you'd set up a proper backend to generate custom tokens.

## Advanced: Custom Token (For Power Users)

If you really want to use custom tokens (no email/password), see `CUSTOM_TOKEN_GENERATION.md`.

This requires:
- Downloading Firebase service account key
- Running a script to generate tokens
- Manually refreshing when needed

**Not recommended for most users!**
