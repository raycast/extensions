# Linkup

Search the web, get answers with sources, and read any page as markdown with [Linkup](https://www.linkup.so).

## Commands

- **Search Web**: search the web and browse results with a content preview. Open a result in the browser, copy its URL, or fetch the full page as markdown.
- **Ask Linkup**: ask a question and get an answer grounded in web sources, with the sources listed underneath.
- **Fetch URL**: fetch a web page and read it as clean markdown.

## Setup

1. Create an account and copy your API key from [app.linkup.so](https://app.linkup.so).
2. Paste the key into the **API Key** preference the first time you run a command.

Optionally, set **Search Depth** to **Deep** for a more thorough search on complex questions. It takes longer than **Standard**.

See the [Linkup documentation](https://docs.linkup.so) for more about the API.
