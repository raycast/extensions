# 功能特性

## 核心功能

### 1. 工时统计 📊

- **平均工时计算**: 自动计算当前考勤周期的平均工作时长
- **目标对比**: 与设定的目标工时进行对比，显示差异
- **智能过滤**: 当天工时小于 8.5 小时时不计入平均值
- **考勤周期**: 自动识别每月 26 日到次月 25 日的考勤周期

### 2. 迟到统计 ⏰

- **自动识别**: 首次打卡时间晚于 10:00 AM 视为迟到
- **次数统计**: 显示当前考勤周期的迟到次数
- **友好提示**: 在统计结果中醒目显示迟到信息

### 3. 双命令模式 🎯

#### 快速查看模式
- **HUD 显示**: 在屏幕顶部快速显示统计信息
- **一键查看**: 无需打开窗口，快速了解工时情况
- **信息精简**: 只显示关键统计数据

#### 详情查看模式
- **完整视图**: 打开独立窗口显示详细信息
- **刷新功能**: 支持手动刷新数据
- **格式化展示**: Markdown 格式，清晰易读
- **包含内容**:
  - 考勤周期
  - 平均工时
  - 目标工时
  - 差异统计
  - 迟到次数
  - 鼓励/提醒信息

## 安全特性 🔒

### 1. 自动密码加密

- **RSA 加密**: 使用 iTalent 官方 RSA 公钥加密密码
- **本地加密**: 加密过程在本地完成，不上传到任何第三方服务器
- **无需手动**: 用户只需输入明文密码，插件自动处理加密
- **标准算法**: 使用 Node.js crypto 模块，采用 RSA_PKCS1_PADDING 填充

### 2. 安全存储

- **Preferences**: 配置信息存储在 Raycast 安全存储中
- **LocalStorage**: Cookie 缓存在 Raycast LocalStorage 中
- **无明文密码**: 不会持久化存储明文密码

### 3. Cookie 管理

- **自动缓存**: 登录成功后自动缓存 Cookie
- **智能刷新**: Cookie 过期时自动重新登录
- **透明管理**: 用户无需关心 Cookie 的生命周期

## 数据处理 📈

### 1. 考勤周期计算

```typescript
// 每月 26 日到次月 25 日
getCurrentPeriod(): string
```

- 自动识别当前日期所在的考勤周期
- 格式化为 `yyyy/MM/dd-yyyy/MM/dd` 格式

### 2. 工时计算

```typescript
calculateWorkHour(response, targetHour): WorkHourStats
```

- 计算平均工时
- 计算与目标工时的差异
- 统计迟到次数

### 3. 数据格式化

```typescript

```

- 格式化统计信息为易读的文本
- 使用 emoji 增强可读性
- 根据数据动态调整显示内容
