# Working Hour Changelog

## [2.1.0] - 2025-01-14

### 新增 ✨

- **自动密码加密**: 用户现在可以直接输入明文密码，插件会自动使用 RSA 公钥加密
- 添加 `encryptPassword` 工具函数，使用 Node.js crypto 模块进行 RSA 加密

### 改进 🚀

- **用户体验**: 无需手动加密密码，简化配置流程
- **安全性**: 密码仅在本地加密，不会上传到任何服务器
- 更新文档，移除手动加密密码的说明

### 变更 🔄

- Preferences 中的 `encryptedPassword` 字段改为 `password`
- 密码输入框描述更新为"登录密码（插件会自动使用 RSA 加密）"

## [2.0.0] - 2025-01-14

### 重大重构 🎉

这是一次完整的代码重构，按照 Raycast 最佳实践重新组织了整个项目。

### 新增 ✨

- 使用 Raycast Preferences API 管理用户配置
- 添加详细的工时统计视图
- 支持刷新功能
- 改进的错误处理和用户提示
- 完整的 TypeScript 类型定义

### 改进 🚀

- **代码结构**: 按照关注点分离原则重新组织代码
  - `services/`: API 调用逻辑
  - `utils/`: 工具函数和本地存储管理
  - `types/`: TypeScript 类型定义
- **安全性**: 移除硬编码的敏感信息，使用 Preferences 管理
- **用户体验**:
  - 快速查看命令（HUD 显示）
  - 详细查看命令（完整视图）
  - 自动 Cookie 管理和刷新
- **代码质量**:
  - 完整的类型定义
  - 更好的错误处理
  - 清晰的代码注释

### 移除 🗑️

- 删除未使用的 `wlb_1.0.5.js` 文件
- 删除硬编码配置文件 `config.ts`
- 移除未完成的 Chrome 自动化代码
