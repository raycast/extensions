# Cushn

Log expenses to your [Cushn](https://github.com/anuarshaidenov/cushn-desktop) budgets and see how they're doing, from Raycast.

Run **Log Expense**, pick a budget (the one you used last comes first), pick an allocation, then type an expense the way you would in Cushn: `Coffee 4.50`, `Groceries 20k + 5k` or `Rent 200 usd`. Press Enter to add it. You can add several expenses in a row, and undo each one from the confirmation.

Run **Browse Budgets** to see your budgets, active or archived. Each budget shows its income, what's spent and what's left in every allocation. Allocations that spent more than planned come first. Open a budget to search its expenses, or narrow them to one allocation.

## Requirements

- The Cushn app for macOS.
- In Cushn, open **Settings → Agents** and turn on **Raycast**.

Cushn doesn't need to be open: the extension starts it in the background when needed.
