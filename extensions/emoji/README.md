# Emoji Search

Search every emoji by name or keyword and insert it into any app, or copy it.

## Commands

- **Search Emoji**: Find an emoji and paste it into the frontmost app, or copy it to your clipboard.

## Preferences

- **Primary action**: paste the emoji into the active app (default) or copy it.
- **Add Shortcodes**: also search by shortcodes like `zap` for ⚡️, as used on GitHub and Slack.
