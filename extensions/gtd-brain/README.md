# GTD Brain for Raycast

[GTD Brain](https://gtdbrain.com/?source=raycast-store) is a Getting Things Done board — Inbox, Next Actions, Projects, Waiting For and Someday/Maybe — that ChatGPT and Claude can run for you. This extension is its keyboard surface on the Mac: capture in one line and work every list without leaving Raycast.

## Commands

- **Capture to Inbox** — a title and optional notes, straight to the top of your Inbox. Type the title right after the command name in the root search to skip the form.
- **Quick Capture** — type it, press Enter, done. No view at all.
- **Inbox** — clarify each card: move it to Next Actions (pick a context), make it a project, park it in Waiting For or Someday/Maybe, or archive it.
- **Next Actions** — filter by context, mark done (⌘D), change context.
- **Projects** — every project with its pinned next action; the ones missing one are flagged.
- **Waiting for** — who you are waiting on and for how many days; mark received or turn into a next action.
- **Someday/Maybe** — activate an idea as a next action or a project, or let it go.

Every card also has **Open on Dashboard** (⌘O) and **Copy Title** (⌘C). Changes land on the same board as the [web app](https://dashboard.gtdbrain.com/?source=raycast-store), the iOS and Android apps, and the ChatGPT / Claude connectors — instantly. Cards are archived, never deleted, so nothing is lost to a slip. Away from the Mac, message the GTD Brain bot on Telegram ([@GTDBrainBot](https://t.me/GTDBrainBot?start=raycast-store)), typed or as a voice note, and it lands in the same Inbox.

## Sign in

Run any list command and enter the email you use on the dashboard. A one-time code is sent to it; there is no password. New here? [Create a free account](https://gtdbrain.com/?source=raycast-store) — the board is set up on your first web login, then come back to Raycast.

## Privacy

The extension stores your sign-in token and a random install id on this Mac and talks only to GTD Brain's API. Usage events (command opened, card captured) help improve the product and are never sold.
