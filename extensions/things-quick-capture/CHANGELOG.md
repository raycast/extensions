# Things Quick Capture Changelog

## [Initial Version] - 2026-01-28

- Quick Capture command with form UI (title, notes, when, project, tags)
- Silent Capture command for instant capture with HUD
- Browser support: Safari, Chrome, Brave, Arc
- Email support: Mail, Outlook (with message links)
- Messaging support: Slack, WhatsApp
- File support: Finder, Notes
- Title sanitization (decodes URL encoding)
- Configurable preferences for default list and URL placement
