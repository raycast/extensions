# Things Quick Capture Changelog

## [Initial Version] - 2026-01-28

- **Quick Capture to Things**: Instantly capture context from frontmost app to Things inbox
- Browser support: Safari, Chrome, Brave, Arc
- Email support: Mail, Outlook (with message links)
- Messaging support: Slack, WhatsApp
- File support: Finder, Notes
- Automatic emoji prefixes by app type
- Configurable default list and URL placement preferences
- Tip: Map to Option+Q (Ctrl+Option+Space conflicts with Things native shortcut)
