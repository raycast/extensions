# Morning Espresso

Morning Espresso is an enhanced version of the Morning Coffee extension.  It lets you organize your daily browsing routine into clean, customizable tab groups—and open everything you need for the day with a single action.

You can create groups, reorder them, import Safari bookmarks, and edit your setup at any time.  Your morning tabs finally behave the way your morning coffee feels: smooth, predictable, and ready when you are.

Features
    •    📁 Organize websites into groups
Create collections like “Morning News”, “Research”, “Work Tools”, or anything that fits your flow.
    •    🚀 Launch everything instantly
Open a full group—or all groups—with one command or a keyboard shortcut.
    •    🔧 Full group management
Add, remove, rename, and reorder sites or entire groups. Everything is editable at any time.
    •    📥 Import from Safari bookmarks
Select a Safari bookmark folder and import it directly into a new or existing tab group.
    •    🎯 Selective importing
Choose exactly which bookmark folders and entries to include.

Commands
    •    Manage Tab Groups
Create, edit, reorder, and maintain all of your groups.
    •    Open Tab Group
Select a group to instantly open all of its sites.
    •    Launch Morning Espresso
Open your designated “morning” group (or all your groups) with a single command.
    •    Import Safari Bookmarks
Choose a Safari bookmark folder and convert it into a tab group.

Usage
    1.    Create a tab group using Manage Tab Groups.
    2.    Add sites manually or import from Safari.
    3.    Reorder groups or sites as your workflow evolves.
    4.    Use keyboard shortcuts or commands to open a group—or everything—instantly.
