# Luci Screen Memory

Control [Luci](https://luci.memories.ai/) screen memory capture directly from Raycast.

## Features

- **Toggle Screen Memory**: Instantly toggle capture on or off via HUD command (assignable to a global keyboard shortcut).
- **Status Menu Bar**: Live macOS menu bar item displaying recording state (`🔴` / `⏸️`) with click-to-toggle.

## Setup

1. **Install Luci**: Make sure [Luci](https://luci.memories.ai/) is installed and running on your Mac.
2. **Accessibility Access**: Raycast requires Accessibility permissions to read and press Luci's recording toggle via macOS System Events. Enable access for Raycast in **System Settings → Privacy & Security → Accessibility**.
