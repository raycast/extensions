# Luci Screen Memory for Raycast

> **Available on the Raycast Store:** Search for **Luci Screen Memory** inside Raycast or browse the Raycast Store to install it directly with one click.

---

Control [Luci](https://luci.ai) screen memory capture directly from Raycast.

## Features

- **Toggle Screen Memory**: Instantly toggle capture on or off via HUD command (assignable to a global keyboard shortcut).
- **Status Menu Bar**: Live macOS menu bar item displaying recording state (`🔴` / `⏸️`) with click-to-toggle.

---

## For Developers

To run and contribute locally:

```bash
npm install
npm run dev
```

Build standalone bundle:

```bash
npm run build
```
