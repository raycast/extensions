# Daily Karte Changelog

## [Initial Release] - 2026-11-20

- You can record activities from a searchable card gallery and create or edit your activity cards.
- You can review today's timeline, edit saved records, and see activity duration totals.
- You can view the current week as a full-width activity calendar.
- You can sign in with Google through Raycast's OAuth integration to use the same account as the Daily Karte Web app.
- You can retry an unchanged recording form after a lost response without losing confirmation of a successful merge.
- Record Activity and Today wait for a successful load before showing an empty state.
