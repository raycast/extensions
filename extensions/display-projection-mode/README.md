# Display Projection

Quickly change Windows Display Projection modes directly from Raycast.

## Features

This extension provides quick access to all Windows display projection modes:

- **PC Screen Only** - Display only on the primary screen (internal display)
- **Duplicate** - Mirror your displays (same content on all screens)
- **Extend** - Use multiple displays as one extended desktop
- **Second Screen Only** - Display only on external screen (disable internal display)

## Requirements

- Windows 10 or later
- No additional setup required - uses built-in Windows functionality
