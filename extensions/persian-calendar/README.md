# Persian Calendar for Raycast

A simple, offline-first Persian (Jalali) calendar for Raycast.

Browse Persian calendar months, convert dates between Jalali and Gregorian formats, and check today's date instantly using the Persian command **چندمه**.

## Features

- **Persian Calendar:** View the current Jalali month, navigate between months, and inspect individual dates.
- **Convert Date:** Convert between Jalali and Gregorian dates, with support for Persian and English numerals.
- **چندمه:** Quickly display today's full Persian date in Raycast search.
- **Offline-first:** Date calculations run locally without an external API.
- **Persian localization:** Persian month names, weekdays, and numerals.
- **Iran timezone:** Today's date is calculated using Asia/Tehran.

## Commands

### Persian Calendar
Open a monthly Jalali calendar, browse months, and view date information.

### Convert Date
Convert between Persian and Gregorian calendar dates.

### چندمه
Type `چندمه` in Raycast to quickly see today's Persian date, such as `امروز ۱۲ آبان ۱۴۰۵`.

## Getting Started

Install the extension from the Raycast Store, then search for any of its three commands.

No API keys, user accounts, or external calendar services are required.

## Technology

Built with the Raycast API, React, TypeScript, and jalaali-js.
