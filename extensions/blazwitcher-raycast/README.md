# Blazwitcher 拼音搜索

在 Raycast 中使用中文、全拼、拼音首字母和中英文混合关键词搜索 Google Chrome 标签页、书签与历史记录。

| 搜索词       | 可匹配的标题示例       |
| ------------ | ---------------------- |
| `zhoubao`    | 项目周报               |
| `zb`         | 项目周报               |
| `release zb` | Release 发布周报       |
| `/t zhoubao` | 已打开标签中的项目周报 |
| `/b zhoubao` | 书签中的项目周报       |
| `/h zhoubao` | 历史记录中的项目周报   |

## 使用前准备

- 需要 macOS、Google Chrome 和 Raycast；当前仅支持 Google Chrome。
- 首次读取或切换标签页时，允许 **Raycast 控制 Google Chrome**。若曾拒绝，在 macOS“系统设置 → 隐私与安全性 → 自动化”中开启 Raycast 对 Google Chrome 的权限，再重新打开命令。
- 官方 [Raycast Browser Extension](https://www.raycast.com/browser-extension) 为可选增强，用于普通网页标签的正文预览和部分网站图标；未安装时仍可搜索和打开结果。

## 搜索与操作

运行“搜索浏览器”，输入关键词。多个词用空格分开；来源可通过下拉框、`/t`、`/b`、`/h` 前缀或 `⌘⇧0/1/2/3` 切换。

“全部来源”按相同的非空标题或完整 URL 合并重复结果，优先保留标签页，其次书签、历史；多个真实标签页仍全部保留。需要查看各个记录时，切换单一来源。

| 动作             | 默认快捷键 | 行为                                             |
| ---------------- | ---------- | ------------------------------------------------ |
| 打开             | Enter      | 聚焦已有标签；书签、历史在所属 Chrome 配置中打开 |
| 在新标签页打开   | ⌘Enter     | 在命令打开时的 Chrome 窗口新建标签               |
| 在当前标签页打开 | ⇧Enter     | 替换命令打开时的 Chrome 标签                     |
| 复制地址         | ⌘C         | 复制原始完整 URL                                 |
| 显示／隐藏详情   | ⌘D         | 展开／收起右侧详情                               |

当前标签或窗口关闭后，对应的打开动作会提示失败，不会改用其他窗口。`⌘K` 打开动作菜单，可切换 Chrome 配置、自定义快捷键、清除启动缓存或打开扩展设置。第一、第二项的 Enter／⌘Enter 由 Raycast 提供，无法通过扩展的快捷键设置改绑。

历史默认读取最近 20,000 条，上限 100,000 条，可在扩展设置调整。“全部配置”合并后仍受总上限约束。无痕标签默认排除，可在设置中开启。需要重新读取浏览器数据时，退出并重新打开命令。

### 可选详情与限制

每次打开命令默认使用单栏列表。按 `⌘D` 查看选中结果的标题、链接、来源及已有的配置、文件夹或访问时间。

普通网页标签可通过官方浏览器扩展读取 Markdown 正文；书签、历史、无痕和特殊协议页面仅展示基础信息。正文预览为试用功能，动态网页的提取效果取决于浏览器扩展。读取失败或超时不影响搜索和打开。

若提示标签尚未连接浏览器扩展，先在 Chrome 刷新该页面，再在动作菜单选择“刷新预览”；仍失败时检查浏览器扩展的网站访问权限。

搜索支持拼音匹配，但列表不显示行内彩色命中高亮。

## 数据与隐私

浏览器数据读取、搜索和索引均在本机处理，不上传浏览索引，不读取或转发 Chrome Cookie。Chrome 书签、历史和本地图标缓存为只读访问；单来源读取失败时保留其他来源的结果，错误显示在“来源状态”中。

启动预览缓存默认启用，每个 Chrome 配置最多保存 100 条书签和 100 条历史，有效期 5 分钟。可在扩展设置关闭，或在动作菜单清除；标签页和无痕记录不写入该缓存。

正文仅在当前命令内存中缓存，最多 10 份、30 秒，最多展示 8,000 字符。启用官方浏览器扩展后，网站图标可能按 API 返回的图片地址加载；读取本地 Chrome 图标时，仅使用所属配置的缓存，临时图片在退出命令时清理。

## 开发

开发需要 Node.js 22.22.2 或更新版本。在扩展目录执行：

```bash
npm ci
npm run dev
```

开发完成后运行 `npm run check`，检查类型、测试、格式和分发构建。源码与问题反馈见 [项目仓库](https://github.com/cjinhuo/blazwitcher-raycast)。
