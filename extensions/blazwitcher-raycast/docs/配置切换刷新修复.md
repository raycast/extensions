# 配置切换期间刷新回退旧配置

## 问题与修复

在操作菜单选中另一个 Chrome 配置（或“全部配置”），配置发现尚未返回时执行刷新，刷新会使用旧 `profileId` 并取消先前加载，最终回退到旧配置的数据。书签和历史可能因此来自错误账户。

在 `configure` 开始时保存新的选择意图，再异步发现、校验配置和读取数据。刷新复用同一个选择；原有 generation 检查仍阻止旧请求覆盖新结果。无效或已删除的配置仍在发现阶段回退到有效默认配置。

- 延迟配置发现的回归测试在修复前失败：预期 `Profile 1`，实际 `Default`；修复后通过。

- 真实 Raycast 开发版本：统一搜索中从配置 A 切换配置 B 后立即刷新，结果完成加载后重新打开菜单，勾选仍在 B。
