# Raycast 原生单栏实施计划

2026-09-16，用户明确要求取消独立浮窗，参照 Clipboard History 调查列表内高亮，同时保留自己的单栏布局。

## 当前实现

- 仅保留“搜索浏览器”一个 `view` 命令，直接渲染 `SearchBrowser`，不启动外部应用。
- 原生 `List` 默认单栏，保留来源图标、标题、灰色 URL、来源标识、结果计数、来源筛选和原生动作菜单。2026-09-30 用户确认可通过 `⌘D` 主动展开详情，开关只在本次命令有效。
- `ResultDetail` 展示基础信息；`usePagePreview` 在选中稳定 250ms 后通过 `readPagePreview` 读取指定标签的 Markdown，前后核对 ID 与 URL，忽略取消后的响应。正文最多 8000 字符、10 份内存缓存、30 秒内复用、6 秒超时，提供独立“刷新预览”动作。
- `SearchBrowser` 协调查询、选中项与动作；`BrowserResultItem` 负责行图标、标题及附件，详情展开时隐藏副标题并跳过隐藏附件计算。`ResultDetail` 只接收正文数据和加载状态，不依赖 hook 返回类型；`preview-markdown` 负责基础信息与正文的紧凑展示，统一滚动、缩小正文标题、图片转链接。收起面板清除展示状态、保留短时缓存；缓存过期重新展开时显示加载状态。
- 继续使用 `text-search-engine@1.5.3` 匹配中文、全拼、首字母、混合文本和 URL，返回原始命中范围。
- `BrowserService` 在 Raycast 扩展进程管理索引；50 条分页、旧查询取消、版本校验、配置切换、单来源错误隔离。
- 上下键、统一四项结果动作、快捷键设置、Chrome 配置切换使用原生列表及 Action API。
- 统一入口提供可选快捷键的来源动作；切换来源保留关键词、移除旧前缀，下拉框显示实际生效的来源。统一动作和快捷键设计见 `openspec/changes/unified-browser-actions/`。
- Electron 代码、安装产物和旧协议保存在 `.local/rejected-desktop/`；停止独立应用，不参与构建。

- 不再提供浏览器列表的手动刷新；启动和切换 Chrome 配置时重新读取。正文有独立“刷新预览”操作。快捷键覆盖值版本化保存在 Raycast LocalStorage，旧偏好只迁移一次。

## 未完成项

1. 列表标题内彩色高亮：本机 Raycast 2.4.1.0 内置 Clipboard History 使用内部 DOM 高亮；公开 List API 及当前扩展渲染路径不提供该能力。详见调查文档。不得用无高亮结果冒充完成。
2. 当前原生列表只支持同一行 title/subtitle；自定义双行排版与背景颜色未开放。
3. 当前已在真实 Raycast 加载单栏，验证拼音搜索、复制和 Chrome 打开书签。其他人工验收边界见验证记录，旧双栏或浮窗记录不能代替。

## 验证边界

逻辑测试覆盖中文、拼音、混合、URL、Unicode、分页、取消、配置竞态、无痕偏好、SQLite 快照、真实标签 ID 和 20,000 条记录的内存预算。实际界面验证另记。不会修改 Raycast 本体、注入内部组件或改写其私有数据库。
