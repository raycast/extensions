# Blazwitcher Raycast 实施计划

## 目标和当前状态

在当前目录新建独立项目，将 Blazwitcher 的核心流程迁移到 Raycast：输入 → 拼音匹配 → 查看命中 → 切换标签页或打开地址。说明、开发约定及界面文案使用中文。

目录：本地克隆的 `blazwitcher-raycast` 项目根目录。

本文件记录实施方案。2026-09-16 已完成实现并启动开发进程；真实 Raycast 的三来源搜索、高亮、Chrome 跳转和刷新已验收。已修复本机验收发现的 100 MB 堆限制问题。最新证据、性能和未覆盖边界见 `验证记录.md`。

### 高亮呈现需要优先验证

已检查 `@raycast/api@1.104.25` 和 `@raycast/api@2.4.1`：`List.Item.title`、`subtitle` 只支持字符串或带 tooltip 的字符串，不支持任意字符范围、HTML 或富文本节点，不能直接复刻 Chrome 列表中的彩色背景高亮。

采用左侧原生结果列表、右侧命中预览。已在真实 Raycast 中验证本地 SVG 黄色背景高亮：输入 `zhongwen` 能强调原文 `中文`；完整实现中 `beiwang`、`bw` 和 `git 备wang` 能强调 `备忘`。当前实现将该预览用于标题和 URL；深色主题和极长文本的真实视觉效果仍是未覆盖边界。

如果必须在“每一行列表标题内”显示任意彩色高亮，需要先调整界面方案或接受 API 限制，不得到实现结束时才悄悄替换成无高亮列表。

## 功能与交互

### 四个入口

1. **搜索浏览器**：统一搜索三种来源。
2. **搜索标签页**：搜索已打开的 Chrome 标签页并切换。
3. **搜索书签**：搜索书签并打开。
4. **搜索历史记录**：搜索历史并打开。

统一入口支持 `/t`、`/b`、`/h` 前缀和来源下拉框，显式前缀优先。独立入口固定来源，避免命令名称与实际对象不一致。

### 结果与动作

- 空输入按来源展示可用标签页和最近数据，并显示数量。
- 标题、URL、来源、窗口或配置名称帮助区分同名结果。
- 右侧预览展示完整标题、URL、原文命中，以及适用的目录和访问时间。
- `Enter`：标签页切换到既有标签；书签和历史在记录所属 Chrome 配置中打开新标签。
- 动作面板提供复制 URL、刷新、展开/收起详情等键盘操作。
- 本次核心交付覆盖搜索与导航；书签删除/撤销、AI 分组等其他 Blazwitcher 能力不作为本次实现的依赖。

### 搜索语义

- 支持中文、英文、全拼、首字母、混合输入和空格分词。
- 搜索标题与 URL，支持不同词分别命中标题和域名。
- 调用引擎获取闭区间命中范围，排序合并后拆分到显示字段。
- 正确处理 emoji、空白、标点、Markdown 特殊字符和异常 URL。
- 排序：完整/前缀匹配优先，标题命中优先，紧凑匹配优先；相关度相同时标签页优先、历史按访问时间排序。具体权重通过固定样例与真实数据验证后固化。
- 不按 URL 删除不同窗口的标签，也不隐藏不同来源的结果；只对同一配置的书签双文件重复记录去重。

## 数据读取与导航

| 来源   | 获取方式                                         | 刷新时机                                     | 边界                                         |
| ------ | ------------------------------------------------ | -------------------------------------------- | -------------------------------------------- |
| 标签页 | JXA/AppleScript 查询窗口、真实标签 ID、标题、URL | 打开命令及手动刷新；低频自动刷新依据性能决定 | Chrome 未启动、无痕、权限拒绝、标签移动/关闭 |
| 书签   | 合并 `Bookmarks` 与 `AccountBookmarks`           | 打开命令、配置切换、手动刷新                 | 文件缺失、同步暂态、重复记录、目录名称       |
| 历史   | 只读 SQLite 取候选，再做内存拼音匹配             | 打开命令、配置切换、手动刷新                 | 锁、WAL 一致性、权限、Chrome 时间戳          |

配置发现读取 Chrome `Local State`，默认采用 `last_used`，允许选择具体配置或全部配置。该值不代表最前方窗口的配置。标签来自所有可读窗口；如果接口无法可靠返回所属配置，只标示窗口，不虚构关联。

历史默认读取最近 20000 条，可配置，并显式说明搜索范围。不得先按拼音做 SQL 字面 `LIKE` 过滤，否则会漏掉中文标题。先验证真实耗时和内存，再确定合理上限。

SQLite 优先只读查询。本机确认 Chrome 使用独占锁，因此后备方案改为复制数据库及 WAL/回滚日志，比较复制前后的 inode、大小及纳秒时间戳，变化时重试，随后检查副本完整性。在私有临时目录中恢复和读取副本，完成后清理，不修改 Chrome 原数据库。独占锁和未 checkpoint 的 WAL 已有真实 SQLite 测试覆盖。

标签跳转在动作执行时按真实 ID 重新查找窗口和位置。目标已关闭时提示并刷新，不跳到旧位置的其他标签。书签和历史按所属配置打开，地址通过参数传入，禁止拼接成可执行脚本。

## 架构

```text
src/
  search-all.tsx / search-tabs.tsx / search-bookmarks.tsx / search-history.tsx
  components/       搜索界面、结果项、命中预览、动作面板
  hooks/            数据加载、来源状态、异步搜索、刷新生命周期
  browser/          配置发现、标签脚本、书签、历史、跳转
  search/           查询解析、匹配、范围转换、排序、分批搜索
  types/            统一记录和来源状态
tests/              逻辑测试和数据适配测试
scripts/            不暴露私人浏览数据的本地诊断
docs/               中文说明和验证记录
openspec/           规格、设计和任务状态
```

数据流：数据适配器 → 统一记录 → 来源/配置筛选 → 拼音匹配和排序 → 列表/命中预览 → 对应跳转动作。

记录包含稳定 ID、来源、标题、URL、配置及来源元数据；搜索结果另外保存各字段命中范围。UI 不直接操作数据库或拼接脚本。

## 性能、状态与隐私

- 输入防抖初始约 80 毫秒，关闭 Raycast 内置过滤，避免它再次剔除拼音结果。
- 不随每次按键重新读取书签/历史；命令生命周期内复用边界映射。缓存按展开后的 boundary 与 originalIndices 总规模限额 20000 个单元，避免按记录条数缓存长 URL 占用过多内存；每 250 条让出执行并检查取消。
- 用请求序号或取消标记防止旧查询、旧配置覆盖新结果。
- 初始约 50 条，按需展示更多；匹配作用于全部已加载候选，不只匹配已显示的 50 条。
- 对 100、1000、20000 条候选分别测读取、索引、匹配耗时和内存。输入后通常在 200 毫秒内更新为优化目标；当前大规模实测仍有查询高于此目标，记录实际数值，不将目标写成保证。
- 区分加载、成功但为空、无匹配和读取失败。单个来源失败不阻塞其他来源。
- 数据只在本地处理，不上传，不持久化完整浏览索引，不记录私人标题和完整 URL，不向远程 favicon 服务发送浏览域名。
- 无痕标签默认排除，可明确开启；不持久化其信息。
