# 搜索匹配与排序体验

## 已复现的问题

1. 两条标题都为“中文文档”的记录，搜索 `zw` 或 `zhongwen` 时，网址恰好包含关键词的一条被当成仅网址命中，分数从 249 降到 49。原因是组合字段的字面匹配提前返回，遮蔽了中文标题的拼音命中。
2. 标题 `GitHub / git guide` 搜索 `github git` 能找到，搜索 `git github` 却漏掉。SDK 按输入顺序逐词占用命中区间，短词先占用了长词的位置。拼音 `zhong zhongwen` 搜索“中文 / 中”同样可复现。

## 行为调整

先尝试完整标题匹配（字面或拼音），标题不能满足整个查询时再搜索标题与网址的组合。评分继续使用原来的标题相关度规则；不合并不同来源或相同网址的记录。

原顺序匹配失败后，按词长降序重试一次，仍复用 text-search-engine 的匹配与区间规则。不会把同一处命中复用给重复词，也不进行排列穷举；它修复短词抢占长词的场景，不保证任意多词排列完全等价。

标题和组合字段缓存共用原有 20,000 展开单位预算。保留取消、分页前全量检索和 Unicode 到原文区间映射。不包含行内着色能力。
