# 来源切换快捷键

## Why

搜索过程中切换来源需要打开下拉框或重写前缀；输入 `/h zw` 后，下拉框选择标签页仍被前缀覆盖。统一入口需要一个保留关键词、明确覆盖旧来源的切换动作。

## What Changes

- 增加全部、标签、书签、历史四个来源动作，默认使用 `⌘⇧0/1/2/3`，支持命令内设置自定义或停用快捷键；旧偏好只迁移一次。
- 快捷键、动作菜单与下拉框共用切换逻辑：移除已有来源前缀、保留关键词、同步显示有效来源。
- 仅有效查询变化时取消旧请求；仅保留统一入口。

## Impact

修改查询工具、共享搜索组件及 manifest；补充测试与使用、验证记录。无新依赖，不更改浏览器数据读取及存储。
