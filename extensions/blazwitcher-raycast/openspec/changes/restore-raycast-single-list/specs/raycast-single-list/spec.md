## ADDED Requirements

### Requirement: Raycast 内单栏搜索

系统 SHALL 在 Raycast 内渲染“搜索浏览器”一个 view 命令，展示单栏结果，不启动独立窗口，不显示右侧详情。

#### Scenario: 打开统一搜索

- **WHEN** 用户执行搜索浏览器
- **THEN** 原生列表展示来源筛选、结果数、标题、网址、来源和操作菜单

### Requirement: 保留匹配与原始记录

系统 SHALL 使用 text-search-engine 返回拼音命中范围，复制和跳转使用原始记录，按版本拒绝过期操作。

#### Scenario: 查询发生变化

- **WHEN** 新查询或数据重新读取令旧结果失效
- **THEN** 旧结果不能再执行复制或跳转，分页只能合并当前查询结果

### Requirement: 明确高亮能力边界

系统 SHALL 区分 Clipboard History 的私有高亮组件与公开扩展 API，不得用括号、详情页或独立窗口冒充列表高亮。

#### Scenario: 公开接口未提供范围渲染

- **WHEN** 当前宿主没有可用的扩展行内高亮接口
- **THEN** 保留原文及匹配数据，并明确记录着色功能未完成

### Requirement: 全部来源去重

系统 SHALL 在全部来源的匹配结果中，按相同的非空标题或完整 URL 去重，优先保留标签页、其次书签、最后历史，并保留所有真实标签页。去重 SHALL 在结果缓存和分页之前完成，其他结果的相关度顺序保持不变。

#### Scenario: 相同页面出现在多个来源

- **WHEN** 命中的标签页、书签和历史标题相同，即使版本参数或登录跳转地址不同
- **THEN** 仅保留标签页，结果数按去重后计算，复制和跳转使用该标签的原始记录

#### Scenario: 查看被合并的记录

- **WHEN** 用户切换到单一来源，或使用只匹配某条记录的 URL 片段搜索
- **THEN** 单一来源保留全部命中记录，未命中的标签不会遮住匹配的书签或历史

#### Scenario: 多个真实标签重复

- **WHEN** 多个标签页标题或 URL 相同
- **THEN** 每个标签页仍可独立选择和跳转

### Requirement: 可选浏览器图标 Adapter

系统 SHALL 通过独立的 BrowserIconAdapter 异步补充普通标签图标，当前使用官方 Raycast Browser Extension，不阻塞文字结果，不修改 JXA 的结果、排序和跳转，保留来源文字。

#### Scenario: 官方扩展可用

- **WHEN** 可用性检查通过且官方 API 返回唯一匹配的 tab ID、URL 和 favicon
- **THEN** 对应普通标签显示网站图标；书签、历史和无痕标签沿用来源图标

#### Scenario: 图标不可用

- **WHEN** 未安装、检测或调用失败、调用超过 1.5 秒、图标缺失、ID 或 URL 不匹配、ID 重复或图片加载失败
- **THEN** 保留来源图标，搜索、复制和跳转继续工作；未安装时不调用 getTabs，不触发安装提示，失败不显示来源错误

#### Scenario: 搜索、配置切换或退出

- **WHEN** 用户搜索、切换来源、分页、切换 Chrome 配置或退出命令
- **THEN** 同一数据版本共享请求，重新打开命令或切换 Chrome 配置后重新读取；旧图标请求不覆盖新结果，退出后不更新组件。不依赖实时事件订阅
