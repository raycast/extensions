## Context

在独立 Raycast 项目迁移 Blazwitcher 的搜索与导航流程。三个参考仓库已经本地阅读，详细来源、实施步骤和验收矩阵见 `docs/实施计划.md`。

Chrome 扩展中的 `chrome.tabs/bookmarks/history` 和网页 DOM 不能在 Raycast 直接使用。原生 `List.Item` 不提供任意字符高亮范围，需要先验证适合原生组件的命中展示方式。

## Goals / Non-Goals

目标：

- 三类来源的全拼、首字母、中英文混合与空格分词搜索。
- 准确展示原文命中区间，可靠切换标签或打开对应配置的地址。
- 中文工程文档、清晰错误状态、可测的性能及真实本机调试。

本次不包含商店发布、远端推送或 Blazwitcher 的 AI 分组、书签管理等其他功能；这些不妨碍本次核心搜索与导航的完整交付。

## Decisions

### 原生列表配合命中预览

使用 Raycast `List`、`List.Item.Detail` 和 `ActionPanel`。关闭内置过滤，结果由 text-search-engine 决定。右侧采用本地 SVG 原文命中预览，已在本机验证 `zhongwen` 对应 `中文`，以及完整三来源中 `beiwang`、`bw`、`git 备wang` 对应 `备忘` 的黄色背景高亮。真实界面验收使用浅色主题，其他视觉边界见验证记录。

不使用拼音串替换标题、不嵌入网页 DOM，也不承诺原生列表标题不支持的任意彩色高亮。

### 统一记录，分离匹配结果

记录包含稳定 ID、来源、标题、URL、配置及来源元数据。数据适配层不依赖 UI。匹配结果单独包含各字段命中区间和排序依据，便于独立测试。

优先复用 text-search-engine 的预计算边界及匹配 API。标题和 URL 组合匹配后按字段偏移拆分闭区间。对范围排序、合并、转义和特殊字符进行测试，禁止把标题或地址作为未转义 Markdown 内容执行渲染。

### 按来源读取 Chrome 本地数据

标签由 JXA/AppleScript 获取真实 ID、窗口和当前位置；书签合并本地与账号 JSON；历史通过只读 SQLite 读取候选再匹配。优先从 Local State 发现配置，默认 last_used，并明确它不等于最前方窗口的配置。

历史初始默认上限 20000 条，范围可配置并明示。不得用拼音 SQL 字面匹配提前缩小候选。若需要数据库快照，必须处理 WAL 一致性。

### 动作时重新定位

标签按真实 ID 在当前窗口集合中重新定位，消除拖动和关闭造成的过期索引问题。书签及历史按所属配置打开；暂不做跨配置 URL 自动复用，避免切换到错误账号环境。参数与可执行脚本分离。

### 来源独立状态与可取消搜索

三种来源独立加载和报错；部分成功仍能使用。配置切换及查询更新使用请求版本或取消标记，防止旧结果覆盖。初始分页展示约 50 条，但匹配覆盖全部候选。

索引仅在命令生命周期内保存。本机 Raycast 的 100 MB 命令堆限制暴露了按 2000 条记录缓存边界占用过大的问题。缓存现改为最多 20000 个 boundary/originalIndices 单元，连续原文匹配直接使用与引擎一致的 indexOf 优先路径，并去掉重复保留的组合原文。默认 20000 条历史的真实搜索、刷新已通过；另以 64 MB old-space 子进程覆盖 20000 条长 URL 的连续拼音查询。耗时和内存实测见验证记录，不宣称 200 毫秒目标全部达标。

## Risks / Trade-offs

- 原生 UI 不支持列表内任意彩色高亮：优先验证右侧命中预览；若必须逐行彩色高亮，需要先调整方案。
- Chrome 自动化或文件读取权限不足：显示具体来源错误，区分用户操作与程序故障，不用模拟数据宣称运行通过。
- 多配置标签归属不可可靠推断：只标示可确认的窗口信息，不按不可靠的推断过滤标签。
- SQLite 锁及同步暂态：有限重试或一致快照，始终避免改写浏览器数据。
- 大量历史记录的索引内存：基准测试后调整有界缓存及分批搜索，读取范围始终可见。
- Raycast 使用的 React 与 text-search-engine peer 声明有差异：仅用核心入口，验证依赖安装和实际构建，不导入其 React 组件。

## Migration Plan

新增独立目录，原参考项目保持不变。先做高亮及数据访问原型，再完成工程基线、数据层、搜索层、界面与本机验收。各阶段产物和通过条件见实施计划；不涉及已有用户数据迁移。

## Open Questions

- 本机只有一个 Chrome 配置，跨账号实际打开仍需其他环境补充验收。
- 深色主题、极长文本、超过默认 20000 条范围的真实运行仍需补充验收。
- 当前采用打开命令和切换 Chrome 配置时读取；手动刷新已移除，关闭标签报错后提示重新打开命令，暂未增加定时读取。
