# 统一浏览器动作与快捷键

## Why

多个入口重复维护来源逻辑；结果只有打开、复制，缺少明确的新标签与当前页操作，也不能分别设置动作快捷键。

## What Changes

- 仅保留“搜索浏览器”，移除三个来源入口和手动刷新动作；来源筛选、分组、去重、图标与配置切换保留。
- 结果动作统一为打开、新标签、当前标签、复制，当前窗口与标签在命令挂载时捕获。
- 原生动作菜单内增加快捷键设置，支持覆盖、停用、冲突校验、保存、恢复默认和旧偏好一次迁移。
- 旧入口的 Raycast 启动热键需要用户改绑至“搜索浏览器”。

## Impact

仅修改 Raycast 扩展。动作以原始记录和实时版本校验为准；不增加依赖、浏览器内容脚本、DOM 键盘监听或通用命令总线。
