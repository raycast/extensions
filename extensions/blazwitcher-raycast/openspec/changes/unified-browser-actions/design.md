## Context

保留原生单栏 List。宿主为首两项动作提供 Enter／⌘Enter，设置额外绑定不能承诺移除这两个宿主按键。

## Decisions

- `actions.ts` 保存动作 ID、顺序、分组、默认绑定及四项动作的解析流程；`shortcuts.ts` 处理规范化、冲突和版本化覆盖值。
- `BrowserActions` 渲染结果与来源动作；`ShortcutSettings` 使用 Action.Push 和原生 Form。菜单与设置共享同一有效配置，加载完成前不挂载额外绑定。
- LocalStorage 仅保存 `{version: 1, overrides}`。缺省继承默认，null 停用额外绑定。首次无存储时迁移旧来源偏好并保存，即使恢复默认也保留版本化空覆盖，避免重复迁移。
- 当前 Chrome 上下文挂载时捕获一次。新标签使用捕获窗口，当前页使用捕获窗口内的标签 ID；执行时通过 JXA byId 引用再次定位，不回退。捕获失败不影响复制或原有标签聚焦。
- URL 使用既有协议白名单，通过 argv 的 JSON 数据传递。书签／历史主动作保留所属配置打开行为；显式新标签动作使用捕获窗口。
- 取消菜单手动刷新；命令启动、重新打开和配置切换仍重新读取。

## Verification

本地单元测试分别覆盖快捷键冲突／迁移／无效配置、结果版本、捕获失败隔离和 JXA 模拟边界。真实 Raycast 菜单、Form、宿主按键及 Chrome 行为独立验收，记录在验证文档；单元测试不等价于真实 UI 验证。
