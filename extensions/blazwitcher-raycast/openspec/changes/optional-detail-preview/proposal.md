# 可选详情预览（试用版）

## Why

搜索结果的标题和 URL 不足以判断页面内容，需要在原生窗口中按需查看基础信息与正文。连接稳定性、窄窗口排版和入口可发现性尚需真实使用反馈，因此先提供试用版。

## What Changes

- 默认单栏，`⌘D` 或动作菜单切换原生详情，支持快捷键设置与旧绑定兼容。
- 官方 Browser Extension API 按指定标签读取 Markdown，独立管理缓存与过期响应。
- 详情基础信息和正文统一滚动，缩小常见标题、图片改链接，左侧优先展示标题。
- 明确连接错误、动态网页适配与真实验收的未完成项；入口提示和跨命令记忆不在当前实现范围。

## Impact

依赖统一浏览器动作与快捷键变更。无新增依赖，不持久化正文，不自动刷新或打开 Chrome 页面。实现与后续方向见 `docs/详情预览试用说明.md`。
