## ADDED Requirements

### Requirement: 按需展开原生详情

搜索界面 SHALL 默认单栏，允许通过动作和可配置快捷键展开或收起选中结果的原生详情。

#### Scenario: 展开与收起

- **WHEN** 用户执行详情开关动作
- **THEN** 切换原生面板并保留查询和选中项，重新进入命令时恢复收起

### Requirement: 正文读取受标签身份与生命周期约束

正文读取 SHALL 只针对普通 HTTP(S) 标签，使用指定 tabId，并在读取前后核对 ID 与 URL。正文只保留于当前命令内存。

#### Scenario: 选择变化或读取失败

- **WHEN** 用户切换选择、关闭详情，或标签导航、读取失败及超时
- **THEN** 旧正文不得覆盖新结果，必要时显示状态提示，搜索与打开操作继续可用

### Requirement: 详情内容适配窄面板

详情 SHALL 由原生 Markdown 组件统一滚动展示基础信息与正文，并对常见大标题和图片进行紧凑化处理。

#### Scenario: 页面包含大图与标题

- **WHEN** Markdown 包含支持的 ATX 标题、普通或引用式图片
- **THEN** 预览缩小标题并显示图片链接，原始 URL 与浏览器页面保持不变
