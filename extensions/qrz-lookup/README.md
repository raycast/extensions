# QRZ Lookup

Look up amateur radio callsigns on [QRZ.com](https://www.qrz.com) from Raycast.

## Setup

1. Create an account on [QRZ.com](https://www.qrz.com) if you do not have one.
2. Open the **Search Callsign** command.
3. Enter your QRZ.com username and password.

## Data

The extension uses the [QRZ XML Logbook Data API](https://www.qrz.com/docs/xml/current_spec.html).
Without an XML Logbook Data subscription, QRZ.com returns only a small set of fields.
Get a subscription on QRZ.com to see all fields.
