# Gitea Code Review Extension

Raycast AI-powered code review assistant for Gitea pull requests.

## Features

- 📋 List all open pull requests from your Gitea repository
- 🤖 AI-powered code review with Raycast AI
- 💬 Generate review comments

## Setup

1. Configure your Gitea settings in Raycast preferences:
   - Gitea URL (e.g., http://your-gitea-instance:3000)
   - Gitea API Token (create one in Gitea under Settings → Applications)
   - Repository (format: owner/repo)

## Usage

1. Open Raycast
2. Search for "List Pull Requests" to see all open PRs
3. Select a PR and choose "Review Pull Request" for AI-powered analysis
4. Optionally post the review as comment to the pull request.
