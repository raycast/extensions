# Notices

JW Library Linker is an unofficial community extension. It is not affiliated with
or endorsed by Watch Tower Bible and Tract Society of Pennsylvania or the
publishers of JW Library. JW Library is a trademark of its respective owner.

The extension's packaged icon is an original vector drawing, with its source in
`tools/render-icon.swift`. Bookmark symbols use Raycast's built-in icon system.
Publication artwork and bookmark titles are read from the user's local
installation at runtime; they are not distributed with the extension.

`src/bible-verses.ts` contains factual numeric reference boundaries for the
66-book NWT canon. It contains no Bible text. Validation uses these boundaries;
verse numbering in other Bible editions may differ.

The project originates from Martin Sakowski's
[Alfred JW Library Linker workflow](https://github.com/msakowski/alfred-library-linker).
Its local workflow metadata identifies Martin Sakowski as the creator.
The project's own source is offered under the MIT license in `LICENSE`.
Dependencies retain their respective licenses. Maintainers should review the
applicable JW Library integration terms before public distribution.
