## Model API Key

1. Go to [dev.meta.ai](https://dev.meta.ai) and sign in.
2. Create a Model API key — it looks like `LLM|...`.
3. Paste it here.

## Muse Model

The default model preselected in the `Ask Muse AI` model picker, e.g. `muse-spark-1.3`. You can still switch to any available Muse Spark model from the dropdown when asking a question.
