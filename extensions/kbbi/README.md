# KBBI

Look up Indonesian word definitions from the **Kamus Besar Bahasa Indonesia (KBBI)** right from Raycast.

## Features

- **Search Word**: type an Indonesian word and get live suggestions as you type
- Definitions with word class and field labels (`n`, `v`, `Huk`, …), pronunciation, and usage examples
- Homonyms (e.g. `apel (1)`, `apel (2)`) are shown as separate entries
- Base words, derived words (_kata turunan_), compound words (_gabungan kata_), variants, proverbs (_peribahasa_), and metaphors (_kiasan_)
- Jump to any related word from the action panel (`⌘K`, or `Ctrl+K` on Windows → **Related Words**)
- Copy the word or its definitions, or open it on the official KBBI website

No API key or setup is required.
