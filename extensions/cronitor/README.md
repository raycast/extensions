# Cronitor

This is a Raycast extension for [Cronitor](https://cronitor.io/) - _Monitoring made for developers._

## 🚀 Getting Started

1. **Install extension**: Click the `Install Extension` button in the top right of [this page](https://www.raycast.com/xmok/cronitor) OR `install` via Raycast Store

2. **Enter your Cronitor API Key**:

    - `Follow` instructions from https://cronitor.io/docs/api to get the Key
    - `Copy` and `Paste` this in Preferences
