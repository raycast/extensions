# Local AI Changelog

## [Fix Setup Check and Model List] - 2026-11-23

- Check Setup no longer reports Apple Intelligence as off when it is on. The check now asks macOS directly.
- Check Setup now tells you when the on-device model is still getting ready or when this Mac is not eligible.
- The model list in the command form no longer shows entries that can't be used from Raycast.
- A command set to Private Cloud Compute now explains why it can't run.

## [Initial Version] - 2026-11-17

- Custom AI commands with prompts, icons, creativity levels and replace or window output
- Per-command hotkeys through Quicklinks
- Built-in starter commands for rewriting, summarizing and translating
- Placeholders for selection, clipboard, date, time and typed arguments
- Ask Local AI and saved chats with image attachments
- Import and export of commands as JSON
- Check Setup command
