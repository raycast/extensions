# Create Barcode Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Generate EAN-13, ITF, NW-7 (Codabar), CODE39 and CODE128 barcodes straight from the search bar
- List every symbology that can encode the current input so you can compare them side by side
- Calculate the EAN-13 check digit automatically when 12 digits are entered
- Preview the barcode in the detail pane with five selectable heights
- Export as PNG or SVG to a configurable folder, or copy to the clipboard
- Pin a single symbology from the search bar dropdown, or leave it on Auto Detect
