# MovieBox for Raycast

Watch movies and TV shows directly from Raycast.

## Requirements

You need one of these media players installed:
* [IINA](https://iina.io/) (Recommended)
* [VLC](https://www.videolan.org/vlc/download-macosx.html)
* [mpv](https://mpv.io/)

## Installation

[Install from Raycast Store](https://www.raycast.com/)

## Commands

* **Discover**: View trending feed
* **Search Movies**: Find movies
* **Search Series**: Find TV shows
