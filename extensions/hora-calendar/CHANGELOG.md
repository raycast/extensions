# hora Calendar Changelog

## [Focus, Agenda and Availability] - 2026-11-13

- Start Focus and Stop Focus — control hora's Focus session, with an optional length in minutes
- Copy My Availability — copy your free time slots as text, with a choice of duration and days ahead
- Today's Agenda — see what is left today and tomorrow, then join, RSVP, copy a link or delete an event
- Focus and Copy My Availability need hora Calendar 3.0.2 or later

## [Initial Version] - 2026-10-07

- Create Calendar Event — describe an event and save it without opening hora
- Create Meeting — parse a sentence, then refine it in hora before saving
- Create Task — add to any Google Tasks list, with a due date and notes
- Join Next Meeting — find an upcoming meeting and open its link in the right account
