# Prolixo

Generate multilingual, thematic placeholder text (**Words**, **Sentences**, and **Paragraphs**) directly from Raycast using the [Prolixo](https://prolixo.vercel.app) API.

## Commands

- **Generate Paragraphs**: Enter the number of paragraphs (default `3`) to copy or paste text, depending on your Quick Command Action preference.
- **Generate Sentences**: Enter the number of sentences (default `3`) to copy or paste text, depending on your Quick Command Action preference.
- **Generate Words**: Enter the number of words (default `25`) to copy or paste text, depending on your Quick Command Action preference.
- **Generate Placeholder Text**: Customize language, domain theme, and linguistic precision, then generate text to preview it or paste it directly.

## Supported Languages & Themes

- **Languages**: Portuguese (`pt`), English (`en`), Spanish (`es`), French (`fr`), and Classical Latin (`la` / *Lorem Ipsum*).
- **Themes**: Business, Ecology, Law, Medicine, Mining, Politics, and Technology.
- **Linguistic Precision**: Optionally inject realistic grammatical or spelling errors for QA, NLP, and spellchecker testing.

## Preferences

Open Extension Preferences (`Cmd+,`) to configure defaults for the quick commands:

- **Language** & **Theme**
- **Grammar Correct** & **Orthography Correct**
- **Quick Command Action** (`Copy to Clipboard` or `Paste to Active App`)
- **API Base URL** (defaults to `https://prolixo.vercel.app`)
