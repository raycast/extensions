# WeBeep Changelog

## [Initial Version] - {PR_MERGE_DATE}

### Added

- **Search Courses** — browse enrolled courses (in progress, past, favourites), drill into sections, folders, files and links, toggle favourites
- **Search Materials** — search and download every file across courses in progress
- **Open Recordings** — open lecture recording archives and virtual classrooms
- **Read Announcements** — latest announcements from all courses in progress
- **Read Notifications** — WeBeep notifications with mark-all-as-read
- **Show Upcoming Events** — calendar events and assignment deadlines
- **Search Course Catalog** — site-wide course search
