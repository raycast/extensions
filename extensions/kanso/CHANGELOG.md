# Kanso Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Capture Note: write a note into any Kanso notebook.
- Add Task: add a task with a typed due date and repeat ("fri 3pm every week") to today's daily note, the Inbox or a chosen note.
- Search Notes and Open Note: find a note and open it in Kanso.
- Connect: pair with Kanso by approving a six-digit code in the app; no key to copy.
