# Kanso

Capture notes and tasks into [Kanso](https://kansoapp.app) and find your notes, straight from Raycast.

Kanso keeps your notes on your own machine. This extension talks only to Kanso's local API on `127.0.0.1`; nothing goes through a server.

## Setup

1. Open Kanso and turn on the local API (Settings › Local API).
2. Run **Connect Kanso** in Raycast. Kanso shows a six-digit code — check it matches and click **Allow**.

The port preference defaults to `19840`.
