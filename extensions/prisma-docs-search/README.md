# Prisma Docs Search

Ask the [Prisma docs](https://www.prisma.io/docs?utm_source=raycast&utm_medium=prisma-docs-search) AI assistant a question from Raycast and read the answer, with the docs pages it used as sources. It covers the whole Prisma platform: [Prisma Postgres](https://www.prisma.io/postgres?utm_source=raycast&utm_medium=prisma-docs-search) (managed Postgres), [Prisma Compute](https://www.prisma.io/compute?utm_source=raycast&utm_medium=prisma-docs-search) (hosting for Node.js, Bun and Next.js apps next to your database) and [Prisma ORM](https://www.prisma.io/orm?utm_source=raycast&utm_medium=prisma-docs-search) (type-safe queries and migrations).

Handy when you're deep in dev work and want an answer in a few keystrokes.

Prefer to work from your AI tool? Connect the [Prisma MCP server](https://www.prisma.io/docs/ai/tools/mcp-server) at `https://mcp.prisma.io/mcp`.
