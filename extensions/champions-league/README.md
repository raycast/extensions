# Champions League

Follow the UEFA Champions League from [Raycast](https://raycast.com/): live scores, fixtures, results, standings, clubs, squads, player profiles, stat leaderboards and every final since 1956.

## Commands

| Command | What it does |
| --- | --- |
| **Standings** | League phase table (or group tables back to 1991/92) with form, qualification zones, rank movement and each club's next fixture. |
| **Fixtures** | Live matches, refreshed every 30 seconds, followed by upcoming fixtures. |
| **Results** | Completed matches, newest first, with infinite scroll back through the season. |
| **Clubs** | Club profiles with coach, stadium, season stats, recent results, European Cup titles, squad and full season schedule. |
| **Players** | Search every registered player and view their profile, season stats and Champions League career by season. |
| **Stats** | Leaderboards for goals, assists, clean sheets, top speed, distance covered and more, for players and clubs, for any season since 1999/2000. |
| **Champions** | Every European Cup and Champions League final, and a ranking of clubs by titles. |

From any match you can open the **summary** (scorers, red cards, aggregate, referee, attendance, weather, player of the match), the **timeline** (goals, cards, substitutions, VAR), the **lineups** and **match stats**.

## Preferences

- **Search Bar Filter**: filter Fixtures and Results by club or by round.

## Data

All data comes from UEFA's public endpoints (`comp.uefa.com`, `match.uefa.com`, `standings.uefa.com`, `compstats.uefa.com`, `matchstats.uefa.com`). No API key is needed.
