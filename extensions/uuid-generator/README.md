# UUID Generator

Generate UUIDs, ULIDs and TypeIDs and copy them to your clipboard, without opening a browser.

## Commands

- **Generate UUIDs**: Random UUIDs (v4).
- **Generate V5 UUIDs**: Name-based UUIDs (v5).
- **Generate V7 UUIDs**: Time-ordered UUIDs (v7).
- **Generate ULIDs**: Sortable ULIDs.
- **Generate TypeIDs**: TypeIDs with a prefix.
- **Parse TypeIDs**: Turns a TypeID back into its UUID.
- **Pack TypeID**: Turns a UUID into a TypeID with a prefix.
- **Format UUID**: Adds dashes to a UUID that has none.
- **View History**: Every ID you've generated.

## Tips

- Give **Generate UUIDs** an alias like `uuid`, so a fresh ID is always a couple of keystrokes away.
