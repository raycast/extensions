# Perplexity Search Changelog

## [Initial Version] - {PR_MERGED_AT}

- Added the **Search the Web** command, which queries the Perplexity Search API (`POST https://api.perplexity.ai/search`) and shows titles, snippets, and source links in a Raycast list.
- Added preferences for API key, max results (1–20), country (ISO 3166-1 alpha-2), and recency filter.
- Added quick actions to open results in the browser and copy URL, title + URL, or snippet.
