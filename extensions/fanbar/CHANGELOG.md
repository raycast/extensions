# FanBar Changelog

## [Initial Version] - 2026-11-06

- Switch Preset: built-in and custom presets, run with or without holding.
- Fan Status: mode, fan speeds and ranges, temperatures, restore time.
- Fixed RPM: a speed checked against every fan's range, with an optional hold.
- Automatic: hand the fans back to macOS.
- FanBar Menu Bar: CPU temperature in the menu bar, with preset switching.
