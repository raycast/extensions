# Bitcoin Barometer

Shows the current Bitcoin Barometer reading from NakamotoNotes: the cycle score out of 100, its zone, when it was computed and the 7-day change. It reads one public, keyless feed (nakamotonotes.com/open/barometer.json) and nothing else.

A description of the current reading against its history, not a forecast or investment advice.

When the feed is unreachable, slow or malformed, the extension shows an error with the HTTP status. It never shows a stored or default number.

Read the method at https://nakamotonotes.com/methodology.
