# LaunchBar File Manager Changelog

## [Initial release] - {PR_MERGE_DATE}

- Browse the filesystem LaunchBar-style: `→` enters folders, `←` goes up, type to filter
- Multi-select with `X`, Quick Look with `Space`, detail pane with `⌘I`
- Single Tab transfer flow: copy or move one item or a whole selection into any folder
- File operations: Rename, Duplicate, Compress to ZIP, Extract archives, Move to Trash
- New Folder / New File, Copy Path, Show in Finder, favorites jumping
- Preferences for start folder, hidden files, and transfer start folder
