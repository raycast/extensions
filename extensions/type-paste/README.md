# Type Paste

A Raycast extension command that types the current clipboard text into the currently focused input field to get your clipboard content into text fields that do not allow pasting.

## Command

- `Type Clipboard`: Reads text from your clipboard and types it with a virtual keyboard.

## Setup

1. Open Raycast and run this extension in development:
   - `npm run dev`
2. macOS will require Accessibility permission for Raycast to simulate keyboard typing.
3. Grant permission in System Settings > Privacy & Security > Accessibility.
