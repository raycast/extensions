# Quick Groups Changelog

## [Initial Release] - {PR_MERGE_DATE}

- Search user-defined things and their fields from local YAML groups.
- Act on projects, machines, writing, clients, and other concepts from one searchable place.
- Open URLs and files, connect over SSH, open Obsidian notes, and copy sensitive values safely.
- Launch values in macOS applications or pass them to Raycast Script Commands.
- Reuse sibling field values with substitutions and diagnose invalid YAML or conflicting records.
- Start immediately with an editable example and optionally use a custom groups directory.
