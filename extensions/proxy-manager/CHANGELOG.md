# Proxy Manager Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Add `Proxy Manager`: routing state, the site in the active browser tab, the app
  you came from, and the target list in one place
- Add `Toggle Routing`: a no-view hotkey path with a one-line HUD
- Add `Add Target`: normalises a URL or host, prefilled from the active tab, with
  an "add another" loop
- Add `Explain Host Routing`: which rule decides a host's route, with the fix as
  the primary action
- Add `App Routing`: per-app rules starting with the frontmost app, plus a
  picker of installed apps instead of a typed bundle ID
- Target management: presets, wildcard rules, enable/disable, reveal in Proxy
  Manager
