# GridView Pro for Raycast

Launch GridView Pro templates and quick-actions directly from Raycast.

## Features

- **Open Template** — 8 professional layouts: Crypto Trading, DeFi Research, Stock Analysis, AI Content Creation, Developer Workflow, Freelancer HQ, Deep Research, News & Media
- **Quick Launch** — Type tickers like "BTC", "AAPL", "NVDA" for instant research panels
- **Manage Grids** — Access your saved GridView layouts
- **Launch App** — One-tap GridView Pro opener

## Requirements

- macOS 14+
- [GridView Pro](https://apps.apple.com/app/gridview-pro/id6758865330) installed

## Installation

1. Install from Raycast Store (coming soon)
2. Or install locally:
   ```bash
   npm install
   npm run dev
   ```

## Usage

- **Open Template**: `Cmd+Space` → type "Open Template" → select layout
- **Quick Launch**: `Cmd+Space` → type "Quick Launch" → search BTC, AAPL, GPT, etc.
- **Launch App**: `Cmd+Space` → type "Launch GridView"

## Preferences

Set custom GridView Pro app path if installed outside Applications folder.
