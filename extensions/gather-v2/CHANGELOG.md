# Gather V2 Changelog

## [Initial Version] - {PR_MERGE_DATE}

Initial release: Raycast extension for Gather V2.

- Toggle Mic and Camera (⌘⇧D)
- Toggle Microphone (⌘⇧A)
- Toggle Camera (⌘⇧V)
- Set Availability Status: Available (⌘O), Busy (⌘I), Away (⌘U)
- Go to Desk (⌘D)
- Search People and Areas (⌘K)
- Toggle Away from Keyboard (mute mic+camera, set status Away)
