# Gather V2

Control [Gather V2](https://www.gather.town) from Raycast.

> Looking for the Gather Classic version? Use the [Gather](https://www.raycast.com/yannglt/gather) extension by [@yannglt](https://github.com/yannglt) instead. This extension targets the rewritten Gather V2 client (`/Applications/GatherV2.app`) and uses the new V2 keyboard shortcuts.

## Commands

| Command | Gather shortcut | What it does |
|---|---|---|
| Toggle Mic and Camera | ⌘⇧D | Toggle your microphone and camera together. |
| Toggle Microphone | ⌘⇧A | Toggle your microphone only. |
| Toggle Camera | ⌘⇧V | Toggle your camera only. |
| Set Availability Status | ⌘O / ⌘I / ⌘U | Set status to Available, Busy or Away. |
| Go to Desk | ⌘D | Return to your desk. |
| Search People and Areas | ⌘K | Open the search bar. |
| Toggle Away from Keyboard | — | Toggle mic+camera and set status to Away. |

## Requirements

- macOS
- Gather V2 installed at `/Applications/GatherV2.app`
- Logged in to Gather (the extension activates Gather and sends keyboard shortcuts via AppleScript)
