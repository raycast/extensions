# Figma Shortcuts for Raycast

A professional Raycast extension that allows you to quickly search and browse Figma keyboard shortcuts for macOS, Windows, and Linux.

## Features

* **Multi-platform Support**: Toggle between macOS, Windows, and Linux shortcut layouts.
* **Search and Filter**: Instant searching across all shortcuts directly from the Raycast search bar.
* **Categorized View**: Shortcuts are organized into logical sections: Essential, Tools, View, Zoom, Text, Shape, Selection, Components, Arrange, Transform, and Export.
* **Copy to Clipboard**: Quickly copy any shortcut combination using `Cmd + C`.
* **Persistent Preferences**: The extension remembers your selected platform using local storage for a consistent experience.
* **Quick Platform Switching**: Dedicated internal shortcuts (`Cmd + Shift + 1/2/3`) to switch systems without leaving the list.

## Usage

1.  Open Raycast.
2.  Run the **Search Figma Shortcuts** command.
3.  Type to find a specific shortcut (e.g., "Rectangle", "Frame", "Flatten").
4.  Use the dropdown menu or extension-specific shortcuts to switch the operating system view.

## Extension Hotkeys

* `Enter`: View shortcut details.
* `Cmd + C`: Copy the shortcut to the clipboard.
* `Cmd + Shift + 1`: Switch view to macOS.
* `Cmd + Shift + 2`: Switch view to Windows.
* `Cmd + Shift + 3`: Switch view to Linux.
