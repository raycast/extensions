# Changelog

## [Initial Version] - 2026-03-20

### Added

- Initial release of Figma Shortcuts extension
- Search and browse Figma keyboard shortcuts for macOS, Windows, and Linux
- Multi-platform support with platform-specific shortcut display
- Categorized view with sections: Essential, Tools, View, Zoom, Text, Shape, Selection, Components, Arrange, Transform, and Export
- Copy to Clipboard functionality for quick shortcut copying
- Persistent preferences for selected platform
- Quick Platform Switching between macOS, Windows, and Linux layouts
