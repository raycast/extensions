# Cross-Platform Process Manager & Task Killer

View, search, and terminate running processes on Windows and macOS directly from Raycast. 

## Features
- 🔍 **Free Process Enumeration:** View all running processes, search by name or PID, and inspect CPU/Memory usage for free.
- 🔒 **Premium Task Killing:** Force-terminate unresponsive or unwanted processes securely. Requires an active $14/month subscription.
- 💻 **Cross-Platform:** Automatically detects your OS and uses native commands (`taskkill` on Windows, `kill` on macOS).
- 🛡️ **Secure Licensing:** Validated via Gumroad with 24-hour encrypted local caching to prevent API rate limiting.
