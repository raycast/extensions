# Mash Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Search Mash: see your latest chats on this machine, find past chats with your coding agents as you type, grouped Today, This week and Earlier by last activity, each with its project, machine and agent; open a chat in the Mash desktop app at the matching message (↵), glance at the match and the messages around it beside the list with the chat's details (⌘Y: agent, project, machine, last activity, message count and the match's place), and copy a link, message ID or passage.
- Search every source at once (this machine by words and by meaning, and your other machines) in one list that fills in as each answers, keeps rows in place once you move the selection, and offers to retry a machine that doesn't answer.
- Open a Codex thread in the ChatGPT app, or a Claude Code session in the Claude app, in the folder it ran in (Add to Claude for a session the app doesn't have yet).
- With the Mash desktop app installed (in `/Applications` or `~/Applications`), open a chat or the full search in the app and copy a `mash://` link; without it, ↵ copies the resume command or message ID, and Get the Mash App opens the downloads page.
- Search Memory: the decisions, preferences and notes Mash remembers, grouped by project, with the quotes behind them, the agent that recorded them, and Open Source Chat in Mash (↵) to go back to the source chat.
- Copy Resume Command for this machine's Claude Code and Codex sessions, and `Search Mash <query>` from Raycast's root search.
- List matching chats or each matching message, from every machine or this one, with the dropdown beside the search bar (or ⌘1 and ⌘2); the choice is remembered.
- Subagent and fork chats your agents start are left out of the latest chats and of search; a preference brings their matches into search, under the task each was started for.
- When Mash can't search, show its message with ways to fix it: try again, the troubleshooting guide, or set where Mash is, by choosing the `mash` file in the extension's preferences.
