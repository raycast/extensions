# Set up Obscurify.ai

1. Create an account at [obscurify.ai](https://obscurify.ai/?utm_source=raycast). You get a random account number: no email, no password.
2. Add a balance on the account page. The API works on every plan with a positive balance.
3. On [obscurify.ai/account](https://obscurify.ai/account), click **Show API Key** and paste the `sk-obs1_...` key here.

Then open the model picker in AI Chat or Quick AI and choose an Obscurify.ai model. Extension models need Raycast Pro.
