# Simple GIF Cap Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Record a region, window or screen to a GIF from Raycast.
- Region and window picker with move and resize handles.
- Countdown, recording frame and floating Stop pill that stay out of the GIF.
- Preview with copy, paste, trim, frame rate, width and fit-under-10-MB actions.
- Recent GIFs grid.
- Built-in GIF encoder on macOS frameworks, with ffmpeg and gifski used automatically when installed.
