# Lorem Ipsum

Generate placeholder text and copy it to your clipboard in one step.

Pick paragraphs, sentences or words, or get a full Markdown or HTML document for testing layouts. If you'd rather have placeholder text about a real topic, ask AI to write it.

## Commands

- **Generate Paragraphs**: Random paragraphs, copied to your clipboard.
- **Generate Sentences**: Random sentences, copied to your clipboard.
- **Generate Words**: Random words, copied to your clipboard.
- **Generate Markdown**: A placeholder Markdown document with headings, lists and more.
- **Generate HTML**: A placeholder HTML document.
- **Generate with AI**: Placeholder text written by AI, for when "lorem ipsum" doesn't look real enough.

## Preferences

- **Default Action**: copy the text (default), paste it into the active app, or both.
