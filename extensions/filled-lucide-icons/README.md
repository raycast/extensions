# Filled Lucide Icons

Search [Filled Lucide](https://filledlucide.dev), the solid variant of the [Lucide](https://lucide.dev) icon set, right from Raycast. It covers all 1,776 Lucide icons and the 355 Lucide Lab icons, with the same names and the same 24×24 grid as upstream Lucide.

## Actions

- **Copy SVG** / **Paste SVG**: the icon as an SVG using `fill="currentColor"`
- **Copy Name**: the kebab-case icon name, e.g. `house`
- **Copy Component**: e.g. `<House />`, or `<Icon iconNode={burger} />` for Lab icons
- **Copy Import**: e.g. `import { House } from "@filled-lucide/react";`
- **Copy SVG URL**: the icon's URL on the filledlucide.dev CDN
- **Open in Browser**: the icon's page on filledlucide.dev

The primary action and the framework used by **Copy Import** can be changed in the extension preferences.

Filled Lucide is an independent community project and isn't affiliated with or endorsed by the Lucide team.
