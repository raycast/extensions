# X Search Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Run Advanced Search to search X posts by words, language, accounts, replies, links, engagement, and dates, and open the search on x.com in any results tab.
- Run Quick Search to type a search query as you would in X's search box and open it on x.com.
- Set a Preferred tab and a Preferred browser in the extension preferences.
