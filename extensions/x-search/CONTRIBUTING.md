# Contributing to X Search

The extension directory holds only what ships to the Raycast Store. Tests, the architecture notes, and the full guide live in the [development repository](https://github.com/raulgg/raycast-extension-x-search). Start with its [CONTRIBUTING.md](https://github.com/raulgg/raycast-extension-x-search/blob/main/CONTRIBUTING.md).

Please [open an issue](https://github.com/raulgg/raycast-extension-x-search/issues) before building a new feature or changing behavior. Small bug fixes do not need one.

## Submit a change

Submit changes to the development repository when you can. A pull request in the Store repository would not update the tests or docs that live beside the extension.

- **In the development repository (recommended).** Change the tests with the code. The quality checks run on the pull request.
- **In the Store repository.** Follow Raycast's [Contribute to an Extension](https://developers.raycast.com/basics/contribute-to-an-extension) guide.
