# Security

Please do not post OAuth tokens, refresh tokens, client-secret JSON files, private calendar URLs, or other credentials in a public issue.

For ordinary bugs, use GitHub Issues.

If you discover a vulnerability that could expose another user's calendar data or credentials, contact [support@daycal.co.uk](mailto:support@daycal.co.uk) or the maintainer privately through the contact information on the GitHub profile rather than publishing exploit details in an issue.
