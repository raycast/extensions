# Google AI Mode Search

Search Google AI Mode from Raycast and continue in your default browser.

## Commands

- **Search Google AI Mode** — Enter a question, or leave it blank to open Google AI Mode.
- **Search Selected Text** — Select text in any application, then send it directly to Google AI Mode.

## Requirements

- macOS
- Access to Google AI Mode in your Google account, country, and language

Google controls AI Mode availability and may change its account, regional, or language requirements.

## Privacy

The extension does not collect analytics or send requests to a custom service. It encodes your query in a Google Search URL and opens that URL in your default browser. Your browser and Google handle the resulting request under their respective settings and policies.

## Development

```bash
npm install
npm run dev
```
