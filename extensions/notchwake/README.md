# Notchwake for Raycast

Control [Notchwake](https://notchwake.com), the island that lives in your Mac's notch, from Raycast.

- **Open Island**: open the island on Home, Calendar, File Tray, Clipboard, Agents, Usage, Timer or Shortcuts.
- **Start Timer** / **Stop Timer**: a countdown under the notch (1 to 600 minutes).
- **Keep Mac Awake**: for 1 to 1440 minutes, or `off`.
- **Add Note**: append a line to the island's note.
- **Close Island**.

Needs Notchwake installed. The extension only opens `notchwake://` links on your Mac: no network, no account, no data leaves the Mac.
