# Raytio

Calculate easily the aspect ratio for different sizes based on a width or height.

### Commands
- **Calculate Aspect Raytio**: see a size in the default and custom aspect ratios, based on a width or height.
- **Resize From Dimensions**: enter an original size (e.g. `1000x800`) to get its ratio (`5:4`), and a new size (e.g. `1000`) to get both results: as new width (`1000×800`) and as new height (`1250×1000`).

### Features
- Default aspect ratios;
- Support for custom ratios;
- Start from width or height arguments;
- Change the base value between width or height;
- Quick change from landscape to portrait;
- Quick copy the value that you are looking for;
- Or copy the all measures (e.g., 1920 × 1080);
- Resize from original dimensions without saving a custom ratio.
