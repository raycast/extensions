# Aspect Raytio Changelog

## [Resize From Dimensions] - 2026-11-09

- Add the **Resize From Dimensions** command: enter an original size (e.g. `1000x800`, `1000 × 800` or `1000 800`) to get its reduced ratio, and a new size to see both results at once (new width and new height).
- Copy or paste the full dimensions, only the width or height, or the ratio. The ratio is temporary and isn't saved to your custom ratios.
- Remove an unused form rendered next to the list in **Calculate Aspect Raytio**.
- Update the Store screenshots and add one for the new command.
