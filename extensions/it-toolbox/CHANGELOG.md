# IT Toolbox Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Add 16 everyday developer tools: Timestamp, URL Encode / Decode, Base64 Encode / Decode,
  Hash (MD5/SHA), UUID / ULID Generator, JSON Format / Validate, JWT Decoder, Radix Convert,
  Text Diff, Random / Password Generator, Case Convert, IP / CIDR Tool, Cron Parser,
  QR Code Generator, Color Convert and Text Toolkit.
- Show live values with no input: commands anchored to "now" (Timestamp) compute a result
  straight away, and `⌘ ⇧ R` refreshes it.
- Fold long values in the list and open them in a scrollable detail page that reports the
  character count, line count and longest line.
- Support both light and dark themes with separate icons.
