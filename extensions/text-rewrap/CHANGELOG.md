# Text Rewrap Changelog

## 0.0.0 - {PR_MERGE_DATE}

### Features

- 📏 **Text Rewrap Form** - Rewrap text from form
- 📎 **Text Rewrap Clipboard** - Rewrap text from clipboard
- 🖱️ **Text Rewrap Selection** - Rewrap currently highlighted
- 📏 **Custom Width Control** - Set any character width (e.g. 80, 100, 120) for text wrapping
- 🔓 **Unwrap Mode** - Leave width blank to unwrap/merge text lines with no wrapping
- 📤 **Auto-copy to Clipboard** - Option to automatically copy rewrapped text to clipboard
