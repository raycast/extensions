# IP Geolocation Changelog

## [Initial Release] - 2026-06-12

- Look up any IPv4, IPv6, or domain with full geolocation, ASN, timezone, and currency data
- Copy My IP command copies your public IP silently to clipboard  
- My IP Address command shows your full public IP profile
- IP Lookup History to revisit past lookups
- Security intelligence (VPN, proxy, Tor, threat score) for paid plan users
