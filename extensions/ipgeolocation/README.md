# IPGeolocation

Look up any IP address or domain without leaving Raycast. The extension uses the [ipgeolocation.io](https://ipgeolocation.io/) API to return the full profile of an IP in one view: city-level location, ASN and organization, time zone, currency, and country details. Paid plans add security signals (VPN, proxy, Tor, threat score), company data, and hostname info.

## Features

- **Lookup IP or Domain**: enter an IPv4 or IPv6 address, or a domain name, and get its location, ASN, time zone, currency, and country details in seconds.
- **Copy My IP**: copy your current public IP address to the clipboard with a single command.
- **IP Lookup History**: revisit past lookups without retyping the address.

## Setup

You need an ipgeolocation.io API key. The free plan includes 1,000 lookups per day, for life, with no credit card required.

1. Sign up at [app.ipgeolocation.io/signup](https://app.ipgeolocation.io/signup).
2. Copy your API key from the dashboard.
3. Paste it into the extension preferences on first run.

## Free vs paid

A free key covers IP lookups with location, ASN, time zone, currency, and country metadata. Lookups by domain name, security detection (VPN, proxy, residential proxy, Tor), and company and hostname data require a [paid plan](https://ipgeolocation.io/pricing.html), starting at $19/month.
