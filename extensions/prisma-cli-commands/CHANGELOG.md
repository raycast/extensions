# Prisma CLI Commands Changelog

## [Prisma ORM 7 Update] - 2026-11-25

- Remove commands and flags that no longer exist in Prisma ORM 7: `prisma introspect`, `generate --data-proxy`, `--accelerate`, `--no-engine`, and `--skip-generate` / `--skip-seed` on `migrate dev`, `migrate reset` and `db push`.
- Replace `init --datasource-provider` with `init --db`, which provisions a [Prisma Postgres](https://www.prisma.io/postgres?utm_source=raycast&utm_medium=prisma-cli-commands) database.
- Update the `generate` details for the `prisma-client` generator and point every reference link to the [Prisma ORM 7 CLI reference](https://www.prisma.io/docs/orm/v7/reference/prisma-cli-reference).
- Update the icon to the current Prisma logo and refresh the description. Learn more about [Prisma ORM](https://www.prisma.io/orm?utm_source=raycast&utm_medium=prisma-cli-commands) and [Prisma Compute](https://www.prisma.io/compute?utm_source=raycast&utm_medium=prisma-cli-commands).
