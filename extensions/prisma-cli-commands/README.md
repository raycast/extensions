# Prisma CLI Commands

Quickly search and copy [Prisma ORM](https://www.prisma.io/orm?utm_source=raycast&utm_medium=prisma-cli-commands) CLI commands, with details and options for each one.

The commands cover the Prisma ORM 7 CLI (`prisma init`, `generate`, `db`, `migrate` and `studio`). Run `prisma init --db` to start a project on a new [Prisma Postgres](https://www.prisma.io/postgres?utm_source=raycast&utm_medium=prisma-cli-commands) database, and host your app next to it on [Prisma Compute](https://www.prisma.io/compute?utm_source=raycast&utm_medium=prisma-cli-commands).

See the [Prisma ORM 7 CLI reference](https://www.prisma.io/docs/orm/v7/reference/prisma-cli-reference) for every command and flag.
