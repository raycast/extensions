# Toki

Track time for projects and tasks. All data is stored locally in a JSON file.

## Setup

By default, Toki stores data at `~/Documents/Toki/toki.json`. You can change this path in the extension preferences.

The file and folder will be created automatically when you first use the extension.

## Features

- **Time Tracker** - Main view to manage projects, tasks, and time entries
- **Menu Bar** - See current tracking status at a glance
- **Stop Tracking** - Quick command to stop the current session
- **AI Tools** - Ask questions about your tracked time using Raycast AI

## AI Commands

With Raycast AI, you can:

- "How much time did I spend on Development?"
- "What are my projects?"
- "Am I tracking time?"
- "Start tracking Development on ProjectX"
- "Stop tracking"
- "Add 2 hours to Meetings on ClientX"

## Data Structure

- **Groups** - Projects or clients
- **Activities** - Tasks within a group
- **Entries** - Individual time records
