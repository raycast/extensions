# HEIC Converter

Convert HEIC images to JPEG format directly from Finder.

## How to Use

1. Select one or more HEIC files in Finder
2. Open Raycast and search for "Convert HEIC to JPEG"
3. Run the command
4. The converted JPEG files will be saved in the same directory as the original files

## Features

- Batch conversion: Convert multiple HEIC files at once
- High quality: JPEG files are saved at 90% quality
- Preserves filenames: Converted files have the same name as the originals with `.jpg` extension
- Works with both `.heic` and `.heif` file extensions
- Shows progress and completion notifications

## Requirements

- macOS (uses Finder integration)
- HEIC files to convert

## Notes

- Original HEIC files are not deleted
- If a JPEG file with the same name already exists, it will be overwritten
- The conversion happens locally on your machine - no files are uploaded anywhere
