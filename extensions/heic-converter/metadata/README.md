# Screenshots for Raycast Store

To prepare your extension for the store, add 3-6 screenshots here:

## Requirements
- **Size**: 2000×1250 pixels
- **Aspect ratio**: 16:10
- **Format**: PNG
- **Background**: Use consistent backgrounds with good contrast
- **Content**: Show the extension in action

## Screenshot Ideas

1. **Main command**: Show searching for "Convert HEIC to JPEG" in Raycast
2. **File selection**: Show selected HEIC files in Finder
3. **Conversion progress**: Show the toast notification during conversion
4. **Success message**: Show the HUD message after successful conversion
5. **Result**: Show the converted JPEG files in Finder alongside the originals

## Tips
- Keep backgrounds consistent across all screenshots
- Don't include sensitive data
- Don't show other applications unless necessary
- Use high contrast for better visibility
- Consider using tools like [Raycast Screenshots](https://www.raycast.com/screenshots) for consistent styling

## Naming Convention
Name your screenshots descriptively:
- `01-search-command.png`
- `02-conversion-progress.png`
- `03-success-message.png`
- etc.

Once you have your screenshots, place them in this directory and reference them when submitting to the Raycast Store.
