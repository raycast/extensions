# TinyFish Search Changelog

## [Search, Reading, and AI Tools] - 2026-10-16

- Sign in to TinyFish in your browser to search the web and fetch page content without an API key.
- Keep using an API key by entering one in extension preferences.
- Search web pages, news, and academic papers with date, publication-year, and domain filters.
- Load more search results and copy all loaded results as Markdown.
- View news publishers and academic metadata, and open available paper PDFs.
- Fetch up to 10 URLs in the new Fetch Pages command, with Markdown, HTML, or JSON output.
- Browse extracted page and image links, request fresh content, and retry failed pages in a batch.
- Save and pin searches with their filters, and rerun recent searches from local history.
- Bookmark pages, save content for offline reading, track read status, and export Markdown files.
- Preserve extraction settings and image links when refreshing saved content.
- Read the current browser tab using the Raycast browser extension.
- Add search and fetch purpose, focused CSS extraction, and reusable extraction presets.
- Search and read pages through Raycast AI, with TinyFish's remote MCP server available in the same extension.

## [Initial Version] - 2026-07-01

- Search the web with TinyFish from Raycast.
- Open result URLs, copy links, and fetch clean page content as Markdown.
