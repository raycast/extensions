A [Raycast](https://raycast.com) extension that lets you set the default wallpapers from Windows 11

Windows 11 makes it difficult to choose individual wallpapers from the Settings app. The Background section only keeps the five most recently used wallpapers, while switching to another default wallpaper often requires changing the entire theme or enabling a slideshow.

This extension gives you quick access to all the default wallpapers stored locally in `C:\Windows\Web`, without having to browse through the Windows folder manually.

## Commands

### Browse Wallpapers

Browse all available Windows 11 default wallpapers. Preview a wallpaper, set it as your desktop background, or copy it to the clipboard.
