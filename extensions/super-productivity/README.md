# Super Productivity

Browse and manage Super Productivity tasks from Raycast.

## Setup

This extension talks to the Super Productivity desktop app over its local REST API.

1. Start the Super Productivity desktop app.
2. Open `Settings -> Misc`.
3. Enable `Local REST API`.

The extension uses `http://127.0.0.1:3876` and does not require an API token.

## Commands

- Show Tags
- Show Projects
- Show Tasks
- Show Today's Tasks
- Show Archived Tasks
- Show All Tasks
- Show Current Task
- Create Task
- Quick Add Task
- Stop Current Task
