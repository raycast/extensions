# Handy for Raycast Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Added Toggle Recording to start or finish a Handy recording from Raycast
- Added Record with Post-Processing to finish a recording and apply Handy's selected AI prompt
- Added Cancel Recording to cancel the current recording or transcription
- Added Copy Last Transcript to copy the latest transcript to the clipboard
- Added Paste Last Transcript to paste the latest transcript into the frontmost app
- Added Search Transcripts to search, preview, copy, paste, save, rename, and delete transcript history
- Added Recent Transcripts for quick access to your latest transcripts
- Added Search Recordings to find, play, reveal in Finder, and inspect saved audio recordings
- Added Add Dictionary Word to add one or more terms to Handy's recognition dictionary
- Added Manage Dictionary to search, add, edit, copy, and remove custom dictionary terms
- Added Select Model to view downloaded transcription models and switch the active model
- Added Select Language to choose automatic detection or a supported transcription language
- Added Handy Dashboard to see recording status, model, language, and stats at a glance with quick access to every command
