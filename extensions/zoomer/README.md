# Zoomer

Trigger [Zoomer](https://zoomer.studio) screenshots and recordings straight from Raycast.

Requires the **Zoomer desktop app** for macOS. Each command hands off to the Zoomer app through a `zoomer://` deep link; if Zoomer isn't installed, the command shows how to get it instead of failing silently.

## Commands

- **Capture Area** — capture a selected region (output: default, copy, save, or upload)
- **Capture Full Screen** — capture the current screen
- **Capture History** — show recent captures for quick access
- **Start Recording** / **Stop Recording** — control a screen recording
- **Open Recordings** / **Open Screenshots** — jump to your recent media
- **Open Settings** — open Zoomer settings (app, recording, or screenshot section)

## Setup

1. Install the Zoomer desktop app from [zoomer.studio](https://zoomer.studio).
2. Run any Zoomer command from Raycast.
