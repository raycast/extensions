# Zoomer Changelog

## [Keep Zoomer in the Background] - 2026-10-16

- Commands no longer bring the Zoomer main window to the front; Zoomer shows a window only when the command needs one

## [Initial Release] - 2026-08-21

- Capture a selected area or the full screen, with a choice of output (default, copy, save, upload)
- Start and stop screen recordings
- Browse recent captures with Capture History
- Open recent recordings, screenshots, and settings
