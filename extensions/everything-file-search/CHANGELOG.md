# Changelog

## [Initial Release] - {PR_MERGE_DATE}

- Instant local file and folder search powered by the Everything engine (NTFS index)
- Filter by file type (folders, documents, images, videos, audio, archives, apps, code, fonts, torrents) with support for custom types
- Sort by name, path, size or date modified with paginated loading
- Preview text and image files in the detail panel with file metadata
- Open files, reveal in Explorer, copy full path or filename
- One-click setup: detect Everything, enable its local HTTP server or install it via winget
