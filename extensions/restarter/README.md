# Restarter

Restart or force-quit any running macOS app from a fuzzy-searchable Raycast list.

## Features

- Lists every running app — including menu-bar utilities like BetterDisplay, BetterMouse, CleanShot X.
- Fuzzy search.
- Restart (`Enter`) or force-quit (`⌘Enter`). `⇧` variants keep the Raycast window open so you can act on multiple apps in a row.
- Hide noisy apps from the list with `⌘H`; manage them in the **Manage Hidden Apps** command.
- Live polling — apps disappear when they quit and come back as they relaunch.

## Shortcuts

| Shortcut | Action |
| --- | --- |
| `Enter` | Restart, close window |
| `⌘Enter` | Force-quit, close window |
| `⇧Enter` | Restart, keep window open |
| `⌘⇧Enter` | Force-quit, keep window open |
| `⌘H` | Hide from list |
| `⌘R` | Manual refresh |
