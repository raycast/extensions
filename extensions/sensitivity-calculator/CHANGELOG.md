# Sensitivity Calculator Changelog

## 0.1.1

### Added
- Result field now always visible, updating automatically as input values change
- Improved UI consistency between both calculators

## 0.1.0

### Added

- **Calculate cm/360 command**: Calculate the physical mouse movement (in cm) needed for a 360° turn
  - Enter in-game sensitivity
  - Enter mouse DPI
  - Select from supported games with correct yaw values
  - Real-time result calculation as you type
  - Copy result to clipboard

- **Calculate Sensitivity command**: Calculate the in-game sensitivity for a target cm/360
  - Enter target cm/360 value
  - Enter mouse DPI
  - Select from supported games with correct yaw values
  - Real-time result calculation as you type
  - Copy result to clipboard

- **Supported Games** (alphabetical order in UI): 
  - Apex Legends, Battlefield 5, CS (1.6), Destiny 2
  - DOOM, Fortnite, Overwatch, Overwatch 2
  - PUBG, QCDE, Q3 Arena, Quake, Quake Live
  - Rainbow Six, Reflex, Siege
  - Source Engine (CS2, CSGO), Unreal Tournament, VAL, Valorant

- **Automatic Calculation**: Results display instantly as you fill in the form fields

- **Clipboard Integration**: Copy calculated values to clipboard with one click
