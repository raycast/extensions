# Geekflare

Search the web, scrape pages, and check websites from Raycast with the [Geekflare API](https://geekflare.com).

## Setup

1. Get an API key at [dash.geekflare.com](https://dash.geekflare.com) (free tier available).
2. Open any Geekflare command and paste the key when Raycast asks for the **API Key** preference.

Each request uses Geekflare credits on your account; see [pricing](https://geekflare.com/pricing/).

## Commands

- **Search Web**: search the live web and open or copy results.
- **Check Website**: run a check on a URL or domain: site status, DNS records, DNSSEC, TLS/SSL, redirect chain, broken links, load time, mixed content, or a Lighthouse audit.
- **Scrape Page to Clipboard**: copy a public page's content as Markdown.

## AI Extension

Mention `@geekflare` in Raycast AI to search the web (including the full Google results page by country or city), read a page, or check a website. For example:

- `@geekflare what does Google show for "best crm" in London?`
- `@geekflare is the TLS certificate on example.com close to expiring?`

## Privacy

Queries and URLs you submit are sent to `api.geekflare.com` to fulfill each request. See the [Geekflare privacy policy](https://geekflare.com/privacy/).
