# Terminal Commands Changelog

## [Initial Version] - 2026-10-21

- "My Commands": a list of your own commands (with "Ping 8.8.8.8" as an example) that run in Terminal, plus a form to create and edit them (multiline commands supported) and an action to delete them.
- "Save as Quicklink" action, to run a saved command straight from Raycast's root search.
- "Run Saved Command": runs a saved command from its quicklink; launched directly, it opens "My Commands".
