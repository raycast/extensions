# Anycap Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Save Current Tab: the page in front of Safari, Chrome, Arc, Brave, Edge, Vivaldi or Anity.
- Search Anycap: every capture, newest first, with meaning matches under the literal ones.
- Quick Capture and Save Clipboard: a link or a note, without opening Anycap.
- Capture: a form with type, title, body or link, folder and tags.
- Capture details: saved image previews and metadata, including dates, tags and author.
- Raycast AI: Save Capture with confirmation, and List Folders.
- Browse Folders and Browse Collections, with Copy Brief.
- Open Latest Capture.
- Keep Save Current Tab on the selected browser when Automation fails.
- Refresh lists and detail metadata after Move, Archive and Undo.
- Show helper errors in folder and collection browsing.
- Find the latest capture without a one-year cutoff.
