# Loop Raycast Extension

Control [Loop](https://github.com/MrKai77/Loop) window layouts from Raycast.

## What it does

- Browses Loop's built-in actions in grouped sections
- Surfaces favorites and recent actions for faster repeat use
- Lets you type and run a named custom Loop keybind
- Copies raw `loop://...` URLs for scripting and automation

## Requirements

- [Loop for macOS](https://github.com/MrKai77/Loop) installed
- Raycast on macOS

## Included commands

- `Window Actions`: searchable launcher for built-in Loop actions plus favorites and recent history
- `Run Keybind`: trigger any named custom Loop keybind
- `Left Half`, `Right Half`, `Maximize`, `Center`: fast dedicated commands for the most common layouts
