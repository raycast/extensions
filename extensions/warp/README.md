# Warp

Open [Warp](https://www.warp.dev) tabs, windows and Tab Configs from anywhere, so you can start every project's terminal setup with one command.

## Commands

- **Open Tab Config**: Opens a Warp Tab Config or a legacy Launch Configuration.
- **Open Directory**: Opens a folder in Warp.
- **New Tab**: Opens a new Warp tab.
- **New Window**: Opens a new Warp window.
- **Open in Warp**: Opens the items selected in Finder in Warp.

## Tips

- Save the terminal layout for each project as a Tab Config in Warp, then give **Open Tab Config** an alias to restore it.
