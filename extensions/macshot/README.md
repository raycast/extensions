# Macshot

Capture, record, and annotate your screen with [macshot](https://github.com/sw33tLie/macshot) — the most feature-rich open-source screenshot tool on macOS.

## Prerequisites

- [macshot](https://github.com/sw33tLie/macshot/releases/latest) v4.1.0 or later installed
- URL scheme enabled in macshot Settings (enabled by default)

## Commands

| Command            | Description                              |
| ------------------ | ---------------------------------------- |
| Capture Area       | Start area capture                       |
| Capture Fullscreen | Capture the full screen                  |
| Capture Last Area  | Re-capture the last selected area        |
| Quick Capture      | Quick capture (uses your Enter action)   |
| Capture Text (OCR) | Capture area and extract text            |
| Record Area        | Start area recording                     |
| Record Fullscreen  | Start full-screen recording              |
| Stop Recording     | Stop the current recording               |
| Scroll Capture     | Start scroll capture                     |
| Open History       | Open the recent captures overlay         |
| Open Settings      | Open macshot settings window             |
| Open in Editor     | Open an image file in the macshot editor |
