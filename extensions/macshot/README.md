# macshot Raycast Extension

Simple Raycast commands that open macshot's existing `macshot://` URL scheme actions.

## Requirements

- macshot installed on macOS
- macshot's `macshot://` URL scheme enabled in macshot Settings
- mise
- Bun, installed from `mise.toml`

## Development

```bash
mise install
mise exec -- bun install
mise exec -- bun run dev
```

Use Raycast's Import Extension command to import this folder during development.
