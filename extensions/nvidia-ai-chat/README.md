# NVIDIA AI

Chat directly with powerful AI models hosted on NVIDIA NIM endpoints right from your Mac. Experience a native chat interface with full markdown support, persistent history tracking, and beautiful styling integrated seamlessly into Raycast.

## ✨ Features

- **Store Chat History:** Automatically keeps track of all past conversations using Lightning-fast persistent cached state. 
- **Dynamic Model Fetching:** Automatically links with your API Key to fetch all currently available NVIDIA NIM models (e.g. Llama 3, Nemotron, Mistral, Gemma).
- **Smart Model Switcher:** Switch between models on the fly. The extension automatically deduplicates endpoints and remembers your 5 most recently used models for quick access!
- **Archive System:** Don't lose your work! Safely **archive** chats instead of deleting them. View your archive, restore old chats, or clear them permanently with a secure confirmation dialog.
- **Rename & Manage:** Keep your workflow organized by manually renaming your chat sessions.
- **Fast and Native:** Uses native Raycast UI components, making it feel just like a built-in macOS feature.

## ⚙️ Configuration

To use this extension, you need an NVIDIA NIM API Key.
1. Sign in to your [NVIDIA developer account](https://build.nvidia.com/).
2. Go to the API Catalog and navigate to keys.
3. Generate a new key and add it to the extension preferences when first launched.

*(If you ever add a new API Key, the extension instantly detects it and fetches the new models for you. No restart required!)*
