# LayoutFixer Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Fix Selected Text: fixes English ⇄ Persian keyboard layout mistakes in the selection, or in the current line when nothing is selected, then switches the keyboard layout.
- Undo Last Fix, Fix Clipboard, Convert Text and Switch Keyboard Layout.
- Check Spelling for English (macOS spell checker or built-in word list) and Persian (built-in word list).
- Finglish to Persian, Clean up Persian Text and Persian Tools (numbers to words, Jalali ⇄ Gregorian dates, digits).
- AI Writing Tools with Raycast AI: fix, formal or casual Persian, translate, shorten.
- Menu bar command showing the current layout, optional fix history, personal dictionary and a Setup command that opens on first use.
