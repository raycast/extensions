# Premiere Pro Projects Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Initial release of Premiere Pro Projects Raycast extension.
- Added native cross-platform support for macOS and Windows.
- Added **Recent Projects** command with responsive Grid and List views.
- Added **Search Projects** command to query `.prproj` projects across home, drive, and system scopes.
- Added **Clear Media Cache** command to safely clean Premiere Pro temporary `Media Cache Files`, `Media Cache`, and `Peak Files` directories.
- Added native metadata extraction from `.prproj` files (sequences, resolutions, aspect ratios, frame rates, and Adobe Productions).
- Added visual card thumbnails and Quick Look support.
- Implemented safe file management with case-collision detection, invalid-filename guards, Trash deletion, and confirmation dialogs.
