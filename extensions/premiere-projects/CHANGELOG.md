# Premiere Pro Projects Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Initial release of Premiere Pro Projects Raycast extension.
- Added native cross-platform support for macOS and Windows.
- Added **Recent Projects** command with responsive Grid and List views.
- Added **Search Projects** command to query projects across home and system scopes.
- Added **Clear Media Cache** command to purge temporary conformed audio (`.cfa`) and peak waveform (`.pek`) files safely.
- Added native metadata extraction from compressed `.prproj` files (sequences, resolutions, aspect ratios, frame rates, and Adobe Productions).
- Added visual card thumbnails and Quick Look support.
- Implemented safe file management with case-collision detection, path traversal guards, and confirmation barriers.
