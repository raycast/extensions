# System Monitor

This is a [Raycast](https://raycast.com/) extension that allows you to monitor your system's CPU, Memory, Disk and Battery usage.

❕ You can toggle between free and used display modes for CPU, Memory and more in `Preferences`.

## Custom Menubar Text
- You can customise the menubar dropdown text in `Preferences` for `Menubar System Monitor`. Hover over the textbox to see what fields are available for each module. 
- Universal Tags
    - Universal tags are always available
    - `<BR>` is a tag that adds a linebreak that is always available
    - `<MODE>` cycles between "Free" and "Used" depending on the module's  display modes
- Common Tags
    - `<VALUE>`
    - `<PERCENT>`
    - `<TOTAL>`
