# Security

Do not include EcoFlow access keys, secret keys, full device serial numbers, account details, or private telemetry in a public issue.

If you find a vulnerability, use GitHub private vulnerability reporting for `Olli0103/Raycast_Ecoflow`. If private reporting is unavailable, open a minimal issue with no exploit details or secrets and ask the maintainer to establish a private channel.

Revoke and replace EcoFlow Developer Platform credentials immediately if you believe they have been exposed.
