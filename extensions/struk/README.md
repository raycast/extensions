# Struk for Raycast

AI-powered text formatting directly in Raycast.

## Features

- **Clean & Format** - Fix spacing and structure messy text
- **Action Items** - Extract tasks and decisions from meeting notes
- **Merge & Structure** - Combine multiple text blocks into one document
- **Repurpose Content** - Transform content for different formats

## Setup

1. Get your free API key at [struk.ai/integrations/raycast](https://struk.ai/integrations/raycast)
2. Install this extension from the Raycast Store
3. Open Raycast preferences (⌘ + ,)
4. Find "Struk" and paste your API key
5. Start formatting text!

## Usage

1. Copy text to your clipboard
2. Open Raycast (⌘ + Space)
3. Search for a Struk command (e.g., "Clean & Format")
4. Press Enter
5. Formatted text is copied back to your clipboard
