# Bricks Builder for Raycast

Work with [Bricks Builder](https://bricksbuilder.io) sites from Raycast: open any page or template in the builder, press builder shortcuts, browse global classes, colors and variables, keep a snippet library, search the Bricks docs, and keep an eye on all your Bricks sites.

## Free and Pro

Most of the extension is free. **Bricks Raycast Pro** adds Site Audit (with the image and alt text audit), Search Bricks Elements, Search Dynamic Data, the Template Library, Form Submissions with the menu bar count, the site tools (maintenance mode, CSS files, caches, code signatures) and helper plugin updates. A license is per site, local sites included; plans and pricing are on [martej.com/bricks-raycast](https://martej.com/bricks-raycast). Commands that need Pro are marked **Pro** below.

## Setup

1. **Install the Bricks Raycast Helper plugin** on each site. The extension ships it: in **Bricks Site Health**, press ⌘⇧H on a site (Install, Update or Reinstall Helper Plugin) to put `bricks-raycast-helper.zip` in Downloads and open the site's Plugins › Add New › Upload Plugin page, then activate it. To update, do the same and pick "Replace current with uploaded". The plugin's source is in [`assets/bricks-raycast-helper`](assets/bricks-raycast-helper). It needs WordPress 6.0 and PHP 7.4 or newer, with Bricks active. The helper powers Bricks templates, global classes, colors and variables, dynamic data, element search, the site audit, the template library, site info and creating templates, and makes Open in Bricks load in a single request. Commands marked *Helper 1.3* or *Helper 1.4* need that version or newer; Bricks Site Health shows which sites need an update. Shortcuts, snippets and docs search work without it.
2. **Create an application password** in WordPress under Users › Profile › Application Passwords. Your user needs to be able to edit posts. See [Application Passwords](https://wordpress.org/documentation/article/application-passwords/).
3. **Add the site in Raycast.** Run **Manage Bricks Sites** and enter the site URL (⌘⇧B fills it from your browser tab, ⌘⇧P opens the site's Application Passwords page), your WordPress username and the application password. If the site lives at a different address (for example it redirects to `www`), it's saved under that address. Tick "Allow self-signed certificate" for Local, DDEV or Herd sites.
4. **Bricks Raycast Pro** (optional): Site Audit, Search Bricks Elements, Search Dynamic Data, Form Submissions, the Template Library and the site tools (maintenance mode, regenerating CSS and code signatures, clearing caches) need a Pro license on the site, and so do plugin updates. Buy one, then run **Bricks Raycast Pro**: add the key once and activate it on one site or all of them (⌘⇧A). It's also offered wherever a command needs Pro, in Manage Bricks Sites and Bricks Site Health (⌘⇧L on a site), and in WordPress under Settings › Bricks Raycast. Each site uses one of the license's activations; deactivating the license or the plugin frees it. Everything else is free.
5. **For the builder commands**, keep Bricks open in your browser. Search Bricks Shortcuts, Edit Current Page in Bricks and pasting snippets act on the frontmost browser tab, so macOS may ask you to allow Raycast to control your browser and System Events.

## Commands

| Command | What it does | Needs |
| --- | --- | --- |
| Search Bricks Shortcuts | All 32 builder shortcuts. ↵ presses it in the Bricks tab, ⌘⇧K turns it into a quicklink you can give its own hotkey, copy as Mac or Windows keys. | – |
| Press Bricks Shortcut | Presses one Bricks shortcut in the builder. Used for hotkeys made with ⌘⇧K in Search Bricks Shortcuts: give the quicklink a hotkey in Raycast Settings and that Bricks action works from anywhere, or from a Stream Deck. | – |
| Open in Bricks | Search pages, posts, Bricks templates and builder-enabled post types; templates show their conditions, and a warning when a header, footer or single template has none. ↵ opens in Bricks, ⌘⇧O live page, ⌘E WordPress editor. ⌘N creates a new draft page, post or Bricks template (header, footer, section, popup…) that opens straight in the builder. | Site (helper for templates) |
| Edit Current Page in Bricks | Toggles the browser tab between the live page and the builder. Works from a wp-admin edit screen too. Give it a hotkey. | Site for wp-admin pages |
| Search Global Classes | Global classes with the CSS Bricks generates for them (per breakpoint), which properties are set on which breakpoints and states, the elements and pages that use them, and filters for unused, empty, utility and locked classes. ⌘U lists the pages using a class. | Helper |
| Search Colors and Variables | Color palettes with swatches, shades and their utility classes (⌘U), and global CSS variables with their resolved values; copy or paste `var(--name)` or the value. | Helper |
| Search Dynamic Data | Every dynamic data tag the builder offers on the site, grouped like Bricks groups them: WordPress, ACF, Meta Box, JetEngine, Pods, WooCommerce and more. ↵ pastes the tag into the builder, ⌘⇧C copies it, ⌘⌥C copies it with `:plain`. | Helper 1.3 · **Pro** |
| Search Bricks Elements | Searches every element on the site (pages, templates, headers, footers and global components) for text, a class name, a color or CSS value, a link or an element id. Pick an element type in the dropdown to answer "which pages have a form?". ↵ opens the page in Bricks, ⌘⇧C copies the element id. | Helper 1.3 · **Pro** |
| Bricks Site Info | Breakpoints with their media queries, theme styles and where they apply, custom states, CSS loading method, Bricks version, and a count of unused classes. | Helper |
| Bricks Site Audit | Opens on an overview with a count per check; ↵ opens one. Unused global classes, which you can move to Bricks' class trash one by one or all at once (with Undo, and restorable here or in the builder's Style Manager); templates that need conditions but have none; Code elements, flagging ones that run PHP and whether their signature is valid; images; and the pages with the most elements. | Helper 1.3 (administrator to trash classes) · **Pro** |
| Bricks Template Library | A site's Bricks templates (sections first) and global components, with their element structure. ↵ pastes one into the open builder, on any site: it brings its global classes and the components it uses along, like copying in Bricks does. ⌘⇧C copies it, ⌘S saves it as a snippet, ⌘O opens the template. | Helper 1.3 · **Pro** |
| Site Audit › Images | Every image Bricks uses: Image and Image Gallery elements, backgrounds (every breakpoint and state), `<img>` tags in text, rich text and code, featured images through dynamic data, in pages, templates and components. Flags missing alt text, alt text that's just a file name, large served files (over 300 KB), images wider than 2560px, JPEG/PNG that could be WebP/AVIF, and broken images (a deleted file, or a media library id copied from another site). Filter by issue, source, page, where to fix it, or media library images without alt that Bricks doesn't use. Preview and details with ⌘D. Add alt text one image at a time or step through them all (⌘⇧A), with Raycast AI suggestions (⌘G) when available, or mark images decorative (⌘⇧E). | Helper 1.3 · **Pro** |
| Bricks Form Submissions | Submissions Bricks saved (Form elements with the "Save submission" action), all forms or one, newest first, with every field, the page, browser and referrer. Reply by email, copy the submission or one field, delete with confirmation. New ones since you last looked get a dot. | Helper 1.4, administrator · **Pro** |
| New Bricks Form Submissions | Menu bar count of new submissions on all your sites, checked every 10 minutes. Click one to open it, or mark a site as read. | Helper 1.4, administrator · **Pro** |
| Search Bricks Snippets | Your library of Bricks elements, CSS, JS and HTML. ↵ pastes into the builder, ⌘N adds a snippet, ⌘⇧N saves the clipboard (copy elements in Bricks with ⌘C first). Export (⌘⇧E) and import (⌘⇧I) your library as JSON. | – |
| Save Clipboard as Bricks Snippet *(off by default)* | The same as ⌘⇧N in Search Bricks Snippets, as its own command. Turn it on in Raycast Settings → Extensions if you want to give it a hotkey. | – |
| Search Bricks Docs | Bricks Academy articles; ⌘Y reads one inside Raycast. | – |
| Bricks Site Health | Every site you added in one list: Bricks, helper plugin, WordPress, PHP and database versions, available WordPress, theme and plugin updates, maintenance mode, CSS loading, code execution and debug mode, and whether Raycast can reach and sign in to it. Flags sites whose helper plugin is missing or older than the extension's, and ⌘⇧H installs or updates it. | Helper 1.4 for full details |
| Toggle Bricks Maintenance Mode, Regenerate Bricks CSS Files, Clear Bricks Site Caches, Regenerate Bricks Code Signatures | Run on the site you last picked, so you can give them hotkeys. Also in Site Tools (⌘⇧T) in Bricks Site Health and Bricks Site Info. Maintenance mode and code signatures ask first. Clearing caches flushes the object cache and LiteSpeed, WP Rocket, W3 Total Cache, WP Super Cache, WP Fastest Cache, SiteGround, FlyingPress, Breeze, Hummingbird, Autoptimize, Nginx Helper, Cloudflare and Kinsta when they're installed. | Helper 1.4, administrator · **Pro** |
| Bricks Raycast Pro | Your license key and every site's license: Pro, Free, Expired, or a helper plugin that needs updating. Add the key once, then activate it on a site (↵) or on all of them (⌘⇧A), deactivate it, or buy a license. | Helper 1.6 |
| Manage Bricks Sites | Add, edit and remove sites. Export Raycast Site List (⌘⇧E, with or without application passwords) saves your sites' Raycast settings, not their Bricks content, so you can import them on another Mac (⌘⇧I). Also ⌘⇧M in every command that uses a site. | – |

Commands marked *off by default* are disabled on install; enable them in Raycast Settings → Extensions → Bricks Builder.

Sites and snippets live in Raycast's encrypted local storage. Form submissions aren't cached on disk.
