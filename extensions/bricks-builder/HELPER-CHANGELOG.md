# Bricks Raycast Helper Changelog

The release script (scripts/release-helper.mjs) publishes the section
matching the plugin's version as the changelog WordPress shows under "View details".

## 1.6.0

- Bricks Raycast Pro license: activate a key under Settings › Bricks Raycast or from Raycast, checked daily with a week's grace when the license server can't be reached.
- Site Audit, element and dynamic data search, Form Submissions, the Template Library and site tools need a Pro license; everything else stays free.
- Updates for licensed sites arrive in Dashboard › Updates like any other plugin.
- Deactivating the plugin frees the site's license activation; activating it again takes it back.

## 1.5.0

- Whole-site scans (Site Audit, images, global classes) are cached and cleared when something changes.
