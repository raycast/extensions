# Bricks Builder Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Open in Bricks: search pages, posts and Bricks templates on your sites and open them in the builder, or create new ones.
- Edit Current Page in Bricks: switch the browser tab between the live page and the builder.
- Search Bricks Shortcuts and Press Bricks Shortcut, with hotkeys for single shortcuts.
- Search Global Classes and Search Colors and Variables, with generated CSS, breakpoints, states and usage.
- Bricks Site Info and Bricks Site Health for all your sites, with the helper plugin ready to install from Raycast.
- Bricks snippet library for elements, CSS, JS and HTML, and Search Bricks Docs.
- Bricks Raycast Pro: Site Audit (unused classes, templates without conditions, Code elements, images and alt text), Search Bricks Elements, Search Dynamic Data, the Template Library, Form Submissions with a menu bar count, and site tools for maintenance mode, CSS files, caches and code signatures.
- Manage Bricks Sites, with export and import of your Raycast site list.
