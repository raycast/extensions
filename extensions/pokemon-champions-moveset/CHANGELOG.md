# Pokémon Champions Moveset Changelog

## [1.0.0] - 2026-04-12

### Added
- Full move list of **919 moves** from Pokémon Champions, sourced from PokéBase
- Search bar with live move count (e.g. "Search 919 moves…"), dynamically updating on filter
- Filter dropdown to narrow moves by **Type** (18 types) or **Category** (Physical, Special, Status)
- Detail panel for each move showing description, type, category, power, accuracy and PP
- Type icons and category icons displayed inline in the list and detail view
- Static `raw.html` reference table for browser-based preview of the full move list

## [0.1.0] - Initial Draft

### Added
- Initial extension scaffold with Raycast List view
- First batch of 100 moves parsed from PokéBase HTML export
- Basic search by move name
- Filter dropdown by type and category
- Move detail panel with metadata (type, category, power, accuracy, PP)
- Bundled type SVG icons and category PNG icons
