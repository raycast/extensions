## Overview

Browse the movelist from Pokémon Champions inside Raycast.

## Features

- **Instant search** — filter by move name, type, or category from the Raycast search bar
- **Type & category filter** — dropdown to narrow the list to a specific type (Bug, Fire, Water…) or category (Physical, Special, Status)
- **Detail panel** — select any move to see its full description, type, category, power, accuracy, and PP in a clean side panel
- **Fully offline** — all data and icons are bundled with the extension

## Data

Move data is sourced from [PokéBase](https://pokebase.app/pokemon-champions/moves) and reflects the Pokémon Champions move roster.
