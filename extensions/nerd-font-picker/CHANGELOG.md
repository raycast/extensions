# ***Nerd Font Picker*** Changelog

## [Improvements] - 2026-08-26

- Remove the extension's icon colour preference option in favour of using Raycast's native `Color.PrimaryText` which automatically adapts to the user's current Raycast theme (light/dark). The icon uses this colour in both the list and detail views (the latter uses the `raycast-tint-color` query parameter to achieve the appropriate effect).
- Updated README
  - Documented the new icon colour behaviour and removed the now redundant `Item Colour` preference option.
  - Added documentation for the `Font Name` preference.

## [1.0.0] - 2026-05-13

### What's Changed

- Add Nerd Font Glyphs: browse, search, and copy Nerd Font PUA glyphs from your locally installed fonts, with live SVG previews, a rich detail panel, and configurable icon colour
