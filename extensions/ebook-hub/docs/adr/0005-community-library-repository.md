# ADR-0005: Central Community Library Repository

- Status: Accepted
- Date: 2026-09-15

## Context

The community shares books through GitHub. Two models were considered: one
central repository, or an index pointing at many personal repositories.
Copyright is the largest risk: a DMCA takedown can remove an entire repository,
and the Raycast Store can reject an extension that distributes infringing
content.

## Decision

Use one central repository, `crafts69guy/ebook-hub-library`:

```text
books/<bcp47-language>/<slug>/
  book.json          # title, authors, language, categories, license, source, chapters
  chapters/0001.md
categories.json      # allowed category slugs
index.json           # generated by CI, never edited by hand
```

- **License allowlist** enforced by CI: `public-domain`, `CC0-1.0`,
  `CC-BY-4.0`, `CC-BY-SA-4.0`. `book.json.source` must link to the original
  publication.
- **CI validation**: schema, allowed categories, license, no raw HTML, no
  remote images, size limits; then computes SHA-256 per file and regenerates
  `index.json`.
- **Distribution**: the extension reads `index.json` through jsDelivr
  (`https://cdn.jsdelivr.net/gh/crafts69guy/ebook-hub-library@main/index.json`,
  configurable preference) to avoid GitHub API rate limits.
- **Integrity**: every downloaded file is verified against its SHA-256 from
  the index. A mismatch aborts the download (usually a CDN cache between
  index and file versions; retry later).
- **Contribution**: pull requests reviewed by CODEOWNERS. The in-extension
  "Share to Community" flow (post-MVP) uses `OAuthService.github` with
  `public_repo` scope to fork, commit, and open a PR.

Index entry shape:

```json
{
  "slug": "truyen-kieu",
  "version": "1.0.0",
  "title": "Truyện Kiều",
  "authors": ["Nguyễn Du"],
  "language": "vi",
  "categories": ["poetry", "classics"],
  "license": "public-domain",
  "summary": "Epic poem in lục bát verse.",
  "path": "books/vi/truyen-kieu",
  "files": [{ "path": "book.json", "sha256": "…" }, { "path": "chapters/0001.md", "sha256": "…" }]
}
```

## Consequences

- One place to moderate content and enforce licenses.
- Maintainers become a review bottleneck; CODEOWNERS per language can spread
  the load.
- jsDelivr caches branch URLs for hours; newly merged books appear with a
  delay unless CI purges the cache.
- Downloaded community books are stored locally with
  `source.kind = "community"` and `visibility = "shared"`.

## Alternatives Considered

- **Decentralized index of personal repos pinned by commit SHA** — no review
  bottleneck, but link rot and no enforceable license control. Rejected.
- **GitHub REST API for listing** — 60 unauthenticated requests per hour.
  Rejected for reads.
