# Logbook

Capture and complete your [Logbook](https://logbook.acrosaas.com) tasks without leaving Raycast.

## Setup

1. Create a free Logbook account at [logbook.acrosaas.com](https://logbook.acrosaas.com) (Google sign-in).
2. Run **Search Tasks** or **Add Task**.
3. Approve the connection when Raycast prompts you to sign in.

No API key is required. The connection stays active until you sign out from the extension preferences or revoke it in the Logbook web app.

## Commands

- **Add Task** — type the task as an argument in Raycast's root search and press Enter. A HUD confirms; nothing else opens.
- **Search Tasks** — browse and search your logbook, filter by pending / completed / all, mark tasks complete or reopen them, and delete with confirmation. Typing a title that doesn't already exist offers to create it.

## Self-hosting

If you run your own Logbook instance, set **Web URL** and **API URL** in the extension preferences, then sign in again.
