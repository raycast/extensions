# Changelog

## [Initial Release] - {PR_MERGE_DATE}

### Added
- **Decide Command**: A new command to help you make decisions by randomly selecting an option from a list.
- **Dynamic Input**: Automatically adds new input fields as you type.
- **Smart Cleanup**: Removes empty input fields when they lose focus.
- **Result View**: Displays the winner, probability, and all candidates.
- **Roll Again**: Quickly re-roll the decision if needed.
