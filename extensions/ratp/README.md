# RATP

Search RATP stations and view upcoming departures in real time for the Ile-de-France transit network (Metro, RER, Transilien, Tram, Bus, Noctilien).

## Getting Your API Key

This extension uses the free **PRIM Ile-de-France Mobilites** API. Follow these steps:

1. Go to [prim.iledefrance-mobilites.fr](https://prim.iledefrance-mobilites.fr)
2. Click **"Créer un compte"** and sign up
3. Once logged in, go to **API** > **Navitia**
4. Click **"S'abonner"** (Subscribe) — it's free
5. Copy your API key from your dashboard
6. Open Raycast, run any RATP command, and paste your key when prompted

## Commands

### Search Station

Search for any station on the Ile-de-France network and view real-time departures. Filter by transport mode or direction, and save stations as favorites.

### My Favorite Stations

Quickly access your saved favorite stations and their departures.

### Traffic Alerts

View current disruptions on the network, grouped by severity.

## Shortcuts

| Shortcut | Action |
|---|---|
| `Cmd + R` | Refresh departures or alerts |
| `Cmd + F` | Add/remove from favorites |
