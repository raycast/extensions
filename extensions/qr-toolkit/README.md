# QR Code Toolkit

Decode QR codes from images and generate QR codes from text — all within Raycast.

## Features

### Decode QR Code

- Automatically detects images in your clipboard and decodes on launch
- Pick an image file manually via file picker
- Identifies content type: URL, WiFi, vCard, or plain text
- Quick actions: copy content, open URL, copy WiFi password

### Generate QR Code

- Create QR codes from any text or URL
- Pre-fills from clipboard text
- Real-time SVG preview
- Customizable options:
  - Error correction level (L / M / Q / H)
  - Dark and light colors (hex)
  - Margin size
- Export as PNG to clipboard or Desktop
- Copy SVG source code
