# Translate Bidirectional AI Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Translate the selected text (or the clipboard, as fallback) with Raycast AI — no setup, no AI Command required
- Automatic language detection: any language → your primary language; if it's already the primary, → your secondary language (defaults: Brazilian Portuguese ⇄ English)
- Streams the result in a native view, preserving the source formatting as Markdown (reads rich clipboard HTML when available)
- Paste or copy the translation from the result view
- Available on macOS and Windows (built on the Raycast 2.0 API)
