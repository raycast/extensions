# Changelog

## [Initial Version] - 2026-08-25

- **Send Update** — compose a styled update: board picker, message, panel (1–4),
  spacing, full-panel mode, and per-block text size, weight, and colors.
- **Quick Send** — send a message straight to a board via preferences
  (`Default Board ID`, `Default Panel`); fields are omitted when unset so the
  API defaults apply.
- **OAuth2 sign-in** (PKCE via Raycast) — tokens in the Keychain, auto refresh,
  built-in Logout preference.
