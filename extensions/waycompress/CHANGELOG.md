# WayCompress Changelog

## [Initial Release] - 2025-02-16

* Added **Compress to Target Size** command to compress videos, images, audio, and PDF documents to an exact MB target.
* Integrated intelligent 2-Pass MP4 (x264) video compression engine with duration and bitrate budget calculations.
* Integrated binary-search FFmpeg image engine for JPEG, WebP, PNG, and GIF formats.
* Integrated AAC/M4A audio compression engine.
* Added Ghostscript and built-in PDF stream optimization engines.
* Added active file detection for Windows Explorer and macOS Finder.
* Added built-in **Compression Engine Diagnostics** command for environment validation.
