# Flashcards Changelog

## [Initial Version] - 2026-08-04

- Initial version code of the Flashcards extension.
- Added **Create Card** command to create Q&A and Multiple-Choice flashcards using Markdown.
- Added **List Cards** command to search, browse, edit, and delete flashcards.
- Added **Tags** command to browse cards by tag.
- Added **Quiz** command with 4 study modes (all, wrong, new, tags) and keyboard controls.
- Added **Import** and **Export** commands to backup or load cards from Markdown.
