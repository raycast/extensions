# Wrap Star Changelog

## [Initial Release] - {PR_MERGE_DATE}

- Wrap the selected text in place with one of six delimiter pairs: parentheses `( )`, single quotes `' '`, double quotes `" "`, square brackets `[ ]`, curly braces `{ }`, or angle brackets `< >`
- **Wrap Selection (Default)** command with a configurable default pair — ideal for a single global hotkey
- **Wrap Selection with…** picker to choose any pair on the fly
- Six dedicated per-pair commands, each independently assignable to its own hotkey
- Per-command icons for quick recognition in Raycast
