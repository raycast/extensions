This folder is where the store screenshots for the Raycast Extension Store live.

**Required**: 3–6 screenshots, **2000×1250 px** PNG (16:10 aspect ratio), light
mode only, no sensitive data visible. File names should be descriptive
(e.g. `next-best-time-1.png`, `next-best-time-2-detail.png`, …).

The Raycast publisher CLI will read this folder when you run `npm run publish`.
