# Timesheet Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Menu bar timer showing the running timer and today's total, with pause, resume, and stop
- Start/Stop timer for any project
- Timer status view with current session and today's summary
- Browse and search projects
- Today's tasks
- Quick log time without starting a timer
- Add a note (and optional file) to the running timer
- Add an expense (and optional receipt) to the running timer
- Log a break within the running timer's window
- Browse open/closed todos and mark them done
- Team status to see who is currently tracking time
- Absences across your organization
- Profile with account, plan, and subscription info
- AI Extension with 12 tools, so Raycast AI can run the timer, log time, and read projects, tasks, todos, team status, and absences
- Mention projects and open todos from the AI Chat `@` menu
- The hosted Timesheet MCP server in Raycast AI, for expenses, notes, reports, and the rest of Timesheet
- Sign in with your Timesheet account; an API token stays available for scripted setups
- Runs on macOS and Windows; the menu bar timer stays macOS only
