# Obsidian Symlink Manager Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Initial release of Obsidian Symlink Manager to the Raycast Store
- **Manage Vault Symlinks**: Inspect, link, and sync plugins, themes, CSS snippets, and settings across Obsidian vaults
- **Core Settings Sync**: Support for live symlinking or copying `app.json`, `hotkeys.json`, and `appearance.json`
- **History & Diff Inspector**: Inspect commit history and restore versions from Default Vault Git history
- **Bootstrap New Vault**: Set up brand new vaults with selected links and mirror configurations
- **Sync Profiles**: Save, manage, and apply reusable sync presets across vaults
