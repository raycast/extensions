# Changelog

## 0.1.0 - Public Beta

- Added OAuth sign-in with PKCE and workspace selection.
- Added unified search across tasks, records, and meetings.
- Added grouped assigned tasks with completion, status changes, and Undo.
- Added task capture, including contextual tasks linked to records and meetings.
- Added upcoming meetings with privacy-aware previews and one-key join actions.
- Added My Day and notification triage.
- Added full task editing, task details, comments, and contextual capture.
- Added dedicated Objects and Records commands with primary-name lists and typed metadata previews.
- Added Kato Connection with OAuth workspace switching.
