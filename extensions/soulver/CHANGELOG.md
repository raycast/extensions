# Soulver Changelog

## [Initial Release] - {PR_MERGE_DATE}

- Add `Solve Expression` command to quickly evaluate math, currency, unit, and date calculations using Soulver CLI.
- Add full suite of Raycast AI Tools for working with Soulver sheetbooks:
  - **Sheets**: `list-sheets`, `create-sheet`, `delete-sheet`, `duplicate-sheet`, `move-sheet`, `pin-sheet`, `archive-sheet`
  - **Lines**: `read-sheet`, `append-line`, `insert-line`, `update-line`, `delete-line`, `mark-line`, `inspect-line`
  - **Variables & Definitions**: `manage-variables`, `manage-definitions`
  - **Search & Export**: `search-sheets`, `export-sheet`
