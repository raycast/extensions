# Tailwind Color Finder                                                       
                                                                                
  Find the nearest Tailwind CSS color from any hex code.                        
                                                                                
  ## Features                                                                   
                                                                                
  - **Instant color matching**: Enter a hex color and get the closest Tailwind  
  color                                                                         
  - **Multiple results**: See the top 8 nearest colors ranked by similarity     
  - **Clipboard detection**: Automatically detects hex colors in your clipboard 
  - **Argument support**: Pass a hex color directly (e.g., `tw #ff5733`)        
  - **Tailwind v3 & v4**: Choose your Tailwind version in preferences           
  - **Quick copy actions**:                                                     
    - Copy color name (`blue-500`)                                              
    - Copy as `bg-{color}`                                                      
    - Copy as `text-{color}`                                                    
    - Copy as `border-{color}`                                                  
    - Copy hex value                                                            
                                                                                
  ## Usage                                                                      
                                                                                
  1. Open Raycast and type "Find Tailwind Color"                                
  2. Enter a hex color (with or without `#`)                                    
  3. Press Enter to copy the nearest color name                                 
                                                                                
  ### With argument                                                             
                                                                                
  Type `Find Tailwind Color`, press Tab, enter your hex code, and press Enter.  
                                                                                
  ### With clipboard                                                            
                                                                                
  Copy a hex color to your clipboard, then open the extension - it will be      
  pre-filled automatically.                                                     
                                                                                
  ## Keyboard Shortcuts                                                         
                                                                                
  | Shortcut | Action |                                                         
  |----------|--------|                                                         
  | `Enter` | Copy color name |                                                 
  | `Cmd+B` | Copy as `bg-{color}` |                                            
  | `Cmd+T` | Copy as `text-{color}` |                                          
  | `Cmd+D` | Copy as `border-{color}` |                                        
  | `Cmd+Shift+C` | Copy hex value |
