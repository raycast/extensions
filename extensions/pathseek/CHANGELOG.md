# Changelog

## Unreleased — Raycast Store preparation

- Improved first-time guidance when `fd` or `fzf` is not installed, with a copyable Homebrew command and a link to the official website. No automatic installs or indexing.
- Added a concise first-time setup guide.
- **Not yet published to the Raycast Store.**

## v0.1.0 — 2026-10-24 (stable development baseline)

- Persistent local file and folder index, rebuilt **only when explicitly requested**.
- Fast `fzf` search with standard file, Finder, Quick Look and path actions.
- Search and select files or navigate to folders inside an existing macOS Open/Save dialog by pasting the chosen absolute path.
- Optional developer tracing and sanitized diagnostics.
- macOS user acceptance and automated quality checks completed for core workflows.

This is a Git development milestone, **not a Raycast Store publication**. A valid Store author, final review and screenshots remain publication steps.
