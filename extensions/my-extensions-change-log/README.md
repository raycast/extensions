# My Extensions Changelog

View changelogs for all your installed Raycast extensions in one place.

## Commands

### Changelog Feed (Primary)

A unified, chronological feed of recent changelog entries from all your installed extensions.

**Features:**
- **Unified Timeline**: See all recent updates across all extensions in one list
- **Chronologically Sorted**: Most recent changes appear first
- **Smart Parsing**: Automatically extracts version numbers, dates, and changes from CHANGELOG.md files
- **Quick Actions**:
  - Open changelog in browser
  - Copy changes to clipboard (⌘C)
  - Copy changelog URL (⌘⇧C)

**Usage:**
1. Open Raycast
2. Search for "Changelog Feed"
3. Browse recent updates from all your extensions
4. Each entry shows: date, extension name, version, and changes

### Browse Changelogs

Browse extensions individually and view their complete changelogs.

**Features:**
- **Extension List**: See all installed extensions with author info
- **Full Changelogs**: View complete changelog content in markdown
- **Quick Actions**:
  - View changelog in Raycast
  - Open changelog in browser
  - Copy changelog URL

**Usage:**
1. Open Raycast
2. Search for "Browse Changelogs"
3. Select an extension to view its full changelog

## Note

This extension only works with official Raycast Store extensions that have changelogs in the [raycast/extensions](https://github.com/raycast/extensions) repository. This extension was built with Claude Code, please feel free to submit issues or pull requests if you find any problems.
