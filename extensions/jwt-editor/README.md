# JWT Decoder

Decode a three-part JWT locally to inspect its header, payload, signature and time claims. The extension checks the token's structure but **does not verify its signature**. An unexpired token is not necessarily authentic or authorized.

Use **Decode JWT** to paste and inspect a token, or **Create JWT Quick Link** to save a prefilled shortcut. Quick links store the token in their Raycast link context, so use them only for non-sensitive test tokens. Copied token content is sent to the system clipboard using Raycast's concealed option.

No API key or network request is required. This extension does not edit, encode or sign JWTs.
