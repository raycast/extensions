# BlueCat BAM Lookup Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Search BlueCat Address Manager by IP address (IPv4/IPv6), CIDR network, or DNS name
- Detail panel tailored to each result type: IP addresses, networks, and DNS resource records
- Shows the containing network and linked DNS records for IP addresses
- Displays user-defined fields
- Open any result directly in the Address Manager web UI
- Copy actions for addresses, ranges, gateways, names, MAC addresses, record values, object IDs, and URLs
- Inline search argument and fallback command support from the Raycast root search
