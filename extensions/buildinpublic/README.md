# Build in Public

Manage your [Build in Public](https://buildinpublic.com) projects and search the maker directory from Raycast.

_This extension requires a Build in Public account._

## Commands

- **My Projects**: see the projects on your profile, open them, edit them or remove them
- **Add Project**: add a project and get the tag or DNS record that verifies it
- **Search Deals**: find discounts and credits on software, see who each offer is for, and request a deal we don't have yet
- **Search Projects**: search verified projects in the directory
- **Search Members**: search makers by name, bio or location, and see their projects

Directory search (Search Projects and Search Members) isn't available for every account yet. Managing your own projects works for everyone.

## Signing in

The first command you run opens buildinpublic.com to connect your account. You can disconnect Raycast any time at [buildinpublic.com/settings/apps](https://buildinpublic.com/settings/apps).

## Development

```sh
npm install
npm run dev
```

To point the extension at a local server (`localhost:3000` and `api.localhost:3000`), set Environment to Development in the extension's preferences.
