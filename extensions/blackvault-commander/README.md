# BlackVault Commander

A connection and service-health companion for BlackVault Commander in Raycast for macOS and Windows.

The extension provides the public service health check, the official MCP endpoint and setup instructions. Use Raycast's built-in Install MCP Server command for OAuth and Manage MCP Servers to verify the connection. Raycast Pro is required for MCP-powered AI use. The Commander service requires a separate account and an authorized paired Windows device. The extension does not store credentials or operate devices itself.

## iPhone and iPad

On supported Raycast iOS versions, use the native MCP server settings to add BlackVault Commander with URL `https://commander.liquiditylabsstudio.com/mcp` and complete OAuth. Community Store extensions are not installable on iOS. The desktop companion is not required for native MCP. Windows native OAuth and read-only tools verified; iPhone native MCP connection tested successfully by the product owner. macOS and iPad are supported connection paths, but have not been independently device-tested for this release. The remote Windows agent remains unchanged.
