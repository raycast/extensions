# Spacepal for Raycast

Switch Spaces by name, note or app, send the front window to another Space, jump back to
your last Space and open the overview. Needs Spacepal running; it reads
`~/Library/Application Support/Spacepal/state.json` and drives Spacepal through its
`spacepal://` URL scheme.

Develop: `npm install && npm run dev`. Publish to the Raycast Store: `npm run publish`.
