# Changelog

## [Initial release] - 2025-12-19

- Time mode with multiple durations (15s, 30s, 60s, 120s)
- Words mode with configurable word counts (10, 25, 50, 100)
- Quote mode with length categories (short, medium, long, thicc)
- Support for many languages from Monkeytype 'database'
- Punctuation and numbers toggle for custom difficulty
- SVG renderer with customizable appearance:
  - Font size adjustment
  - Multiple caret styles (block, line, underscore)
  - Custom color schemes for correct, wrong, next characters
  - Active word highlighting
- Terminal/Markdown renderer with text styling options
- Visual update frequency control (instant, fast, slow, very slow)
- Results screen with WPM, accuracy, and performance ranking
- Language selector with live search
- Game mode configuration form
- Comprehensive appearance settings
- Persistent settings across sessions
- Keyboard shortcuts for quick restart (⌘+R)
- Backspace support for deleting characters and returning to previous words
