# Tui Type - Monkeytype for Raycast

A typing test extension for Raycast, inspired by [Monkeytype](https://monkeytype.com). With customizable appearance settings and comprehensive typing modes.

## Features

### 🎮 Game Modes

- **Time Mode**: Race against the clock (15s, 30s, 60s, 120s)
- **Words Mode**: Type a set number of words (10, 25, 50, 100)
- **Quote Mode**: Type famous quotes of varying lengths (short, medium, long, thicc)

### 🌍 Language Support

Supports all Monkeytype languages including:

- English, Spanish, French, German, Italian, Portuguese
- Chinese, Japanese, Korean, Russian, Arabic

### ⚙️ Customization Options

**Text Modifiers**:

- Punctuation toggle
- Numbers toggle

**Render Modes**:

- **SVG Renderer**: 'Smooth', graphical display with custom fonts and colors
- **Terminal Renderer**: Text-based display with markdown styling

**SVG Appearance Settings**:

- Font size (12px - 32px)
- Caret style (block, line, underscore)
- Custom colors for:
  - Correct characters
  - Wrong characters
  - Upcoming characters
  - Active word highlight

**Terminal Appearance Settings**:

- Text styles (bold, italic, strikethrough, link)
- Custom caret character
- Style customization for correct, wrong, and current words

**Performance**:

- Visual update frequency (instant, fast, slow, very slow)
- Optimized rendering for smooth typing experience

### 📊 Results & Statistics

After completing a test, view statistics:

- Words Per Minute (WPM)
- Accuracy percentage
- Character counts (correct, wrong, total)
- Time taken
- Rank based on performance (Novice → Typing God)

## Installation

1. Make sure you have [Raycast](https://raycast.com) installed
2. Add Tui-type as an extension
