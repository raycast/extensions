# Store Screenshots

Capture 2000x1250 PNG screenshots before opening a PR to `raycast/extensions`.

Required naming:

- `tesla-clips-1.png`
- `tesla-clips-2.png`
- up to 6 screenshots total

Suggested scenes:

1. Event list with scanned clips
2. Detail panel showing camera breakdown
3. Folder picker / source selection
4. Merge in progress toast
5. Completed merge with status indicators
6. Empty state or preferences reference

Use a consistent Raycast theme and avoid sensitive paths or personal data in screenshots.
