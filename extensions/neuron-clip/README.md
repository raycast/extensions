# Neuron Raycast Extension

Capture notes and search your knowledge base from Raycast.
Syncs with your [Neuron](https://www.neuronapp.tech) dashboard.

## Get your API key

1. Open your Neuron dashboard in the browser.
2. Go to your organization’s **Developers** page:
   - **URL:** `https://www.neuronapp.tech/organizations/YOUR_ORG_SLUG/settings/organization/developers`

   - Example: `https://www.neuronapp.tech/organizations/acme/settings/organization/developers` (replace `acme` with your organization slug if different).

3. On that page, **generate** an API key.
4. Copy the key, then in Raycast open **Extensions → Neuron → Preferences**
5. Paste the key into the **API Key** field and you’re done.

After that, Create Note and Search Content will use your Neuron account.
