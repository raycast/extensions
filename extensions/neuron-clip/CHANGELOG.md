# Neuron Changelog

## [Current] - {PR_MERGE_DATE}

### Commands

- **Create Note** – Capture a thought with title, content, optional URL, and tags (picker + new tags). Notes sync to your Neuron dashboard as Raycast type.
- **Search Content** – Search notes, folders, and tags. Detail view shows content preview and metadata (type, tags, updated). Throttled search.
- **Write Journal Daily Note** – Pick a date, write markdown; creates a new daily note or appends to existing. Toast when the date already has a note. Submit with **⇧ Enter**.

### Search Content actions

- **Notes:** Start Recall, Open in Browser, Copy Link
- **Folders:** Open in Browser, Copy Folder Link
- **Tags:** Open in Browser, Copy Tag Link

### Preferences

- **API Key** (required) – Get it from your Neuron org Developers page (www.neuronapp.tech).
