# Mealie Changelog

## [Initial Version] - 2026-09-05

- Search recipes and open them in Mealie
- Plan a recipe for a day with `Cmd+M`, defaulting to dinner
- Put a recipe's ingredients on a shopping list with `Cmd+S`
- Add items to a shopping list with autocompletion over existing Mealie foods, keeping the aisle label
- Browse and manage shopping lists, check items off with optimistic updates, edit quantity, unit, note and label
- Week view of the meal plan with add, retype, move and remove
- Import recipes from a URL, showing the imported name for verification
