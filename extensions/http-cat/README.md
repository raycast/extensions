# Http-Cat

Browse and search HTTP status codes with fun cat images, powered by [http.cat](https://http.cat).

## Features

- 🔍 Search by status code or name (e.g. `404`, `not found`, or `5` for all `5XX` errors)
- 🐱 View cat images for each HTTP status code
- 🌐 Open status code details on https://http.cat in your browser

## Usage

Simply type to search for HTTP status codes by number or description. Press `Enter` on any result to view more details on https://http.cat

## Note

The app is not dynamic, so needs maintaining.  By not being dynamic the search works nicely offline!

## Maintenance

If a new status is made available, a status is renamed or a new image is provided on https://http.cat you can just run `make update` in this repo to update the codebase.
