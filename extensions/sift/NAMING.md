# Naming — Collision Vetting + Recommendations

> Product: Raycast extension, any file on Mac → LLM-ready Markdown, local (MarkItDown).
> Current working name: **Convert to Markdown**.
> Vetting: 15-agent workflow, 284 web searches (Raycast Store + dev-tool/SERP), May 2026.
> Verdict key: **clean** = go · **caution** = usable, notable association · **avoid** = collision too strong.

## TL;DR
- Only **Vole** and **Heron** are fully clean on the original shortlist.
- Best concept names (**Pith**, **Sumi**) are clean-ish but carry minor flags.
- **Marrow** (new) is the strongest overall: clean + M-prefix "md" launcher boost + concept-perfect.
- Every "real-product-feel" name (Forge/Quill/Scribe/Slate/Phoenix/Loom/Mint/Prism) is **already taken**.
- Three shortlist names are **already live in the Raycast Store**: Bento, Hermes, Glyph. ("Render" too, from the new list.)
- Watch the metaphor: the product **distills** (strips to essence). Names meaning **hoard/collect** (Magpie, Trove, Bee, Burrow) point the wrong way.

## Recommendation
**Ship `Marrow`.** Only candidate that hits all four criteria at once: clean, M-prefix bonus, instantly drawable, and the metaphor *is* the product (the dense core inside the bone). **Pith** is the best shortlist-only pick; **Sumi** if you want pure aesthetic over legibility.

### Top 5 from shortlist
1. **Pith** — concept-perfect (the essential core), short, distinctive. Flag: a Claude Code "Pith" hook exists in the same AI-tooling audience.
2. **Sumi** — cleanest + most drawable (Japanese ink), near-empty SERP. Weakness: meaning opaque to Western devs.
3. **Vole** — fully clean, searchable, Mole-family. Weakness: derivative + says nothing about function.
4. **Heron** — fully clean, "patient precise extractor." Weakness: generic bird, weak concept-fit.
5. **Sieve** — strong filter metaphor, drawable. Flags: "holes/leak" connotation; sievedata.io (AI, adjacent).

### New names stronger than the shortlist
- **Marrow** ⭐ (M) — clean, md-boost, dense-core metaphor. The pick.
- **Decant** — clean, "pour clear off the sediment" = clarity. Only wine/perfume apps.
- **Marl** (M) — clean, short; meaning (crumbly stone) obscure.
- **Lye** — clean, 3 letters, drawable; harsh "caustic/soap" connotation.
- **Macerate** (M) — ZERO collisions but 3 syllables (too long).
