# Hex Color Transparency

Look up hexadecimal transparency/alpha values for any opacity level (0-100%).

## Usage

- Open the command to browse all 101 opacity values
- Type a hex color (e.g. `FF0000` or `#FF0000`) to see combined `#RRGGBBAA` values
- Add a number after the color to jump to a specific percentage (e.g. `FF0000 50`)
- Press Enter to copy the value to your clipboard
