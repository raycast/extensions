# Input Source Switcher Changelog

## [1.0.0] - {PR_MERGE_DATE}

### Added

- Initial release
- List all enabled keyboard layouts and input methods
- Filter by name, alias, or language code (e.g. `ru`, `jp`, `by`)
- Switch with Enter; HUD confirms the active layout
- Display name normalization: "Belarusian" instead of Apple's internal "Byelorussian"; "Pinyin — Simplified Chinese" instead of "Pinyin - Simplified"
- Universal binary helper (arm64 + x86_64), macOS 13+
