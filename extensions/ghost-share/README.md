# Ghost Share 👻

**Ghost Share** is a Raycast extension designed for the fastest possible file sharing. Select a file in Finder, run the command, and get a shareable link on your clipboard instantly.

## ✨ Features

- **Finder Integration**: Automatically detects your current file selection in macOS Finder.
- **Fast Upload**: Powered by the reliable Catbox.moe API.
- **Instant Copy**: The share link is copied to your clipboard as soon as the upload finishes.
- **Privacy-First**: No personal data is collected. Shared files are hosted anonymously.

## 🚀 How to Use

1.  Select a file in **Finder**.
2.  Open Raycast and search for **Ghost Share**.
3.  Press **Enter**.
4.  Paste the link anywhere (`Cmd + V`).

## 🛠️ Requirements

- **macOS** with Raycast installed.
- **Internet Connection** for file uploads.
