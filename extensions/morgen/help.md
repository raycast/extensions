# Connect Morgen

1. Sign in to [Morgen platform](https://platform.morgen.so).
2. Open **Developers API** and copy your API key.
3. Paste it into **Morgen API Key** in Raycast preferences.

Your Morgen plan must include API access. A 401 response means the key is invalid; a 403 “Missing entitlements” response means the plan lacks access.

Use **List Today's Events**, **Search Events**, or **Create Event**. With Raycast AI access, open **Ask Morgen** or mention `@Morgen` in AI Chat.

This independent integration is maintained by [chaOSSlabs](https://github.com/chaosslabs/morgen-raycast).
