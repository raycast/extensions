# Memory Machine Changelog

## [Memory Machine Rebrand] - 2026-11-24

- Renamed the extension to Memory Machine and updated its icon and screenshots.
- Updated Search, History, and Settings to use the `memorymachine://` links introduced in Memory Machine 1.6.0.
- Updated search and Raycast AI examples to use `app:` filters, including quoted app names and groups of apps.
- Added download and retry actions when the Memory Machine Mac app is missing.

## [Initial Version] - 2026-03-17

- Added AI extension tools:
  - Search Orbit: Opens Orbit Search with a provided query.
  - Open Orbit Timeline: Opens the Orbit timeline, optionally jumping to a specified date or time.
  - Open Orbit Settings: Opens Orbit settings.
- Added commands:
  - Search Orbit: Opens Orbit Search with the exact query.
  - Open Timeline: Opens the Orbit timeline, optionally jumping to a specified date or time.
  - Open Settings: Opens Orbit settings.
