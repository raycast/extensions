# The Insight Journal Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Search and browse blog posts from aryantechie.com
- Menu bar command with background checks and notifications for new posts
- Search Projects command for project write-ups from aryantechie.com/work
- Open Random Post command
- Grid view with cover images, toggled with ⌘⇧L
- Posts grouped by month, projects by year
- Reading time for every post
- Reading list: save posts with ⌘S and filter by Reading List
- Mark as Unread, Share on X and LinkedIn, and Copy as Rich Link actions
