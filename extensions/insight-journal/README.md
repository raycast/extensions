# The Insight Journal

Browse and search posts from [aryantechie.com/blog](https://aryantechie.com/blog) right from Raycast, and get notified when a new post is published.

## Commands

- **Search Blog Posts** — list every post with cover image, summary, topics and date. Posts are grouped by month. Filter by topic, switch between list and grid view (⌘⇧L), share on X or LinkedIn, copy as a plain, Markdown or rich link, mark posts as read or unread, and save posts to a reading list with ⌘S (pick "Reading List" in the dropdown to see them). Each post shows its reading time, taken from the website.
- **Search Projects** — the same browser for project write-ups from aryantechie.com/work, filterable by tech stack.
- **Open Random Post** — opens a random post in your browser.
- **New Blog Posts** — a menu bar item that checks the RSS feed every 30 minutes. It shows a count of unread posts and, if enabled, sends a macOS notification when a new post appears.

## Notifications

Run **New Blog Posts** once to enable it. Raycast then refreshes it in the background. In the command preferences you can:

- turn macOS notifications on or off
- hide the menu bar icon when there are no new posts

The first run marks all existing posts as read, so you only hear about posts published after that.
