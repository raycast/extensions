# Ring Intercom Changelog

## [Multiple Intercoms, Intercom Video and Windows] - 2026-11-25

- Added Select Default Intercom: choose which intercom Unlock Door opens, see each intercom's battery and connection, and unlock any of them
- Ring Intercom Video is now supported
- Unlock Door no longer guesses when you have several intercoms: it opens the list until you choose a default
- Now available on Windows
- Your Ring password is no longer stored; Authenticate removes one saved by earlier versions
- Unlock Door no longer waits for an internet check before unlocking
- A sign-in that Ring has expired now asks you to run Authenticate again, instead of showing Ring's error
