# Transfa Changelog

## [1.0.0] - 2026-05-15

### Added

- **Upload File** command: pick any file, set TTL and optional password, get a shareable link auto-copied to clipboard
- **Recent Uploads** command: browse, copy links, and delete your uploads (requires API key)
- Guest mode support — works without an API key (10 MB / 24h TTL)
- Direct download URL alongside the share page URL
- Global preferences: API key and default expiry
