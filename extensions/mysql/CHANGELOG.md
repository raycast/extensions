# MySQL Client Changelog

- Run Query with a results table and JSON / CSV copy
- Command Palette with common MySQL commands
- Browse Schema (databases, tables, columns)
- Query History with favorites (last 100)
- Manage Connections with multiple profiles, SSL modes, and a Test Connection action
- AI tool to query the database (with confirmation for data- or schema-changing statements)
