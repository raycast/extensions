# SVG Studio



An advanced SVG playground right inside Raycast. Preview, edit, and export SVGs instantly.

**SVG Studio** transforms Raycast into a lightweight IDE for vector graphics. Whether you need to check an icon from your clipboard, tweak a color attribute, or export a high-resolution PNG for a presentation, SVG Studio handles it all with a native-like experience.

*(Note: Replace `metadata/1.png` with your actual screenshot path if needed)*



## ✨ Features



- **⚡️ Instant Preview**: Automatically detects SVG code from your clipboard on startup.
- **📝 Pro Code Editor**: Integrated **Ace Editor** provides syntax highlighting, code folding, and auto-completion.
- **🎨 Interactive Canvas**:
  - **Pan**: Hold `Space` and drag to move the canvas.
  - **Zoom**: Use mouse wheel or on-screen controls to zoom in/out.
  - **Auto Fit**: One-click to center and fit the image to the window.
- **🌑 Dark Mode Support**: The editor and canvas automatically adapt to your system's theme.
- **🖼 High-Res Export**: Export SVGs to PNG with 1x, 2x (Retina), or 4x scaling options.
- **📋 Smart Copy**: One-click copy the rendered PNG to your clipboard.



## 🚀 How to Use



1. **Copy & Open**: Copy any SVG code and run the "Open SVG Studio" command.
2. **Edit**: Modify the code on the left sidebar. The preview updates in real-time.
3. **Inspect**: Use `+` / `-` buttons or your mouse wheel to zoom. Hold `Space` to pan around.
4. **Export**: Select your desired scale (e.g., 2x for Retina) and click "Save PNG" or "Copy".



## 🛠 Technical Details



- **Engine**: Powered by a local Webview with **Ace Editor** (CDN).
- **Security**: Rendering happens locally. No SVG data is sent to any server.
- **Performance**: Optimized for smooth 60fps panning and zooming.

# SVG Studio (中文介绍)



一个极其强大的 Raycast SVG 游乐场。直接在 Raycast 中预览、编辑并导出 SVG。

**SVG Studio** 将 Raycast 变成了一个轻量级的矢量图形 IDE。无论你是想快速查看剪贴板里的图标、微调颜色属性，还是为 PPT 导出一张高清 PNG 图片，SVG Studio 都能为你提供原生般的流畅体验。



## ✨ 核心功能



- **⚡️ 即时预览**: 启动时自动检测并渲染剪贴板中的 SVG 代码。
- **📝 专业编辑器**: 内置 **Ace Editor** 内核，支持语法高亮、代码折叠和自动补全。
- **🎨 交互式画布**:
  - **拖拽**: 按住 `空格键 (Space)` 并拖动鼠标即可移动画布。
  - **缩放**: 支持鼠标滚轮或界面按钮进行无损缩放。
  - **自动适配**: 一键归位，自动计算最佳比例展示全图。
- **🌑 深色模式**: 编辑器配色和画布背景会自动跟随系统主题切换。
- **🖼 高清导出**: 支持将 SVG 导出为 PNG，提供 1x、2x (Retina)、4x 等多种倍率。
- **📋 智能复制**: 一键将渲染好的 PNG 图片复制到剪贴板。



## 🚀 使用指南



1. **复制与打开**: 复制任意 SVG 代码，运行 "Open SVG Studio" 命令。
2. **编辑**: 在左侧侧边栏修改代码，右侧预览图会实时更新。
3. **查看**: 使用 `+` / `-` 按钮或鼠标滚轮缩放。按住 `空格键` 拖拽画布查看细节。
4. **导出**: 选择你需要的清晰度（例如 2x），点击 "Save PNG" 下载或 "Copy" 复制。



## 🛠 技术细节



- **引擎**: 基于本地 Webview 和 **Ace Editor** (CDN) 构建。
- **安全**: 所有的渲染过程均在本地完成，不会上传任何 SVG 数据。
- **性能**: 针对拖拽和缩放进行了专门优化，丝般顺滑。
