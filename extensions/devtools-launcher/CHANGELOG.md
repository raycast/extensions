# DevTools Launcher Changelog

## [21 New Tools] - {PR_MERGE_DATE}

- Add commands for 21 new DevTools tools, including JSON Diff, DB Diagram, Semver, and Time Zone Converter.
- Update the bundled tool list that Search Tools uses when the app has not written its own list. The list now has 62 tools.

## [Initial Version] - 2026-11-18

- One command per DevTools tool, so you can type a tool's name in Raycast's root search and open it.
- Search Tools: find a DevTools tool by name, category, or keyword, and open it. It also works as a fallback command.
- Open DevTools: open the app, or its command palette with a search.
