## [Initial Release] - 2026-03-23

- Process list with CPU, memory, PID, name, and type sorting
- Grouping by type (App/System/Helper), parent process, and usage tier
- Instant kill with no confirmation dialogs
- Force kill and sudo force kill options
- Multi-select with bulk kill
- Kill All Visible and Force Kill All Visible
- Freeze (SIGSTOP) and Resume (SIGCONT) process control
- Priority control via renice
- Kill duplicates (keep oldest, kill the rest)
- Kill by Port command with full listening port overview
- Resource Hogs command for high CPU/memory processes
- Recently Killed history with re-kill by name
- Detail panel with path, ports, uptime, and nice value
- Color-coded CPU and memory tags
- Configurable thresholds, refresh interval, and display options
