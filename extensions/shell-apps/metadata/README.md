# Screenshots

This directory contains screenshots for the Raycast Store listing.

# Requirements

- **Resolution**: 2000×1250 pixels (16:10 aspect ratio)
- **Format**: PNG
- **Count**: 2 screenshots (Raycast recommends at least 3, maximum 6)

## Naming Convention

- `shell-apps-1.png` - Create Shell App form
- `shell-apps-2.png` - Shell Apps list with the action menu open

## Guidelines

- Use high-contrast backgrounds
- Keep backgrounds consistent across all screenshots
- Showcase the most useful features
- Avoid including sensitive data
- Use consistent theming (all light or all dark mode)
