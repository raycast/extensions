# Changelog

All notable changes to this extension will be documented in this file.

## [1.0.0] - 2026-01-07

### Added
- Initial release of GCS Uploader.
- Upload files/images directly from clipboard.
- Fallback to manual file picker.
- Optional CDN support for generated links.
- Integration with `gcloud` CLI for authentication.
- Access Token authentication fallback.
