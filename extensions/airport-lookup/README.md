# Airport Lookup

Search airports by ICAO code (`KJFK`), IATA code (`JFK`), name, or city, and
see quick facts about them — location, continent, coordinates, elevation,
airport type, and whether it has scheduled service.

From the results list you can:

- Copy the ICAO or IATA code
- Open the airport in Google Maps
- Open its Wikipedia article (when available)
- Open its official website (when available)
- Open it on Flightradar24

## Data

Airport data is bundled with the extension and covers every large and medium
airport worldwide, plus any smaller airport that still carries a commercial
IATA code — sourced from the public-domain [OurAirports](https://ourairports.com/data/)
dataset.
