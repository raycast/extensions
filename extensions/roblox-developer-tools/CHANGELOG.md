# Roblox Developer Tools Changelog

## [Robux Earned] - 2026-10-24

- Track game or account earnings in your menu bar, updated every 30 seconds with automatic retries
- Choose a time range and display Robux or estimated DevEx USD
- Optionally hide the menu bar item when earnings are zero, while continuing to refresh
- Enjoy a clean menu with a Robux icon and your game or account name
- Match the Robux icon to the menu bar’s light or dark appearance
- Configure time range, currency, and visibility in the command’s Raycast settings
- Open the game page or launch Roblox directly from the Player Count menu
- Simplify settings descriptions and setup instructions

## [Initial Release] - 2026-10-22

- Launch Roblox games
- Open places in Roblox Studio
- Publish the current place from Roblox Studio
- Restart game servers
- View player counts in the menu bar
- Open the Roblox game page
- Open the game in Creator Dashboard
