# Amino Acid Lookup Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Look up amino acids by one-letter code, three-letter code or full name
- Convert peptide sequences between one-letter and three-letter notation
- Show side-chain class, molecular weight and DNA codons for each amino acid, and length and average mass for sequences
- Color amino acids with the Clustal X (default) or Taylor scheme, selectable in the extension preferences
