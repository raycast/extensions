# Raycast LifeOps Progress

Raycast menubar progress trackers for:
- **Weight** (from Home Assistant)
- **Savings / TR buffer** (from Firefly III)

## Dev

Prereqs:
- Raycast
- Node.js

Install deps:
```bash
npm install
```

Run in Raycast dev mode:
```bash
npm run dev
```

## Configuration

Set values in Raycast **Extension Preferences** (Raycast → Settings → Extensions → LifeOps Progress).

No secrets are committed.
