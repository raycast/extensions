# Page Scanner Changelog

## [Initial Version] - {PR_MERGE_DATE}

- **Scan Current Tab** saves the tab in front of your browser as a vector PDF, a PNG or a JPEG, through the Page Scanner Chrome extension, then copies the file, shows it in Finder, opens it, or opens the capture in the extension's editor.
- **Set up Page Scanner** installs the helper and waits for Connect in the extension, checking each step as it goes.
- Preferences for the folder, the file name, the format, the page size, a Markdown copy of the text, the theme, the page width, hiding clutter, and which connected browser to use.
