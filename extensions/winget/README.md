# Winget Extension for Raycast

A powerful Raycast extension that allows you to manage Windows packages using WinGet directly from Raycast.

## Features

- 🔍 **Search Packages**: Search for packages in WinGet repositories
- 📦 **Install Packages**: Search and install packages using WinGet
- 📋 **List Installed**: View all installed packages with upgrade and uninstall options  
- ⬆️ **Upgrade Packages**: Show and upgrade outdated packages

## Prerequisites

- Windows operating system
- [WinGet](https://docs.microsoft.com/en-us/windows/package-manager/winget/) installed and available in PATH

## Commands

### Search Packages

Search for available packages in WinGet repositories. Simply type your search query and browse through the results.

### Install Package

Search and install packages directly from Raycast. Select a package from the search results and install it with one click.

### List Installed Packages

View all packages currently installed on your system. Options to upgrade or uninstall packages are available for each item.

### Upgrade Packages

Check for and install updates for your installed packages. Keep your software up to date effortlessly.

## Installation

This extension is available in the [Raycast Store](https://raycast.com/masteroftime/winget).

## Development

To run this extension in development mode:

```bash
npm install
npm run dev
```
