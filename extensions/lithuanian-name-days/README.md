# Lithuanian Name Days

See who celebrates a name day (*vardadienis*) today, tomorrow and during the next week in Lithuania, and look up the name day of any Lithuanian name.

## Commands

- **Today's Name Days** – today plus the next 7 days. Dates follow the `Europe/Vilnius` time zone, regardless of your system time zone.
- **Search Name Day** – type a name (diacritics optional: `Zydrunas` finds `Žydrūnas`) and see its name day dates.

## Actions

- Copy Names / Copy Date
- Open Full Calendar – <https://dovanasuvardu.lt/vardadieniai/>
- Copy Data Attribution

## Data and licenses
