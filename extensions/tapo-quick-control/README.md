# Tapo Quick Control

Control Tapo devices from Raycast.

## Features
- Lists all Tapo devices (plugs, lights, cameras, and others).
- Controls on/off for plug and light models.
- Light color control when supported.
- Device selection command to limit which devices appear.
- Auto subnet discovery with optional manual IP overrides.

## Preferences
- Tapo Email / Password: Your account credentials.
- Device Scope: All devices or only selected ones.
- Subnet: Optional override (e.g., 192.168.1.0/24).
- IP Overrides: `deviceId=ip` or `alias=ip` entries.

## Commands
- Prizler: Control all plugs.
- Isiklar: Control all lights.
- Tum Cihazlar: List and control all devices.
- Cihaz Secimi: Choose which devices are in scope.
