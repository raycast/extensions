# OpenCode

Use the models from your [OpenCode Console](https://opencode.ai) workspace in Raycast AI Chat, Quick AI, and AI Commands.

Models come from the managed OpenCode catalog and are billed pay-as-you-go to your workspace. Models disabled in the Console are hidden.

## Setup

1. Create an API key in the OpenCode Console under **Service Accounts > API Keys**.
2. Paste it into the extension's **API Key** preference.
3. Allow the extension to provide models from the Raycast model picker.

Run **Refresh Models** after changing models in the Console to update the picker immediately.

Using models provided by extensions requires Raycast Pro.
