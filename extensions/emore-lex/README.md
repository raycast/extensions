# Emore Lex

Emore Lex 是一个面向英语学习和运维英语场景的 Raycast 扩展，支持快速查询单词、短语、发音、释义、例句、同义词、收藏、历史和技术语境解释。

## 本地开发

```bash
npm install
npm run dev
```

## 构建验证

```bash
npm run build
npm run lint
```

## 当前能力

- Dictionary API 英文释义、音标、例句和发音音频
- Datamuse 同义词
- 本地中文释义补充
- 运维英语词库解释
- 本地缓存、收藏和查询历史
- Markdown / CSV 导出到剪贴板
