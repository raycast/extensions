# Emore Lex

Emore Lex is a Raycast extension for English word lookup and operations-focused vocabulary learning.

## Development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run lint
npm run build
```

## Features

- Dictionary API definitions, phonetics, examples, and pronunciation audio
- Datamuse synonyms
- Local English usage notes for common technical vocabulary
- Operations vocabulary explanations
- Local cache, favorites, query history, and study statistics
- Markdown and CSV export actions
