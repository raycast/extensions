# TaskTickr for Raycast

Manage your [TaskTickr](https://tasktickr.app) tasks without leaving Raycast.

## Commands

- **My Tasks** — Browse, complete, edit, and manage your tasks and subtasks.
- **Add Task** — Quickly create a new task with notes, duration, and due date.
- **Tasks Due Today** — A menu-bar item showing how many tasks are due today.

## Setup

1. Install the extension.
2. Open any command and sign in to your TaskTickr account.
3. (Self-hosted only) Set **Server URL** in the extension preferences to point at
   your instance. It defaults to `https://tasktickr.app`.

## Preferences

| Name       | Description                                                        | Default                 |
| ---------- | ------------------------------------------------------------------ | ----------------------- |
| Server URL | Base URL of your TaskTickr instance — change it for self-hosting. | `https://tasktickr.app` |
