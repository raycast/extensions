# Screenshots

This directory contains screenshots for the Raycast Store listing.

## Required Screenshots

Raycast Store recommends adding screenshots to showcase your extension. You can add screenshots here with the following names:

- `timestamp-converter-1.png` - Main conversion view(timestamp to datetime)
- `timestamp-converter-2.png` - Main conversion view(datetime to timestamp)
- `timestamp-converter-3.png` - Current time display
- `timestamp-converter-4.png` - Preferences/settings
- etc.

## How to Take Screenshots

1. Open your extension in Raycast
2. Take screenshots showing the key features:
   - Converting a timestamp
   - Converting a datetime
   - Current time display
   - Different formats
   - Settings/preferences

3. Screenshots should be:
   - Clear and well-lit
   - Show the extension in action
   - Demonstrate key features
   - PNG format
   - Reasonable size (not too large)

## Adding to Store Listing

When you publish, the Raycast team will review your extension and may use these screenshots in the store listing.
