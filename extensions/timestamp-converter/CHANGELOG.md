# Changelog

## [1.0.0] - 2025-11-10

### Added

- Initial release
- Smart conversion between Unix timestamps and datetime formats
- Support for both seconds (10-digit) and milliseconds (13-digit) timestamps
- Live current time display with real-time updates
- Multiple output formats: ISO 8601, full format, localized, Unix timestamps, and relative time
- Multi-timezone support (Local, UTC, Beijing, New York, Los Angeles, London, Tokyo, Singapore)
- Configurable preferences for timezone, format, and display options
- Quick access with multiple keyword aliases
- One-click copy to clipboard
- Paste directly to active application
