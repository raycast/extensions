# Tagesschau

Read the latest news from the German news service [Tagesschau](https://www.tagesschau.de) without leaving Raycast.

## Features

- Browse the latest headlines and open them in your browser or copy their link
- Search the loaded headlines by typing and see how long ago each one was published
- Filter by section ("Ressort") and subsection, including all 16 German federal states:
  - Alle Meldungen
  - Inland
  - Ausland
  - Wirtschaft
  - Wissen
  - Faktenfinder
  - Investigativ
- Your last selected section is remembered

The headlines and section names are in German, as published by Tagesschau.

## No Setup Needed

All news comes from the [official RSS feeds of Tagesschau](https://www.tagesschau.de/mehr/rss-feeds), so no account or API credentials are needed.
