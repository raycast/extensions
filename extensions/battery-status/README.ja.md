# Battery Status

Macのバッテリー情報を詳細に表示するRaycastエクステンション

## 機能

- **充電状態**: 充電量（%）、充電/放電状態、フル充電済みかどうか
- **電源**: AC接続状態、充電中かどうか、アダプタのワット数
- **残り時間**: 充電完了までの時間 / バッテリー残り時間
- **バッテリー温度**: 現在の温度（高温時は警告表示）
- **充放電電流**: 現在の電流値（mA）
- **健康状態**: バッテリーの状態（正常/まもなく交換/今すぐ交換/バッテリー修理）
- **最大容量**: バッテリーの最大容量（%）
- **サイクル数**: バッテリーの充電サイクル数

## 多言語対応

- 英語（English）
- 日本語
- 自動検出（macOSのシステム言語設定から判定）

言語設定はRaycastの設定画面から変更可能です。

## インストール

[Raycast Store](https://www.raycast.com/store)からインストールしてください（公開準備中）。またはソースコードからビルドできます。

## 使い方

1. Raycastを開く
2. 「Battery Status」と入力
3. Enterキーを押してバッテリー情報を表示
4. `Cmd+R`または「更新」でEnterキーを押すと情報を更新

### 言語の変更方法

1. Raycastの設定を開く
2. Extensions → Battery Statusに移動
3. 「Language」ドロップダウンから言語を選択：
   - Auto-detect (System): macOSのシステム言語を使用
   - English: 英語表示に固定
   - 日本語 (Japanese): 日本語表示に固定
4. エクステンションを再起動（Cmd+K → Reload）すると変更が反映されます
