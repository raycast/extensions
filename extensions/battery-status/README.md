# Battery Status

Display detailed battery information for your Mac in Raycast.

## Features

- **Charge Status**: Battery level (%), charging/discharging state, fully charged status
- **Power Source**: AC adapter connection, charging status, wattage
- **Time Remaining**: Time until fully charged / remaining battery time
- **Battery Temperature**: Current temperature with high temperature warning
- **Charge/Discharge Current**: Current flow in milliamperes (mA)
- **Health Status**: Battery condition (Normal / Replace Soon / Replace Now / Service Battery)
- **Maximum Capacity**: Battery's maximum capacity percentage
- **Cycle Count**: Number of charge cycles completed

## Multi-Language Support

- English
- Japanese (日本語)
- Auto-detect (based on macOS system language)

You can change the language in Raycast preferences.

## Installation

Install from the [Raycast Store](https://www.raycast.com/store) (coming soon) or build from source.

## Usage

1. Open Raycast
2. Type "Battery Status"
3. Press Enter to view detailed battery information
4. Press `Cmd+R` or Enter on "Update" to refresh the information

### Changing Language

1. Open Raycast preferences
2. Navigate to Extensions → Battery Status
3. Select your preferred language from the "Language" dropdown:
   - Auto-detect (System): Uses your macOS system language
   - English: Force English display
   - 日本語 (Japanese): Force Japanese display
4. Restart the extension (Cmd+K → Reload) to apply changes
