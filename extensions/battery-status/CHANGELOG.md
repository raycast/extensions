# Battery Status Changelog

## [Initial Version] - 2025-10-18

### Added

- Initial release of Battery Status extension
- Display battery charge level and charging status
- Show battery temperature with high temperature warnings
- Display charge/discharge current in milliamperes
- Show battery health status (Normal/Replace Soon/Replace Now/Service Battery)
- Display maximum capacity percentage and cycle count
- Show AC adapter connection status and wattage
- Display remaining time until fully charged or battery remaining time
- Multi-language support (English and Japanese with auto-detection)
- Refresh battery information with Cmd+R
