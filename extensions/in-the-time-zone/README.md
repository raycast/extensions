# In The Timezone

Visualize and scrub time across multiple time zones. Perfect for coordinating meetings with distributed teams.

## Features

- **Timeline View** — See all your cities side by side, with each hour colored by time of day
- **Cursor** — Move a cursor along the timeline to compare times; a red line shows the cursor's local time in every city, and a green line marks the current time
- **Snapping** — Jump the cursor to the previous or next full hour (or half hour) to pick meeting times quickly
- **Colors** — Blue for sleep (22-6), strong yellow for work (9-17), pale yellow for the hours in between
- **Sunrise/Sunset** — Know when the sun rises and sets in each city
- **Any City** — Search and add any city in the world

## Usage

1. Open "In The Timezone" from Raycast
2. Use `Cmd+E` to add/remove cities
3. Use `←` / `→` to move the cursor by your configured Arrow Key Scrub Minutes
4. Use `Option+←` / `Option+→` to move it by your configured Option+Arrow Key Scrub Minutes
5. Use `Shift+←` / `Shift+→` (or `Shift+Option+←` / `Shift+Option+→`) to snap it to the previous / next step
6. Use `Cmd+R` to reset to the current time

## Keyboard Shortcuts

| Shortcut                            | Action                                                       |
| ----------------------------------- | ------------------------------------------------------------ |
| `←` / `→`                           | Move the cursor by configured Arrow Key Scrub Minutes        |
| `Option+←` / `Option+→`             | Move the cursor by configured Option+Arrow Key Scrub Minutes |
| `Shift+←` / `Shift+→`               | Snap to the previous / next Arrow Key Scrub step             |
| `Shift+Option+←` / `Shift+Option+→` | Snap to the previous / next Option+Arrow Key Scrub step      |
| `Cmd+E`                             | Edit cities                                                  |
| `Cmd+L`                             | Timeline view                                                |
| `Cmd+R`                             | Reset to now                                                 |
