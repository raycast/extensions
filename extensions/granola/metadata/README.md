# Granola

Create, manage, and review Granola notes in Raycast. Start recordings, browse notes and folders, export notes or transcripts in bulk, and use AI tools to summarize or retrieve content.

## Setup
- Install and sign in to the Granola app.
- Keep Granola running while using the extension.
- Grant Raycast access to your Granola data folder:
  - macOS: `~/Library/Application Support/Granola`
  - Windows: `%APPDATA%\\Granola`

## Commands
- Search Notes
- Create Note
- Create Note from Transcript
- Export Transcripts
- Export Notes
- Search People
- Search Companies

## AI Tools
- List Meetings
- Get Note Content
- Get Transcript
- List Folders
- Save to Notion
- Recipes

## Highlights
- Open notes in Granola, copy share links, or copy content as Markdown or HTML.
- Batch export notes or transcripts with folder-aware filtering and ZIP output.
- Create notes from text or YouTube transcripts with AI summaries.
- Save notes to Notion in batches.
- See meeting duration when transcript timing is available.
- Works on macOS and Windows.

## Privacy
This extension reads data from your local Granola app folder and uses your local Granola session token to access notes via the Granola API. It does not collect data. Notion exports only occur when you explicitly trigger them.
