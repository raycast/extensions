Capture screenshots with Flameshot

## Commands

### Capture Selection

Capture a screenshot of a selected area with optional delay and pinning arguments.

### Capture Screen

Capture the screen with optional delay argument.

### Capture All Screens

Capture all screens with optional delay argument.
