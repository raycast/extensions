# Ducat

Add transactions in natural language to your [Ducat](https://ducat.money/) account from Raycast. 

Don't have an account yet? [Register here.](https://web.ducat.money/register?source=Raycast)

## Prerequisites

This extension requires an integration key to work. Here's how to get one:

1. [Log in to Ducat](https://web.ducat.money/login)
2. Visit the [Integrations](https://web.ducat.money/integrations) page
3. Create a Raycast integration
4. Copy the generated integration key
5. Paste it in the Raycast extension preferences
