# Paste Image Changelog

## [Native Raycast Experience] - {PR_MERGE_DATE}

- Upgraded the extension to the latest Raycast API and development toolchain.
- Added native paste, copy, Quick Look, open, Finder, Trash, and confirmation actions.
- Added collision-safe saving to the Desktop and support for more image formats.
- Added compact, transparent, aspect-ratio-preserving previews that keep image metadata visible without nested scrolling.
- Improved folder importing, filtering, cache consistency, error recovery, and file metadata.
- Added safer image renaming and resilient handling for missing files or unavailable folders.
- Added automated filesystem and cache tests plus complete user and developer documentation.
