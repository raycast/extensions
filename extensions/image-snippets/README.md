# Image Snippets

Save and organize images as reusable snippets. Perfect for logos, signatures, memes, or any images you frequently paste.

## Features

- **Add Image to Snippets**: Save the current clipboard image with a custom name and keywords
- **Browse Image Snippets**: View all your saved images in a grid, search by name or keywords, and copy with one click
- **Pin favorites**: Keep frequently used images at the top
- **Keywords**: Add comma-separated keywords for quick search

## Usage

1. Copy an image to your clipboard (screenshot, image from web, etc.)
2. Run **Add Image to Snippets** command
3. Give it a name and optional keywords
4. Find it later with **Browse Image Snippets**

## Keyboard Shortcuts (Browse)

| Shortcut | Action |
|----------|--------|
| `Enter` | Copy to clipboard |
| `⌘ + E` | Edit name/keywords |
| `⌘ + ⇧ + P` | Pin/Unpin |
| `⌘ + O` | Reveal in Finder |
| `⌘ + R` | Refresh |
| `⌘ + ⌫` | Delete |

## Configuration

You can configure the folder where images are stored in the extension preferences. Default: `~/Pictures/raycast-snippets`
