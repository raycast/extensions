# eBay Search for Raycast

Search active and sold eBay listings in your default browser.

Choose **United States** or **Canada** under **Marketplace** in Raycast Settings. Each selected-text command has its own **Use Clipboard Fallback** setting, which is off by default.

Regular and sold searches have separate histories, each with up to seven recent queries. Each history includes typed and selected-text searches. When the search field is empty, use the action panel to remove a query or clear the current history. Reopening a query uses the current command and marketplace.
