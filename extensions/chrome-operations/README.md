# Open in Chrome

Quickly switch your browsing to Google Chrome or launch a private browsing session.

## Commands

### Open URL in Chrome

Open the current page from any supported browser in Google Chrome. Automatically detects the active browser and transfers the URL to Chrome.

**Supported browsers:** Safari, Google Chrome, Microsoft Edge, Firefox

### Open Chrome Incognito Mode

Launch Google Chrome in Incognito (private) mode with a blank window.

## Requirements

- macOS
- Google Chrome installed

## Usage

Press `⌘ + K` in Raycast, then search for "Open in Chrome" commands.
