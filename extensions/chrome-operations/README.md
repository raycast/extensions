# Open in Chrome

Quickly switch from Safari, Edge, or Firefox to Google Chrome, or launch a new Incognito window.

## Unique Value

This extension focuses on **browser switching** - a quick way to transfer your current webpage from Safari, Microsoft Edge, or Firefox to Google Chrome without manually copying and pasting URLs.

## Commands

### Open Current Page in Chrome

Automatically detect the active browser (Safari, Edge, or Firefox) and open the current URL in Google Chrome.

**Why this is useful:**
- No need to manually copy and paste URLs
- Works across different browsers
- Perfect for testing sites in Chrome
- Ideal for developers who use multiple browsers

**Supported browsers:** Safari, Google Chrome, Microsoft Edge, Firefox

### Launch Chrome Incognito

Quickly open a new Chrome Incognito (private) window with a blank page.

**Why this is useful:**
- Fast access to private browsing
- One-key shortcut from Raycast
- No need to navigate Chrome menus

## Requirements

- macOS
- Google Chrome installed

## Usage

Press `⌘ + K` in Raycast, then search for "Open in Chrome" commands.
