# Phi

Control [Phi Browser](https://phibrowser.com) directly from Raycast.

## Features

- Search and switch between Phi Spaces.
- Search browsing history, open tabs, pinned tabs, and bookmarks.
- Activate, close, or reload tabs, and copy their URLs.
- Run common page actions, including refresh, force refresh, manage extensions, and Split View.
- Open new tabs in a selected Space.
- Open a standard or incognito window.

## Requirements

Phi 2.4.0 or later is required. macOS will ask for Automation permission when Raycast controls Phi.
