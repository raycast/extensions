# App Drawer

A Launchpad-style app drawer for Raycast. Browse, search, and organize your applications with folders — all within Raycast's native Grid UI.

## Features

- **Grid View**: Browse all your applications in a clean grid layout
- **Folders**: Organize apps into folders with drill-down navigation
- **Folder Icons**: Folder thumbnails show a 3x3 preview of contained apps
- **Reorder**: Move apps and folders up/down with keyboard shortcuts
- **Search**: Instantly filter apps by name using Raycast's built-in search
- **Import from Launchpad**: One-click import of your existing Launchpad layout (folders, ordering)
- **Configurable Columns**: Choose between 5, 6, 7, or 8 columns in the grid

## Usage

Open Raycast and type "App Drawer" to launch. Your installed applications will be displayed in a grid.

### Keyboard Shortcuts

| Action | Shortcut |
|--------|----------|
| Open App | `Enter` |
| Move Up | `Cmd+Shift+Up` |
| Move Down | `Cmd+Shift+Down` |

### Folder Operations

- **Open Folder**: Select a folder and press `Enter`
- **Create Folder**: Select an app → "Move to Folder" → "New Folder…"
- **Move to Folder**: Select an app → "Move to Folder" → choose folder
- **Rename Folder**: Select a folder → "Rename Folder"
- **Delete Folder**: Select a folder → "Delete Folder" (apps return to main grid)

### Import from Launchpad

Select any item → "Import from Launchpad" to import your current Launchpad layout including folder structure and app ordering.

## Preferences

| Preference | Description | Default |
|------------|-------------|---------|
| Grid Columns | Number of columns in the grid layout | 7 |
