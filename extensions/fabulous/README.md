# NicNames

This is a **Raycast** extension for [Fabulous](https://fabulous.com/) - _Expert Tools for Domainers_.

With this extension you can List Domains and their DNS Records.

## 🚀 Getting Started

1. **Install extension**: Click the `Install Extension` button in the top right of [this page](https://www.raycast.com/xmok/fabulous) OR `install` via Raycast Store

2. **Enter credentials**: Please enter "username" and "password" in `Preferences`
