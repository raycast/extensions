# Parallex for Raycast

Open your [Parallex](https://parallex.mandip.dev) instances and workspaces, and make a second copy of any app, from Raycast.

- **Open Instance**: every instance, by name, with its own icon. Open it, show it in Parallex, or copy its `parallex://` link.
- **Open Workspace**: open every instance in a workspace at once.
- **New Instance**: pick an app, and Parallex opens with it ready to copy; you name it and choose its color.

It reads your instances from `~/Library/Application Support/Parallex` and acts through `parallex://` links, so it never changes or removes anything. Parallex itself needs to be installed.
