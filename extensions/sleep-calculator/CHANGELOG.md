# Sleep Calculator Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Initial release with "Wake Up At" and "Sleep Now" commands
- Calculate optimal bedtimes based on 90-minute sleep cycles
- Flexible time input parser supporting multiple formats (7am, 7:30 AM, 0730, noon, etc.)
- Color-coded sleep quality indicators (Optimal, Great, Good, Light, Nap, Minimal)
- Show More option to view additional cycle times
- Copy times to clipboard with single action
