# Sleep Calculator

Calculate optimal sleep and wake times based on 90-minute sleep cycles.

## Features

### Wake Up At

Enter your desired wake-up time and see the best times to go to bed. The extension calculates bedtimes for multiple sleep cycles, highlighting the recommended options (5-6 cycles for optimal rest).

### Sleep Now

Going to bed right now? This command shows you the optimal times to wake up based on complete sleep cycles, helping you feel more refreshed in the morning.

## How It Works

Sleep science suggests that waking up at the end of a 90-minute sleep cycle helps you feel more refreshed. This extension:

1. Uses the standard 90-minute sleep cycle duration
2. Adds a 15-minute buffer for the time it takes to fall asleep
3. Calculates optimal times for 3-6 complete cycles
4. Recommends 5-6 cycles (7.5-9 hours) for optimal rest

## Supported Time Formats

The extension accepts many time input formats:

| Format | Example |
|--------|---------|
| Standard | 7:30 AM, 7:30 PM |
| Short | 7am, 7pm, 7a, 7p |
| 24-hour | 07:30, 14:30 |
| Military | 0730, 1430 |
| Keywords | noon, midnight |
| Natural | half past 7, quarter to 8 |
| Written | seven, seven thirty |

## Usage

1. Open Raycast
2. Type "Wake Up At" or "Sleep Now"
3. For "Wake Up At", enter your desired wake time
4. View the calculated times and copy any time to your clipboard

## Tips

- **5-6 cycles** (7.5-9 hours) are recommended for adults
- **4 cycles** (6 hours) is the minimum for adequate rest
- **3 cycles** (4.5 hours) should only be used occasionally
