# Radiokollen

Raycast-extension för att söka låtspelningar i Sveriges Radio P4.

## Kommandon

- `Sök Radiokollen`: Kör ny sökning med filter, datumintervall och matchningsläge.
- `Radiokollen Historik`: Återkör och hantera sparade sökningar.

## Lokalt

```bash
npm --workspace radiokollen run dev
```

## Datakälla

- Direktanrop mot SR API via `@filipkillander/radiokollen-sdk`.
