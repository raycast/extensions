# Changelog

All notable changes to this extension will be documented in this file.

## [1.0.0] - 2026-01-07

### Added
- Initial release of Water Reminder extension.
- Track daily water intake (ml).
- Daily history view with statistics.
- Menu bar integration for quick tracking.
- Background reminders to drink water.
- Integrations: Habitify, NocoDB, and Apple Shortcuts.
- Webhook support for custom integrations.
- Confetti celebration upon goal achievement.
