# Glimpse Changelog

## [Recording Mode, Replacements, and Windows] - 2026-09-20

- Start, pause, resume, bookmark, and finish Glimpse recordings from Raycast.
- Recording Status shows a timer in the menu bar while you record.
- Browse Library marks recordings and shows how many tracks they have.
- New Manage Replacements command.
- Clearer messages when Glimpse or the CLI is missing, or a license is required.
- Windows support. Recording Status stays macOS only, since Raycast has no menu bar on Windows.
- Recording commands ask you to update when Glimpse is older than 1.2.0.
- Library exports work with names that contain characters like ":".
- Switch Speech Model sends downloads to the Models page in Glimpse.
