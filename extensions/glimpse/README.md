# Glimpse for Raycast

Use [Glimpse](https://tryglimpse.cc) dictation from Raycast.

Glimpse has a free tier; commands that write or edit data need a license. Install the CLI once from Glimpse → Settings → About → Install CLI. The Microsoft Store version of Glimpse on Windows includes it. Optionally set the binary path in the extension preferences if it isn’t at `~/.local/bin/glimpse` (`glimpse.cmd` on Windows).

## Commands

- **Search Transcriptions**: search and copy past dictations.
- **Copy Last Dictation**: copy your latest dictation.
- **Paste Last Dictation**: paste your latest dictation.
- **Transcribe File**: transcribe an audio or video file.
- **Transcribe Selected File**: transcribe the file selected in Finder or File Explorer.
- **Browse Library**: browse and export Library transcripts.
- **Switch Speech Model**: choose your speech model.
- **Add Dictionary Word**: add a word to your dictionary.
- **Manage Dictionary**: add and remove dictionary words.
- **Manage Replacements**: add, edit, and remove text replacements.
- **Start Recording**: start a recording with your last sources.
- **Pause or Resume Recording**: pause or resume the current recording.
- **Add Recording Bookmark**: bookmark this moment in the current recording.
- **Finish Recording**: save the current recording to your Library, optionally with a name.
- **Recording Status**: show the recording timer in the menu bar while you record (macOS only).
- **Local API**: run a local transcription API.
