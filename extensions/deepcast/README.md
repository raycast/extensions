# Deepcast

Translate words, sentences, and entire documents into 30 different languages using DeepL.

## Features

- **Text Translation**: Translate selected text or clipboard content
- **Document Translation**: Translate complete documents while preserving formatting
  - Supported formats: DOCX, PDF, PPTX, XLSX, HTML, TXT, SRT, and more
  - Option to convert PDFs to editable DOCX format
  - **Finder Integration**: Automatically pre-selects documents when invoked with files selected in Finder
  - **Flexible Download Locations**: Choose where to save translated documents
- **Multiple Languages**: Support for 30+ languages
- **Formality Control**: Choose formal or informal tone for supported languages
- **Flexible Input**: Use selected text or clipboard content

## How to Use Document Translation

1. **Method 1 - Finder Integration (Recommended)**:
   - Select a document in Finder (supported formats: DOCX, PDF, PPTX, XLSX, TXT, HTML, SRT, etc.)
   - Open Raycast and search for "Translate Document"
   - The selected file will be automatically pre-selected
   - Choose target language, download location, and options, then translate

2. **Method 2 - Manual Selection**:
   - Open Raycast and search for "Translate Document"  
   - Click "Browse" to select your document
   - Choose target language, download location, and options, then translate

## Download Location Options

The extension offers flexible download locations for your translated documents:

- **Same folder as original** (default): Saves translated document next to the original file
- **Downloads folder**: Saves to your system's Downloads directory
- **Documents folder**: Saves to your Documents directory  
- **Desktop**: Saves to your Desktop
- **Custom folder**: Choose any directory on your system

You can set a default download location in the extension preferences, and optionally override it for individual translations.

## Supported File Formats

The following file formats are supported for document translation:
- Microsoft Word (DOCX, DOC)
- PDF files
- PowerPoint (PPTX)
- Excel (XLSX)
- HTML files
- Plain text (TXT)
- Subtitle files (SRT)
- Translation files (XLF, XLIFF)
