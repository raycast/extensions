# Deepcast

Translate words or whole sentences into 30 languages with [DeepL](https://www.deepl.com), from anywhere on your Mac.

## Commands

- **Translate**: Translate selected or typed text into your default language.
- **Translate into {language}**: One command per language, so you can give the ones you use their own hotkeys. Covers Arabic, Bulgarian, Chinese, Czech, Danish, Dutch, English (UK and US), Estonian, Finnish, French, German, Greek, Hungarian, Indonesian, Italian, Japanese, Korean, Latvian, Lithuanian, Norwegian, Polish, Portuguese (and Brazil), Romanian, Russian, Slovak, Slovenian, Spanish, Swedish, Thai, Turkish and Ukrainian.

## Setup

Deepcast needs a DeepL API key. The free plan works.

1. Sign up at [deepl.com/pro#developer](https://www.deepl.com/pro#developer).
2. Open your [account summary](https://www.deepl.com/pro-account/summary) and copy your API key.
3. Paste it into the extension's preferences, and choose a default target language.

## Tips

- Set **On Translation Action** to **Paste in Frontmost App**, select text in any app and press the hotkey for a **Translate into** command. The translation is pasted in place, without switching apps.
