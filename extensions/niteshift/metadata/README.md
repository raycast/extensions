# Store screenshots

This folder is required by the Raycast Store. When submitting the extension to
the public Store, drop **3-6 screenshots** here, named:

- `niteshift-1.png`
- `niteshift-2.png`
- ... up to `niteshift-6.png`

Each screenshot must be **2000 × 1250 pixels (16:10)**. Use Raycast's built-in
**Window Capture** tool with the extension running (`npm run dev`) to capture
exactly the right size.

Suggested screenshots for the v1 submission (only two top-level commands —
all other features are reachable via the action menu (`⌘K`) inside List Tasks):

1. `List Tasks` with several real tasks visible — clean status icon + title +
   right-anchored timestamp
2. `List Tasks` with the action menu (`⌘K`) open on a task, showing
   **Watch Stream**, **Send Follow-up Prompt**, **Copy Pickup Command**, etc.
3. `Watch Stream` Detail view (push target from List Tasks) streaming a
   running task — you can see the metadata panel on the right with
   "Status: running" and "Stream: Live"
4. `Send Follow-up Prompt` form (push target from List Tasks) with some text
   typed in
5. `Run Task` form with the prompt argument prefilled and a repo selected

This folder is empty in the repo until the screenshots are taken — the file
you're reading is just a placeholder so the directory exists.
