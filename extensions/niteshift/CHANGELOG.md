# Niteshift for Raycast — Changelog

## [Initial Version] - 2026-04-08

- Run Task: form with prompt argument prefill, repo + model dropdowns, branch override
- List Tasks: searchable list across repos with detail panel and repo filter
- Watch Task: live SSE message streaming with state polling
- Send Prompt: follow-up prompt form
- Pick Up Task: discovery surface that copies `niteshift pickup <id>` to clipboard
- AuthGate that reads the CLI's `~/.config/niteshift/cli-auth.json`
- Environment preference (prod/staging/dev)
