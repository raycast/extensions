# Expo Orbit

Launch simulators and emulators, and open EAS builds, updates, and Snacks on any device, from Raycast.

## Setup

Install [Expo Orbit](https://expo.dev/orbit) with `brew install --cask expo-orbit`. Orbit doesn't need to be running. To install builds from private EAS projects, sign in to Expo in Orbit.

## Manage Devices

Your simulators, emulators, and physical devices in one list. Pin the ones you use most to keep them on top, and hide the rest without deleting them. Press `⌘K` for all actions.

## Launch Build or Update

Paste a link or pick a file, then choose a device. It accepts EAS Build links and `.apk`, `.app`, `.ipa`, or `.tar.gz` files, EAS Update links, Snack links, and `expo-orbit://` links. If a build needs re-signing for an iPhone, use **Open in Expo Orbit**.

## Pair Android Device

Connect an Android device over Wi-Fi with a pairing code or a QR code, found in **Developer options → Wireless debugging** on the device.

## Preferences

The extension uses the same settings as Expo Orbit. Trusted sources you add here are also added to Orbit's list.

## Raycast AI

Ask `@expo-orbit` to list, launch, or stop devices, or to open a build, for example "@expo-orbit boot my iPhone simulator". Raycast asks before changing anything. Requires [Raycast Pro](https://www.raycast.com/pro).
