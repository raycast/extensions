# Shodan Raycast Extension

A comprehensive Raycast extension that provides powerful network intelligence and security analysis using Shodan's platform. This extension offers 7 distinct commands to help security professionals, network administrators, and researchers analyze network infrastructure, monitor security threats, and gather intelligence about internet-connected devices.

## 🎯 **Key Features**

### 🔍 **Search Host** - Deep IP Analysis
- Look up detailed information about any IP address or hostname
- View comprehensive host data including organization, location, and system information
- Access port information, services, and security vulnerabilities
- Search history with persistent storage for quick re-access
- Interactive port exploration with service details and banners

### 🌐 **Search Shodan** - Advanced Network Discovery
- Advanced search with filters and criteria
- Browse search results with detailed metadata
- Filter by country, organization, port, and more
- Support for complex search queries and filters
- Real-time search result analysis

### 📊 **Shodan Stats** - Data Analytics
- Get statistics about search results
- View country and organization breakdowns
- Analyze trends and patterns in network data
- Visual breakdowns of search result distributions

### 🏠 **My IP** - Personal Security Assessment
- Instantly look up your external IP address in Shodan
- See what information is publicly available about your network
- Quick security assessment of your public-facing services
- Multiple fallback services for reliable IP detection

### 📈 **API Info** - Account Management
- View your Shodan API usage and account information
- Monitor query credits, scan credits, and monitored IPs
- Track your API consumption and limits
- Real-time account status monitoring

### 🔬 **On-Demand Scan** - Active Network Scanning
- Request new scans of specific IPs and services
- 15+ predefined scan categories (Web Services, Database, IoT, etc.)
- Monitor scan progress and results in real-time
- Recent scans history with status tracking
- Support for custom protocol combinations

### 👁️ **Monitored IPs** - Security Monitoring
- View your monitored IP alerts and notifications
- Track changes to specific IP addresses
- Stay informed about network security events
- Quick access to alert management

## 🔧 **Installation & Setup**

1. **Get Shodan API Key**: Visit [account.shodan.io](https://account.shodan.io/) to get your free API key
2. **Install Extension**: Search for "Shodan" in Raycast Store
3. **Configure API Key**: Enter your API key in extension preferences
4. **Start Exploring**: Use any of the 7 commands to begin network analysis
