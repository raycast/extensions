# Publora

Create, schedule and manage social media posts for X, Bluesky, Mastodon, LinkedIn and other networks through [Publora](https://publora.com), without leaving Raycast.

## Setup

Create a Publora account at [app.publora.com](https://app.publora.com) and connect your social accounts. The first time you run a command, Raycast asks you to sign in to Publora.

If you prefer an API key, open **API** in the Publora sidebar, create a key and paste it into the "Publora API Key" field in the extension settings.

## Commands

- **Schedule Post**: write a post, pick the accounts and a time. Leave the time empty to save a draft. Publora splits long posts on X and Threads into a thread.
- **Manage Posts**: browse your posts by status, edit drafts and scheduled posts, and delete posts.
