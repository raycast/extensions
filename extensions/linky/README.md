# Linky for Raycast

Companion extension for [Linky](https://github.com/AlbrechtSuerer/linky), a free menu bar app that copies lasting links to files and folders. Paste a link into your notes, tasks or docs, click it, and the file opens.

**Requires the Linky app (1.3 or later).** The extension asks Linky to create and open links, so links keep working when files are moved or renamed.

## Commands

- **Copy Linky Link**: copies a link to the files or folders selected in Finder, in the format you chose in Linky.
- **Search Linky Links**: search every link you made. Copy it again, open the file, show it in Finder, or relink missing files in Linky.
