# Dictionnaire CNRTL

Accédez au **Centre National de Ressources Textuelles et Lexicales** (CNRTL) directement depuis Raycast — sans quitter le clavier.

Le CNRTL héberge le **Trésor de la Langue Française informatisé (TLFi)**, la référence académique du français : 100 000 mots, définitions complètes, étymologies, exemples littéraires.

---

## Commandes

| Commande | Description |
|---|---|
| **Définition** | Définitions du TLFi : catégorie grammaticale, sections numérotées, exemples |
| **Synonymes** | Synonymes avec degré de proximité (●●● très proche → ●○○ lié) |
| **Antonymes** | Contraires et antonymes avec le même système de degrés |
| **Étymologie** | Origine historique : période, langue source, évolution |
| **Morphologie** | Formes fléchies et conjuguées complètes |

---

## Utilisation

1. Ouvrez Raycast et lancez l'une des commandes (`Définition`, `Synonymes`…).
2. Tapez un mot français — les résultats apparaissent en temps réel.
3. Sélectionnez un résultat pour le copier ou l'ouvrir sur le CNRTL.

### Raccourcis clavier

| Action | Raccourci |
|---|---|
| Ouvrir sur le CNRTL | `⌘ O` |
| Copier le contenu | `⌘ C` |
| Copier le mot seul | `⌘ ⇧ C` |
| Préférences | `⌘ ⇧ ,` |

---

## Préférences

- **Taille de l'historique** — Nombre de mots mémorisés (défaut : 50 ; 0 pour désactiver).
- **Ouvrir dans le navigateur** — Ouvrir automatiquement la page CNRTL à la validation.

---

## À propos du CNRTL

Le CNRTL est un portail du CNRS (laboratoire ATILF, Université de Lorraine) qui donne accès gratuitement au TLFi et à d'autres ressources linguistiques de référence. Cette extension utilise uniquement les pages publiques du site.
