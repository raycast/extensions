# Changelog

## [1.0.1] - 2026-11-04

- Currently Running shows the Amp wordmark in the menu bar, green while agents work.
- Thread rows no longer show the thread ID subtitle.

First release.

- New Thread and Start Thread start agents in orbs, with project, mode, title, orb size, and Fast.
- Search Threads with Amp's query syntax, quick and per-project filters, and live working state. Thread actions: send a message, read the transcript, copy URL, mention, or continue command, rename, archive.
- Thread Activity and Currently Running menu bar commands.
- Ask Puck chat and Call Puck.
- Search Projects and Open Portal.
