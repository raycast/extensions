Text Scramble is a more human alternative to Lorem Ipsum for decks and design drafts.

It replaces selected copy with pronounceable invented language while preserving exact whitespace, punctuation, line breaks, word lengths, casing, and a close visual measure. Repeated words remain consistent within a selection, and numerals are anonymized by default.

Everything runs locally. There are no AI calls, analytics, network requests, or stored text.

Highlights:

- Replace selected text directly or copy the result as plain text
- Selected-text and clipboard source priority
- Shape-scored, non-semantic invented words
- Exact structural preservation with close estimated line width
- Optional numeral preservation
- MIT-licensed source, automated tests, and CI
