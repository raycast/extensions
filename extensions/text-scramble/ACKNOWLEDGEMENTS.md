# Acknowledgements

## Change Case

Text Scramble's selected-text and clipboard fallback, plus its paste-or-copy interaction model, was inspired by Eric (`erics118`) and the contributors to Raycast's open-source [Change Case](https://www.raycast.com/erics118/change-case) extension.

No Change Case source code is bundled or copied here. The interaction pattern was studied from the MIT-licensed [Raycast extensions repository](https://github.com/raycast/extensions/tree/main/extensions/change-case) and then implemented for Text Scramble's distinct purpose.
