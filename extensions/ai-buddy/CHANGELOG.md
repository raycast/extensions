# AI Buddy Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Buddy Translate: English ⇄ your language (12 languages); dictionary card for words (IPA, usage, examples, read aloud); vocabulary panel with IPA for sentences
- Buddy Draft Reply: replies in the message's language (or always in English), revised with ideas you type in your own language
- Buddy Polish English: correct, natural English with grammar lessons in your language; Quick Replace swaps the selected draft in place
- Continue with… (⌘B): translate → reply, translate → polish, reply or polish → translate, without reselecting
- AI Setup: pick the provider (with logos), paste the key and see right away whether it works, then pick the model
- AI Buddy: run any buddy on typed text, connection status, model per buddy (⌘M), editable prompts (⌘E)
- Providers: Raycast AI (with Raycast Pro, no key), Google Gemini, OpenAI, Claude, Groq, OpenRouter, or any OpenAI-compatible server (own proxy, local LLM)
- With nothing selected, the input form starts with the clipboard text
