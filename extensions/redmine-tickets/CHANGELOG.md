# Redmine Tickets Changelog

## [Open Issues, AI Extension, issue editing, project filter] - {PR_MERGE_DATE}

- Added an **Open Issues** command listing all currently open issues, sorted by most recently updated first.
- Renamed the assigned-issues command to **Assigned to Me** (now scoped to your open issues).
- Added a **Created by Me** command, scoped to the open issues you created.
- Added an **AI Extension** (read-only) with a `Search Issues` tool: full-text search across open/closed issues and structured filtering by status, assignee, or creator.
- Added an **issue detail view** (⏎ on an issue) showing description, metadata and comments, with keyboard actions to **add a comment**, **change status**, **change assignee** and **change priority**.
- Added a **project filter** dropdown in the search bar of both list commands (remembers your last choice).
- List items now show the assignee and priority as accessories.
