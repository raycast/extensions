# Bible Q&A

Ask a biblical question in [Raycast](https://www.raycast.com). Unlike a general AI, [Gamaliel](https://gamaliel.ai) finds the most relevant Bible passages, reads them, and then answers—so the response is grounded in Scripture, not a model’s memory of the text.

Each answer includes scripture links. Open one to read that passage on gamaliel.ai.

Set a **theology** and a **profile** so the answer matches your tradition and your biblical familiarity—from first questions to long study.

Gamaliel is free. No account, no ads.

## Use

1. Run **Bible Q&A**, type a question, and press Return.
2. Click a scripture link to open that passage.
3. Use **Ask Another Question** to follow up (up to 20 questions), or **New Conversation** to start over.

## Preferences

**Raycast Settings → Extensions → Bible Q&A**

| Preference | Default | What it changes |
| --- | --- | --- |
| Theology | General Christian | The tradition that shapes how the answer is framed |
| Profile | Universal Explorer | Your biblical familiarity and maturity |
| Bible Translation | English NIV | The translation used for scripture. The search bar picker is grouped by language. |
| Max Words | 300 | How long the answer can be |

The [prompts and guidelines](https://github.com/gamaliel-ai/gamaliel-prompts) are open source.

To build or change this extension, see [DEVELOPMENT.md](DEVELOPMENT.md).
