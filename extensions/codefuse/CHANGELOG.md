# Codefuse Changelog

## [1.0.0] - 2025-10-27

### Added
- Search Recent Projects command that surfaces Codefuse’s recent folders/workspaces/files (via `state.vscdb`) with filtering and inline actions.
- Integrated direct launching via the `codefuse` CLI with automatic binary discovery and helpful errors when missing.
- Raycast command now exposes Finder reveal, copy path, and manual refresh actions for each entry.
- Extension icon updated to use the official Codefuse app artwork for consistent branding.
