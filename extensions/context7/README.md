# Context7 Search

Search the Context7 documentation library to find if your favorite libraries have been indexed.

## Features

- **Search Libraries**: Search through the Context7 documentation index to find libraries and frameworks
- **Detailed Information**: View comprehensive metadata including stars, trust score, snippets, pages, and tokens
- **Quick Actions**: Open documentation in browser or copy library IDs to clipboard
- **Real-time Search**: Search results update as you type with intelligent throttling

## Setup

1. Get your Context7 API key from [Context7](https://context7.com)
2. Open the extension in Raycast
3. Enter your API key when prompted in the preferences

## Usage

Simply type to search for any library or framework. Results will show:
- Library title and description
- Last update time (human-readable)
- Stars and trust score
- Total snippets, pages, and tokens available
- Branch and state information

Use `⌘ + Enter` to open the documentation in your browser or `⌘ + C` to copy the library ID.
