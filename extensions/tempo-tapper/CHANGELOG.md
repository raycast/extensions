# Changelog

## [Initial Release] - {PR_MERGE_DATE}

- Calculate tempo (BPM) by tapping
- Rolling average mode (configurable window: 2, 4, 8, or 16 beats)
- Cumulative average mode
- Display half time and double time BPM
- Display milliseconds per beat
- Display musical tempo marking (Largo, Andante, Allegro, etc.)
- Tap stability indicator
- Toggle decimal precision
- Copy BPM to clipboard
- Auto-reset after 3 seconds of inactivity
- Configurable default mode and rolling window size
