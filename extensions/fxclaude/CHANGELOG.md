# Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Manage isolated Claude desktop accounts as fxclaude workspaces, adapted from the fxcodex extension.
- Create, open, select, erase, and delete workspaces, and set Raycast or custom image icons.
- Inspect status and diagnostics, even when the CLI is unavailable.
- Discover, install, select, replace, and remove fxclaude executables without bundling the CLI. Install verified GitHub releases for the current user, in extension support, in a custom directory, or with Homebrew.
- Add **Open Link in Workspace** to deliver a `claude://` link to one workspace's Claude, with the link from the command argument or the clipboard. The command is disabled by default; enable it in Raycast Settings when needed.
- Add **Open Link…** to each workspace's action panel.
- Omit workspace renaming, app renaming, and automatic-update controls.
