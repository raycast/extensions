# Docker

Manage your Docker containers, images and Compose projects without opening Docker Desktop or typing `docker ps`.

## Commands

- **Manage Containers**: List all containers. Start, stop or restart them, and see their details.
- **Manage Compose Projects**: See your Docker Compose projects and manage them.
- **Manage Images**: List installed images.

## Setup

Docker needs to be running. If your Docker socket isn't at the default location (for example with Colima or OrbStack), set **Socket path** in the extension's preferences.
