# Teamwork Changelog

## [Initial Release] - {PR_MERGE_DATE}

- Search tasks assigned to you with active/completed filter
- Recent tasks list for quick re-access
- Start, pause, resume, and stop/log timers from any task
- Menu bar timer display with live updates (10-second refresh)
- Running timer shown in menu bar title with pause, stop and log, and open task actions
- Paused timers listed in menu bar as submenus with resume, stop and log, and open task actions
- Standalone **Pause Active Timer** command for keyboard-only workflow
- **Resume Timer** command shows a list of all paused timers to choose from
- **Stop and Log Timer** command shows all timers (running and paused) to choose from
- Automatic resume of paused timers when starting a task that already has one
