# Configure Luxafor

1. Connect your device and run the Luxafor companion app.
2. Enable **Webhook** mode and copy the User ID from that tab.
3. Paste it into **Luxafor User ID**. Keep this identifier private.
4. Use **api.luxafor.com**, the documented endpoint.

Opening the extension does not change the light. Choose a color deliberately after setup. API acceptance does not confirm physical device state.
