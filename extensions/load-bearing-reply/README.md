# Load-Bearing Reply

Paste a confidently over-engineered reply into the frontmost app.

Use **Paste Random Load-Bearing Reply** for the quickest possible joke, or **Browse Load-Bearing Replies** to choose a phrase. The browse command pastes with Enter and copies with `⌘ C`.

The extension uses a local phrase library only. It does not read message content, call an AI model, or send messages.

## Development

```sh
npm run dev
```

Run `npm run build` before publishing.
