# Emoticon Search

Search thousands of dongers, Lenny faces and other text emoticons, then paste or copy them. ( ͡° ͜ʖ ͡°)

It works like Emoji Search, but for faces made out of text.

## Features

- 3,000+ emoticons in 42 categories, like Dongers, Lenny Faces, Table Flip, Shrug and Cats
- Search by name or category, or paste part of a face like `( ͡` to find all its cousins
- Pick a category from the dropdown
- Pin your favorites with `⌘ .`
- A Frequently Used row that learns what you use the most
- Zoom in and out with `⌘ +`, `⌘ -` and `⌘ 0`
