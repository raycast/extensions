### Set Up Your API Key

1. Sign in to your Spinal workspace at [app.spinalcms.com](https://app.spinalcms.com).
2. Open **Settings → API** and create an API key. This requires a plan with API access.
3. Copy the key into the **API Key** preference, then continue.

Raycast stores the key on your Mac. It sends the key only to the Spinal API, and only when it reads or creates resources for you.
