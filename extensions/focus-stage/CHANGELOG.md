# Focus Stage Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Toggle Focus Stage: centers the focused window, covers everything else with a plain backdrop on all displays, hides the menu bar, and restores everything when toggled again
- Glow around the focused window, "Focus Stage on" label and optional background grain
- Covers the focused app's other windows and follows focus between them
- Optional notification hold until the session ends
- Hides the menu bar and, by default, the Dock during a session
- Reset Focus Stage: ends any session and restores windows, menu bar, Dock and notifications
- Menu bar command showing whether a stage is on
