# Magic Eraser

Copy text that still has Notion-style `[ ]` checkboxes, bullets, or numbers, then run **Magic Eraser**. It strips those list markers and leaves bold, italics, links, and spacing alone.

## How to use

1. Copy the text.
2. Open Raycast and run **Magic Eraser**.
3. Paste. Rich apps (Gmail, Docs) get formatted HTML; Slack and Notion get cleaned markdown.
