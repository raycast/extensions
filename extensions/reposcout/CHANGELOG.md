# RepoScout Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Instantly find and open the Git repositories in the folders you choose
- Fast tiered fuzzy search (exact › prefix › acronym › fuzzy) over a cached index
- Pick search folders inside the extension with a native folder picker; searches
  only your chosen folders, never your whole Mac
- Incremental background indexing — only changed repositories are re-read
- At-a-glance metadata: current branch, dirty/clean status, and last-commit age
- Open in VS Code, Cursor, Finder, or Terminal; copy the path or Git remote; open
  the remote on the web
- Favorites, pins, and recents that shape ranking over time
- Detects normal, worktree, and bare repositories
