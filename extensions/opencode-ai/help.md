## OpenCode API Key

1. Go to [opencode.ai/auth](https://opencode.ai/auth) and sign in.
2. Create an API key and add billing.
3. Paste it here.

## Default Model

The model preselected in the `Ask OpenCode AI` model picker, e.g. `go/gpt-6-luna` (Go) or `claude-sonnet-5` (Zen). Go models use the `go/` prefix. You can switch to any Zen or Go model from the dropdown when asking.
