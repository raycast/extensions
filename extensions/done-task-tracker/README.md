# Done Task Tracker

A simple extension to track completed tasks and boost your productivity.

## Features

- **Log Done Tasks**: Quickly log tasks you've just completed with a simple form
- **View Tasks by Day**: Browse all your completed tasks organized by date
- **Export to Google Sheets**: Copy tasks in tab-separated format ready for spreadsheet import
- **Task Management**: Delete tasks and manage your completion history
- **Character Limits**: Smart validation to keep task descriptions concise

## Usage

### Log Done Task

Use the "Log Done Task" command to quickly record a task you've just completed. The extension will automatically timestamp it for the current day.

### View Done Tasks

Use the "View Done Tasks" command to browse your completed tasks organized by day. You can:

- View tasks for any specific day
- Copy individual tasks or entire days to clipboard
- Export data in Google Sheets format
- Delete tasks you no longer need

## Data Storage

All task data is stored locally using Raycast's LocalStorage API. Your data stays private and is never sent to external servers.
