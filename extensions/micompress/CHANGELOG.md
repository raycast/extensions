# MiCompress Changelog

## [Initial Version] - {PR_MERGE_DATE}

- **Compress File** command: pick one or more files, choose a preset, and get optimized `-min` copies.
- Supports image, PDF, video, audio, document and archive formats via micompress.com.
- Optional **API Key** preference (personal key from micompress.com/account) for files up to 100 MB.
