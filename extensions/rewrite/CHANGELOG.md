# Rewrite Changelog

## [Initial Release] - {PR_MERGE_DATE}

- Run custom AI actions on any selected text directly from any app — no copy-paste needed
- Replace selected text inline or view the result in a Raycast Detail view before using it
- Run one-off prompts on the fly from the search bar without saving an action
- Create, edit, and delete custom actions with a title, icon, prompt, and default mode
- Reorder actions with `Cmd+Shift+Up/Down`, edit with `Cmd+E`, delete with `Cmd+Delete`
- Set a default mode (replace inline or show result) per action
- Configure AI provider and model in-app — supports RaycastAI, OpenAI, Anthropic, Gemini, and OpenRouter
- API keys stored locally per provider
- Model error toast links directly to the Configure AI Model command
- Windows platform support via Raycast cross-platform APIs
