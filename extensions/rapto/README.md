# Rapto

Switch to any open window on any desktop from Raycast, powered by [Rapto](https://rapto.app), the free window manager for macOS.

## Requirements

- [Rapto](https://rapto.app) 5.60 or later, running
- macOS 26 or later

The first time you use the command, macOS asks whether Raycast may control Rapto. Allow it. You can change this later in System Settings → Privacy & Security → Automation.

## Commands

- **Switch Window**: lists every open window on every desktop, most recently used first. Type part of the app name or window title, then press Enter. Rapto jumps straight to that window, switching desktops without the slide animation.

Tip: give the command its own hotkey or alias in Raycast settings to open the list directly.

## Privacy

The extension talks only to Rapto on your Mac. Nothing is sent over the internet.
