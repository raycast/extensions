# svg.new for Raycast

Convert raster images (PNG, JPG, WebP) to clean SVG vectors using [svg.new](https://svg.new) — AI-powered vector tracing.

## Commands

- **Convert Image to SVG** — Select an image in Finder, run the command, get an SVG saved next to the original
- **Convert Clipboard Image to SVG** — Convert an image from your clipboard to SVG, saved to Downloads

## Setup

1. Get an API key at [svg.new/account](https://svg.new/account)
2. Install the extension
3. Enter your API key in preferences

## Features

- Full-color AI vector tracing
- Supports PNG, JPG, WebP, AVIF
- SVG saved alongside original file
- Clipboard image support
