- Switch between built-in speakers, DisplayPort, and virtual outputs

- Set volume level when activating scenes
- Set input device (microphone) per scene
- Launch apps when activating scenes
- Copy hotkey links for scene shortcuts via Quicklinks
- Auto-remember output mappings for Bluetooth devices
- Lazy dependency checking (blueutil only required for Bluetooth)
