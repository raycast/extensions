# STE Translator Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Convert selected text, clipboard text, or typed text to Simplified Technical English
- Content types: email, chat message, technical document, SOP/runbook, incident report
- Modes: standard rewrite, minimal changes, strict technical review
- Protects code, URLs, IP addresses, IDs, file paths, configuration keys, and numbers with units
- Checks the result against ASD-STE100-style structural rules and shows review warnings
- Raycast AI by default, with an optional OpenAI-compatible provider
