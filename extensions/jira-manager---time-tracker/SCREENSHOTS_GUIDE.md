## Screenshot Best Practices

### General Guidelines:
1. **Resolution**: Use Raycast's default window size
2. **Theme**: Use dark theme (matches Raycast aesthetic)
3. **Data**: Use realistic but sanitized data (no real company info)
4. **Focus**: Each screenshot should highlight ONE main feature
5. **Quality**: High-resolution, clear text, no blur

### Example Issue Keys to Use:
- PROJ-123, PROJ-456, PROJ-789
- TEAM-101, TEAM-202
- BUG-42, FEAT-99

### Example Summaries:
- "Implement user authentication system"
- "Fix login page responsive design"
- "Update API documentation"
- "Refactor database queries for performance"
- "Add dark mode support"

### Example Worklogs:
- 08:00 - "Initial investigation" (1h)
- 10:30 - "Implementation work" (2h 30m)
- 14:00 - "Code review and testing" (1h 15m)
- 16:00 - "Documentation updates" (45m)

## Notes
- Raycast Store typically shows 3-5 screenshots in the listing
- First screenshot is the most important (will be featured)
- Show the extension's unique features (smart switching, timeline view)
- Avoid showing error states or empty states
- Make sure all text is readable at thumbnail size
