# Contributing to Pods Control

Thanks for helping out. The extension's directory holds only what ships to the Raycast Store. The tests, architecture notes, and full guide live in the [development repository](https://github.com/raulgg/raycast-extension-pods-control), so start with its [CONTRIBUTING.md](https://github.com/raulgg/raycast-extension-pods-control/blob/main/CONTRIBUTING.md).

Please [open an issue](https://github.com/raulgg/raycast-extension-pods-control/issues) before building a new feature or changing behavior. Small bug fixes do not need one.

## Submit a change

Please submit your changes to the development repository if you can. The Store repository contains only the source code and metadata that ships to the Store, so a pull request there would not update the corresponding tests or docs living in the development repository to ensure the extension's quality.

- **In the development repository (recommended).** You can change or add tests along with the code, and the quality checks, including tests, run on your pull request.
- **In the Store repository.** Follow Raycast's [Contribute to an Extension](https://developers.raycast.com/basics/contribute-to-an-extension) guide.
