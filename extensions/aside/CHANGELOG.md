# Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Added tab search across normal and incognito Aside windows.
- Added native actions to focus, reload, close, and copy tab URLs.
- Added URL and search-query opening with configurable search engines.
- Added new tab, normal window, and incognito window commands.
- Added bookmark search using Aside's supported scripting dictionary.
- Added clear loading, empty, stale-tab, installation, and Automation-permission states.
- Added composable Raycast AI tools for tabs, windows, bookmarks, and clipboard actions.
- Added one explicit confirmation before AI-requested batch tab closing.
- Revalidate AI-requested tab IDs and show current titles and URLs before destructive confirmation.
- Added bounded AI results, clear AI privacy guidance, and a non-blocking Aside compatibility notice.
- Removed the CLI-backed Ask Aside tool to avoid subprocess hangs and keep AI actions deterministic.
