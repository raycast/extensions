# Aside Changelog

## [Initial Version] - 2026-08-19

- Added search, focus, duplicate, close, and deduplication workflows for open Aside tabs.
- Added bookmark search with nested folders, frecency ranking, and profile selection.
- Added unified Google search, URL opening, open tabs, and browsing history.
- Added a dedicated command for searching Aside browser history with profile selection.
- Added commands for opening a new tab, window, and incognito window in Aside.
- Added Raycast AI tools for bounded browser-state reads and exact tab actions, with destructive confirmations and eval coverage.
