# Rexcast Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Session Activity menu bar item: server status, one submenu per session with its state (working, needs your input, finished, failed or idle), what it is doing, tabs and panes, and an optional notification (off by default) when a session needs you, finishes or fails
- Peek at Session: see the screen of any session without opening Rex
- Open Finder Folder in Rex: create a session in the selected folder
- Send Text to Session: type text or the clipboard into a session without focusing Rex
- Manage Sessions, New Session, Run Command and Open Rex
