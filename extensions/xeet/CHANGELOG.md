# Xeet Changelog

## [Initial Version] - 2026-11-16

- Create local post previews with author images, verification badges, engagement counts, and weighted character counts.
- Render public X post URLs, text, or structured Post JSON and copy or save PNGs.
- Compare themes, surfaces, widths, resolution, and expanded text, and export theme and width contact sheets.
- Save and reopen local drafts, or render directly from the clipboard.
- Render previews offline without an X account.
- Create, inspect, compare, save, and export previews with eight Raycast AI tools.
- Use all five commands on Windows with native keyboard shortcuts and File Explorer actions.
