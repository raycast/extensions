# Changelog

## 1.0.0 — Initial Release

Jira time tracking extension for Raycast. Browse assigned tasks, start/stop timers, log worklogs directly to Jira via REST API.

- Browse active Jira issues with real-time status
- Quick-start timer from issue key in clipboard
- Stop timer with adjustable duration before logging
- Menu bar widget showing running timer (1m poll interval)
- Basic auth via Jira API token
