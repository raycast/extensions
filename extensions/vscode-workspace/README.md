# VS Code Workspace

Search and open recent projects from VS Code and compatible editors, even when they're not running. Works offline using cached data.

## Features

- **Offline Search**: Find recent projects even when VS Code is not running
- **Multiple Editor Support**: Works with Visual Studio Code, Cursor, Windsurf, VSCodium, and more
- **Smart Filtering**: Filter by project type (folders, workspaces, remote)
- **Quick Actions**: Open in editor, copy path, reveal in finder

## Supported Editors

- Visual Studio Code
- Visual Studio Code - Insiders
- Cursor
- Windsurf
- VSCodium
- VSCodium - Insiders
- Antigravity
- Kiro
- Positron
- Trae
- Trae CN
- Lingma

## Requirements

- One of the supported editors installed
- Windows or macOS

## Usage

1. Run the command "Search Workspace" in Raycast
2. Search for your recent projects
3. Select a project to open it in your chosen editor

## Configuration

Select your preferred editor in the extension preferences. The extension will automatically detect recent projects from your editor's history.
