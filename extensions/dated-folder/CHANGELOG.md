# Dated Folder Changelog

## [Windows Support] - {PR_MERGE_DATE}

- Available on Windows: follows the Default Terminal Application setting, opening the folder in Windows Terminal or a PowerShell console
- A terminal chosen in the preferences is launched with the new folder as its working directory
- The Reveal preference opens File Explorer on Windows

## [Initial Version] - 2026-09-09

- Create a folder named after today's date and open it in a terminal
- Preferences for parent folder, terminal app, folder name format, and revealing in Finder
- Follows the system default terminal when no app is chosen
