# OpenTask Changelog

## [Added OpenTask] - {PR_MERGE_DATE}

Initial version.

- My Tasks command with Today (incl. overdue), Upcoming, Inbox, and Completed views
- Search Tasks command with server-side full-text search across tasks and comments
- Create Task form with natural-language due dates, priority, project, section, labels, and deadline
- Quick Add Task command using OpenTask's smart input syntax
- Show Projects and Show Labels commands for browsing tasks
- Menu Bar Tasks command showing today's task count with complete/postpone actions
- Task actions: complete, edit, schedule, change priority, move to project, delete, open in OpenTask
