# Better JSON Inspector Icon

Final asset: [`assets/better-json-icon.png`](../assets/better-json-icon.png).

The icon was generated using the built-in image generation tool and downscaled with macOS `sips` to a 512×512 PNG while retaining its alpha channel. It uses a charcoal/teal tile, pale mint JSON braces, and an ivory data node, with transparent outside margins.

Raycast's [extension icon requirements](https://developers.raycast.com/basics/prepare-an-extension-for-store#extension-icon) specify a 512×512 PNG, readability on both light and dark themes, and an original icon rather than the default Raycast icon.

## Generation prompt

Use case: logo-brand. Asset type: replacement production icon for the Better JSON Inspector Raycast extension, not a presentation or mockup. Create ONE square app icon. Subject: a bold, beautifully balanced pair of curly JSON braces { } framing one small central diamond/data node. Crisp geometric mark, broad strokes, very simple silhouette that remains legible at 24 pixels. A polished deep charcoal rounded-square tile with subtle teal-to-emerald color depth; luminous pale mint braces, tiny warm ivory center node. Restrained premium developer-tool aesthetic, gentle edge highlights, flat front view, precise symmetry, no perspective, no ornamental detail, no words, no letters, no watermark, no Raycast logo. Fill about 84% of the square canvas with the rounded-square tile and keep the outside margin genuinely transparent (alpha), not a checkerboard pattern. Interior mark has generous breathing room. Strong visual contrast on both light and dark launcher backgrounds. Deliver a PNG icon at exactly 512 by 512 pixels if supported. Only the icon itself.
