# DPI Converter

Convert pixels to centimeters, millimeters, and inches, and vice versa! Useful for printers.

## Features

- Convert single or dual dimensions
- Support for pixels (px), centimeters (cm), millimeters (mm), inches (in)
- Customizable DPI resolution (default: 300)
- Detailed calculation display
- Quick copy actions with keyboard shortcuts

## Usage

1. Enter your dimension(s) with unit (e.g., 512px, 10cm)
2. Optionally add a second dimension for width × height
3. Set DPI, if different from 300
4. Convert
