# Token Terminal Search

Search Token Terminal projects and chains directly from Raycast. Copy project logos and details with a simple keyboard shortcut.

## Features

- Search through all Token Terminal projects and chains
- Filter by name, symbol, tags, or market sectors
- Copy logo URLs to clipboard (primary action)
- View project details including chains, tags, and market sectors
- Quick access to project symbols and names

## Setup

1. Install dependencies:

   ```bash
   cd token-terminal-search
   npm install
   ```

2. Configure your API token:
   - The extension will prompt you for your Token Terminal API token on first use
   - You can also set it in Raycast preferences

3. Run in development mode:
   ```bash
   npm run dev
   ```

## Usage

1. Open Raycast
2. Search for "Search Projects"
3. Start typing to filter projects
4. Press Enter to copy the logo URL

## API Token

You need a Token Terminal API token to use this extension. Set it in the extension preferences when prompted.
