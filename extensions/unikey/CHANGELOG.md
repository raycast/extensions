# UniKey Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Local-first, AES-256-GCM encrypted password vault stored at `~/.unikey/vault.enc`
- Type `unikey` from root search to open and instantly unlock via macOS Keychain
- Fuzzy search across slug, username, group, URL, and metadata; field prefixes `pass:` / `group:` / `meta:` / `user:`
- Copy & Paste on Enter into the previously focused app; ⌘C to copy only; optional clipboard auto-clear
- Create / copy / edit / delete password entries
- Group management with rename and delete
