# Blume Search

Search the projects, conversations, messages, setup artifacts, and suggestions indexed by Blume,
then open any result in the desktop app.

## Requirements

- Install Blume 1.0.66 or later.
- Open Blume once so it can discover your local projects and conversations.

## Choose a Blume Installation

The extension searches the stable Blume installation by default. To search Blume Canary instead,
open the extension preferences and select it under **Blume Application**.

## Privacy

Search stays on your Mac. The extension uses the local search helper bundled with Blume and reads
Blume's SQLite index in read-only mode. Search terms and results are not sent to an external service.
