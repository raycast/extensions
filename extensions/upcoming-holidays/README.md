# Upcoming Holidays

Show upcoming holidays for a country, with pinned countries and a selectable date range.

Holiday dates and countdowns use local calendar days, so Canadian Remembrance Day appears on November 11 and shows “in 2 days” on November 9.

To run locally:

```sh
cd extensions/upcoming-holidays
npm ci
npm run dev
```

Run the date regression tests with Node.js 24 or later using `npm test`.
