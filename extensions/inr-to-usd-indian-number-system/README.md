# INR to USD

Raycast extension to convert INR to USD with Indian number system support.

**Input:** `15.22 lac crore`, `50 lakh`, `3 crore`, etc.

Handles common typos like `lkah`, `coreo`, `thousandsa`.

## Install

```
git clone https://github.com/Mohit0233/inr-to-usd-raycast-extension.git
cd inr-to-usd-raycast-extension
bun install && bun run build
```

Then open Raycast and search "INR to USD".
