# PostOnce

Publish and schedule posts to LinkedIn, X, Threads, Bluesky, Facebook Pages, Instagram, TikTok, YouTube, Pinterest and more with [PostOnce](https://postonce.to), without leaving Raycast.

## Setup

1. Create a PostOnce account at [postonce.to](https://postonce.to) and connect your social accounts.
2. In the PostOnce dashboard, open **Preferences → API keys** and create a key.
3. Paste the key into the "API Key" field the first time you run a command.

## Commands

- **Create Post**: write a post, pick the accounts, optionally add a public image or video URL and a time. Leave the time empty to publish now.
- **Search Posts**: browse your posts by status, open them in PostOnce or on each network, and cancel scheduled posts.
- **Connected Accounts**: see which accounts are connected and which need to be reconnected.
