# IT Tools Native (Raycast Extension)

Native Raycast tools inspired by common IT toolbox workflows.

## Included Commands

- `Tools` (single entry command)
  - Open a tool hub list
  - Select and open:
    - Date Time
    - JSON Stringify Decode
    - Hash Text

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
