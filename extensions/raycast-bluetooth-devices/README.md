# Bluetooth Devices for Raycast

[![Latest release](https://img.shields.io/github/v/tag/athNdev/raycast-bluetooth-devices?sort=semver&label=version&style=flat-square&color=0070F3)](https://github.com/athNdev/raycast-bluetooth-devices/releases/latest)
[![License: MIT](https://img.shields.io/badge/license-MIT-green?style=flat-square)](LICENSE)

Manage Windows Bluetooth devices directly from [Raycast](https://raycast.com). Connect, disconnect, pair, remove, and toggle your adapter — including a real-time scan that matches what Windows Settings sees.

---

## Features

| Command | Description |
|---|---|
| **Manage Bluetooth Devices** | Sectioned list of paired devices. Connect, disconnect, or remove any device. Shows MAC address, device kind, and audio output status. |
| **Toggle Bluetooth** | Instantly flip the adapter on or off. Displays a HUD confirmation. |
| **Scan for Bluetooth Devices** | Active radio scan. Discover and pair nearby devices. |

### Audio Output Integration

Connected devices show a speaker badge indicating their audio status:
- `🔊 Green` — Current default audio output.
- `🔊 Grey` — Audio endpoint matched but not the default.
- *(no badge)* — No audio endpoint found.

Use **Set as Audio Output** (`⌘A`) to switch the default without opening Sound Settings.

## 🚀 Installation & Development

### 1. Requirements for Development
To work on this extension locally, you need:
- [Node.js](https://nodejs.org/) (v20+)
- [.NET 8 SDK](https://dotnet.microsoft.com/en-us/download) to compile the C# CLI.

### 2. Run Locally

```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/YOUR_REPO_NAME.git
cd YOUR_REPO_NAME

# Install dependencies
npm install

# Compile the C# CLI and start the Raycast HOT-reload watcher
npm run dev
```

### 3. Other Commands

```bash
npm run build        # production build
npm run lint         # ESLint + Prettier check
npm run fix-lint     # auto-fix

# Rebuild the CLI binary only:
dotnet publish WinBluetoothCli.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o ./assets/cli
```

## 📂 Architecture

The project consists of a single root acting as both the **Node.js** Raycast extension and a **.NET 8** C# application.

```text
repository-root/          Raycast extension (TypeScript) + C# .NET 8 app
│
├── package.json          Raycast manifest & build scripts
├── Program.cs            WinRT + Win32 Bluetooth APIs
├── WinBluetoothCli.csproj
│
├── src/                  Raycast Extension UI
│   ├── bluetooth.ts      
│   ├── manage-devices.tsx
│   ├── toggle-bluetooth.tsx
│   └── scan-devices.tsx  
│
└── assets/cli/           Ignored in Git, generated by build.
    └── WinBluetoothCli.exe
```

## 📦 Automated Versioning (Release Please)

This repository uses **[Google's Release Please](https://github.com/googleapis/release-please)** to automatically manage semantic versioning, create release PRs, and generate the `CHANGELOG.md`.

⚠️ **CRITICAL:** For the automated versioning to work, your PRs and commit messages **MUST** adhere to the [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/) specification! 

If you commit messages like `fixed bug` or `updated stuff`, Release Please **will log "unable to parse commit"** and no automatic release will be triggered!

### Correct Commit Formats:
- `feat: add device battery level` (Triggers a `MINOR` release, e.g. 1.0.0 -> 1.1.0)
- `fix: airpods reconnect loop` (Triggers a `PATCH` release, e.g. 1.0.0 -> 1.0.1)
- `feat!: drop windows 10 support` (Exclamation mark triggers a `MAJOR` release, e.g. 1.0.0 -> 2.0.0)

### GitHub Actions Secrets
To publish to the Raycast store upon release, add the following secret to your repository (**Settings → Secrets → Actions**):
- `RAYCAST_API_TOKEN` (Get this from [raycast.com/settings](https://www.raycast.com/settings) -> API)
