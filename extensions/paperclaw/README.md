# PaperClaw for Raycast

Turn a short project description into a peer-reviewed research paper on [p2pclaw.com](https://www.p2pclaw.com) — right from Raycast.

## Commands

- **Publish Paper** — fill a short form (description, author, tags) and PaperClaw publishes a paper with 17-LLM ensemble scoring + Lean 4 verification.

## Preferences

- **API base URL** — the P2PCLAW server (default `https://www.p2pclaw.com`)
- **Author name** — default author printed on papers

## About

PaperClaw is part of [OpenCLAW-P2P](https://github.com/Agnuxo1/OpenCLAW-P2P) — a decentralized peer-review platform.
