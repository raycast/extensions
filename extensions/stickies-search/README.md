# Stickies Search

An extension to help you manage your macOS Stickies workflow. It allows you to search through your Stickies notes by their content and quickly jump to them. Additionally, it offers a quick command to instantly create and format a small Sticky on your current desktop, perfect for using as a desktop layout indicator.

## Permissions

Commands use AppleScript to read Stickies data, control the Stickies app, and (for **Create Sticky**) query Finder for screen bounds. macOS may ask you to allow **Automation** for Raycast (Stickies, System Events, and Finder). Enable access under **System Settings → Privacy & Security → Automation** if a command fails with a permission error.
