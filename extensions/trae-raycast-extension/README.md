# Trae Recent Projects

Search and open your recent Trae projects directly from Raycast.

## Features

- **Search Recent Projects**: Lists projects from your Trae history.
- **Open in Trae**: Open any selected project immediately.
- **Open New Window**: Launch a new empty Trae window.
- **Copy Path**: Copy the file path of any project to your clipboard.

## Requirements

- [Trae](https://www.trae.ai/) must be installed.
- You must have opened at least one project in Trae.

## Troubleshooting

If no projects are found:
1. Ensure Trae is installed.
2. Verify you have opened projects in Trae recently.
3. Check if the database file exists at `~/Library/Application Support/Trae/User/globalStorage/state.vscdb`.
