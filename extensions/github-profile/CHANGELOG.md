# GitHub Profile Changelog

## [Improve Dashboard and Loading Reliability] - 2026-11-14

- The contribution heatmap now appears first with light and dark appearances, recent totals, and streak statistics.
- Profile details now use a compact layout, and repository previews include descriptions and activity statistics.
- A searchable repository browser now provides clone links and shortcuts to issues and pull requests.
- Each profile section now loads independently, preserves cached data during refresh, and reports request failures after a 15-second timeout.
- Missing authentication and contribution failures now show recovery instructions instead of fabricated or zero-contribution data.
- OSS Insight charts now have consistent display widths and open through the **Show Public Activity Charts** action.
- The command now offers **Refresh Profile** and **Open Extension Preferences** actions, along with shortcuts to starred repositories and authored issues and pull requests.
