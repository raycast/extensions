# Segue

Control [Segue](https://segue.pylondev.com) directly from Raycast. Focus on what matters, dim the rest.

## Requirements

- [Segue](https://segue.pylondev.com) must be installed on your Mac
- macOS 14.0+

## Commands

| Command | Description |
|---------|-------------|
| Toggle Segue | Turn overlay on/off |
| Enable Segue | Turn overlay on |
| Disable Segue | Turn overlay off |
| Deep Mode | Full coverage overlay for maximum focus |
| Ambient Mode | Subtle gradient from edges |
| Static Shader | Simple gradient effect |
| Dynamic Shader | Animated meshy effect |
| Set Blur Low | 20% blur intensity |
| Set Blur Medium | 50% blur intensity |
| Set Blur High | 80% blur intensity |
| Exclude Current App | Add focused app to ignore list |
| Include Current App | Remove app from ignore list |
| Open Settings | Access Segue preferences |

## About Segue

Segue creates a beautiful overlay behind your focused window, helping you concentrate on what matters. Whether you're writing, coding, or reading — Segue keeps distractions at bay with customizable blur, tint, and animation effects.

Get Segue at [segue.pylondev.com](https://segue.pylondev.com)
