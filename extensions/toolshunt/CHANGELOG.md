- Initial release with 20+ utility tools

### Tools Included
- **Text Formatting**: Time format conversion, JSON formatting, Cookie formatting, JavaScript formatting
- **Encoding/Decoding**: Base64, URL encoding/decoding, Base64 image processing
- **Comparison Tools**: JSON comparison, Text comparison, CURL comparison
- **Generators**: UUID/ULID generation, QR code generation, Hash generation, Favicon generation, Domain generation
- **Converters**: CURL to Python requests, JSON to SQL conversion
- **AI Tools**: ID photo generation, Photo enhancement, Food calorie annotation
- **Other**: HTML renderer for code preview
