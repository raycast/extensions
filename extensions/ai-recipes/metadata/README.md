# Metadata Screenshots

This folder should contain screenshots of your extension in action.

## Required Screenshots

According to Raycast extension guidelines, you need to add at least one screenshot showing:

1. **Browse Recipes view** - showing the main recipe list interface
2. **Create Recipe view** - showing the recipe creation form
3. **Use Recipe view** - showing a recipe being used with input/output

## Screenshot Format

- Recommended size: 1280x800 pixels or higher
- Format: PNG or JPEG
- Name: Descriptive names like `browse-recipes.png`, `create-recipe.png`, `use-recipe.png`

## How to Capture

1. Run the extension in Raycast
2. Use Command+Shift+4 on macOS to capture specific areas
3. Save screenshots to this folder
4. Update the extension's Store metadata with screenshot references

## Example File Structure

```
metadata/
├── README.md (this file)
├── ai-recipes-1.png
├── ai-recipes-2.png
└── ai-recipes-3.png
```

Please add your screenshots here before submitting to the Raycast store.
