# AI Recipes Changelog

## [Initial Version] - 2026-1-11

### Added

- Browse and manage reusable AI recipes with custom prompts
- Create, edit, duplicate, and delete recipes
- Tag system for organizing recipes by category
- Usage history tracking with prompt version control
- Three main commands:
  - Browse Recipes: View and use your saved recipes
  - Create Recipe: Build new AI recipes with custom prompts
  - Manage Tags: Organize recipes with tags
- Support for multiple AI models
- Adjustable creativity levels for AI responses
- Input/output type customization for recipes
