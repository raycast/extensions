# Changelog

## [Initial Version] - 2024-11-29

- Initial release of EXR Converter
- Added support for EXR, JPG, PNG, TIFF, and TX (Arnold) formats
- Added multiple compression options for each format
- Added image resizing functionality with multiple modes
- Added batch processing from Finder selection
- Added automatic OpenImageIO detection and setup instructions
- Added output location options (same folder, custom folder, replace original)
