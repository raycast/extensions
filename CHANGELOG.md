# Zhigeng Capture Changelog

## [Initial Release] - {PR_MERGE_DATE}

- Quick capture of notes and todos into an Obsidian vault as raw Markdown drafts
- Atomic, non-overwriting writes with stable capture IDs and content fingerprints
- Local draft persistence with receipt-based duplicate submission protection
- Support for todo scheduling date, due date, and priority
- Legacy meeting draft migration (restored as notes with preserved event dates)
- Single `vaultPath` preference; no external CLI, Python, or API dependencies
