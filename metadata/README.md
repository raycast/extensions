# Metadata for Raycast Store

This directory contains screenshots and other metadata for the Raycast Store listing.

## Screenshots

Add at least one screenshot showing your extension in action. Raycast recommends:

- **Format**: PNG or JPG
- **Size**: At least 1280x800px recommended
- **Content**: Show the extension's UI and key features
- **Naming**: Use descriptive names like `brightness-control-main.png`

## Tips for Great Screenshots

1. **Show the extension in use** - Capture the actual UI with realistic data
2. **Highlight key features** - Show the display selection, current brightness, and the HUD notification
3. **Use high resolution** - Retina screenshots look best
4. **Keep it clean** - Remove personal information or distracting elements

## How to Capture Screenshots

1. Open Raycast and run your extension
2. Use macOS built-in screenshot tool (Cmd+Shift+4)
3. Save screenshots to this directory
4. Run `npm run publish` when ready to submit
