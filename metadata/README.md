# Screenshots Required

The Cookery extension requires screenshots for the view command to pass Raycast store review.

## Required Screenshots

Place the following screenshots in this folder:

1. `generate-recipes-1.png` - Main form view showing recipe input fields
2. `generate-recipes-2.png` - Generated recipe result view
3. `generate-recipes-3.png` - Configuration view (if API key not set)

## Screenshot Guidelines

- Dimensions: 1280x800 pixels (recommended)
- Format: PNG
- Show the extension in action with realistic content
- Ensure text is readable
- Use light theme for consistency

## How to Create Screenshots

1. Open Raycast
2. Run the Cookery extension
3. Take screenshots using Cmd+Shift+4
4. Save to this folder with the names above
5. Update package.json if you add more screenshots
