# RG AdGuard Links — Microsoft Store URL Converter

## Summary

This extension converts Microsoft Store URLs to direct download links via rg-adguard.net, allowing users to download Microsoft Store apps without using the Microsoft Store itself.

## What This Extension Does

- Converts Microsoft Store URLs or Product IDs to downloadable .appx/.msix files
- Makes POST requests to rg-adguard.net API
- Displays all available downloads with file sizes and metadata
- Shows app information including name, version, and product ID
- Supports multiple architectures (x64, x86, ARM64)

## Technical Implementation

### API Integration
```typescript
POST https://store.rg-adguard.net/api/GetFiles
Content-Type: application/x-www-form-urlencoded

type=ProductId&url={productId}&ring=Retail&lang=en-US
```

### Features
1. **Product ID Extraction** - Parses various Microsoft Store URL formats
2. **HTML Response Parsing** - Extracts download links and metadata from HTML
3. **File Size Display** - Shows formatted file sizes (KB, MB, GB)
4. **Architecture Detection** - Identifies x64, x86, ARM64 packages
5. **App Metadata** - Displays app name, version, and product ID

### Supported URL Formats
- `https://www.microsoft.com/store/productId/9XXXXXXXXXXXXX`
- `https://apps.microsoft.com/detail/9XXXXXXXXXXXXX`
- `https://apps.microsoft.com/store/detail/9XXXXXXXXXXXXX`
- Product ID only: `9XXXXXXXXXXXXX`
