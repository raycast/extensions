# Sugar levels

See your sugar levels from Nightscout in your menu bar.

## How to use

1. Open the Raycast extensions menu
2. Click on the `Sugar levels` extension
3. Enter your Nightscout API URL (https://HOSTNAME/api/v1/entries.json)
4. Optionally select the units you want to use (mg/dL or mmol/L) (mg/DL is default)
5. Click on `Save`
