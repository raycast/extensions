# 📹 Screencast Recording Guide

## What to Record (30-60 seconds)

### **Quick Demo Script:**

1. **Open Raycast** (Cmd + Space)
   - Type "Add Website to Block"
   - Enter: `youtube.com`
   - Show success message

2. **Open a Browser**
   - Navigate to YouTube.com
   - Show it loading normally

3. **Enable Blocking**
   - Open Raycast
   - Type "Enable Website Blocking"
   - Authenticate with Touch ID
   - Show the browser tab closing

4. **Try to Access**
   - Try to open YouTube.com again
   - Show it's blocked (won't load)

5. **Disable Blocking**
   - Open Raycast
   - Type "Disable Website Blocking"
   - Show YouTube loads again

## Recording Tools:

- **macOS Built-in:** Cmd + Shift + 5 (screenshot toolbar)
- **QuickTime Player:** File > New Screen Recording
- **Recommended:** Use Raycast's own screen recording (Cmd + Shift + R)

## Tips:

- Keep it under 60 seconds
- Show the actual blocking working (tab closing)
- Use a popular site like YouTube or Facebook
- Keep cursor movements smooth
- No audio needed
- Export as MP4 or GIF

Upload to:
