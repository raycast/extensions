## 🔧 If Icons Still Don't Show

### Option 1: Restart Mac
Sometimes macOS needs a full restart to clear icon caches:
```bash
sudo shutdown -r now
```

### Option 2: Reimport Extension
1. Open Raycast Preferences
2. Go to Extensions
3. Remove WebBlocker completely
4. Close Raycast
5. Reopen Raycast
6. Re-import extension from this folder

### Option 3: Check Icon Format
Verify icons are valid PNG files:
```bash
file icon.png add-website-icon.png
```
