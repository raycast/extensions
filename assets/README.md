# Assets

## Icon

For development, this extension uses an emoji icon (☀️).

For Raycast Store submission, you'll need to add a proper 512x512 PNG icon:
- Name it `icon.png` and place it in this folder
- Design should work well in both light and dark modes
- Use a sun/brightness-related design
- Update `package.json` to reference `"icon": "icon.png"`

You can create an icon using:
- Design tools like Figma, Sketch, or Affinity Designer
- AI image generators
- Icon creation services
