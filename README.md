# String Formatter - Raycast插件

一个用于格式化字符串的Raycast插件，支持自定义分隔符和修饰符。

## 功能特性

- 🔤 **字符串输入**：支持多行字符串输入
- ⚙️ **自定义分隔符**：支持逗号、分号、空格、竖线、制表符、换行符等
- 🎨 **修饰符选择**：支持单引号、双引号、反引号、方括号、圆括号、花括号
- 👀 **实时预览**：输入内容后立即显示格式化结果
- 📋 **一键复制**：快速复制格式化结果到剪贴板
- ⚠️ **错误处理**：友好的错误提示和异常处理

## 使用示例

**输入**：`a,b,c`
**分隔符**：逗号 (,)
**修饰符**：单引号 (')
**输出**：`'a','b','c'`

## 快捷键

- `Cmd + C`：复制格式化结果
- `Cmd + R`：重置表单

## 安装

1. 确保已安装 [Raycast](https://raycast.com/)
2. 在项目目录运行：`npm install`
3. 开发模式：`npm run dev`
4. 构建：`npm run build`
