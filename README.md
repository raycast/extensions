# Pollinations AI

Chat with powerful AI models powered by [Pollinations.ai](https://pollinations.ai) — free, no account required.

## Features

- **Chat with AI** — Streaming chat interface with conversation history
- **Quick Ask** — One-shot questions with instant answers
- **Fix Grammar** — Correct grammar and spelling in any language
- **Translate** — Translate text into 29 languages

## Setup

No setup required. The extension works out of the box using the free tier.

**Optional:** Add a Pollinations API key in extension preferences (`⌘ ,`) to unlock premium models (GPT-5, Gemini, Claude, DeepSeek and more).

Get a key at [auth.pollinations.ai](https://auth.pollinations.ai).

## Commands

| Command | Description |
|---|---|
| Chat with AI | Full streaming chat with model switching and history |
| Quick Ask | Ask a one-shot question, get a Markdown-formatted answer |
| Fix Grammar | Paste any text — returns corrected version in the same language |
| Translate | Translate text into any of 29 supported languages |

## Models

The free tier includes fast models like `openai` (GPT-5.4 Nano). With an API key you get access to the full model list including vision, reasoning, and search-enabled models.
