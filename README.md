# Smart OCR for Raycast

Capture a screenshot, recognize text instantly, and copy it to your clipboard with **smart paragraph formatting**.

## ✨ Features

- **📸 Instant OCR**: High-accuracy English recognition using the native macOS Vision framework.
- **🧠 Smart Formatting**: 
  - Automatically merges split lines into proper paragraphs.
  - Preserves titles and distinct blocks of text.
  - Formats bullet points (`•`, `-`) and numbered lists (`1.`) into clean Markdown.
- **🇨🇳 One-Key Translation**: Press `Cmd + Shift + C` to translate the result to Chinese.
- **🔒 Privacy First**: OCR is performed locally on your Mac.

## 🚀 Usage

1. Run the **Capture OCR** command.
2. Select an area on your screen.
3. The extension will automatically:
   - Recognize the text.
   - Fix the formatting (merge lines, preserve paragraphs).
   - Copy the result to your clipboard.

## 🛠 Requirements

- macOS Ventura or later.
